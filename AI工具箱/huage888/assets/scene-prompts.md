| 字段 | 内容 |

### LibTV 场景生成消息

**场景简介**：
断桥雨中（古风）：室外/暴雨雷天/烟雨朦胧压抑古典

**场景描述**：
```
西湖断桥，暴雨倾盆的白天（但乌云使整体光线昏暗如同傍晚）。

空间结构：
- 主体：西湖断桥（石拱桥），白色石栏杆，青石板桥面
- 环境：桥两侧西湖水面（因暴雨激起涟漪），远处烟雾朦胧可见对岸树影
- 前景/中景：桥墩旁有青苔和小型石雕，地面有积水和溅落的水花
- 天气效果：**暴雨**——密集可见的雨丝（从上向下快速落下的雨滴），远处乌云密布

光线设置（符合 VB 光影基准表"夜景室外-暴雨"）：
- 主光源：顶部，雨幕漫反射的冷白色光（整体照度均匀偏暗）
- 色调：灰蓝色调（cold grey-blue palette）
- 高光点缀：白色元素（云头绣鞋/白裙）形成高光对比
- 远处：乌云边缘有微弱蓝光透射
- 强度：整体中低强度，压抑昏暗

氛围关键词：
- 烟雨朦胧（远景雾气感）
- 压抑（整体低亮度）
- 古典（青石/白栏/中式桥型）
- 仙气（白衣女子出场时白光点点）
- 暴雨真实感（雨丝/积水/溅水）

视角：俯拍/全景建立 → 桥墩旁细节（中景）
参考：国风古风电影中雨景，青绿山水画派的雨雾意境，真实感强
```

**参考图需求**：
- 全景图（断桥全貌+西湖+雨幕）× 1（必须）
- 中景图（桥墩附近，积水泥地）× 1（必须，展示许仙所在位置）
- 特写细节图（雨丝+水花溅落）× 1（如需要）

### 文字锚点（分镜提示词兜底）

```
**文字锚点**：
- 核心场景词：1. 西湖断桥石拱 2. 暴雨倾盆 3. 烟雨朦胧
- 光源描述：顶部冷白雨幕漫反射，远处乌云蓝光透射
- 色调：灰蓝主调，白色点缀高光
- 禁止词：阳光/暖黄色光/晴朗/干燥地面
```

| 核心陈设 | 牛油果树（大叶革质），阳光穿透树冠的光柱效果 |
| 特效 | 光斑，树冠边缘光晕，阳光光柱 |

### LibTV 场景生成消息

**场景简介**：
异域果园（热带）：室外/正午阳光/阳光充沛温暖生机

**场景描述**：
```
热带或亚热带牛油果园，正午时分，阳光充沛。

空间结构：
- 主体：牛油果树（多棵可见），树冠大而圆润，革质深绿色叶片（叶片大，约15-30cm，椭圆形，深绿色有光泽）
- 光线：阳光穿透树冠，形成明显的光柱和斑驳光影（树冠光斑），地面有斑驳光点
- 背景：天空明亮（可见部分蓝天），远方可见更多果树排布
- 地面：自然土壤，落叶或碎石，自然真实感

光线设置（符合 VB 光影基准表"热带果园，正午"）：
- 主光源：**顶部太阳直射**（direct overhead sunlight）
- 色温：**暖黄色**（warm golden yellow）
- 强度：**高强度**（bright，高光明显）
- 光影效果：
  - 树冠边缘：金色边缘光（golden rim lighting）
  - 树冠下方：斑驳光斑（dappled light）落在地面上
  - 果实：阳光照在牛油果表皮形成自然光泽
  - 整体：温暖明亮，空气中有光尘感（atmosphere haze with light）

氛围关键词：
- 阳光充沛（warm sunlight, abundant）
- 热带风情（tropical feel）
- 自然生机（natural vitality）
- 温暖（warm）
- 品质感（premium, natural）
- 真实（不需过度后期的自然感）

视角：中景（展示果树全貌）→ 特写（树上牛油果）
参考：自然纪录片热带果园镜头，产品广告级自然光，阳光金色光质感
```

**参考图需求**：
- 全景图（多棵牛油果树，阳光充足）× 1（必须）
- 牛油果挂果特写（树上，阳光照射表皮）× 1（必须）
- 光斑地面细节图 × 1（如需要）

### 文字锚点（分镜提示词兜底）

```
**文字锚点**：
- 核心场景词：1. 牛油果树大叶深绿 2. 阳光穿透树冠 3. 暖金黄光线
- 光源描述：顶部太阳直射，暖黄高强度，树冠斑驳光影
- 色调：暖金黄主调，深绿树叶，深紫黑果点缀
- 禁止词：雨/阴天/冷色调/蓝色滤镜/乌云/室内
```
