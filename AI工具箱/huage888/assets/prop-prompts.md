## 银色勺子 | P002 | 等级：一级

### 基本信息

| 字段 | 内容 |
|------|------|
| 外观描述 | 纯银色，精致，约10cm长，弧形，柄端云纹雕花，整体光泽柔和不刺眼 |
| 叙事功能 | 象征白娘子给许仙的"元气补充"，替代破伞的转折道具，代表从困境到满足的转变 |
| 出现段落 | 第4段末尾（镜头14，白娘子施法变出）、第5段（镜头16，许仙使用）|
| 出现次数 | 2次 |
| 是否需要特写 | 是（镜头14施法出现特写，镜头16许仙使用特写）|
| 状态变化 | 出现（完好无损，银色光泽）→ 使用中（许仙用勺挖取牛油果）|
| 资产状态 | 新建（需独立出资产，在 LibTV 单独注册）|
| Visual Bible 对照 | ✅ 符合 VB P002 锚点 |

### 外观详细描述

```
材质：纯银（或银色金属，高级质感，非镜面反光而是柔和光泽）
形状：
- 整体：约10cm长，勺部弧形优雅
- 勺部：椭圆形，深度适中（约2cm深），用于挖取软质食物（牛油果）
- 柄部：细长，末端收尖，柄表面有简洁云纹雕花（古典中式纹样）
光泽：柔和不刺眼（matte silver finish），有手工感，无工业抛光镜面感
整体风格：古典雅致，与白娘子的"仙气"气质匹配，非现代极简主义
```

### LibTV 道具主体创建消息

**一句话主体简介**：
银色古典勺子：纯银，约10cm，弧形，柄端云纹，柔和光泽

**主体描述**：
```
精致银色古典小勺。

材质：纯银质感（或高品质银色金属），表面处理为柔和哑光（柔和银色光泽，非镜面反光）。
形状：总长约10cm，勺部椭圆形弧形，深度约2cm（适合挖取软质食物），柄部细长末端收尖。

装饰：柄末端有简洁云纹雕花（古典中式纹样，云朵卷草图案，线条流畅不繁复），雕花深度浅，触感平滑。

整体质感：手工感，有温度，非工业量产品质感，有古典雅致气质。
整体风格：古典中式雅致风格，与白衣仙气女子气质匹配。
光泽：柔和不刺眼，有轻微做旧感，无全新工业品的光亮刺眼感。

使用状态参考（可选）：沾有少量嫩黄色果肉（牛油果）时的特写，有生活感但不脏。

禁止出现的变体：金色/铜色/玫瑰金色/现代极简无装饰/镜面抛光刺眼反光/塑料质感
```

**参考图需求**：
- 单独银勺正面图 × 1（必须，主锚点，展示整体形状和云纹）
- 银勺侧面图 × 1（必须，展示弧形深度）
- 银勺特写（云纹细节）× 1（必须，展示雕花细节）
- 银勺使用状态（沾有牛油果）× 1（如需要）

### 文字锚点（分镜提示词兜底）

```
**文字锚点**：
- 核心外观词：1. 纯银色柔和光泽 2. 约10cm弧形 3. 柄端云纹雕花
- 标志性细节：云纹雕花，哑光柔和质感（非镜面反光）
- 禁止词：金色/铜色/塑料/镜面反光刺眼/现代简约无装饰
```
