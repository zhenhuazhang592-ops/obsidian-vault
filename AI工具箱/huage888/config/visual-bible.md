## 整体风格

### 美术风格

**本剧混合风格**（两种模式切换）：

**模式A：古风烟雨（场景：断桥）**
- 参考风格：国风古风，青绿山水 × 写实古风人物
- 关键词：烟雨朦胧、水墨意境、古建筑、青石板路
- 色调：冷调灰蓝 + 白衣白伞点缀

**模式B：异域果园（场景：产品揭秘转场）**
- 参考风格：自然纪录片质感 + 广告级产品摄影
- 关键词：阳光充沛、热带果园、绿色植物、露珠光斑
- 色调：暖金黄 + 深紫黑牛油果色 + 自然绿

## 漠玫传 · IP 说话风格锚点（第7层）

> 来源：漠玫品牌 IP 设计文档
> 适用：漠玫传所有剧集，跨集统一

### 漠玫 | C001 | 品牌形象代言人 | 信息禅者

| 字段 | 内容 |
|------|------|
| **口癖/口头禅** | 施主、也罢、何必执着、虚妄、因缘 |
| **语气词** | 轻笑、淡然、微叹、平静 |
| **句长偏好** | ≤15字/句，诗意留白，不说满 |
| **情绪温度** | 冷（克制），内敛，静水深流 |
| **禁止词汇** | 现代网络语、感叹号连用、超过20字的句子、咆哮语气 |
| **语气标签** | 古典冷艳 + 诗意留白 + 信息禅意 |
| **说话节奏** | 每句留白，不急于表达，停顿感强 |

**台词示例：**
```
漠玫：施主，何必执着。
漠玫：（轻笑）虚妄二字，你还未参透。
漠玫：也罢。既是因缘，便随它去。
漠玫：（淡然）胜负，在你心，不在金箍。
```

### 大圣（狼狈相）| C002a | 三变体之一
