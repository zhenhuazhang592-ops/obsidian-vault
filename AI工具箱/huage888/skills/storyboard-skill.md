# skills/storyboard-skill.md — 分镜脚本规范

> huage888 系统 | 分镜师 Agent 使用
> 输出：outputs/02-storyboard-script.md（LibTV 脚本节点格式）
> 版本：v2.0（新增资产一致性强制规则 + 结构化 JSON Schema）

---

## 一、核心职责

将导演讲戏本转化为**分镜脚本**，格式与 LibTV 脚本节点完全兼容，可直接粘贴到 LibTV 画布。

**不做的事**：不写生视频 prompt，不调 LibTV Skill。
**做的事**：写出结构完整的分镜脚本表格，制片人据此在 LibTV 执行批量生成。

---

## 二、资产一致性强制规则（必须遵守）

> 参考 Toonflow getAssets 工具规则，以下为硬性约束，违反 = 审核 FAIL

```
⚠️ 资产使用强制规则：
1. 必须原封不动地使用 assets/03-asset-registry.md 中的资产编号和名称
   - 角色：只能写 C001、C002、C002a、C002b 等，不可用近义词、缩写、变体
   - 场景：只能写 S001、S002 等，不可用场景描述替代编号
   - 道具：只能写 P001、P002 等，不可用描述性词汇替代
2. 禁止在资产名称前后添加修饰词（如「优雅的C001」「破碎的P001」）
3. 禁止捏造资产注册表中不存在的角色、场景、道具
4. 分镜脚本表格「主体引用」列只能填 C001/C002...，「场景引用」列只能填 S001/S002...
5. 镜头详解中出现道具/场景时，须在括号中标注对应编号（如「银色勺子（P002）」）
```

## 三、分镜脚本格式

### 3.1 台词写作要求

> **必须严格遵守 Visual Bible 中的「角色说话风格锚点」（第7层身份锚点）**

写台词时对照每个角色的锚点字段：
- 口癖/口头禅是否出现
- 句长是否符合「句长偏好」
- 情绪温度是否匹配当前场景的情绪
- 禁止词汇是否出现

口癖是角色记忆点，**必须出现**但不要过度（每角色每集出现 1-2 次为宜）。

### 3.2 镜头数量规范

| 剧集时长 | 镜头数参考 | 每镜头平均时长 |
|---------|-----------|--------------|
| 约 30s | 12-18 个 | 2-3s |
| 约 45s | 18-25 个 | 2-3s |
| 约 60s | 25-35 个 | 2-3s |

> 竖屏短剧节奏快，单镜头不宜超过 5s（观众注意力窗口）

### 3.3 分镜脚本 Markdown 模板

```markdown
# outputs/02-storyboard-script.md — 分镜脚本

> 项目：[剧名] | 集数：S01E01 | 总时长：约 [X] 分钟
> 生成时间：[日期]
> Visual Bible 版本：v[X.X]
```

### 4.2 输出格式要求

```
分镜师最终输出：
1. 分镜脚本表格（Markdown 格式，可读性优先）
2. 末尾附上等效 JSON（格式校验用）

qwen-max 行为：
- 表格中字段缺失 → 补全或标注「待制片人填写」
- dialogue 字段默认空数组（无需对话的镜头）
- libtvPrompt 栏：每个镜头提供 1-2 句简化的画面描述词
- visualBibleCheck 栏：✅=完全符合 / ⚠️=轻微偏差（制片人确认）/ ❌=严重违规（打回）
```

## 五、自查清单（输出前必查）

```
[ ] 资产编号与 assets/03-asset-registry.md 完全一致（无近义词/变体）
[ ] 色调描述与 visual-bible.md 整体风格一致
[ ] 光影描述与 visual-bible.md 光影基准表一致
[ ] 台词符合角色说话风格锚点（第7层）
[ ] 口癖出现但不过度（每角色 1-2 次）
[ ] 镜头描述为叙事语言，无模型指令词
[ ] 所有道具首次出现时有编号标注（如「银色勺子（P002）」）
[ ] 段落情绪与讲戏本 keyEvents 对应
[ ] 总时长在合理范围内（±5s 误差）
[ ] 资产引用表包含所有出场角色/场景/道具
[ ] LibTV 生成提示（libtvPrompt）简洁可操作
[ ] visualBibleCheck 无 ❌ 项
```

## 七、运镜 Prompt 库（Doubao API 视频生成专用）

> 分镜脚本中的运镜方式 → Doubao Seedance 视频 Prompt 映射
> 每个运镜方式给出：中文说明 + Doubao Prompt 写法 + 示例

| 运镜方式 | Doubao Prompt 写法 | 示例 |
|---------|-------------------|------|
| **固定** | 镜头固定，[主体]在画面中[动作/表情]，[环境描述] | 镜头固定，漠玫在竹林中央静静睁眼，数据粒子在周围飘浮 |
| **推镜头** | 镜头缓缓推向[主体/面部]，[主体]的[动作/表情变化]，[情绪]感增强 | 镜头缓缓推向漠玫面部特写，金色瞳孔中数据流加速闪烁，营造神秘氛围 |
| **拉镜头** | 镜头缓缓拉远，[主体]从[特写/近景]逐渐展开为[中景/全景]，[情绪]释放 | 镜头缓缓拉远，漠玫身影在赛博竹林中逐渐变小，竹林全景展开 |
| **横移** | 镜头从左至右平移，[主体]在画面中[方向移动]，[场景]逐渐展现 | 镜头从左至右平移，大圣在竹林中持棒横步，竹竿电路逐一入画 |
| **摇镜头** | 镜头围绕[主体]轻微摇动，[主体]保持[动作/表情]，[动感]画面 | 镜头轻微摇动，漠玫缓缓抬手，指尖青蓝色光芒随摇动产生光迹效果 |
| **升降** | 镜头从低处升起（或高处降下），[主体]逐渐进入画面，[场景/氛围]展开 | 镜头从地面升起，漠玫从竹林深处缓步走来，数据粒子随镜头升起而飞舞 |
| **跟拍** | 镜头跟随[主体]移动，[主体]在[场景]中[动作]，视角同步，[动线] | 镜头跟随大圣横移，大圣持棒走向漠玫，竹林背景随跟拍产生速度感 |
| **甩镜头** | 镜头快速甩至[目标主体/场景]，[动感转场]，[原主体]逐渐虚化 | 镜头快速甩至漠玫面部，漠玫平静的表情与虚化的大圣形成对比 |

| **缓慢拉远** | 镜头缓慢拉远，[主体/场景]逐渐展开，[情绪]随拉远释放 | 镜头缓慢拉远，大圣从战意腾腾逐渐变为平静凝视，竹林恢复宁静 |
