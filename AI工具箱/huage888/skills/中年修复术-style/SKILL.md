# 中年人的修复术 · 内容风格模板

> 来源：中年人的修复术风格模板.html
> 半写实动漫 × 金继美学 × 当代华人情感叙事
> 适用场景：竖屏/横屏短剧、情感叙事短片、品牌故事片

---

## 1. 整体风格定义

### 风格标签

| 标签 | 说明 |
|------|------|
| 半写实动漫 | 写实皮肤纹理 + 动漫线条简化，介于真人与动漫之间 |
| 金继美学 | 日本金继（Kintsugi）哲学：破碎被接纳，裂缝即荣耀 |
| 今敏笔触 | 参考《千年女优》人物精度，情绪克制而深刻 |
| 吉卜力氛围 | 温暖中带疲惫，物件传递情绪而非台词 |
| 华人情感叙事 | 当代都市中年人的内心世界 |

### 核心规则

- **画面质感**：写实皮肤纹理 + 动漫线条简化，介于真人与动漫之间，参考今敏《千年女优》人物精度
- **情绪基调**：克制、内敛、温暖中带疲惫，不煽情、不戏剧化，像一杯放凉了的茶
- **叙事节奏**：慢镜头感，大量留白，物件特写传递情绪而非台词
- **光源规则**：每个场景只有 1-2 个主光源，拒绝平铺直叙的打光
- **构图原则**：偏爱近景与特写，人物常处于画面 1/3 处，另外 2/3 是场景叙事

### 允许 vs 禁止

| ✓ 应该有 | ✗ 禁止出现 |
|---------|-----------|
| 岁月感面孔 | 偶像派完美脸 |
| 自然做旧道具 | 高饱和霓虹色 |
| 单一温暖光源 | 动作英雄体型 |
| 不完美的身体比例 | 全局均匀打光 |
| 留白构图 | 奇幻 / 魔法元素 |
| 龟裂 / 金继修复痕迹 | 西式漫画线条 |

### 色彩使用规则

- **金色使用规则**：只出现在器物裂缝修复处，绝不用于服装、背景装饰
- **饱和度**：整体去饱和，HSL 饱和度控制在 20-45% 之间
- **对比度**：暗部压重，亮部柔和，整体低对比胶片感
- **禁用色**：纯白、纯黑、高饱和红 / 绿 / 蓝

## 3. 人物规范

### 主角人物模板

| 维度 | 规范 |
|------|------|
| **年龄感** | 35-50岁，面部必须有真实的岁月痕迹：法令纹、眼角细纹、额头轻微纹路 |
| **眼神** | 深邃、疲惫中带温度，禁用"闪闪发光"的动漫大眼处理 |
| **发型** | 略显凌乱或松散，不要精心造型，允许白发/发丝飞散 |
| **体型** | 真实比例，允许轻微发福、肩膀微驼，拒绝漫画英雄体型 |
| **服装** | 灯芯绒、亚麻、棉布；颜色以灰、米、旧蓝、深棕为主 |
| **手部** | 手部细节必须精细，劳动痕迹（老茧/轻微污迹）是人物性格载体 |
| **表情** | 克制，不外放，情绪藏在眼睛和嘴角的细微变化里 |

### 性别 × 职业参考原型

| 原型 | 描述 |
|------|------|
| 男 · 手艺人 | 40岁陶器修复师，下岗后自学金继，沉默寡言但手极稳 |
| 女 · 编辑 | 38岁出版社编辑，婚姻疲惫，用修复旧书来逃避现实 |
| 男 · 旧书商 | 50岁旧书店老板，城市改造中坚持不搬，每本书都认识 |
| 女 · 厨师 | 42岁家常菜馆老板，用食物维系一条街的人情关系 |

## 4. 场景规范

### 核心场景类型

| 场景类型 | 光线特征 |
|---------|---------|
| **室内工坊** | 自然光从侧面纸窗/老木窗透入，尘埃粒子可见，工作台杂而有序 |
| **旧城街道** | 下午4-6点侧光，老砖墙 + 苔藓，街道有人情但不热闹 |
| **市场/早市** | 晨雾中的菜市场，水汽与光线交织，色温偏冷中带暖 |
| **老公寓室内** | 70-80年代公寓，旧家具、老照片、积灰的书架 |
| **茶馆/小餐馆** | 昏黄白炽灯，木桌椅，窗上有雾气 |

### 光线规范

| 时段 | 光线描述 | 色温 | 适用场景 |
|------|---------|------|---------|
| 早晨 | 冷白光 + 薄雾 | 5500-6000K | 开场建立孤独感 |
| 下午 | 侧入暖光，尘埃粒子 | 3500-4000K | 人物内心戏 |
| 黄昏 | 橙金逆光，轮廓光为主 | — | 关键情感转折点 |
| 夜晚 | 单一白炽灯源，大面积暗部 | — | 独处/回忆场景 |
| **禁止** | 工作室均匀三点打光、霓虹补光、闪光灯感 | — | — |

## 5. 道具体系

| 道具名 | 叙事意义 | 英文 Prompt |
|--------|---------|------------|
| 金继陶碗 / 茶杯 | 核心意象。金色裂缝 = 人生伤痕被接纳，每集必出现 | `kintsugi ceramic bowl, gold lacquer cracks, white porcelain, held in weathered hands` |
| 旧书 / 信件 | 承载记忆与关系，泛黄书页、手写字迹 | `aged paperback book, yellowed pages, handwritten margin notes, worn spine` |
| 手工工具 | 修复刀、毛笔、砂纸，劳动是治愈的具体形式 | `traditional repair tools, bamboo brush, urushi lacquer bowl, wooden workbench` |
| 搪瓷杯 / 铁饭盒 | 70-80年代物件，触发中年人童年集体记忆 | `vintage Chinese enamel mug, faded floral pattern, worn edges, warm tea inside` |
| 植物 / 盆栽 | 生长缓慢但持续的生命力，对应主题 | `small bonsai on windowsill, weathered clay pot, soft afternoon light` |
| 老照片 / 相册 | 时间线索，触发叙事回忆，胶片颗粒感处理 | `old family photograph, film grain, faded colors, 1990s Chinese interior background` |

## 6. 叙事结构（5幕情感弧）

> 推荐时长：15-30分钟 / 单集

### 叙事弧线

| 幕 | 名称 | 时长参考 | 描述 |
|----|------|---------|------|
| 1 | **破碎时刻** | 开场2-3分钟 | 用一个具体的物件或事件切入——摔碎的碗、收到的旧信、发现父亲的遗物。不解释背景，直接进入状态 |
| 2 | **劳动作为逃避** | 中段1 | 主角用手工劳动回避情绪——修复陶器、整理旧书、切菜备料。大量道具特写，少台词 |
| 3 | **意外的连接** | 中段2 | 另一个人物出现，带来新视角。不是浪漫爱情，而是人与人之间偶然的真实相遇 |
| 4 | **金继时刻**（高潮） | — | 裂缝被正视，而非掩盖。用修复完成的器物作为视觉隐喻，情绪在此释放——但克制，不爆发 |
| 5 | **开放结局** | 结尾 | 不给答案，给一个动作或画面：把修好的碗放回架子，泡一杯茶，推开窗。生活还在继续 |

## 7. 提示词库

```
semi-realistic anime style, Satoshi Kon influence, Studio Ghibli atmosphere, muted warm tones, cinematic lighting, detailed texture, film grain, 8k quality, emotional depth
```

### 场景通用词

```
warm afternoon side light through old wooden window, dust motes visible, worn wooden surfaces, aged ceramic objects, subtle paper texture background, shallow depth of field, soft bokeh
```

### 人物通用词

```
middle-aged Asian face, natural aging details, nasolabial folds, tired but warm eyes, slightly disheveled hair, linen or corduroy clothing in muted tones, weathered hands with calluses, contemplative expression
```

### 道具通用词

```
kintsugi gold lacquer cracks on white porcelain, aged enamel objects, yellowed paper, traditional repair tools, worn wooden workbench surface, patina on metal
```

```
young idol face, perfect smooth skin, bright saturated colors, western comic style, 3D CGI render look, action hero body, fantasy elements, chibi, flat 2D anime, neon lights, overly dramatic expression, low quality, blurry
```
