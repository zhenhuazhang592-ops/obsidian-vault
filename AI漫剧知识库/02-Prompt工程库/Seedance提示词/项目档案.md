## 1. 电影风格

> 专业电影手法，适合漫剧短剧场景氛围构建。

### 1.1 好莱坞专业赛车电影（勒芒风格）

**来源**：John (@johnAGI168)

```markdown
风格：好莱坞专业赛车电影（勒芒风格），电影感夜晚，雨天，高风险运动。
时长：15秒。

[00-05s] 镜头1：老将（内景/特写）。
雨水拍打着赛道上高科技赛车的挡风玻璃。老赛车手（戴头盔）看过来，冷静而专注。
仪表盘的灯光反射在他的面罩上。
对白提示：他微微点头，低声说："出发吧。"

[05-10s] 镜头2：挑战者（内景/特写）。
切换到旁边对手的车内。年轻的车手紧握方向盘，呼吸沉重。眼神中充满了肾上腺素。
对白提示：他对自己小声说："专注。"

[10-15s] 镜头3：绿灯亮起（远景动作）。
起跑灯变绿。两辆车在潮湿的沥青路面上同步加速。水花飞溅到镜头上。
运动模糊将体育场的灯光变成了长长的彩色线条。
```

**结构分析**：时间戳分镜 + 景别标注 + 对白提示（口型）

### 2.6 动态海报展示

```markdown
一个15秒竖屏9:16的卡点音乐短片，背景音乐使用@音频1，
视频全程保持固定机位景别不变，
视频中的元素陆续按@图片1中的九宫格分镜依次显现，
从左上角第一个镜头开始从左到右、从上到下依次推进。
```

**流程**：
1. 用 Nano Banana Pro 根据海报做出一张元素依次生成的九宫格分镜图
2. 让 Seedance 2.0 根据九宫格图做出元素的依次展现

**Tips**：可在提示语中补充更详细的信息，明确告诉元素出现的顺序。

### 2.7 广告复刻

```markdown
模仿【@视频1】的分镜设计，把视频中所有产品都替换成【@图片1】的无人机，

同时更换配音旁白和音乐为介绍无人机的内容，画面主要颜色使用蓝色和黑色
```

**Tips**：如果某个镜头效果不好，可以先用 NanoBanana Pro 做出该分镜的效果图片，让 Seedance 2.0 替换指定镜头。

### 5.2 哪吒与敖丙冰火交锋（时空折叠）

**来源**：Adam also known as Jimmy (@Adam38363368936)

```markdown
第一幕：静止与爆发（测试从静止开始的加速度）
视觉：特写。哪吒的混天绫在风中轻轻摇曳，火星四溅。镜头突然快速缩小。
动作：哪吒突然蹬地，导致地面碎裂。
视觉焦点：测试 Seedance 2.0 对碎片轨迹的模拟，以及从静止到超高速运动的过渡。

第二幕：属性转换（测试匹配剪辑）
视觉：哪吒挥舞火尖枪横扫，形成一个圆形的火焰环。
过渡设计：火焰环在旋转时无缝转化为敖丙的旋转冰刃。
镜头跟随武器的旋转轴线，实现从红调到蓝调的瞬间平滑过渡。

第三幕：激战交互（测试物理碰撞与摄影）
视觉：侧面中景。火尖枪和冰剑在半空中碰撞。
动作：火花和冰屑同时爆炸。敖丙身形如龙，绕着火柱螺旋上升；
哪吒在空中倒立，脚踩风火轮冲向地面。
视觉焦点：测试模型在两个角色高速决斗期间是否出现肢体崩坏。

第四幕：终极过渡（测试空间折叠）
视觉：哪吒一拳击碎冰墙。
过渡设计：破碎的冰晶在空中转化为飞舞的红叶或火羽。
镜头穿过冰块碎片，瞬间切入下一场。
视觉焦点：测试 Seedance 2.0 利用粒子连续性的逻辑连贯性。
```

## 提示词结构体系

### 通用结构要素

从所有提示词中提取的通用组成：

```
[风格标签] + [时长/格式] + [时间戳分镜] + [场景描述] + [动作/对白] + [技术参数]
```

### 四大分层架构

| 层级 | 标签格式 | 作用 | 示例 |
|------|---------|------|------|
| **风格层** | `[电影风格]` / `【风格】` | 整体调性定位 | 90年代香港艺术电影风格 |
| **情感层** | `[核心对白]` | 情感锚定 | "如果记忆是一个罐头…" |
| **分镜层** | `[00:00-00:05]` | 镜头编排 | 时序、景别、动作 |
| **技术层** | `[技术参数]` | 摄影参数 | 模拟手持摄影机，浅景深 |

### 时间戳分镜格式

```markdown
[00-05s]  镜头1描述（景别标注）
[05-10s]  镜头2描述
[10-15s]  镜头3描述
```

**变体**：
- `[00:00-00:04]`（冒号格式，精度更高）
- `0–2秒：`（纯文字描述）
- `2–4秒：`（无方括号）

### 景别标注方式

```
极远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 极端特写
内景 / 外景
过肩视角 OTS / 驾驶舱视角 / 侧面中景
```

### 对白/口型标注方式

```
对白提示：他微微点头，低声说："出发吧。"
对白口型：男主嘶吼："你凭什么替我做决定！"
口型与字幕：姐姐，你为什么这样
（对口型）
```
