# Prompt进化规则

> [!abstract] 版本：1.0.0
> **目的**：建立Prompt从"生成→评分→分析→优化→再验证"的正向飞轮
> **核心**：数据驱动，让每次失败都有价值，让成功经验自动沉淀

---

## 进化闭环（5步）

```
P1 效果追踪 → 产出 effect_score + tags
        ↓
P2 进化引擎 → 聚类分析 + 词频提取 + 模板生成
        ↓
验证通过 → Prompt 入库成功库
        ↓
新镜头复用验证通过模板
        ↓
复用数据 → 补充 P1 效果日志
        ↓
再次触发进化 → 形成正向飞轮
```

---

## Step 1：聚类分析

**触发条件**：同一场景类型累计 ≥ 5 个镜头有评分数据

**执行方法**：
```
按 tags[场景标签] 聚合（如"都市职场"、"古风国潮"）
或按 subcategory 聚合（如"MCU中景-对话"）
```

**输出**：相似镜头分组

---

## Step 2：词频提取

**方法**：分离高分组（score ≥ 0.7）和低分组（score < 0.7），计算每个词的权重分数

**权重分数公式**：
```
某词权重 = (高分频率) - (低分频率)
权重 > 0 = 高价值词（高分镜头中更常见）
权重 < 0 = 低价值词（低分镜头中更常见）
```

**输出**：`{"关键词": 权重分数}` 排序表

---

## Step 3：权重提升

**策略**：高权重关键词放在Prompt前部（权重更高），必要时重复一次增强

```python
# 高权重词重复一次示例
原Prompt: "男子站在窗前，俯瞰城市夜景"
优化后: "男子男子站在窗前，俯瞰城市夜景"  # "男子"是高权重词
```

---

## Step 4：模板生成

**输入**：权重最高的Top10关键词

**模板骨架**：
```
[Top10关键词拼接], [镜头类型], [场景标签], cinematic, high quality
```

**入库条件**：
- 验证使用 ≥ 3 次
- success_rate ≥ 0.7（评分≥0.6的镜头占比≥70%）

---

## Step 5：安全护栏

**禁止事项**：
- ❌ 进化过程中不得删除原始成功Prompt（保留回滚能力）
- ❌ 新模板首次使用需人工确认（不得全自动发布）
- ❌ 发现违反安全规则 → 立即停止进化流程

**回滚机制**：
- 每个新模板有 `parent_prompt_id` 可追溯
- 连续3次失败 → 自动回退到父模板

---

## 进化决策树

```
累计 ≥ 5 个同类镜头数据？
    │
    ├── 否 → 继续累积数据，不触发进化
    │
    └── 是 → 执行进化算法
              │
              ├── 高分组关键词提取成功？
              │   ├── 否 → 数据不足，需更多样本
              │   │
              │   └── 是 → 生成新模板
              │            │
              │            ├── 验证通过（≥3次，success_rate≥0.7）
              │            │   → 入库为"已验证模板"
              │            │
              │            └── 验证失败
              │                → 记录失败原因 → 调整关键词权重
```
