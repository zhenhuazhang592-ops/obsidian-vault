## 文档1：prompts.chat全局研究

**来源**：prompts.chat-main/，143k+ GitHub stars，CC0许可

### 核心架构
- Next.js + Prisma + PostgreSQL + MCP Server
- 质量检查：`confidence < 0.85` 不下架，避免误杀
- 事件追踪：view/copy/fork/submit/vote完整漏斗

### 漫舟可借鉴点
- **AI质量阈值**：min_chars≥50，min_words≥10，confidence≥0.85
- **提示词结构模板**：角色定义 / 约束条件 / 输出格式 / 质量标准 / 禁止项
- **Change Requests版本控制**：漫舟CDP可引入版本记录机制
- **不借鉴**：18种多语言（当前不需要）

### 质量检查代码参考
```typescript
// 基础检查
min_chars: 50
min_words: 10

// AI质量检查（OPENAI_API_KEY）
confidence < 0.85 → 不下架
JSON解析失败 → 默认通过
API调用失败 → 默认通过
```

## 文档2：awesome-seedance详细研究

**来源**：awesome-seedance-main/，字节跳动Seedance 2.0，CC BY 4.0

### 核心发现：七大结构要素

| 要素 | 语法 | 示例 |
|------|------|------|
| 风格定义 | `【风格】` | 好莱坞专业赛车电影风格 |
| 时长控制 | `【时长】` | 15秒 |
| 时间轴 | `[00:00-00:05]` | 每镜头独立时间码 |
| 景别标注 | 特写/中景/远景 | 镜头编号后标注 |
| 动作描述 | `[Action]` | 主角紧握方向盘 |
| 对白标注 | `【口型/字幕】` | 口型与字幕逐字一致 |
| 技术参数 | `[Technical Parameters]` | 浅景深/偏色/情感强烈 |

### 景别规范表

| 景别 | 英文 | 时长建议 | 适用场景 |
|------|------|----------|---------|
| ECU 极特写 | Extreme Close-up | 2-5秒 | 情感爆发/关键道具 |
| CU 特写 | Close-up | 3-6秒 | 人物表情/对话 |
| MCU 中特写 | Medium Close-up | 4-8秒 | 情绪对话 |
| MS 中景 | Medium Shot | 5-10秒 | 日常对话/动作 |
| WS 远景 | Wide Shot | 5-12秒 | 环境展示/动作全景 |
| EWS 极远景 | Extreme Wide Shot | 8-15秒 | 史诗规模/宏大场景 |

### 运镜指令集

**运动类型**：推（Zoom In）/ 拉（Zoom Out）/ 摇（Pan/Tilt）/ 移（Dolly/Tracking）/ 旋转（Orbit）/ 手持（Handheld）

**速度控制**：慢动作 / 快切 / 定格

**特效词汇**：运动模糊 / 抽帧效果 / 慢速快门拖影

## 文档3：seedance-prompt-skill研究

**来源**：seedance-prompt-skill-master/，MIT许可

### 十大核心能力

| # | 能力 | 对漫舟的对应 |
|---|------|------------|
| 1 | 纯文本生成 | 小说→剧本→分镜 |
| 2 | 一致性控制 | 角色DNA/CDP |
| 3 | 运镜与动作复刻 | 运镜指令集 |
| 4 | 创意模板/特效复刻 | 风格库 |
| 5 | 剧情创作/补全 | 导演控制塔 |
| 6 | 视频延长 | 视频拼接 |
| 7 | 声音控制 | Audio Layer |
| 8 | 一镜到底 | 分镜连贯性 |
| 9 | 视频编辑 | 后期剪辑 |
| 10 | 音乐卡点 | BGM情绪曲线 |

### 多模态引用语法

```
@图片1 ~ @图片9  — 角色参考、场景背景、首帧/尾帧控制
@视频1 ~ @视频3  — 运镜、动作、特效、节奏参考
@音频1 ~ @音频3  — 背景音乐、音色、音效参考
```

### 四步工作流

```
第一步：描述创意 → "一段古风武侠打斗"
第二步：确认参数 → Claude询问时长、比例、参考素材、风格偏好
第三步：生成提示词 → ≤15秒生成2-3个版本，>15秒输出多段拼接方案
第四步：微调优化 → 调整时间段画面、镜头语言、台词、音效或风格
```

### 与漫舟v6.2的核心差距

| 维度 | seedance-prompt-skill | 漫舟v6.2 |
|------|----------------------|---------|
| 引用系统 | @图片1-@图片9 | CDP char_XX/loc_XX/item_XX |
| 时间轴 | [00:00-00:05] 秒级 | 有时长，无精确秒级 |
| 运镜 | 自然语言 | Yaw/Pitch/Dolly数值 |
| 口型同步 | 台词逐字+情绪标注 | Lip-sync viseme标注 |
| 音效 | 音效单独描述 | Audio Layer四分栏 |
| 情感 | 情感映射字段 | 情绪曲线 |

## 文档4：漫舟借鉴与升级建议（综合）

详见 [[漫舟Prompt升级建议]]

### 核心结论

1. **时间轴格式是最大差距**：漫舟需要引入P01秒级时间码
2. **王家卫风格立即可用**：情感戏分镜提升明显
3. **CDP引用语法需对齐Seedance**：@语法是行业趋势
4. **质量检查机制可引入prompts.chat阈值**：提升自动化水平
