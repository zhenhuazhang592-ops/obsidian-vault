# Step 00 · 项目配置

> [!abstract] 评级：A级 | 多次验证
> **目的**：确定项目基本信息，为后续所有环节提供统一配置基线
> **必须性**：❌ 禁止跳过，没有全局配置，后续Prompt无法生成

---

## 执行时机

**紧接用户输入小说/IP名称后，第一步执行。**

---

## 执行内容

### 1. 确定5个全局参数

| 参数 | 选项 | 默认 | 说明 |
|------|------|------|------|
| **风格预设** | 16种（见下表） | ShortDrama_Style | 注入所有镜头Prompt后缀 |
| **画幅比例** | 9:16竖屏 / 16:9横屏 | 9:16竖屏 | 短视频平台原生 |
| **单镜头时长** | 8s / 10s / 15s | 10s | 影响分镜数量 |
| **目标集数** | 6集 / 12集 / 24集 | 12集 | 标准短剧12集 |
| **主视角角色** | 从IP角色中选择1位 | — | 出场占比≥60% |

### 2. 风格预设选择（16选1）

| ID | 名称 | 适用题材 |
|----|------|---------|
| ShortDrama_Style | 短剧爽感 | 打脸逆袭/情绪爆发 |
| Villeneuve_Style | 史诗科幻 | 大场面/商战/家族对决 |
| WongKarwai_Style | 情绪港风 | 都市情感/暧昧试探 |
| SciFiWasteland_Style | 废土科幻 | 末世/未来都市 |
| ChinesePeriod_Style | 古风国潮 | 古装/传统美学 |
| anime | 日漫 | 校园/热血/冒险 |
| cn_anime | 国风动漫 | 仙侠/古风少女 |
| cn_3d | 国风3D | 游戏CG/史诗战斗 |
| ink | 水墨国风 | 文艺/文人意境 |
| cyber | 赛博朋克 | 都市科幻/未来设定 |
| us_comics | 美漫 | 超级英雄/动作打斗 |
| real | 写实 | 真实故事/生活剧情 |
| horror | 恐怖惊悚 | 黑暗心理/灵异氛围 |
| pixar | 皮克斯 | 家庭动画/冒险喜剧 |
| shinkai | 新海诚 | 唯美青春/风景抒情 |
| miyazaki | 宫崎骏 | 奇幻冒险/自然治愈 |

### 3. 生成配置单

---

## 输出模板

```yaml
=== 全局参数配置单 ===

项目名称：[小说/IP名称]
类型：[都市职场/古风/甜宠/悬疑/复仇/其他]
目标平台：[抖音/快手/视频号/其他]

风格预设：[从16种中选择]
画幅比例：[9:16竖屏 / 16:9横屏]
单镜头时长：[8s / 10s / 15s]
目标集数：[6集 / 12集 / 24集]
主视角角色：[角色名称]

预算估算：[待评估]
制作周期：[待规划]
```

---

## 关键检查项

- [ ] 风格预设与IP题材匹配
- [ ] 画幅比例符合目标平台
- [ ] 主视角角色在剧本中戏份≥60%
- [ ] 成本预算在可接受范围
