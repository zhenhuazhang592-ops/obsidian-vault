# Step 04 · 导演控制塔

> [!abstract] 评级：A级 | 2026-03-26 新增验证
> **目的**：在剧本和分镜之间建立导演分析层，确保运镜意图传递
> **关键**：❌ 禁止跳过此步骤！剧本→分镜必须经过导演控制塔

---

## 执行时机

**Step 03 剧本生成完成后，Step 06 分镜脚本之前执行。**

> [!warning] 强制执行
> 导演控制塔是漫舟 v6.0.0 的核心新增步骤，不允许跳过。
> 跳过此步骤 = 分镜脚本缺少运镜意图 = 视频生成效果失控

---

## 四个输出阶段

### 阶段D1：情绪基调定义

```markdown
## 第X集 · 情绪基调卡

- **情绪类型**：爽 / 虐 / 甜 / 悬疑 / 复仇 / 逆袭 / 甜宠
- **基调色温**：冷 / 暖 / 明 / 暗 / 对比强烈 / 柔和
- **叙事节奏**：快节奏紧凑 / 中速叙事 / 慢速沉浸
- **本集核心情绪**：[一句话描述，如"压抑中的希望"]
- **情绪转折点**：[列出本集3个情绪转折位置]
```

### 阶段D2：场景节拍分析

```markdown
## 第X集 · 场景节拍表

| 场景 | 场景名 | 功能 | 情绪值 | 节拍位置 | 核心动作 |
|------|--------|------|--------|---------|---------|
| S01 | 会议室 | TENSION | L3 | B06 | 曾婵贞宣布 |
| S02 | 茶水间 | MOOD | L2 | B07 | 方芳安慰 |
| S03 | 停车场 | REVEAL | L4 | B10 | 程睿敏警告 |
```

**场景功能类型**：

| 类型 | 含义 | 适用场景 |
|------|------|---------|
| TENSION | 制造冲突 | 对话/对峙 |
| MOOD | 情绪铺垫 | 独处/沉思 |
| REVEAL | 揭露关键信息 | 反转点 |
| ACTION | 推动情节 | 动作场景 |
| TRANSITION | 过渡连接 | 转场 |
| CLIFFHANGER | 制造悬念 | 结尾钩子 |

**情绪值（L1-L5）**：

| 值 | 状态 | 描述 |
|----|------|------|
| L1 | 平静 | 无动作，冷场 |
| L2 | 克制 | 内心波动，外表平静 |
| L3 | 隐忍 | 明显压抑情绪 |
| L4 | 爆发 | 情绪外化，行动激进 |
| L5 | 高潮 | 最高强度，持续动作 |

### 阶段D3：节拍追踪

```markdown
## 第X集 · 节拍追踪

| 时间点 | 镜头 | 情绪曲线 | 节拍类型 | 导演意图 |
|--------|------|---------|---------|---------|
| [00:00-00:08] | P01 | L1→L2 | B01开场 | 建立职场压抑感 |
| [00:08-00:16] | P02 | L2→L3 | B04催化剂 | 镜头跟随潭斌反应 |
| [00:16-00:24] | P03 | L3 | B05辩论 | ECU瞳孔放大 |
```

### 阶段D4：运镜意图指令

```markdown
## 第X集 · 运镜意图指令

### 镜头P01（[00:00-00:08]）

**情绪状态**：L1平静
**节拍位置**：B01开场画面
**运镜意图**：
- 建立镜头（Establishing Shot）→ WS全景
- 冷蓝月光 + 台灯暖黄对比 → 突出孤独感
- 镜头缓慢推进（dolly in）→ 引导视线聚焦潭斌

**禁止**：
- ❌ 不要在此镜头使用ECU（情绪未到位）
- ❌ 不要用快速剪辑（节奏需要慢）
```

## 轴线规则

**180度轴线约束（双人对话场景必须标注）**：

```
角色A ←———— 180度轴线 ————→ 角色B

角色A在轴线左侧 → 角色B必须在轴线右侧
禁止在同一侧拍摄两个角色（除非特写）
```

## 执行Prompt模板

```markdown
你是AI漫剧导演。请对以下剧本进行导演分析，生成导演控制塔输出。

要求：
1. 逐场分析场景功能（TENSION/MOOD/REVEAL/ACTION/TRANSITION/CLIFFHANGER）
2. 标注每场情绪值（L1-L5）
3. 标注每场节拍位置（B01-B15）
4. 逐镜制定运镜意图（为什么这样拍）
5. 双人对话场景标注180度轴线
6. 禁止在情绪未到位时使用ECU特写
7. 情绪曲线跳变不能超过2级（L1→L4禁止）

---
剧本：
[粘贴标准化剧本]

角色DNA：
[粘贴角色档案]

全局风格：
[粘贴项目配置单]
---
```

## 导演控制塔 → 分镜脚本的约束传递

```
导演控制塔输出
    ↓
[运镜意图] → manzhou-shot-script 的 camera_action 字段
[场景功能] → manzhou-shot-script 的 emotion_level 字段
[节拍位置] → manzhou-shot-script 的 节拍# 字段
[轴线约束] → manzhou-shot-script 的 180度轴线 字段
[情绪曲线] → manzhou-shot-script 的 emotion_curve 字段
```

---

## 关键检查项

- [ ] 每场有场景功能标注
- [ ] 每场有情绪值（L1-L5）
- [ ] 每场有节拍位置（B01-B15）
- [ ] 每镜有运镜意图（为什么要这样拍）
- [ ] 双人对话有轴线标注
- [ ] 没有情绪跳变超过2级（L1→L4禁止）
- [ ] 没有在情绪未到位时使用ECU
