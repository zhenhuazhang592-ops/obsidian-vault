# Step 09 · 音频制作

> [!abstract] 评级：A级 | 多次验证
> **目的**：生成TTS配音 + BGM背景音乐 + SFX音效，完成三轨时间轴整合
> **核心**：音频与视频分轨制作，最后在剪辑阶段整合

---

## 执行时机

**Step 08 视频生成完成后执行（可与Step 10剪辑并行）。**

---

## 三轨音频体系

### 轨道1：TTS配音

**四维VO参数**：

| 参数 | 选项 | 说明 |
|------|------|------|
| 情绪 | 平静/激动/悲伤/愤怒/温柔/嘲讽/紧张/兴奋 | 决定语调和语速 |
| 语速 | 快速/中速/缓慢 | 影响节奏感 |
| 音量 | 高/中/低 | 通常中等 |
| 音色 | 沉闷/清脆/沙哑/磁性/尖锐 | 角色声音特征 |

**标注格式**：
```markdown
voice:(情绪, 语速)"对白台词"

# 示例
voice:(平静/缓慢)"今晚的月色真美。"
voice:(激动/快速)"不可能！这绝对不可能！"
voice:(温柔/缓慢)"你还好吗……"
voice:(愤怒/中速)"你给我滚出去！"
```

**AI唇形同步**：
- 台词≤15字时唇形同步效果最佳
- 语速越慢，唇形同步越准确

### 轨道2：BGM背景音乐

**情绪曲线绑定**：

| 场景情绪 | BGM类型 | 节奏 |
|---------|---------|------|
| 压抑/悲伤 | 低沉弦乐/钢琴独奏 | 慢(40-60bpm) |
| 紧张/悬疑 | 电子氛围/鼓点 | 中(60-90bpm) |
| 甜/温馨 | 钢琴+弦乐 | 慢(60-80bpm) |
| 爽/逆袭 | 电子+节拍 | 快(100-140bpm) |
| 冲突/对峙 | 不协和弦乐 | 压迫感 |

**标注格式**：
```markdown
[BGM: 情绪描述, 曲风, BPM, 起始时间点]

# 示例
[BGM: 悬疑紧张, 低沉弦乐, 60bpm, 00:00]
[BGM: 温柔抒情, 钢琴独奏, 65bpm, 01:30]
[BGM: 逆袭爽感, 电子+鼓点, 120bpm, 02:00]
```

### 轨道3：SFX音效

**六维SFX参数**：

| 参数 | 选项 | 说明 |
|------|------|------|
| 类型 | 机械/自然/拟音/环境/特效 | 音效大类 |
| 强度 | 强/中/弱 | 音量大小 |
| 频率 | 高/中/低 | 音调高低 |
| 持续 | 点音效/持续音 | 单次/循环 |
| 位置 | 左/中/右 | 声道位置 |
| 混音 | 淡入/淡出/渐变 | 过渡方式 |

**标注格式**：
```markdown
[SFX: 音效类型, 时间点, 混音方式]

# 示例
[SFX: 门关闭声, 00:01]
[SFX: 键盘敲击声, 00:05, 淡入]
[SFX: 城市夜晚白噪音, 00:00, 持续到01:30]
[SFX: 手机震动, 00:30]
[SFX: 玻璃破碎声, 01:45, 强音]
```

## 三轨时间轴整合

```markdown
## 第N集 · 音频时间轴

| 时间点 | TTS轨 | BGM轨 | SFX轨 |
|--------|-------|-------|-------|
| 00:00-00:05 | [无对白] | [BGM: 都市孤独, 钢琴] | [SFX: 窗外白噪音] |
| 00:05-00:10 | voice:(平静)"..." | [持续] | [无变化] |
| 00:10-00:15 | voice:(震惊/快速)"..." | [BGM转: 紧张悬疑] | [SFX: 门关闭声] |
| ... | ... | ... | ... |
```

## 执行流程

```
Step 08 视频生成
    ↓
Step 09 音频制作
    ├── TTS生成（按分镜脚本对白标注）
    ├── BGM生成（Suno/Udio + 标注情绪曲线）
    ├── SFX生成（环境音/点音效）
    └── 三轨整合（时间轴对齐）
    ↓
音频文件上传OSS → 记录URL
```

## 关键检查项

- [ ] TTS情绪与场景情绪匹配
- [ ] TTS语速与画面节奏匹配
- [ ] 每句台词≤15字（唇形同步优化）
- [ ] BGM情绪曲线与视频情绪曲线对齐
- [ ] SFX时间点与视频事件精准对齐
- [ ] 三轨音量比例合理（语音> BGM > SFX）
- [ ] 音频文件上传OSS并记录URL

## 常见问题

> [!warning] TTS情感不够
> **原因**：情绪标签不够细化
> **解决**：在情绪标签前加描述词，如"压抑的愤怒"而非仅"愤怒"

> [!warning] BGM与画面情绪不搭
> **原因**：没有按场景情绪选择BGM类型
> **解决**：参考BGM情绪对照表，每场单独标注BGM类型
