# Step 06 · 分镜脚本

> [!abstract] 评级：A级 | 多次验证
> **目的**：生成可直接用于AI视频生成的完整分镜脚本（每镜含image_prompt + video_prompt + 音频标注）
> **核心**：分镜脚本 = 导演控制塔的运镜指令 + 资产库的角色引用 + 音频层的标注注入

---

## 执行时机

**Step 05 资产库构建完成后执行。**
**前置依赖**：导演控制塔（Step 04）必须完成

---

## 分镜脚本结构

```markdown
# 第N集 · 分镜脚本

> 总时长：120秒
> 总镜头数：12镜
> 单镜时长：10秒
> 主视角：char_XX
> 风格预设：[预设名称]

---

## 镜头 01

| 字段 | 内容 |
|------|------|
| 时长 | 8秒 |
| 景别 | WS（全景） |
| 运镜 | 固定 |
| 轴线 | 居中 |
| 节拍 | B01开场画面 |
| 情绪值 | L1 |
| 场景功能 | MOOD |
| 情绪曲线 | L1→L2 |

### 导演指令
冷蓝月光透过落地窗，潭斌独自站在窗前。缓慢推进镜头，建立职场精英的孤独感。

### 分场内容
[char_01] 独自站在CBD落地窗前，俯瞰夜景。桌上放着笔记本电脑和咖啡杯。
他点燃一根烟，表情沉静。

### 角色ID
- char_01（潭斌，主视角）

### 场景ID
- loc_01（潭斌办公室）

### [Image Prompt]
char_01: 40岁男性, 商务精英形象, 藏青色西装, 剑眉, 眼神深沉, 侧脸,
站在落地窗前俯瞰城市夜景, 冷蓝月光与室内台灯暖黄对比, 桌上笔记本电脑,
烟雾缭绕, ShortDrama_Style, 高质量, 电影感

### [Video Prompt]
char_01站在CBD落地窗前俯瞰城市夜景, 冷蓝月光, 室内台灯暖黄光,
西装革履, 商务精英形象, 侧脸, 手指夹烟, 烟雾缭绕, 缓慢推进镜头(dolly in),
ShortDrama_Style, 高质量, 电影感, 8K, 竖屏9:16

### [Audio Layer]
- TTS: voice:(平静/缓慢)"[无对白]"
- BGM: [BGM: 都市孤独, 钢琴独奏, 60bpm, 00:00]
- SFX: [SFX: 窗外城市夜景白噪音, 00:00]
```

## 景别速查表

| 缩写 | 名称 | 用途 |
|------|------|------|
| ECU | 极致特写 | 情绪高潮/微表情 |
| CU | 特写 | 关键反应/情绪传递 |
| MCU | 中特写 | 面部+上半身 |
| MS | 中景 | 对话/互动 |
| WS | 全景 | 建立镜头/环境 |
| EWS | 大全景 | 宏观场景 |
| LS | 长镜头 | 情绪铺垫/场景转换 |

---

## 运镜速查表

| 运镜 | 描述 | 适用场景 |
|------|------|---------|
| 固定 | 无运动 | 冷静/观察/压迫 |
| 推(dolly in) | 前进靠近 | 聚焦/紧张/逼近 |
| 拉(dolly out) | 后退远离 | 释放/退让/冷静 |
| 摇(pan) | 左右旋转 | 扫视/对比/建立 |
| 移(tracking) | 跟随移动 | 跟随/观察/代入 |
| 跟(follow) | 跟随主体 | 主观视角/代入感 |
| 升降(boom) | 上下运动 | 大场面/情绪升降 |

## 执行Prompt模板

```markdown
你是AI漫剧分镜导演。请根据导演控制塔和资产库，生成完整分镜脚本。

要求：
1. 每镜包含：时长/景别/运镜/轴线/节拍/情绪值/场景功能/情绪曲线
2. 每镜必须引用角色ID（char_XX）和场景ID（loc_XX）
3. 每镜生成：image_prompt（AI生图）+ video_prompt（AI视频）+ Audio Layer（TTS/BGM/SFX）
4. image_prompt必须引用角色DNA外貌描述词
5. video_prompt必须遵循导演控制塔的运镜意图
6. Audio Layer使用标准标注格式
7. 单镜时长不超过15秒，不少于3秒

---
导演控制塔：
[粘贴导演控制塔内容]

资产库（角色DNA）：
[粘贴角色DNA手册]

资产库（场景）：
[粘贴场景档案]

项目配置单：
[粘贴全局参数]
---
```

## 关键检查项

- [ ] 每镜有时长/景别/运镜/轴线标注
- [ ] 每镜有节拍位置（B01-B15）
- [ ] 每镜有情绪值（L1-L5）和情绪曲线
- [ ] 每镜有场景功能标注
- [ ] image_prompt引用了角色DNA外貌描述
- [ ] video_prompt遵循导演运镜意图
- [ ] Audio Layer完整（TTS/BGM/SFX）
- [ ] 角色使用ID引用，场景使用ID引用
