# Seedance视频创作手册 · 设计文档

> 版本：v1.0.0 · 制定时间：2026-03-26
> 定位：面向有基础自媒体人的AI漫剧全流程操作手册
> 核心价值：全链路闭环 + 逐字可执行Prompt + 三类积累 + 社区驱动进化

---

## 一、设计决策汇总

| 维度 | 决策 |
|------|------|
| 输出形态 | Obsidian Vault |
| 目标用户 | 有基础的自媒体人（懂AI工具，会复制粘贴Prompt） |
| 覆盖范围 | 完整链路：小说 → 剧本 → 资产规划 → 分镜 → 分镜图 → 视频Prompt |
| 核心工具 | Seedance（即梦 / liblib.tv），统一 16:9 画幅 |
| Prompt深度 | **逐字可执行**（用户填入内容即可直接复制到Seedance） |
| Vault结构 | 三区分离：SOP手册 + 模板库 + 我的项目 |
| 核心价值 | **全流程闭环**——步骤之间不断裂，资产/风格/音效四维锁定 |
| 风格库 | 30+种可扩展（主库15种 + 用户自建"我的风格库"） |
| 稳定性保障 | 人物角色DNA + 场景资产 + 风格标签 + 音效标签四维锁定 |
| 自我学习 | **社区驱动**——用户贡献成功Prompt → 作者审核合并 → 主库迭代 |

## 三、每个SOP笔记的固定结构

每个 Step 的 SOP 笔记包含以下 5 个模块：

```
## 该步做什么（What）
   简明目标说明，1-3段

## 为什么这样做（Why）
   分镜/剧本/导演逻辑基础
   让用户理解原理，举一反三

## 操作步骤（How）
   编号步骤清单，用户可照做

## 逐字可执行模板（Template）
   ✅ 可直接复制到 Seedance 的完整 Prompt
   ✅ [方括号] 标注需要替换的内容

## 示例（Example）
   填好后的完整示例 Prompt
```

## 四、核心设计决策

### 4.1 风格库设计

**15种主风格卡片结构**（每张卡片固定格式）：

```markdown
# [S01] 怀旧现实风

## 适用场景
- 年代小说（60-90年代中国农村/县城）
- 现实主义题材
- 情感克制、叙事性强

## Seedance风格标签（必填）
【色调】低饱和度，泛黄胶片感，高ISO颗粒
【光线】自然光，偏暗，窗户漫射光
【质感】写实，颗粒感，略微过曝高光
【运镜】缓慢推进，固定镜头为主

## 角色一致性锚点
- 服装描述固定：颜色+款式+标志性配饰
- 外貌特征固定：脸型+发型+肤色
- 表情特点固定：眼神+嘴角+习惯动作

## BGM推荐
- 年代感钢琴/民谣
- 标签：#怀旧 #缓慢 #叙事

## 对应音效
- 标签：#老式收音机 #钟表声 #风声 #自行车铃声

## 示例Prompt（生图）
[见T05模板中的示例]

## 示例Prompt（生视频）
[见T06模板中的示例]
```

**风格选择流程**：
```
Step 2 资产规划时 →
  用户阅读"风格索引.md" →
  对照剧本题材选择1种主风格 →
  填写T02/T03时固定该风格标签 →
  Step3/4/5全程引用该风格标签 →
  四维锁定完成
```

### 4.2 四维锁定机制

**为什么需要四维锁定？**
AI视频生成最大问题是角色/场景一致性。四维锁定确保从剧本到最终Prompt的每个环节，人物、场景、风格、音效描述完全一致。

**四维锁定表**：

| 维度 | Step2锁定 | Step3引用 | Step4引用 | Step5引用 |
|------|----------|----------|----------|----------|
| **角色DNA** | 角色DNA手册生成 | 分镜脚本角色Id | 生图Prompt角色描述 | 生视频Prompt角色描述 |
| **场景资产** | 场景资产表生成 | 分镜脚本场景Id | 生图Prompt场景描述 | 生视频Prompt场景描述 |
| **风格标签** | 选定1种风格 | 贯穿全程 | 生图Prompt风格层 | 生视频Prompt风格层 |
| **音效标签** | — | 分镜脚本Audio Layer | — | 生视频Prompt音效层 |

**操作方式**：每步产出文件顶部必须有「四维锁定头」，后续所有步骤@引用：

```markdown
---
## 四维锁定头
- 风格：S01-怀旧现实风
- 角色：char_01(许三观) / char_02(许玉兰) / char_03(一乐)
- 场景：loc_01(丝厂) / loc_02(李家村口) / loc_03(医院)
- 音效：BGM_01(民谣) / SFX_01(工厂广播) / SFX_02(猪血味)
---
```

## 五、三类积累机制

### 5.1 资产库积累

每完成一个项目，用户的「02-我的项目/[小说名]/」目录永久保留：
- 角色DNA手册 → 可复用于同IP续作
- 场景资产表 → 可复用于同世界观项目
- 道具表 → 可复用于同题材项目

**跨项目复用规则**：
```
同类题材新项目 →
  查阅"02-我的项目/"历史项目 →
  复制适用的角色DNA/场景资产 →
  粘贴到新项目 →
  仅调整台词和分镜
```

### 5.2 Prompt库积累

每个项目的「视频Prompt/」目录是天然Prompt库：
- shot_01_prompt.md 等文件按镜头类型分类
- 效果好的Prompt → 标记 ⭐ → 手动移动到「00-SOP手册/06-风格库/[对应风格]/优质Prompt/」
- 效果不好的Prompt → 标记 ⚠️ → 存入「99-反馈与进化/失败案例分析/」

**Prompt贡献流程**：
```
项目复盘 →
  识别优质Prompt →
  填写"Prompt贡献区.md" →
  包含：风格标签/适用场景/完整Prompt/效果评级/作者备注 →
  手册作者定期审核 →
  合并到对应风格卡片的优质Prompt区 →
  手册版本+1
```

### 5.3 音效库积累

用户在项目中使用的BGM/SFX标签 → 自动汇入「00-SOP手册/07-音效库/用户积累/」：
- 按情绪标签分类（#怀旧/#紧张/#温情...）
- 记录来源项目（便于追溯风格适配性）
- 效果好的音效方案 → 标记 ⭐ → 优先推荐


## 十、与现有知识库的协同

本手册以「Obsidian Vault」形态落地，与漫舟AI漫剧知识库的关系：

| 知识库内容 | 手册如何引用/继承 |
|---------|----------------|
| 01-制作SOP（12步卡片） | 精简为5步核心链路，保留关键产出格式 |
| 02-Prompt工程库（Seedance提示词） | 继承风格标签体系，转化为逐字可执行模板 |
| 07-执行层（LibTV管道） | 手册聚焦Prompt输出，执行层面由用户自行操作Seedance |
| 04-项目案例库 | 作为「示例」数据源，手册示例从案例库提取 |
| 03-工具手册（Seedance） | 作为「工具操作指引」附录，手册正文不重复 |

**核心差异**：
- 知识库 = 面向漫舟Agent的可执行代码
- 手册 = 面向人的操作指引文档（更简洁、更直观）
