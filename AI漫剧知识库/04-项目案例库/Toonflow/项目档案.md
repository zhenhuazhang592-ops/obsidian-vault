## 核心功能

| 功能 | 说明 |
|------|------|
| 角色生成 | 自动分析小说文本，智能识别生成角色设定 |
| 剧本生成 | 基于选定事件和章节，生成结构化剧本 |
| 分镜制作 | 智能生成分镜提示词与画面设计（前后景/角色动态/道具） |
| 视频合成 | 集成AI图像与视频，支持在线编辑 |

## 技术架构

### 路由体系（src/routes/）

```
routes/
├── novel/       # 小说管理
├── outline/     # 大纲管理
├── project/     # 项目管理
├── prompt/      # 提示词管理
├── script/      # 剧本生成
├── storyboard/  # 分镜管理
├── video/       # 视频生成
├── assets/      # 素材管理
├── setting/     # 系统设置
├── task/        # 任务管理
└── user/        # 用户管理
```

### AI服务

| 服务 | 技术 |
|------|------|
| LLM | AI SDK（多Provider统一抽象） |
| 图像 | Nano Banana Pro |
| 视频 | Sora / 豆包 |

### 特色设计

- **Aigne**：LLM API 统一管理与接入中间件
- **Electron**：桌面端独立应用
- **better-sqlite3**：高性能本地数据库
- **Sharp**：图像处理库
