### 关键设计

#### World模型（世界观）
- 统一管理世界/故事大纲/视觉风格/色彩语言/构图偏好

#### Character模型
```python
reference_image: URL          # 角色参考图
emotion_voices: JSON         # 情感音色映射
sora_character: ExternalID    # 外部角色ID
```

#### 剧本解析（parse_script_to_shots）
- 代码化实现（1100行），不依赖LLM推理
- 支持 `max_group_duration` 参数可配镜头时长
- **180度轴线规则** + 强制拆分多人对话 ⭐

## 漫舟 vs 智剧通 核心对比

| 能力项 | 漫舟 | ZJT | 差距 |
|--------|------|-----|------|
| 解析入口 | LLM指令（Skill） | 代码（1100行） | ZJT更机器友好 |
| 输出格式 | Markdown + 双Prompt | JSON结构化 | ZJT更规范 |
| 镜头时长 | 固定15s/镜 | 参数可配 | ZJT更灵活 |
| 多人对话 | 合并描写 | **180度轴线+强制拆分** ⭐ | **ZJT领先** |
| 角色一致性 | 角色DNA（框架） | reference_image URL | 漫舟更灵活 |
| 导演控制 | Step 4.5 导演控制塔 | 无 | **漫舟领先** |
| 进化能力 | ✅ Skill进化系统 | ❌ 无 | **漫舟领先** |
