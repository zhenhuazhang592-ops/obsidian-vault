## 核心能力

### 剧本创作（剧本工作室）

**两大模式**：
- 原创剧本：从元素到分集的三步引导
- 小说改编：上传TXT/DOCX，自动解析章节，勾选后一键改编

**三步创作流程**：
```
Step 1: 元素+创意   → 题材/剧情/情绪/时代/角色设定 + 生成N条差异化创意
Step 2: 生成大纲     → 集数设置 + 短剧大纲专用模板 → 总大纲 + 人物小传
Step 3: 分集创作     → 选中某集 → 详细剧本（对白+动作+场景）
```

**状态机**：`IDLE → CONCEPT_GENERATING → CONCEPT_SELECTED → OUTLINE_GENERATING → OUTLINE_CONFIRMED → CHAPTER_GENERATING → COMPLETED`

---

### 分镜模块（漫剧V3工作台）

**六步全链路**：
```
步骤 1: 全局设置（风格/画幅/模型/时长）
  ↓
步骤 2: 故事脚本（导入小说 → CDP解析 → 提取角色/场景/物品 + 生成镜头）
  ↓
步骤 3: 角色/场景/物品（资产库管理，批量生成角色图）
  ↓
步骤 4: 分镜脚本（编辑每镜头脚本 + 九宫格分镜图）
  ↓
步骤 5: 分镜视频（批量生成视频）
  ↓
步骤 6: 视频预览（导出剪映/打包下载）
```

**九宫格分镜**：3x3网格单张图，九格表达同一镜头的连续运镜变化（远景→全景→中景→近景→特写等），硬约束禁止任何文字/字幕/Logo/水印

## 底层架构亮点

### CDP JSON — 全系统唯一真实数据源

```json
{
  "version": "1.0",
  "format": "comic_drama_package",
  "meta": { "runId", "append", "source": {...} },
  "title": "短视频漫剧：XXX",
  "settings": { "targetPlatform", "aspectRatio", "stylePreset", "shotDurationSec", "episodeDurationMin" },
  "characters": [{ "id", "name", "aliases", "gender", "age", "appearance", "clothing", "persona" }],
  "locations": [{ "id", "name", "description", "props" }],
  "items": [{ "id", "name", "description", "appearance" }],
  "shots": [{
    "id", "shotNumber", "durationSec",
    "locationId", "characterIds", "itemIds",
    "script", "dialogue": [{ "speakerId", "text" }],
    "imagePrompt", "videoPrompt",
    "objective", "action": "0-5s/5-10s/10-15s",
    "reference"
  }]
}
```

**关键特性**：
- `meta.append=true` 支持增量追加，同名角色/场景/物品复用已有id
- `cdpVersions[]` 记录版本历史
- `videoPrompt` Sora2格式：`Global Context（无文字/无字幕/无音乐）` + `Shot N / Duration: X sec / Scene: ...`

## 执行层借鉴价值

### 高价值点

1. **CDP JSON Schema**：完整镜头数据结构，可复用于漫舟分镜脚本的JSON/YAML格式设计
2. **九宫格分镜设计**：3x3单张图表达连续运镜变化，分镜可视化的差异化方向
3. **灵石定价策略**：分级模型定价，Sora2（¥0.14/15s）最优性价比参考
4. **剪映一键导出**：自动检测剪映草稿目录，实现AI生成到剪辑软件无缝衔接
5. **action时间轴规范**：`0-5s/5-10s/10-15s`三段式，与漫舟导演控制塔节拍约束逻辑一致
6. **videoPrompt Sora2格式**：`Global Context + Shot N / Duration / Scene`格式，可作为LibTV videoPrompt格式参考

### 低价值点

- 剧本工作室Prompt：面向网文短剧（逆袭/马甲/战神），与漫舟改编业务定位不同
- 异步任务队列：漫舟已有LibTV执行+轮询，无需迁移
- 强引导交互：漫舟定位专业用户，不需要降门槛设计
