## LibTV执行管道（最完整）

**用途**：漫舟最需要的部分 —— 直接拿来用

```
LibTV API 管道：
1. create_session.py    → 发送Prompt给LibTV，返回sessionId
2. query_session.py     → 轮询结果，每8秒一次
3. upload_file.py       → 上传本地图片/视频到OSS
4. download_results.py  → 提取URL+并行下载+命名
5. change_project.py    → 切换项目
```

**集成方式**：把 `libtv-skills-main/scripts/` 复制到漫舟项目，Claude Code Skill 直接调用。

## ZJT多Agent架构（最复杂）

**用途**：漫舟编排层的参考 —— 学习其PM→Expert→Skill的调度逻辑

```
Agent体系：
PMAgent（项目经理）
  → 负责任务拆分、派发、验证、协调
  → 加载 SkillLoader，调用多个 ExpertAgent

ExpertAgent（专家智能体）
  → 执行具体任务（生图/视频/分镜）
  → 基于 Gemini Client 调用 LLM

TaskManager（任务管理器）
  → 维护任务队列
  → 支持失败重试、断点恢复

HistoryManager（历史管理器）
  → 保存会话历史到文件
  → 支持增量摘要

SkillLoader（技能加载器）
  → 加载外部Skill
  → 动态构建Agent的system prompt
```

