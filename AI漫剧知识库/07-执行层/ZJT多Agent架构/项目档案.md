## Agent详解

### 1. BaseAgent — Agent基类

```python
class BaseAgent:
    agent_id: str
    skill_names: List[str]
    model: str
    allowed_tools: List[str]
    system_prompt: str
    conversation_history: List[Dict]

    def send_message(self, message) -> Dict  # 发送消息
    def handle_tool_call(self, tool_name, tool_args) -> Dict  # 工具调用
    def add_to_history(self, role, content)  # 添加历史
```

**关键设计**：
- `system_prompt` 由 SkillLoader 动态构建
- `allowed_tools` 白名单控制工具权限
- `conversation_history` 支持多轮对话

---

### 2. PMAgent — 项目经理Agent

```python
class PMAgent(BaseAgent):
    task_manager: TaskManager
    file_manager: FileManager
    agents_config: Dict  # ExpertAgent配置

    def dispatch_task()  # 拆解任务派发给Expert
    def validate_result()  # 验证Expert结果
    def coordinate()  # 多Expert协调
```

**职责**：
1. 接收用户输入（可能超5000字，自动截断+存文件）
2. 加载相关Skill，构建增强system prompt
3. 拆解为子任务，派发给ExpertAgent
4. 验证Expert输出，决定是否重试
5. 协调多Expert并行/串行执行

---

### 3. ExpertAgent — 专家Agent

```python
class ExpertAgent(BaseAgent):
    skill_loader: SkillLoader
    gemini_client: GeminiClient
    history_manager: ExpertHistoryManager

    def execute_task(task)  # 执行具体任务
    def call_llm(messages)  # 调用LLM
    def save_session()  # 保存会话历史
```

**执行流程**：
```
1. 接收PMAgent派发的任务
2. SkillLoader加载相关Skill，构建system prompt
3. 多轮LLM对话（带tool_calls）
4. ToolExecutor执行工具（生图/视频/文件操作）
5. ExpertHistoryManager保存会话历史
6. 返回结果给PMAgent
```

---

### 4. TaskManager — 任务管理器

```python
class TaskManager:
    def submit_task(agent_task: AgentTask)  # 提交任务
    def get_task_status(task_id) -> TaskStatus  # 查询状态
    def retry_task(task_id)  # 重试失败任务
    def cancel_task(task_id)  # 取消任务
```

**TaskStatus枚举**：
- `QUEUED` → `RUNNING` → `SUCCESS` / `FAILED`

---

### 5. HistoryManager — 历史会话管理

```python
class ExpertHistoryManager:
    history_dir: Path  # agent_history/expert_sessions/
    pm_summaries_dir: Path  # agent_history/pm_summaries/

    def save_expert_session(skill, session_id, task, execution, history)
    def load_sessions(skill) -> List[Dict]
    def save_pm_summary(summarized_context)
```

**关键功能**：
- Expert会话历史持久化（Skill维度和SessionID）
- PM摘要持久化（长期上下文积累）
- 文件路径复用 FileManager 路径体系

---

### 6. SkillLoader — 动态Skill加载

```python
class SkillLoader:
    def load_skill(skill_name) -> str  # 加载单个Skill
    def build_system_prompt(skill_names, context) -> str  # 构建System Prompt
```

**设计思路**：
- Skill = Markdown格式的指令集
- 动态拼入Agent的system prompt
- 支持多Skill组合（PM用orchestrator，Expert用专业Skill）

```python
SCRIPT_PARSER_SYSTEM_PROMPT = """你是一个专业的影视剧本分析师和分镜师..."""

def parse_script(script_text, max_group_duration=15) -> Dict:
    """剧本 → JSON分镜，返回结构化数据"""
```

**输出格式**：
```json
{
  "script_title": "第1集",
  "total_duration": 120.0,
  "style": "都市写实",
  "characters": [
    {"id": "char_001", "name": "潭斌", "role": "主角", "description": "..."}
  ],
  "locations": [
    {"id": "loc_001", "name": "会议室", "type": "室内", "atmosphere": "紧张"}
  ],
  "shot_groups": [
    {
      "group_id": "grp_001",
      "duration": 15,
      "shots": [
        {
          "shot_id": "s001",
          "shot_type": "WS",
          "opening_frame_description": "【潭斌】站在会议室门口...",
          "dialogue": {"char_001": "各位，今天宣布一个重要人事任命。"}
        }
      ]
    }
  ]
}
```

**关键约束**（来自System Prompt）：
- 分镜描述中**禁止写人物外貌**（外貌在角色库）
- 角色名用【【角色名】】格式
- `location_db_id` 必须匹配数据库真实ID
- `opening_frame_description` 必须非常详细（用于AI首帧生成）

## 漫舟可借鉴的设计

### 1. 多Agent职责分离
```
漫舟当前：1个Agent（master）做所有事
漫舟应改为：
  - MasterAgent（总调度）→ 类似PMAgent
  - ScriptAgent（剧本）→ 类似ExpertAgent(skills: script)
  - VisualAgent（视觉）→ 类似ExpertAgent(skills: image/video)
  - AudioAgent（音频）→ 类似ExpertAgent(skills: tts/bgm)
```

### 2. Skill动态加载
```
当前：Claude Code内置Skill
应改为：SkillLoader.load_skill(skill_name) → 动态注入system prompt
好处：可以在运行时加载新的Skill，不需要重启Agent
```

### 3. 任务队列+断点恢复
```
TaskManager.submit_task(AgentTask)
TaskManager.get_task_status(task_id)
TaskManager.retry_task(task_id)
```

### 4. 会话历史持久化
```
ExpertHistoryManager.save_expert_session()
ExpertHistoryManager.load_sessions()
长期运行中保持上下文不丢失
```

### 5. 长文本处理
```
process_long_input()
自动截断+文件保存，5000字限制变为可处理任意长度
```
