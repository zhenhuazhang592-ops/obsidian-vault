# 联易方舟复刻版 · 漫舟CDP Agent

> **版本**：v1.0.0
> **日期**：2026-03-26
> **定位**：原封不动照搬联易方舟架构逻辑，输出完整项目文档
> **核心差异**：生图/生视频交给用户手动处理，最终输出为完整项目文档

---

## 一、架构总览

### 1.1 与联易方舟的对应关系

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          联易方舟复刻版（漫舟CDP Agent）                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  步骤 1: 全局设置（风格/画幅/模型/时长）                                    │
│     ↓                                                                    │
│  步骤 2: 故事脚本（导入小说 → CDP解析 → 提取角色/场景/物品）                  │
│     ↓                                                                    │
│  步骤 3: 角色/场景/物品（资产库管理）                                       │
│     ↓                                                                    │
│  步骤 4: 分镜脚本（编辑每镜头脚本 + 九宫格分镜）                             │
│     ↓                                                                    │
│  步骤 5: 分镜视频（生成Prompt输出，用户手动执行）                            │
│     ↓                                                                    │
│  步骤 6: 导出配置单（最终项目文档打包）                                     │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 1.2 核心数据模型

**CDP JSON** 是整个系统的唯一真实数据源：

```json
{
  "version": "1.0",
  "format": "comic_drama_package",
  "meta": { "runId", "append", "source" },
  "title": "短视频漫剧：XXX",
  "settings": { "targetPlatform", "aspectRatio", "stylePreset", "shotDurationSec" },
  "characters": [],
  "locations": [],
  "items": [],
  "shots": []
}
```

```
## 系统角色

你是一位顶尖的AI漫剧剧本改编专家，擅长将小说文本转化为短剧分镜脚本。
你的核心输出是CDP JSON格式（Comic Drama Package）。

## 输入

小说原文：[粘贴用户上传的小说文本]

## 任务

请将上述小说文本改编为短视频漫剧剧本，严格遵循以下约束：

### 基础约束

1. **时长**：每集2分钟，单镜头15秒 → 每集约8个镜头
2. **开场**：前5秒必须抓人（撞破/打脸/揭穿/威胁）
3. **台词**：口语化、短句、不超过15字
4. **结尾**：强钩子（新证据/新威胁/身份翻面/关键人物闯入）
5. **镜头目标**：开场抓人 → 冲突升级 → 结尾钩子

### CDP JSON输出格式

### 角色提取规则

1. 主角必须提取详细appearance和persona
2. 每个角色必须有aliases数组（包含剧中所有称呼）
3. 配角至少提取id/name/appearance
4. 群演不需要提取

### 场景提取规则

1. 每个新场景必须提取为locations数组项
2. 场景描述需包含：时间/空间/氛围/光线
3. props数组列出场景中的关键道具

### 镜头拆分规则

1. 每15秒一个镜头（durationSec=15）
2. 每个镜头必须有script（叙事描述）
3. 每个镜头必须有dialogue（对白）
4. 每个镜头必须有imagePrompt（生图Prompt）
5. 每个镜头必须有videoPrompt（视频Prompt）
6. 每个镜头必须有action三段式

### 质量自检

输出前请自检：
- [ ] 所有对白不超过15字
- [ ] 每镜有script/dialogue/imagePrompt/videoPrompt/action
- [ ] 角色ID引用正确（c_c1/c_c2...）
- [ ] 场景ID引用正确（l_l1/l_l2...）
- [ ] JSON格式正确，可被JSON.parse解析
