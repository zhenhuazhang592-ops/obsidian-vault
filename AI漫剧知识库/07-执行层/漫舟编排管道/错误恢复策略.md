# 漫舟错误恢复策略

> **定位**：Agent执行过程中的错误处理手册
> **原则**：自动可恢复的错误自动兜底，不可恢复的错误触发人工介入
> **适用范围**：Step 01 ~ Step 10 全流程
> **最后更新**：2026-03-26

---

## 错误分类体系

### E1: 可自动恢复（Auto-Retry）

| 错误类型 | 典型表现 | 处理策略 | 重试次数 | 退避策略 |
|---------|---------|---------|---------|---------|
| 网络超时 | `ConnectionTimeout` / `ReadTimeout` | 等待后重试 | 2次 | 10s → 30s |
| 临时断连 | `ConnectionReset` / `EOF` | 等待后重试 | 2次 | 5s → 15s |
| AI平台限流 | HTTP 429 | 等待后重试 | 3次 | 60s → 120s → 300s |
| 视频生成排队 | `queued` / `pending` 持续 | 继续轮询 | 18次（3分钟） | 每8s轮询一次 |
| 格式校验小偏差 | 字段缺失/多余 | 自动补全后重试 | 1次 | 无 |
| 下载失败 | `HTTP 502/503/504` | 等待后重试 | 3次 | 10s → 30s → 60s |

### E2: 需要参数调整（Adjust-Retry）

| 错误类型 | 原因 | 调整策略 | 重试次数 |
|---------|------|---------|---------|
| Prompt过长截断 | token超限 | 缩短Prompt至70%重试 | 1次 |
| 角色图风格偏差 | 外观描述不够精确 | 补充DNA外貌锁关键特征词重试 | 2次 |
| 视频运动过度 | motion参数过高 | 降低motion至0.5以下重试 | 2次 |
| 运镜未执行 | camera参数写法错误 | 对照运镜对应表修正格式重试 | 1次 |
| BGM情绪不搭 | 情绪标签错误 | 重新标注情绪类型重试 | 1次 |
| 场景图色调偏差 | 缺少色调/光线描述 | 补充场景档案光线/色调标签重试 | 1次 |
| TTS情感不足 | 情绪标签不够细化 | 加描述词如"压抑的愤怒"重试 | 1次 |
| 视频时长偏差 | duration参数不对 | 按分镜脚本时长重设参数重试 | 1次 |

### E3: 需要人工介入（Human-In）

| 错误类型 | 触发条件 | 处理策略 | 上报必填 |
|---------|---------|---------|---------|
| 角色外观描述歧义 | E2连续3次重试仍失败 | 暂停，输出具体歧义点，等待用户确认 | 是 |
| 视频内容违规被拒 | 平台返回违规/封号 | 修改Prompt去除敏感词重试1次，仍拒则上报 | 是 |
| 关键资产缺失 | 角色图/场景图全部生成失败 | 暂停，列出缺失资产，等待补充 | 是 |
| 用户主动中断 | 用户发送中断指令 | 写Checkpoint，停止所有操作 | 是 |
| 角色一致性彻底失败 | 同一角色连续5次风格不一致 | 暂停，输出当前最接近版本，等待用户选择 | 是 |
| 分镜脚本逻辑错误 | 分镜时长与剧本总时长严重不符（>20%） | 暂停，输出不符点，等待用户确认 | 是 |

### E4: 不可恢复（Abort）

| 错误类型 | 触发条件 | 处理策略 |
|---------|---------|---------|
| 无效输入 | 文件损坏/文本为空/文件不存在 | 立即终止并报告 |
| API Key无效 | HTTP 401/403 鉴权失败 | 立即终止并报告 |
| 账户额度耗尽 | HTTP 402 / 平台明确提示余额不足 | 立即终止并报告 |
| 模型不可用 | 平台返回 `model not available` | 切换模型，仍失败则终止并报告 |
| 输入文件格式错误 | 非JSON/非YAML格式无法解析 | 立即终止并报告 |
| 关键资产目录不存在 | Step 05 依赖的资产目录缺失 | 立即终止并报告 |

## 每步错误处理

### Step 01: 短剧改编

**失败条件**：
- LLM输出格式不符（无场次/无对白）
- 章节数 < 3
- 开场5秒无冲突
- 台词 > 15字

**常见错误**：

| 错误类型 | 原因 | 处理策略 | 重试次数 |
|---------|------|---------|---------|
| LLM超时 | 网络问题 | 等待10s重试 | 2次 |
| 输出格式不符 | Prompt不够明确 | 补充格式约束（场次/对白/动作用---分隔）重试 | 1次 |
| 章节数不足 | 小说太短 | 降低阈值至2章；或警告但继续执行 | — |
| 开场无冲突 | 小说开篇慢热 | 自动重排，从第一个冲突场景开始 | — |
| 台词超长 | 未执行剃刀法则 | 自动压缩至15字以内 | — |

**兜底逻辑**：

```python
def adapt_novel(novel_text):
    # 1. 字数预检
    word_count = len(novel_text)
    if word_count < 1000:
        warn("小说字数过少（<1000字），生成质量可能不佳")

    # 2. 生成适配稿
    result = llm_call(ADAPT_PROMPT.format(novel=novel_text))

    # 3. 格式校验
    if not validate_format(result):
        result = llm_call(ADAPT_PROMPT_WITH_FORMAT.format(
            novel=novel_text,
            constraints="输出格式：场次标题 | 场景描述 | 对白（≤15字） | 动作（≥25字）"
        ))

    # 4. 章节数兜底
    chapters = extract_chapters(result)
    if len(chapters) < 3:
        if word_count > 5000:
            warn("章节数<3但小说较长，将降低阈值至2章继续")
        else:
            abort("小说章节不足3章，建议补充内容后重试")

    # 5. 开场冲突兜底
    if not has_opening_conflict(result):
        result = rearrange_opening(result)
        if not has_opening_conflict(result):
            abort("无法生成有效开场冲突，请检查小说内容")

    return result
```

**Checkpoint字段**：
```yaml
step01:
  status: completed
  output: "01-IP档案/改编稿.md"
  chapters: 5
  characters: ["char_01", "char_02"]
```

|---------|------|---------|---------|
| YAML解析失败 | LLM输出格式错误 | 提取关键字段手动构建YAML | 1次 |
| 必填字段缺失 | Prompt不够明确 | 补充必填字段Prompt重试 | 1次 |
| 角色数量异常 | 小说角色过多/过少 | 按剧本重新统计并标注主次 | — |

**兜底逻辑**：

```python
def parse_ip_yaml(raw_yaml):
    try:
        ip_data = yaml.safe_load(raw_yaml)
        required_fields = ["标题", "类型", "核心冲突", "目标受众"]
        for field in required_fields:
            if field not in ip_data:
                ip_data[field] = llm_call(f"从以下内容提取{field}：{raw_yaml}")
        return ip_data
    except yaml.YAMLError:
        # YAML格式错误，尝试手动提取
        return extract_ip_manual(raw_yaml)
```

### Step 03: 剧本生成

**失败条件**：
- 剧本与改编稿核心情节不符
- 单集时长超出限制（>150秒/<60秒）

**常见错误**：

| 错误类型 | 原因 | 处理策略 | 重试次数 |
|---------|------|---------|---------|
| LLM超时 | 网络问题 | 等待10s重试 | 2次 |
| 情节与改编稿不符 | 忠实度不够 | 补充"必须保留的核心情节"约束重试 | 2次 |
| 单集时长超限 | 分镜估算错误 | 调整分镜数量或单镜时长重试 | 1次 |
| 情绪节奏平淡 | 每45秒无爽点 | 重新生成并标注情绪转折点 | 1次 |

**兜底逻辑**：

```python
def generate_script(adapted_text, ip_data):
    result = llm_call(SCRIPT_PROMPT.format(
        adapted=adapted_text,
        constraints="每45秒一个情绪转折点，每句台词≤15字，无内心独白"
    ))

    # 时长校验
    estimated_duration = estimate_duration(result)
    if estimated_duration > 150:
        warn(f"预计时长{estimated_duration}秒超出限制，将调整分镜数量")
        result = split_into_more_episodes(result)
    elif estimated_duration < 60:
        warn(f"预计时长{estimated_duration}秒过短，考虑合并集数")

    return result
```

```python
def generate_character_image(char_dna, char_refs=None):
```

```python
def generate_shot_script(script, assets):
    result = llm_call(SHOT_SCRIPT_PROMPT.format(
        script=script,
        characters=assets["characters"],
        scenes=assets["scenes"]
    ))

    # 时长校验
    total_duration = sum(shot["duration"] for shot in result["shots"])
    expected_duration = script["expected_duration"]

    if abs(total_duration - expected_duration) / expected_duration > 0.2:
        warn(f"分镜总时长{total_duration}秒与预期{expected_duration}秒偏差>20%")
        result = adjust_shot_durations(result, expected_duration)

    return result
```

```python
def generate_image(prompt, char_ref_urls=None):
    MAX_POLL_ATTEMPTS = 18  # 3分钟
    POLL_INTERVAL = 8  # 秒

    # Step 1: 创建会话
    session = create_session(prompt, char_ref_urls)
    last_seq = 0

    for attempt in range(MAX_POLL_ATTEMPTS):
        time.sleep(POLL_INTERVAL)

        # Step 2: 轮询结果
        result = query_session(session["sessionId"], after_seq=last_seq)
```

### Step 08: 视频生成

**失败条件**：
- 视频生成超时（10分钟无结果）
- 连续3次质量评分 < 0.6
- 角色外观完全走形

**常见错误**：

| 错误类型 | 原因 | 处理策略 | 重试次数 |
|---------|------|---------|---------|
| 视频生成超时 | 平台繁忙 | 等待30s轮询 | 20次（30s间隔） |
| 429限流 | 请求过快 | 等待60s重试 | 3次 |
| 视频质量差（运动过度） | motion参数过高 | 降低motion至0.3重试 | 2次 |
| 视频质量差（风格偏差） | Prompt描述不够精确 | 补充运镜/情绪描述重试 | 2次 |
| 视频内容违规 | 敏感内容 | 修改Prompt去除敏感词重试 | 1次 |
| 运镜没有执行 | camera参数写法错误 | 对照运镜对应表修正格式重试 | 1次 |
| 角色走形 | 参考图模式选择错误 | 改用首尾帧模式或单图模式重试 | 2次 |

**兜底逻辑**：

```python
# 来自 LibTV 轮询策略 + 火宝视频生成服务
def generate_video(video_prompt, image_url=None, reference_mode="single"):
    MAX_RETRIES = 3
    RETRY_DELAYS = [10, 30, 60]  # 秒
    MAX_POLL_ATTEMPTS = 20  # 最多轮询20次（30s间隔=10分钟）
    POLL_INTERVAL = 30  # 秒

    for attempt in range(MAX_RETRIES):
        try:
            # Step 1: 创建生成任务
            session = create_session(video_prompt, image_url)
            last_seq = 0

            # Step 2: 轮询结果
            for poll_attempt in range(MAX_POLL_ATTEMPTS):
                time.sleep(POLL_INTERVAL)
                result = query_session(session["sessionId"], after_seq=last_seq)

                if result.get("status") == "completed":
                    # 质量评分
                    quality_score = score_video(result["video_url"])
                    if quality_score >= 0.7:
                        return download_results(session["sessionId"])
                    else:
                        # 质量不达标 → 参数调整重试
                        adjusted_prompt = reduce_motion(video_prompt)
                        break  # 跳出poll，进入外层retry

                last_seq = result.get("max_seq", last_seq)

            # poll超时或质量不达标，进入外层retry
            adjusted_prompt = reduce_motion(video_prompt) if attempt == 0 else \
                              enhance_prompt_precision(video_prompt) if attempt == 1 else \
                              video_prompt
            video_prompt = adjusted_prompt

        except RateLimitError:
            sleep(RETRY_DELAYS[attempt])
        except QualityError:
            adjusted_prompt = reduce_motion(video_prompt)
            retry(adjusted_prompt)
        except ContentViolationError:
            sanitized_prompt = remove_sensitive_terms(video_prompt)
            retry(sanitized_prompt)

    # 全部重试失败 → E3人工介入
    trigger_human_review(
        step="step08",
        prompt=video_prompt,
        error_log=error_log,
        session_id=session.get("sessionId")
    )
```

**质量评分标准**：

| 评分区间 | 判定 | 处理 |
|---------|------|------|
| >= 0.8 | 优秀 | 直接使用 |
| 0.7-0.8 | 合格 | 可用，建议检查 |
| 0.6-0.7 | 勉强 | 降级使用（降低期待） |
| < 0.6 | 不合格 | 必须重试或人工介入 |

```yaml
      duration: 8
      quality_score: 0.85
    shot_02: ...
```

### Step 09: 音频制作

**失败条件**：
- TTS音色与角色不匹配
- 音频时长与分镜时长偏差 > 20%

**常见错误**：

| 错误类型 | 原因 | 处理策略 | 重试次数 |
|---------|------|---------|---------|
| TTS超时 | API问题 | 重试 | 2次 |
| TTS口型不匹配 | 音频时长偏差 | 调整语速重录 | 1次 |
| 角色音色混淆 | 多角色音色未区分 | 重新指定音色参数（声线/语速）重录 | 1次 |
| BGM情绪不符 | 情绪标注错误 | 重新生成情绪曲线标注，重生BGM | 2次 |
| SFX时间点错位 | 与视频事件不对齐 | 手动调整SFX时间点 | — |
| 音频文件损坏 | 生成/下载过程损坏 | 重新生成 | 2次 |
| 三轨音量比例失衡 | 混音参数错误 | 按语音> BGM > SFX比例重新混音 | 1次 |

**兜底逻辑**：

```python
def generate_tts(dialogue_text, voice_params):
    try:
        audio_data = tts_api.call(
            text=dialogue_text,
            voice=voice_params["音色"],
            speed=voice_params["语速"],
            emotion=voice_params["情绪"]
        )

        # 时长校验
        expected_duration = calculate_expected_duration(dialogue_text, voice_params["语速"])
        actual_duration = audio_data.duration

        if abs(actual_duration - expected_duration) / expected_duration > 0.2:
            warn(f"TTS时长偏差{abs(actual_duration-expected_duration):.1f}秒，重新调整语速")
            adjusted_speed = adjust_speed(voice_params["语速"], expected_duration, actual_duration)
            return generate_tts(dialogue_text, {**voice_params, "语速": adjusted_speed})

        return audio_data

    except TTSApiError:
        return retry_generate_tts(dialogue_text, voice_params)
```

### Step 10: 导出剪辑

**失败条件**：
- 视频片段缺失
- 音频与视频时长不匹配（>10%偏差）
- 导出文件损坏

**常见错误**：

| 错误类型 | 原因 | 处理策略 | 重试次数 |
|---------|------|---------|---------|
| FFmpeg执行失败 | 命令行错误/文件损坏 | 检查FFmpeg安装，验证输入文件 | 2次 |
| 视频片段缺失 | Step 08部分失败 | 回退到Step 08，补生成缺失镜头 | — |
| 音频时长不匹配 | 视频总时长与音频总时长偏差>10% | 调整音频播放速度对齐，或截断超出部分 | 1次 |
| 字幕时间点错位 | SRT格式错误 | 重新从TTS标注提取对白生成SRT | 1次 |
| 导出文件损坏 | 编码问题 | 更换编码格式（H.264→H.265）重试 | 1次 |
| 色调不统一 | 各片段来源不同 | 应用统一LUT调色 | — |
| 拼接处跳帧 | 相邻片段帧率不一致 | 统一转换为30fps后拼接 | — |

**兜底逻辑**：

```python
# 来自火宝短剧 FFmpeg 错误处理
def export_episode(shots, audio, output_path):
    # 1. 素材校验
    for shot in shots:
        if not os.path.exists(shot["local_path"]):
            abort(f"视频片段缺失：{shot['shot_id']}，请回退到Step 08补生成")

    # 2. 计算总时长
    video_duration = sum(get_video_duration(shot["local_path"]) for shot in shots)
    audio_duration = get_audio_duration(audio["tts_path"])

    # 3. 时长对齐
    if abs(video_duration - audio_duration) / audio_duration > 0.1:
        warn(f"视频总时长{video_duration:.1f}s与音频{audio_duration:.1f}s偏差>10%，调整音频")
        # 方案A：调整音频播放速度
        adjust_audio_speed(audio["tts_path"], target_duration=video_duration)
        # 方案B：截断超出部分（保守策略）
        # trim_audio(audio["tts_path"], video_duration)

    # 4. FFmpeg合成
    try:
        ffmpeg.merge_with_xfade(
            input_paths=[shot["local_path"] for shot in shots],
            audio_path=audio["tts_path"],
            bgm_path=audio["bgm_path"],
            sfx_path=audio["sfx_path"],
            output_path=output_path
        )
    except FFmpegError as e:
        # 尝试简单拼接（无转场）
        warn(f"转场合并失败，尝试简单拼接：{e}")
        ffmpeg.concatenate_videos(
            input_paths=[shot["local_path"] for shot in shots],
            output_path=output_path
        )
        # 单独混音
        ffmpeg.mix_audio(
            video_path=output_path,
            audio_path=audio["tts_path"],
            output_path=output_path
        )

    # 5. 导出校验
    exported_duration = get_video_duration(output_path)
    if abs(exported_duration - video_duration) / video_duration > 0.05:
        abort(f"导出文件损坏：时长{exported_duration:.1f}s与预期{video_duration:.1f}s不符")

    return output_path
```

### 断点恢复（Checkpoint）

```python
CHECKPOINT_FILE = "logs/checkpoints/{project_id}.yaml"

def write_checkpoint(project_id, step, data):
    checkpoint = {
        "project_id": project_id,
        "last_completed_step": step,
        "last_updated": datetime.now().isoformat(),
        "step_data": data
    }
    try:
        with open(CHECKPOINT_FILE.format(project_id=project_id), "w") as f:
            yaml.dump(checkpoint, f)
    except IOError:
        # 降级：尝试写入本地备份
        backup_path = f"logs/checkpoints/{project_id}.yaml.bak"
        with open(backup_path, "w") as f:
            yaml.dump(checkpoint, f)
        warn(f"主Checkpoint写入失败，已备份到{backup_path}")

def resume_from_checkpoint(project_id):
    checkpoint_path = CHECKPOINT_FILE.format(project_id=project_id)

    # 优先读主文件，失败则读备份
    for path in [checkpoint_path, checkpoint_path + ".bak"]:
        try:
            with open(path) as f:
                checkpoint = yaml.safe_load(f)
            return checkpoint["last_completed_step"], checkpoint["step_data"]
        except FileNotFoundError:
            continue

    # 无checkpoint → 从Step 01开始
    warn(f"未找到checkpoint，从Step 01开始")
    return None, None

# Agent启动时自动恢复
last_step, step_data = resume_from_checkpoint(project_id)
if last_step is not None:
    log(f"从{last_step}恢复，上次数据：{step_data}")
    proceed_to_next_step(last_step)
```
