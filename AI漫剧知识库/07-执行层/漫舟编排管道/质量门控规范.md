# 漫舟质量门控规范

> 定位：每步输出的质量门控，判断是否通过、可重试或需人工介入
> 来源：参考 prompts.chat AI质量检查机制 + NanoPhoto质量维度 + 漫舟效果追踪评分体系
> 版本：v1.0.0
> 制定时间：2026-03-26

---

## 1. 质量评分体系

### 五维评分（质量门控用）

| 维度 | 名称 | 分值范围 | 计算方式 | 权重 |
|------|------|---------|---------|------|
| D1 | 完整性 | 0-1 | 必需字段完整率（prompts.chat: min_chars≥50, min_words≥10） | 0.20 |
| D2 | 一致性 | 0-1 | 角色/场景/风格跨Step一致性（NanoPhoto Persist） | 0.25 |
| D3 | 指令合规 | 0-1 | 运镜/情感/风格符合导演约束 | 0.25 |
| D4 | 生成质量 | 0-1 | 视觉/音频/视频AI生成质量（NanoPhoto 16维度） | 0.20 |
| D5 | 用户满意度 | 0-1 | 人工标注或行为数据（观看时长/完成率/重播次数） | 0.10 |

**综合评分公式**：
```
综合评分 = D1×0.2 + D2×0.25 + D3×0.25 + D4×0.2 + D5×0.1
```

### 五维评分（效果追踪用 — 与门控五维对应）

| 追踪维度 | 对应门控 | 权重 | 说明 |
|---------|---------|------|------|
| T1 角色一致性 | D2一致性 | 0.30 | 角色外貌与DNA是否一致（NanoPhoto Persist） |
| T2 场景还原度 | D3指令合规 | 0.20 | 场景氛围是否符合剧本设定 |
| T3 运镜执行度 | D3指令合规 | 0.20 | 运镜指令是否准确执行 |
| T4 情感传递度 | D3指令合规 | 0.15 | 情绪是否有效传递给观众 |
| T5 技术质量 | D4生成质量 | 0.15 | 清晰度/无畸形/无穿帮 |

```
效果追踪综合分 = T1×0.3 + T2×0.2 + T3×0.2 + T4×0.15 + T5×0.15
```

### 评分等级

| 评分区间 | 含义 | 行动 |
|---------|------|------|
| 0.80 - 1.00 | 优秀，无需修改 | 入库为"成功Prompt" |
| 0.70 - 0.79 | 合格，轻微调整可用 | 微调后使用 |
| 0.60 - 0.69 | 一般，需要优化 | 记录失败原因，触发优化 |
| 0.00 - 0.59 | 失败，不能使用 | 入库失败日志，触发进化 |

**最低红线**：任何维度 < 0.50 → **立即停止并报警**

## 2. 每步质量门控阈值

### prompts.chat 基础质量检查常量

```typescript
const MANZHOU_QUALITY_THRESHOLDS = {
  min_chars: 50,              // 单个镜头描述最小字符数
  min_words: 10,               // 单个镜头描述最小词数
  min_shot_duration: 2,        // 最小镜头时长（秒）
  max_shot_duration: 15,       // 最大镜头时长（秒）
  ai_confidence_threshold: 0.85,   // AI置信度阈值（prompts.chat基准）
  viseme_match_threshold: 0.90,    // 口型匹配阈值
  lip_sync_precision: 0.90,       // Lip-sync精确度
  camera_transition_min: 0.5,      // 镜头间最小转场时长（秒）
};
```

---

### Step 3：剧本生成

| 指标 | 阈值 | 不达标处理 |
|------|------|---------|
| 场景数 | ≥ 5 | 补充场景 |
| 对话完整性（D1） | ≥ 0.80 | 补全缺失对话 |
| 冲突强度（D3） | ≥ 0.60 | 强化冲突描写 |
| 角色出场覆盖 | ≥ 0.75 | 补充角色戏份 |
| 综合评分 | ≥ 0.70 | 人工审核 |

**检查逻辑**：
```
- 场景数 < 5 → 返回"场景数不足，请补充至少N个场景"
- 对话缺失率 > 20% → 标记缺失段落，要求补全
- 无冲突点 → 增加冲突事件（争吵/抉择/危机）
```

---

### Step 4：导演控制塔

| 指标 | 阈值 | 不达标处理 |
|------|------|---------|
| 节拍数 | 与剧本节拍一致 | 对齐剧本节拍 |
| 情绪曲线完整性（D3） | ≥ 0.80 | 补充情感峰值镜头 |
| 轴线约束覆盖率 | ≥ 0.85 | 补充轴线说明 |
| 运镜指令明确度 | ≥ 0.80 | 量化运镜参数 |
| 综合评分 | ≥ 0.70 | 人工审核 |

**检查逻辑**：
```
- 节拍数不匹配 → 重新对齐剧本节拍表
- 情绪曲线无峰值 → 插入高潮/转折镜头
- 轴线说明缺失 → 补充180度轴线规则
```

---

### Step 5：资产库构建（角色参考图）

| 指标 | 阈值 | 不达标处理 |
|------|------|---------|
| 角色相似度（D2） | ≥ 0.75 | 补充参考图+重绘 |
| 风格一致性（D2） | ≥ 0.80 | 统一风格参数 |
| 服装道具准确性（D1） | ≥ 0.70 | 调整描述重绘 |
| 视角覆盖（正面/侧面/背面） | 每角色≥3视角 | 补充缺失视角 |
| 综合评分 | ≥ 0.70 | 人工确认 |

**检查逻辑**：
```
- 相似度 < 0.75 → 提供3张不同角度参考图，要求重绘
- 风格不一致 → 提取统一风格关键词，统一重绘
- 视角缺失 → 补充缺失视角的角色图
```

---

### Step 7：分镜脚本

| 指标 | 阈值 | 不达标处理 |
|------|------|---------|
| 镜头数匹配 | 时长/8秒（±1） | 调整镜头数 |
| 运镜合规（D3） | ≥ 0.85 | 修正运镜描述 |
| 情感曲线峰值（D3） | 需有峰值 | 补充情感峰值镜头 |
| 口型标注覆盖率（D1） | ≥ 0.90 | 补全viseme标注 |
| Lip-sync精确度 | ≥ 0.90（viseme_match_threshold） | 逐字修正口型序列 |
| 时长合规（单镜） | 2-15秒 | 调整单镜时长 |
| 综合评分 | ≥ 0.75 | 人工审核 |

**检查逻辑**：
```
- 镜头数偏差 > 1 → 按每镜8秒重新分配
- 运镜描述模糊 → 量化运镜参数（推进速度/角度变化）
- 无情感峰值 → 插入高潮镜头（D4级情绪）
- 口型标注缺失 → 逐字生成viseme序列
```

---

### Step 8：视频生成（LibTV执行层）

| 指标 | 阈值 | 不达标处理 |
|------|------|---------|
| 动作自然度（D4） | ≥ 0.70 | 降低motion参数重生成 |
| 角色一致性（D2） | ≥ 0.80 | 更换参考图重生成 |
| 运镜符合度（D3） | ≥ 0.80 | 调整运镜参数重生成 |
| 无违禁内容 | = 1.00（零容忍） | 修改Prompt重生成，立即停止 |
| Lip-sync匹配度 | ≥ 0.85 | 调整音素对齐参数 |
| 画面质量（D4） | ≥ 0.70 | 调整Seedance/Kling参数 |
| 综合评分 | ≥ 0.70 | 人工审核 |

**违禁内容零容忍清单**：
- 色情/低俗内容
- 暴力/血腥画面
- 政治/宗教敏感内容
- 版权侵权内容（未授权IP）

## 3. 自动触发机制

### 触发时机

```
每Step完成后 → 立即计算评分 → 评分 < 阈值？──是──→ 触发重试或人工介入
                                                          ↓ 否
                                                    通过，进入下一步
```

### 触发流程（决策树）

```
Step完成
    ↓
计算五维评分（D1-D5）
    ↓
综合评分 ≥ 阈值？
    ├── 是 → 通过，进入下一步
    │
    └── 否 → 各维度逐一检查
                ↓
        哪维度最低？
                ↓
        可自动调整？
        ├── 是 → 自动调整参数 + 重试（最多2次）
        │
        └── 否 → 人工介入
                    ↓
            用户确认/修改 → 继续
```

### prompts.chat 式质量检查代码

```typescript
const MANZHOU_QUALITY_CHECKER = {
  // 基础格式检查
  checkFormat(shot: ShotDescriptor): FormatResult {
    const chars = shot.description.length;
    const words = shot.description.split(/\s+/).length;

    if (chars < this.thresholds.min_chars) {
      return { pass: false, reason: `描述过短（${chars}字符，需要≥${this.thresholds.min_chars}）` };
    }
    if (words < this.thresholds.min_words) {
      return { pass: false, reason: `描述过短（${words}词，需要≥${this.thresholds.min_words}）` };
    }
    if (shot.duration < this.thresholds.min_shot_duration) {
      return { pass: false, reason: `镜头时长不足（${shot.duration}秒，需要≥${this.thresholds.min_shot_duration}秒）` };
    }
    if (shot.duration > this.thresholds.max_shot_duration) {
      return { pass: false, reason: `镜头时长超限（${shot.duration}秒，需要≤${this.thresholds.max_shot_duration}秒）` };
    }
    return { pass: true };
  },

  // AI置信度检查
  checkAIConfidence(shot: ShotDescriptor, confidence: number): boolean {
    return confidence >= this.thresholds.ai_confidence_threshold; // 0.85
  },

  // 口型匹配检查
  checkLipSync(shot: ShotDescriptor, matchScore: number): boolean {
    return matchScore >= this.thresholds.viseme_match_threshold; // 0.90
  },
};
```

### 重试策略

| 失败类型 | 自动重试次数 | 重试策略 |
|---------|------------|---------|
| 格式错误 | 1次 | 自动修正后重试 |
| 质量不达标（单项） | 2次 | 调整最低维度参数后重试 |
| 质量不达标（综合） | 2次 | 全面调整参数后重试 |
| 违禁内容 | 0次 | **立即停止，人工介入** |
| 连续2次仍不达标 | 0次 | 强制人工介入 |

## 4. 人工介入触发条件

### 必触发（强制人工介入）

| 条件 | 原因 | 处理方式 |
|------|------|---------|
| 连续2次自动重试仍不达标 | 自动修复已达上限 | 人工分析根因，手动修正 |
| 违禁内容检测 | 零容忍风险 | 删除内容，修改Prompt，重新生成 |
| 角色外观严重偏离描述 | 角色一致性崩溃 | 重新生成角色参考图，人工确认 |
| 音频/视频技术崩溃 | 工具层异常 | 记录错误日志，联系技术支持 |
| 场景还原度 < 0.50 | 场景一致性崩溃 | 重新生成场景，人工审核 |

### 可选触发（建议人工介入）

| 条件 | 原因 | 处理方式 |
|------|------|---------|
| 特殊风格要求 | 王家卫/诺兰/维伦纽瓦等 | 人工风格审核 |
| 高价值项目（VIP标记） | 质量要求更高 | 降低阈值10%，人工审核 |
| 评分在阈值边缘（0.65-0.70） | 风险区域 | 人工决定是否继续 |
| 用户主动要求审核 | 人工确认需求 | 按需进行 |
| 新场景类型首次生成 | 无参考基准 | 人工建立质量基准 |

## 5. 效果追踪数据模型

### 镜头事件接口

```typescript
interface ShotEvent {
  // 基础信息
  project_id: string;      // 项目ID
  episode_id: string;       // 集数ID
  shot_id: string;          // 镜头ID（EP01-P03格式）
  step: number;            // 产生该数据的Step编号

  // 五维质量评分（门控用）
  completeness_score: number;       // D1 完整性 (0-1)
  consistency_score: number;         // D2 一致性 (0-1)
  instruction_compliance: number;   // D3 指令合规 (0-1)
  generation_quality: number;       // D4 生成质量 (0-1)
  user_satisfaction: number;         // D5 用户满意度 (0-1)
  composite_score: number;            // 综合评分

  // 效果追踪维度（追踪用）
  dimensions: {
    character_consistency: number;   // T1 角色一致性
    scene_reconstruction: number;   // T2 场景还原度
    camera_execution: number;        // T3 运镜执行度
    emotion_transfer: number;        // T4 情感传递度
    technical_quality: number;       // T5 技术质量
  };

  // 行为数据（上线后采集）
  behavior: {
    watch_duration: number;          // 用户观看时长（秒）
    completion_rate: number;          // 完成率（0-1）
    replay_count: number;             // 重播次数
    drop_off_shot: string;           // 流失镜头ID
    like_count: number;               // 点赞数
    share_count: number;              // 分享数
  };

  // Lip-sync专项
  lip_sync: {
    match_score: number;             // 口型匹配分（0-1）
    viseme_accuracy: number;         // Viseme精确度（0-1）
    sync_offset_ms: number;          // 音画同步偏移（毫秒）
  };

  // 质量门控记录
  gate: {
    gate_passed: boolean;             // 是否通过门控
    gate_failed_dimensions: string[]; // 未达标维度列表
    retry_count: number;              // 重试次数
    human_intervention: boolean;      // 是否人工介入
    intervention_reason: string;      // 人工介入原因
  };

  // 技术信息
  tool: string;                      // 生成工具（Seedance/Kling/LibTV）
  video_prompt: string;              // 使用的Prompt文本
  created_at: string;                 // ISO时间戳
  notes: string;                     // 备注（失败原因/改进建议）
}
```

## 6. 评分仪表盘

### 最低质量红线

```
任何维度 < 0.50 → 立即停止并报警（红色警报）
综合评分 < 0.60 → 强制人工介入
```

### 项目健康度

```
项目健康度 = 所有镜头的平均综合评分

≥ 0.80：优秀（绿色）  → 自动流程
0.70 - 0.79：合格（黄色） → 轻微调整
0.60 - 0.69：需干预（橙色） → 人工审核
< 0.60：危险（红色）  → 立即停止
```

### 质量趋势预警

```
连续3个镜头评分下降 → 触发质量预警

预警级别：
- 黄牌：下降 < 0.05 → 自动记录，持续监控
- 橙牌：下降 0.05-0.10 → 人工审查最近3个镜头
- 红牌：下降 > 0.10 → 立即停止，排查根因
```

## 7. 与效果追踪的联动

### 进化触发条件

| 条件 | 触发动作 |
|------|---------|
| 同场景类型 ≥ 5个评分数据 | 启动聚类分析，提炼场景模板 |
| 新Prompt验证 ≥ 3次且成功率 ≥ 0.70 | 入库为"已验证模板" |
| 新Prompt连续3次失败 | 自动回滚到父模板，触发进化 |
| 违禁内容出现 | 立即停止，回滚所有相关版本 |

### Prompt进化数据流

```
每次视频生成
    ↓
填写ShotEvent（D1-D5 + T1-T5）
    ↓
存入效果追踪数据库
    ↓
累计≥5条同类数据 → 聚类分析
    ↓
成功率≥70% → 入库成功Prompt库
    ↓
成功率<40% → 标记为失败，进化触发
```
