## 脚本详解

### 1. `_common.py` — API公共模块

```python
# 关键函数
api_post(path, body)       # POST请求
api_get(path)              # GET请求
create_session(session_id, message)  # 创建会话
query_session(session_id, after_seq) # 查询会话
build_project_url(project_id)         # 拼接画布URL
```

```python
# 环境变量
LIBTV_ACCESS_KEY          # 必填，Bearer鉴权
OPENAPI_IM_BASE / IM_BASE_URL  # 可选，默认 https://im.liblib.tv
```

---

### 2. `create_session.py` — 创建会话+发消息

**功能**：创建新会话，或向已有会话发送消息（生图/生视频）

```bash
# 创建新会话并发送消息
python3 create_session.py "生一个动漫视频"

# 向已有会话追加消息
python3 create_session.py "再生成一张风景图" --session-id SESSION_ID

# 只创建/绑定会话，不发消息
python3 create_session.py
```

**返回**：
```json
{
  "projectUuid": "aa3ba04c5044477cb7a00a9e5bf3b4d0",
  "sessionId": "90f05e0c-...",
  "projectUrl": "https://www.liblib.tv/canvas?projectId=aa3ba04c5044477cb7a00a9e5bf3b4d0"
}
```

---

### 3. `query_session.py` — 轮询会话状态

**功能**：查询会话消息列表，用于轮询生图/生视频结果

```bash
# 查询完整消息列表
python3 query_session.py SESSION_ID

# 增量拉取（只返回 seq > N 的消息）
python3 query_session.py SESSION_ID --after-seq 5

# 附带项目地址（方便展示）
python3 query_session.py SESSION_ID --project-id PROJECT_UUID
```

**返回**：
```json
{
  "messages": [
    {"id": "msg-xxx", "role": "user", "content": "生一个动漫视频"},
    {"id": "msg-yyy", "role": "assistant", "content": "..."},
    {"id": "msg-zzz", "role": "tool", "content": "{\"task_result\": {\"videos\": [...]}"}
  ],
  "projectUrl": "https://www.liblib.tv/canvas?projectId=..."
}
```

---

### 4. `upload_file.py` — 上传文件到OSS

**功能**：上传本地图片/视频，返回OSS地址（编辑/参考时需要）

```bash
# 上传图片
python3 upload_file.py /path/to/image.png

# 上传视频
python3 upload_file.py /path/to/video.mp4
```

**限制**：
- 仅支持 `image/*` 和 `video/*`
- 文件大小 ≤ 200MB

**返回**：
```json
{
  "url": "https://libtv-res.liblib.art/claw/{projectUuid}/{uuid}.png"
}
```

---

### 5. `download_results.py` — 下载生成结果

**功能**：从会话中提取图片/视频URL，批量下载到本地

```bash
# 从会话自动提取并下载所有结果
python3 download_results.py SESSION_ID

# 指定输出目录
python3 download_results.py SESSION_ID --output-dir ~/Desktop/项目名

# 指定文件名前缀（自动编号）
python3 download_results.py SESSION_ID --prefix "ep01_shot"

# 直接下载指定URL列表
python3 download_results.py --urls URL1 URL2 URL3 --output-dir ./output

# 调整并行线程数
python3 download_results.py SESSION_ID --workers 10
```

**URL提取逻辑**：
- 从 `role: tool` 的消息中解析 `task_result.images/videos`
- 从 `role: assistant` 的文本中用正则提取 `https://libtv-res.liblib.art/...`

**返回**：
```json
{
  "output_dir": "/Users/xxx/Downloads/libtv_results",
  "downloaded": ["/Users/xxx/Downloads/libtv_results/ep01_shot_01.png", "..."],
  "total": 9,
  "errors": [{"file": "...", "error": "..."}]  // 下载失败时
}
```

## 典型工作流（4个场景）

### 场景A：生成图片/视频（最常见）

```bash
# Step 1: 创建会话 + 发送Prompt
python3 create_session.py "生成15镜分镜图" --session-id ""

# 拿到 sessionId + projectUuid
# {"sessionId": "xxx", "projectUuid": "yyy", "projectUrl": "https://..."}

# Step 2: 轮询（每8秒一次）
python3 query_session.py SESSION_ID --after-seq 0
# 检查 messages 中是否有 assistant 回复含 URL

# Step 3: 下载结果
python3 download_results.py SESSION_ID --output-dir ./ep01 --prefix "shot"
```

### 场景B：上传参考图后生成

```bash
# Step 1: 上传参考图
python3 upload_file.py ./character_ref.png
# 拿到 oss_url

# Step 2: 发送消息 + 参考URL
python3 create_session.py "根据参考图生成角色九宫格，参考图：{oss_url}"

# Step 3: 轮询 + 下载
```

### 场景C：编辑已有内容

```bash
# Step 1: 上传原视频
python3 upload_file.py ./original.mp4

# Step 2: 发送编辑指令
python3 create_session.py "把四周的纸船都换成白色爱心，参考视频：{oss_url}"

# Step 3: 轮询 + 下载
```

### 场景D：在已有会话中追加新任务

```bash
python3 create_session.py "再生成5张背景图" --session-id SESSION_ID
# 复用已有会话（保持上下文）
```

---

## 轮询策略（关键）

```
间隔：每 8 秒查询一次
增量拉取：首次用 --after-seq 0，后续用上次最大 seq
完成判断：messages 中出现 assistant 消息含图片/视频 URL
超时：连续 3 分钟无结果 → 告知用户可去画布查看
错误重试：单次失败重试1次，连续3次失败停止
```

## SKILL.md 核心原则（来自官方）

> **用户侧不做创作，只做传话**

- ✅ 上传：用户给本地文件 → `upload_file.py` 拿 OSS URL
- ✅ 传话：把用户描述原封不动发给 `create_session.py`
- ✅ 取件：轮询 → 下载 → 展示
- ❌ 不要替用户扩写/润色/翻译 Prompt
- ❌ 不要自行拆解任务步骤
- ❌ 不要自己编分镜描述再逐条发
