# 漫舟CDP Agent · 交互式脚本使用说明

## 概述

`cdp_doc_generator_interactive.py` 是完整复刻联易方舟六步流程的交互式脚本，每一步都与用户确认。

## 快速开始

```bash
cd /Users/huage/Obsidian\ Vault/AI漫剧知识库/07-执行层
python3 cdp_doc_generator_interactive.py
```

## 两种使用模式

### 模式1：全自动（使用已有CDP JSON）

```bash
# 先准备好CDP JSON文件，然后运行
python3 cdp_doc_generator_interactive.py
# 在步骤2选择"1. 导入CDP JSON文件"
# 输入CDP JSON文件路径
# 后续步骤直接确认即可
```

### 模式2：半自动（手动创建项目）

```bash
# 步骤1: 运行脚本，配置项目信息
python3 cdp_doc_generator_interactive.py
# 步骤2: 选择"3. 手动输入剧本内容"
# 步骤3-6: 确认或调整
```

## 与联易方舟的对应关系

| 联易方舟 | 漫舟CDP Agent | 交互内容 |
|---------|---------------|---------|
| 步骤1: 全局设置 | 步骤1: 全局设置 | 风格/画幅/平台/时长 |
| 步骤2: 故事脚本 | 步骤2: 故事脚本 | 导入CDP JSON或手动输入 |
| 步骤3: 资产库 | 步骤3: 资产库 | 查看资产/选择生成工具 |
| 步骤4: 分镜脚本 | 步骤4: 分镜脚本 | 编辑镜头/生成九宫格 |
| 步骤5: 分镜视频 | 步骤5: 分镜视频 | 选择模型/创作模式 |
| 步骤6: 导出 | 步骤6: 导出配置单 | 输出目录/导出内容 |

## 与非交互式的区别

| 功能 | cdp_doc_generator.py | cdp_doc_generator_interactive.py |
|------|----------------------|--------------------------------|
| 交互 | 无，纯自动 | 6步交互确认 |
| 输入 | 需要CDP JSON文件 | 支持手动创建 |
| 编辑 | 不可编辑 | 可编辑镜头/配置 |
| 确认 | 无确认 | 每步确认/跳过 |
| 适用 | 已有CDP JSON | 从零开始项目 |
