## 核心功能

| 功能 | 说明 |
|------|------|
| 镜头检测 | 内容感知镜头边界检测（ContentDetector） |
| 自适应检测 | 双通道版本，处理快速摄像机运动（AdaptiveDetector） |

| 帧保存 | 保存每个镜头的关键帧图像 |

## 快速使用

### 命令行

```bash
# 检测镜头并分割视频
scenedetect -i video.mp4 split-video

# 保存关键帧
scenedetect -i video.mp4 save-images

# 跳过前10秒
scenedetect -i video.mp4 time -s 10s
```

### Python API

```python
from scenedetect import detect, ContentDetector

# 内容感知检测
scene_list = detect('my_video.mp4', ContentDetector())

# 打印结果
for i, scene in enumerate(scene_list):
    print(f'Scene {i+1}: {scene[0].get_timecode()} / {scene[1].get_timecode()}')
```

## 对漫舟的价值

漫舟当前分镜由人工设计/Claude生成，PySceneDetect可用于：

1. **竞品分析自动化**：自动拆分对标短剧的镜头，用于学习节奏
2. **参考视频提取**：从参考视频中提取关键帧作为风格参考
3. **成品分析**：分析生成视频的镜头时长分布

**集成建议**：作为漫舟 `Step 04.5 导演控制塔` 的辅助工具，输入参考视频 → 输出镜头列表 → 自动生成导演指令
