## 自研分镜Prompt维度（可直接复用）

```
必含维度：
1.  镜头边界检测（时间点+时长）
2.  分镜描述（中文，主体+动作+表情）
3.  景别（ELS/LS/MS/MCU/CU/ECU）
4.  相机角度（平/俯/仰/过肩/Dutch）
5.  运镜方式（固定/推进/拉远/跟踪/摇镜）
6.  构图（主体位置）
7.  光影风格（5灯系统：key/rim/fill/kicker/neg）
8.  调色（Grade: S-curve/bloom/vignette/grain）
9.  景深（浅/深）
10. 焦段感（35mm/50mm/85mm）
11. 角色一致性标注（Persist）
12. 台词（带时间戳）
13. 音效Cue（精确到0.1s）
14. BGM（风格+BPM）
15. 转场（CUT/FADE）
16. 视频结构（montage/long-take等10种）
```

## 集成建议

### 方案A: 自建一键拉片Agent

**输入**: 抖音/快手视频URL
**输出**: 结构化分镜脚本（兼容漫舟Step 7格式）

**技术路径**:
1. 视频下载（yt-dlp）
2. 帧提取（FFmpeg）
3. 镜头检测（PySceneDetect，已在知识库）
4. 画面描述（Gemini/OpenAI Vision）
5. 分镜格式化（LLM）

### 方案B: 集成TapNow

**输入**: 视频 → TapNow拉片 → 导出分镜 → 漫舟执行
**优势**: 不用自建
**劣势**: 依赖外部服务、API认证需申请

### 方案C: 集成NanoPhoto API

**输入**: YouTube/URL/本地视频 → NanoPhoto → 结构化Prompt → 格式转换 → 漫舟
**优势**: API文档完整，10+维度更专业
**劣势**: 无关键帧图，需格式转换适配Step 7
