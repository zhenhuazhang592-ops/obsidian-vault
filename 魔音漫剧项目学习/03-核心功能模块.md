# 魔因漫创 核心功能模块

## 1. 剧本解析引擎

### 功能

- 智能拆解剧本为场景、分镜、对白
- 自动识别角色、场景、情绪、镜头语言
- 支持多集/多幕剧本结构

### 核心服务

```typescript
// src/lib/script/
├── script-parser.ts        # 剧本解析主逻辑
├── shot-generator.ts      # 分镜生成
├── scene-viewpoint-generator.ts  # 场景视角生成
├── ai-character-finder.ts  # AI 角色识别
├── ai-scene-finder.ts     # AI 场景识别
├── character-calibrator.ts # 角色校准
├── scene-calibrator.ts    # 场景校准
└── full-script-service.ts # 全流程服务
```

### 解析流程

```
原始剧本文本
    ↓
场景分割 → 分镜拆分 → 对白提取 → 角色识别 → 情绪标注
    ↓
结构化剧本数据
```

## 2. 角色一致性系统

### 功能

- **6层身份锚点**：确保同一角色在不同分镜中外观一致
- 角色圣经 (Character Bible) 管理
- 支持角色参考图绑定

### 核心服务

```typescript
// src/lib/character/
└── character-prompt-service.ts  # 角色提示词服务

// src/packages/ai-core/services/
└── character-bible.ts          # 角色圣经管理
```

### 身份锚点层级

| 层级 | 内容 |
|-----|------|
| 1 | 姓名/身份 |
| 2 | 外貌特征 |
| 3 | 服装造型 |
| 4 | 表情习惯 |
| 5 | 动作特点 |
| 6 | 视角一致性 |

## 4. 分镜导演系统

### 功能

- 电影级摄影参数（景别、机位、运动方式）
- 自动排版和导出
- 视觉风格一键切换（2D/3D/写实/定格等）

### 核心配置

```typescript
// src/lib/constants/
├── cinematography-profiles.ts  # 摄影参数配置
└── visual-styles.ts          # 视觉风格配置
```

### 摄影参数

| 参数 | 说明 |
|-----|------|
| 景别 | ECU/CU/MS/WS/EWS |
| 机位 | 固定/移动/手持 |
| 运动 | 推/拉/摇/移/跟 |

## 5. S级板块 (Seedance 2.0)

### 功能

- 多镜头合并叙事视频生成
- 支持 @Image/@Video/@Audio 多模态引用
- 智能提示词构建（三层融合）
- 首帧图网格拼接
- 参数约束自动校验

### 核心服务

```typescript
// src/components/panels/sclass/
├── sclass-prompt-builder.ts   # 提示词构建
├── auto-grouping.ts           # 自动分组
└── use-sclass-generation.ts   # 生成逻辑
```

### 三层融合

```
┌─────────────────────────────────────────┐
│  第一层: 动作描述                         │
├─────────────────────────────────────────┤
│  第二层: 镜头语言（景别/运动/角度）        │
├─────────────────────────────────────────┤
│  第三层: 对白唇形同步                     │
└─────────────────────────────────────────┘
```

### 参数约束

- ≤ 9 图
- ≤ 3 视频
- ≤ 3 音频
- prompt ≤ 5000 字符
