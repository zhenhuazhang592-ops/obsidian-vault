# 魔因漫创 (Moyin Creator) 项目概述

## 项目简介

**魔因漫创** 是一款面向 AI 影视创作者的生产级工具，支持 **Seedance 2.0**，实现从剧本到成片的全流程批量化创作。

## 核心Slogan

> **🎬 AI 影视生产级工具 · 支持 Seedance 2.0 · 剧本到成片全流程批量化**

## 五大核心板块

```
📝 剧本 → 🎭 角色 → 🌄 场景 → 🎬 导演 → ⭐ S级（Seedance 2.0）
```

每一步的产出自动流入下一步，无需手动搅合。

## 核心功能

| 板块          | 功能                       |
| ----------- | ------------------------ |
| **S级板块**    | Seedance 2.0 多镜头合并叙事视频生成 |
| **剧本解析引擎**  | 智能拆解剧本为场景、分镜、对白          |
| **角色一致性系统** | 6层身份锚点，角色圣经管理            |
| **场景生成**    | 多视角联合图生成                 |
| **专业分镜系统**  | 电影级摄影参数，自动排版导出           |
| **批量化生产**   | 一键全流程，多任务并行队列            |

## 技术栈

| 层级 | 技术 |
|-----|------|
| 桌面框架 | Electron 30 |
| 前端框架 | React 18 + TypeScript |
| 构建工具 | electron-vite (Vite 5) |
| 状态管理 | Zustand 5 |
| UI 组件 | Radix UI + Tailwind CSS 4 |
| AI 核心 | @opencut/ai-core |

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/MemeCalculate/moyin-creator.git
cd moyin-creator

# 安装依赖
npm install

# 启动开发模式
npm run dev

# 构建 Windows 安装程序
npm run build
```

## 环境要求
