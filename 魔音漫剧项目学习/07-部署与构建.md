# 魔因漫创 部署与构建

## 环境要求

| 环境 | 要求 |
|-----|------|
| Node.js | >= 18 |
| npm | >= 9 |
| 操作系统 | Windows / macOS / Linux |

---

## 开发模式

```bash
# 克隆仓库
git clone https://github.com/MemeCalculate/moyin-creator.git
cd moyin-creator

# 安装依赖
npm install

# 启动开发模式
npm run dev

# 仅编译（不打包）
npx electron-vite build
```

---

## 生产构建

### 构建命令

```bash
# 编译 + 打包 Windows 安装程序
npm run build

# 或分别执行
npm run prebuild  # 停止已有进程
electron-vite build  # 编译
electron-builder --win  # 打包
```

### 构建配置

```yaml
# electron-builder.yml
appId: com.memecalculate.moyin-creator
productName: 魔因漫创
directories:
  buildResources: build
  output: release
files:
  - out/**/*
  - package.json
win:
  target:
    - target: nsis
      arch:
        - x64
  icon: build/icon.ico
nsis:
  oneClick: false
  perMachine: false
  allowToChangeInstallationDirectory: true
  installerIcon: build/icon.ico
  uninstallerIcon: build/icon.ico
```

## 配置文件

### electron-vite 配置

```typescript
// electron.vite.config.ts
import { defineConfig, externalizeDepsPlugin } from 'electron-vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  main: {
    plugins: [externalizeDepsPlugin()],
  },
  preload: {
    plugins: [externalizeDepsPlugin()],
  },
  renderer: {
    plugins: [react()],
  },
})
```

## 常见问题

### 1. 构建失败

```bash
# 清理缓存
rm -rf node_modules/.vite
rm -rf out

# 重新安装
npm install
npm run build
```

### 2. 图标问题

```bash
# 使用脚本生成图标
node scripts/generate-icon.mjs
```

### 3. Windows 签名

如需代码签名，请在 electron-builder.yml 中配置：
```yaml
win:
  signingHashAlgorithms:
    - sha256
  certificateFile: path/to/cert.pfx
  certificatePassword: password
```
