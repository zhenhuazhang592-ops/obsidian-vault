## 数据流

```
1. 用户导入剧本 → script-store
2. 剧本解析 → 拆解为场景/分镜/角色
3. AI 校准 → 场景/分镜/角色二次优化
4. 生成素材 → 角色图/场景图
5. 导演板块 → 生成分镜图
6. S级板块 → 调用 Seedance 生成视频
```

## 核心状态管理

| Store | 职责 |
|-------|------|
| script-store | 剧本解析、场景拆分、角色识别 |
| scene-store | 场景管理、视图生成 |
| character-library-store | 角色库、角色一致性 |
| director-store | 分镜编辑、镜头参数 |
| sclass-store | Seedance 2.0 多镜头合并 |
| api-config-store | AI 服务商配置 |
| media-store | 媒体资源管理 |
