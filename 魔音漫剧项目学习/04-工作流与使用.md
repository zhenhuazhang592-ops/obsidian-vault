# 魔因漫创 完整工作流

## 流程总览

```
⚙️ 准备工作 → 📝 剧本 → 🔧 AI校准 → 🌄 场景/🎭 角色 → 🎬 导演/⭐ S级 → 🎥 生成视频
```

---

## 第一步：准备工作

### 1.1 添加 API 服务商

进入 **设置 → API 配置 → 添加服务商**，配置 AI 服务商账号：

- 建议添加 **多个 API Key**，支持轮询负载均衡
- Key 越多，**并发线程数越高**
- 支持服务商：memefast、RunningHub 等

### 1.2 服务映射

进入 **设置 → 服务映射**，为各功能选择 AI 模型：

| 功能 | 推荐模型 |
|-----|---------|
| 图片生成 | gemini-3-pro-image-preview |
| 视频生成 | doubao-seedance-1-5-pro-251215 |

### 1.3 图床配置

进入 **设置 → 图床配置**，配置图片托管服务

---

## 第二步：剧本板块

### 两种开始方式

- **A. 导入剧本** — 粘贴或导入已有完整剧本
- **B. AI 创作** — 使用 AI 辅助从零创作剧本

### 剧本格式

系统自动分析剧本，拆解为：
- 场景 (Scene)
- 分镜 (Shot)
- 角色 (Character)
- 对白 (Dialogue)
- 情绪 (Emotion)
- 镜头语言 (Cinematography)

> 参考格式见 `docs/SCRIPT_FORMAT_EXAMPLE.md`

---

## 第三步：AI 二次校准

依次点击三个校准按钮进行二次深化：

### 3.1 AI 场景校准

- 优化每个场景的环境描述
- 添加氛围、光影等细节

### 3.2 API 校准分镜

- 精确校准每个分镜的镜头语言
- 景别、构图、运动方式

### 3.3 AI 角色校准

- 深化角色外观描述
- 表情、动作等一致性锚点

> 校准后，系统自动生成更精细的提示词

---

## 第四步：生成素材（可选）

### 4.1 生成场景

- 根据校准后的场景描述
- 批量生成场景参考图

### 4.2 生成角色

- 根据校准后的角色描述
- 生成角色参考图

---

## 第五步：导演板块 / S级板块

### 5.1 加载剧本分镜

点击 **右边栏「加载剧本分镜」**

### 5.2 自动填写参数

左边栏自动填写：
- 首帧提示词
- 尾帧提示词
- 视频提示词

### 5.3 自由微调

所有参数均可手动调整：
- 镜头运动
- 时长
- 风格

---

## 第六步：生成图片与视频

### 生图方式

| 方式 | 说明 |
|-----|------|
| 单镜生成 | 逐个分镜单独生成 |
| **合并生成（推荐）** | 批量生成，自动分配到各分镜 |

### 生成视频

图片分配完成后，点击 **「生成视频」** 批量生成分镜视频

---

## S级板块 - Seedance 2.0 进阶

### 功能

1. **多镜头合并叙事** — 多个分镜组合生成连贯叙事
2. **灵活分组** — 1个镜头→15秒 / 多镜头→15秒片段
3. **多模态引用** — 自动收集 @Image/@Video/@Audio
4. **三层融合** — 动作+镜头语言+对白唇形同步

### 参数校验

- ≤ 9 图
- ≤ 3 视频
- ≤ 3 音频
- prompt ≤ 5000 字符

---

## 板块选择指南

| 板块 | 适用场景 |
|-----|---------|
| S级板块 | 多镜头连贯叙事（短剧、番剧预告） |
| 导演板块 | 逐镜头精细控制 |
