## 核心要点总结

### 技术选型

- **桌面**: Electron 30
- **前端**: React 18 + TypeScript + Vite
- **状态**: Zustand 5
- **UI**: Radix UI + Tailwind CSS 4

### 五大核心板块

```
📝 剧本 → 🎭 角色 → 🌄 场景 → 🎬 导演 → ⭐ S级
```

### 关键技术

1. **角色一致性**: 6层身份锚点
2. **分镜系统**: 电影级摄影参数
3. **AI 调度**: 多 Key 轮询 + 任务队列
4. **提示词**: 三层融合（动作+镜头+对白）
5. **存储**: IndexedDB / OPFS 本地存储
