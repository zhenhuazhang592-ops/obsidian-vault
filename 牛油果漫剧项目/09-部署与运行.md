# 漠玫牛油果漫剧项目 - 部署与运行

## 一、环境要求

### 1.1 硬件要求

| 配置 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 4核 | 8核 |
| 内存 | 8GB | 16GB |
| 硬盘 | 50GB SSD | 100GB SSD |
| 网络 | 10Mbps | 50Mbps |

### 1.2 软件要求

| 软件 | 版本要求 |
|------|---------|
| Node.js | >= 18.0.0 |
| npm | >= 9.0.0 |
| SQLite | 3.x |
| FFmpeg | >= 4.0 |

## 二、快速开始

### 2.1 安装依赖

```bash
# 克隆项目
git clone https://github.com/your-repo/momo-comic.git
cd momo-comic

# 安装依赖
npm install
# 或
yarn install
```

### 2.2 配置环境变量

```bash
# 复制环境变量模板
cp env/.env.example env/.env

# 编辑环境变量
nano env/.env
```

**环境变量配置：**

```env
# 服务配置
PORT=3000
NODE_ENV=development

# 数据库
DB_PATH=./data/momo-comic.db

# AI 服务
CLAUDE_API_KEY=your-claude-key
OPENAI_API_KEY=your-openai-key
GEMINI_API_KEY=your-gemini-key

# 视频生成
SEEDANCE_API_KEY=your-seedance-key
RUNWAY_API_KEY=your-runway-key

# 文件存储
OSS_ENDPOINT=your-oss-endpoint
OSS_BUCKET=your-bucket
OSS_ACCESS_KEY=your-access-key
OSS_SECRET_KEY=your-secret-key
```

### 2.3 启动服务

```bash
# 开发模式
npm run dev

# 生产模式
npm run build
npm start

# Docker 部署
docker-compose up -d
```

## 三、Docker 部署

### 3.1 Dockerfile

```dockerfile
FROM node:18-alpine

WORKDIR /app

COPY package*.json ./
RUN npm ci --only=production

COPY . .

RUN npm run build

EXPOSE 3000

CMD ["npm", "start"]
```

### 3.2 docker-compose.yml

```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "3000:3000"
    volumes:
      - ./data:/app/data
      - ./uploads:/app/uploads
    environment:
      - NODE_ENV=production
      - DB_PATH=/app/data/momo-comic.db
    restart: unless-stopped

  ffmpeg:
    image: jrottenberg/ffmpeg:latest
    volumes:
      - ./uploads:/app/uploads
    command: -watch
    restart: unless-stopped
```

## 四、PM2 部署

### 4.1 安装 PM2

```bash
npm install -g pm2
```

### 4.2 启动服务

```bash
# 启动服务
pm2 start npm --name "momo-comic" -- run start

# 查看日志
pm2 logs momo-comic

# 查看状态
pm2 status

# 重启
pm2 restart momo-comic
```

### 4.3 开机自启

```bash
pm2 save
pm2 startup
```

## 六、常用命令

### 6.1 开发命令

```bash
npm run dev          # 开发模式启动
npm run build        # 构建生产版本
npm run lint         # 代码检查
npm test             # 运行测试
```

### 6.2 数据库命令

```bash
# 初始化数据库
npm run db:init

# 备份数据库
cp data/momo-comic.db data/momo-comic-backup.db

# 查看数据库
sqlite3 data/momo-comic.db ".tables"
```

### 6.3 运维命令

```bash
# 查看服务状态
pm2 status

# 查看日志
pm2 logs momo-comic --lines 100

# 重启服务
pm2 restart momo-comic

# 停止服务
pm2 stop momo-comic
```

## 八、常见问题

### 8.1 数据库锁定

```bash
# 如果遇到数据库锁定
rm data/momo-comic.db-journal
```

### 8.2 AI服务超时

- 检查网络连接
- 增加超时时间配置
- 使用备用AI服务

### 8.3 视频生成失败

- 检查FFmpeg是否安装
- 检查API配额
- 查看错误日志

## 九、监控与告警

### 9.1 基础监控

```bash
# PM2 监控
pm2 monit
```

### 9.2 日志分析

```bash
# 统计错误日志
grep "ERROR" logs/*.log | wc -l

# 查看最近错误
tail -100 logs/error.log
```
