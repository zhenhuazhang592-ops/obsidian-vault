# 漠玫牛油果漫剧项目 - 项目概述

## 项目简介

**漠玫牛油果漫剧** 是一款基于 AI 技术的幽默治愈类知识科普漫剧项目。故事发生在"漠玫轻食餐厅"，通过主角漠小漠（牛油果拟人）的各种"作死"尝试，向观众传递牛油果挑选、保存、搭配、吃法等实用知识。

## 项目定位

| 项目 | 内容 |
|-----|------|
| **内容形态** | 动态漫画（Motion Comic）+ 轻度动画 |
| **单集时长** | 60-90秒 |
| **更新频率** | 每周2-3集 |
| **第一季规模** | 20集 |
| **核心价值** | 用幽默方式传递牛油果实用知识 |

## 目标受众

| 画像 | 特征 |
|------|------|
| 核心受众 | 22-35岁都市年轻人，尤其关注健康饮食的女性 |
| 痛点 | 买牛油果总是踩坑——太生太硬、太熟太黑、不知道怎么保存 |
| 心理 | 想吃得健康但不想花精力研究，渴望"简单粗暴"的实用技巧 |
| 观看场景 | 午休刷手机、做饭前快速学习、睡前放松 |

## 核心Slogan

> **"每一颗牛油果，都死于它不该承受的自信。"**

## 核心功能

| 功能模块 | 说明 |
|---------|------|
| **剧本生成** | 基于真实生活场景的剧本创作 |
| **角色生成** | 漠小漠+6个配角的角色设定 |
| **分镜设计** | 专业电影级分镜提示词 |
| **视频生成** | AI视频生成 + 后期合成 |
| **批量生产** | 批量化漫剧制作工作流 |

## 技术栈

| 层级 | 技术选型 |
|-----|---------|
| 前端 | React + TypeScript + Electron（桌面端） |
| 后端 | Node.js + Express + TypeScript |
| AI SDK | Vercel AI SDK |
| 数据库 | SQLite |
| 视频生成 | Seedance / Runway / 可灵 |
| 图片生成 | Midjourney / Stable Diffusion / Gemini |

## 项目版本

|-----|------|------|

## 参考项目

本项目基于以下AI漫剧项目的最佳实践：

- **Toonflow** - 多Agent协作、Prompt工程
- **魔因漫创** - 6层身份锚点、角色一致性
