# 漠玫牛油果漫剧项目

> 基于AI技术的幽默治愈类知识科普漫剧项目

## 项目简介

**漠玫牛油果漫剧** 是一款利用 AI 技术生成幽默科普漫剧的项目。故事发生在"漠玫轻食餐厅"，通过主角漠小漠（牛油果拟人）的各种"作死"尝试，向观众传递牛油果挑选、保存、搭配、吃法等实用知识。

## 核心Slogan

> **"每一颗牛油果，都死于它不该承受的自信。"**

| 后端 | Node.js + Express + TypeScript |
| AI SDK | Vercel AI SDK |
| 数据库 | SQLite |
| 视频生成 | Seedance / Runway / 可灵 |

## 快速开始

```bash
# 安装依赖
npm install

# 配置环境变量
cp env/.env.example env/.env

# 启动开发服务
npm run dev

# 构建生产版本
npm run build

# Docker 部署
docker-compose up -d
```
