## 4.3 六大剧情模式

### 模式一：顾客作死尝试型

```
【真实场景】
顾客（尤其是新顾客）："我想这样吃，可以吗？"
漠小漠：盲目自信地配合
结果：翻车

【典型剧情】
顾客："老板，给我做个牛油果沙拉，不要蛋黄酱，要放酸奶！"
（酸奶+牛油果 = 蛋白质凝固 = 口感奇怪）
紫薯精："我有一个大胆的想法，加点蜂蜜试试？"
漠小漠：盲目跟进
→ 死亡
→ 玫博士科普
```

### 模式二：认知偏差型

```
【真实场景】
顾客有错误认知，坚持要这样做
店员解释不听

【典型剧情】
顾客（康叔）："牛油果必须放冰箱！不然全坏了！"
玫博士："其实还没熟的要常温..."
顾客："不可能！我活了50年还不知道？"
（结果：冰箱太冷，牛油果被"冻死"）
→ 死亡 → 科普
```

### 模式三：网红跟风型

```
【真实场景】
顾客刷到网红推荐，慕名而来
网红怎么吃我就怎么吃

【典型剧情】
播播（网红）："家人们！牛油果+柿子=神仙搭配！我来漠玫家打卡！"
紫薯精：（拱火）"试试嘛，网红都这样吃！"
漠小漠：跟进
→ 死亡
→ 玫博士："根据研究显示..."
```

### 模式四：健身误区型

```
【真实场景】
健身人士过度追求蛋白质
忽略牛油果的真实营养

【典型剧情】
志远："老板！给我来5个牛油果，我要补充优质脂肪！"
（吃太多 = 热量爆炸）
漠小漠：崇拜地模仿
→ 死亡
→ 志远和玫博士科普："不是越多越好"
```

### 模式五：亲子喂养型

```
【真实场景】
妈妈给宝宝吃牛油果，但方法不对
小朋友贪吃

【典型剧情】
妈妈："乐乐，多吃点牛油果，对大脑好！"
乐乐："还要再吃！"
（结果：一次吃太多，或吃到未成熟的）
→ 身体不适 → 科普
```

### 模式六：玄学误区型

```
【真实场景】
顾客相信各种"养生传言"
没有科学依据

【典型剧情】
康叔："星期三不能吃牛油果！我算过的！"
诗涵姐："我查过资料，这个没有科学依据..."
康叔："你们年轻人懂什么？"
→ 坚持错误 → 翻车 → 打脸
```

## 4.5 剧本创作流程

```
┌─────────────────────────────────────────────────────────────┐
│                    剧本创作六步法                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ① 选题确认                                                │
│     - 选择选题（20选1）                                    │
│     - 确认知识点                                           │
│     - 确定剧情模式                                          │
│           ↓                                                │
│  ② 场景选择                                                │
│     - 根据时段选场景（厨房/吧台/用餐区）                   │
│     - 确定出场配角                                          │
│           ↓                                                │
│  ③ 分镜设计                                                │
│     - 按75秒结构分配各幕时长                               │
│     - 确定每个分镜的景别、角度                             │
│     - 标注动作和台词                                        │
│           ↓                                                │
│  ④ 台词撰写                                                │
│     - 角色台词符合人设                                     │
│     - 科普自然融入                                         │
│     - 口头禅点缀                                           │
│           ↓                                                │
│  ⑤ AI生成                                                  │
│     - 调用Script Agent生成                                 │
│     - 导演审核（80分及格）                                 │
│           ↓                                                │
│  ⑥ 人工优化                                                │
│     - 知识点校验                                           │
│     - 笑点打磨                                             │
│     - 节奏调整                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 剧本审核清单

```
【知识点检查】
□ 科普内容准确无误
□ 原理说明清晰易懂
□ 无错误认知

【笑点检查】
□ 有让人发笑的设计
□ 节奏恰当
□ 不尴尬

【角色检查】
□ 台词符合人设
□ 口头禅使用正确
□ 角色互动自然

【技术检查】
□ 时长60-90秒
□ 分镜数量合理（6-8个）
□ 景别切换有节奏
```
