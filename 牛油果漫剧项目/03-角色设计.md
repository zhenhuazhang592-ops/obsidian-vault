## 3.2 主角设计：漠小漠

| 项目 | 设计 |
|------|------|
| **名字** | 漠小漠（nickname：小漠/阿漠） |
| **身份** | 漠玫轻食餐厅的"首席体验官"——专门试吃各种牛油果料理 |
| **外形** | 胖乎乎椭圆形牛油果，深绿色果皮光泽，两个黑色圆点眼睛 |
| **性格** | 盲目自信、好奇心极强、永远认为自己能驾驭任何料理 |
| **口头禅** | "不至于吧？"（作死前）、"我裂开了！"（死亡时）、"再给我一次机会！"（复活时） |
| **视觉特点** | 永远睡不醒的眼神，紧张时果皮表面"出汗"渗出水珠 |

**漠小漠的诞生故事**：
> 漠小漠是一颗来自秘鲁安第斯山脉的树熟哈斯牛油果，因为太自信太爱尝试各种"黑暗料理"，被漠玫店长留在餐厅里"以身试法"，每次翻车后由店员救治复活，成为餐厅里的"活宝"。

### 漠小漠6种死亡表情

| 表情 | 适用场景 | 视觉描述 |
|------|----------|----------|
| 震惊死 | 遇到意外 | 眼睛凸出成大圆点、嘴巴O型、果柄竖起 |
| 痛苦死 | 操作失误 | 眼睛眯成两条缝、嘴角下撇、果皮渗出3滴冷汗 |
| 无语死 | 被嘲笑 | 眼睛变成蚊香旋转、嘴巴微张、灵魂出窍 |
| 安详死 | 放弃治疗 | 眼睛紧闭、嘴角微微上扬、果皮变淡 |
| 冤枉死 | 被冤枉 | 眼泪汪汪、嘴巴委屈下撇、果皮变深绿 |
| 蒙圈死 | 被打扰 | 眼睛变成两个空洞、舌头（果柄）吐出 |

## 3.6 AI角色生成提示词

### 3.6.1 多角度角色设计（关键！）

> **重要**：AI 生图无法保持角色一致性，必须通过多角度参考图来解决。
> 每个角色需要生成 4 个角度的标准形象，后续所有分镜都参考这些图生成。

```
┌─────────────────────────────────────────────────────────────┐
│              多角度角色参考图系统                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  每个角色 4 个角度：                                        │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐        │
│  │ 正面    │ │ 3/4侧面 │ │  侧面   │ │  背面   │        │
│  │ 特写用  │ │ 最常用  │ │ 动作用  │ │特殊场景│        │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘        │
│                                                             │
│  生成顺序：先角色 → 后场景 → 最后分镜                      │
│  参考方式：每张分镜图都使用 --ref 参考对应角度的角色图    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
