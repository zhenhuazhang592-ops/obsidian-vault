## 一、画风选择：日漫风格 (Manga)

### 1.1 画风定位

基于牛油果漫剧的受众（年轻、健康生活爱好者）和内容调性（幽默科普），采用**日漫风格**作为核心画风，融合轻食健康的清新感。

| 维度 | 选择 | 说明 |
|------|------|------|
| 画风 | manga | 日漫风格，角色眼睛大而有神 |
| 基调 | energetic + warm | 活力为主，温馨为辅 |
| 布局 | cinematic | 电影感分镜，适配横屏视频 |

### 1.2 日漫风格核心特征

```
【线条】
- 流畅线条 (1.5-2px)，有轻重变化
- 表情丰富：感叹号、问号、汗珠、星星等情绪符号
- 速度线表现动作和冲击感

【眼睛】
- 大而传神，多高光点
- 漠小漠：睡不醒的死鱼眼 + 高光
- 配角：玫博士（严肃）、紫薯精（奸诈）、诗涵姐（温柔）

【动态】
- 夸张表情和肢体语言
- 摔倒、惊恐等有漫画感的动作
- "死亡"定格画面借鉴热血漫画的夸张表现

【背景】
- 对话时简化，重要场景详细
- 漠玫餐厅：INS风绿植 + 原木色调
- 适当使用抽象背景渲染情绪
```

## 三、面板布局 (Layout)

### 3.1 横屏视频布局

采用 **cinematic** 电影感布局，适配 16:9 横屏：

```
【开场 Hook - 1 格】
┌─────────────┐
│             │
│   特写镜头   │  ← 漠小漠表情/道具
│             │
└─────────────┘

【作死过程 - 3-4 格】
┌─────┬─────┐
│ 中  │ 特  │  ← 动作拆解
│ 景  │ 写  │
├─────┴─────┤
│           │
│  反应镜头  │  ← 配角表情
│           │
└───────────┘

【死亡瞬间 - 1 格】
┌─────────────┐
│             │
│   全幅定格   │  ← 夸张死亡表情
│             │
└─────────────┘

【科普时刻 - 2 格】
┌─────────────┐
│  玫博士特写  │
├─────────────┤
│  知识卡片    │
└─────────────┘
```

### 3.2 镜头类型库

| 镜头 | 英文 | 用途 | 牛油果漫剧应用 |
|------|------|------|---------------|
| 特写 | Close-up | 表情变化 | 漠小漠6种死亡表情 |
| 中景 | Medium Shot | 动作展示 | 作死过程、互动 |
| 全景 | Wide Shot | 场景交代 | 餐厅环境 |
| 过肩 | Over Shoulder | 对话 | 漠小漠+配角对话 |
| 仰视 | Low Angle | 权威感 | 玫博士出场 |
| 俯视 | High Angle | 弱势感 | 漠小漠被教训 |

## 四、文本元素规范

### 4.1 对话气泡

| 类型 | 形状 | 使用场景 |
|------|------|----------|
| 正常对话 | 圆角矩形 | 日常对话 |
| 内心独白 | 云朵形 | 漠小漠的OS |
| 惊讶 | 尖刺状 | 死亡瞬间 |
| 尖叫 | 锯齿状 | 震惊死 |

### 4.2 文字风格

- 字体：手写风格（非电脑字体）
- 大小：对话 > 旁白 > 音效
- 颜色：黑色为主，情绪场景用深绿/红色强调

### 4.3 音效文字

```
【常见音效】
- 啪叽！→ 摔倒
- 咔嚓！→ 骨折/裂开
- 砰！→ 撞击
- 吨吨吨吨→ 喝水
- 吸溜~→ 好吃
```

## 五、动态效果

### 5.1 死亡动画（借鉴日漫战斗漫画）

```
【震惊死】
- 眼睛凸出 + 问号/感叹号
- 镜头：推近 + 黑白闪回
- 音效：咔！！！→ 啪叽

【痛苦死】
- 汗水成河 + 青色血管
- 镜头：抖动 + 旋转
- 音效：呜呜呜... → 咚

【无语死】
- 蚊香眼旋转 + 灵魂出窍
- 镜头：螺旋 + 虚化
- 音效：嗡——
```

### 5.2 情绪符号库

| 符号 | 名称 | 使用场景 |
|------|------|----------|
| 💧 | 汗珠 | 紧张/尴尬 |
| ❗ | 感叹号 | 惊讶/警告 |
| ❓ | 问号 | 疑惑 |
| ✨ | 星星 | 好吃/开心 |
| 💢 | 愤怒 | 生气 |
| 💕 | 爱心 | 感动 |
| 🔥 | 火焰 | 好吃/燃起来 |
| 💨 | 速度线 | 快速/逃跑 |

### 5.3 速度线应用

```
【加速奔跑】
- 背景：横向速度线
- 效果：紫薯精逃跑专用

【冲击瞬间】
- 集中向一点的速度线
- 效果：漠小漠被打击

【美食诱惑】
- 向上飘的食物香气线
- 效果：菜品出场
```

## 七、画风+基调组合建议

### 7.1 内容类型对照表

| 场景类型 | 画风 | 基调 | 说明 |
|----------|------|------|------|
| 作死过程 | manga | energetic | 活力满满，好笑 |
| 死亡瞬间 | manga | dramatic | 夸张冲击 |
| 日常闲聊 | manga | warm | 温馨可爱 |
| 科普讲解 | ligne-claire | neutral | 专业冷静 |
| 美食展示 | manga | romantic | 让人流口水 |
| 打斗追逐 | manga | action | 速度感 |

### 7.2 快速选择指南

```
1. 作死 → manga + energetic
2. 科普 → ligne-claire + neutral
3. 感动 → manga + warm
4. 搞笑 → manga + energetic
5. 神秘 → realistic + dramatic
```
