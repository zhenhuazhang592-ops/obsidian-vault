# 牛油果漫剧第一集执行方案

> 完全按照魔因漫创（Moyin Creator）工作流程优化
> 版本：v1.0 | 基于魔因漫创 v0.1.7 工作流

---

## 一、流程总览

```
⚙️ 准备工作 → 📝 剧本 → 🔧 AI校准 → 🌄 场景/🎭 角色 → 🎬 导演板块 → 🎥 生成视频
```

> **重要**：本方案完全对齐魔因漫创的五大板块工作流，每一步产出自动流入下一步。

---

## 二、准备工作：环境配置

### 2.1 安装魔因漫创

下载并安装魔因漫创客户端：
- 链接: https://pan.baidu.com/s/1ImH6tOIiuFxIDXC0fC-6Lg 提取码: 8888

### 2.2 配置 API 服务商

进入 **设置 → API 配置 → 添加服务商**，配置以下 AI 服务商：

| 服务商 | 用途 | 建议模型 |
|-------|------|---------|
| memefast | 图片生成 | gemini-3-pro-image-preview |
| RunningHub | 视频生成 | doubao-seedance-1-5-pro-251215 |

> 💡 **建议**：配置多个 API Key 以提升并发能力

### 2.3 服务映射

进入 **设置 → 服务映射**，配置：

| 功能 | 推荐模型 |
|------|---------|
| 文生图 | gemini-3-pro-image-preview |
| 图生视频 | doubao-seedance-1-5-pro-251215 |
| 文生视频 | doubao-seedance-1-5-pro-251215 |

### 2.4 图床配置

进入 **设置 → 图床配置**，配置图片托管服务（用于上传参考图、首帧图等素材）。

## 三、第一步：剧本板块

### 3.1 剧本导入

按照魔因漫创标准剧本格式，将第一集剧本导入到剧本板块。

### 3.2 剧本格式（魔因标准）

```
【标题】《牛油果漫剧》第一集：微波炉惊魂

【大纲】
一颗盲目自信的牛油果（漠小漠），在紫薯精的拱火下尝试把牛油果放进微波炉加热，结果悲惨"裂开"。玫博士出场科普牛油果含水量高达73%，微波炉加热会内部产生高压导致爆裂。

【人物小传】
漠小漠（1）：漠玫轻食餐厅首席体验官，盲目自信，永远认为自己能驾驭任何料理
紫薯精（1）：话唠搅局者，唯恐天下不乱，爱拱火甩锅
玫博士（1）：餐厅主厨+营养学博士，毒舌但专业
```

## 四、第二步：AI 二次校准

> **重要**：魔因漫创的核心是"二次校准"，系统自动分析后需要手动触发三个校准按钮深化。

在校准面板依次点击：

### 4.1 AI 场景校准

点击 **AI 场景校准**，优化每个场景的环境描述、氛围、光影等细节。

**校准后的场景描述**：

| 场景 | 优化后的描述 |
|------|-------------|
| 漠玫餐厅厨房 | 开放式厨房，绿植环绕，原木色调，INS风，开放式厨房可以看到制作过程，右侧可见微波炉，暖色调氛围，漠玫logo装饰 |

### 4.2 API 校准分镜

点击 **API 校准分镜**，精确校准每个分镜的镜头语言、景别、构图。

**校准后的分镜参数**：

| 分镜 | 景别 | 机位 | 运动 |
|------|------|------|------|
| 1-1 | 特写 | 俯视45° | 固定 |
| 1-1 | 中景 | 平视 | 推镜头 |
| 1-2 | 中景 | 平视 | 固定 |
| 1-3 | 特写 | 俯视 | 固定 |
| 1-4 | 全幅 | 平视 | 固定 |
| 1-5 | 特写 | 平视 | 侧跟 |
| 1-6 | 特写 | 平视 | 固定 |

### 4.3 AI 角色校准

点击 **AI 角色校准**，深化角色外观描述、表情、动作等一致性锚点。

**校准后的角色锚点**：

| 角色 | 身份锚点 | 外貌锚点 | 表情锚点 |
|------|---------|---------|---------|
| 漠小漠 | 牛油果、盲目自信 | 胖椭圆、深绿果皮、果核眼 | 6种死亡表情 |
| 紫薯精 | 话唠搅局者 | 紫色圆身、大白眼珠、呆毛 | 奸笑、抱头 |
| 玫博士 | 营养博士 | 戴眼镜、穿白大褂、放大镜 | 专业冷静 |

## 六、第四步：进入导演板块

切换到 **导演板块**。

### 6.1 加载剧本分镜

点击右边栏 **「加载剧本分镜」**，将剧本中的所有分镜导入当前板块。

### 6.2 分镜自动填充

系统会自动为每个分镜填写：
- 首帧提示词
- 尾帧提示词
- 视频提示词

### 6.3 分镜参数微调

所有参数均可根据个人喜好自由微调（如镜头运动、时长、风格等）。

---

## 七、第五步：生成图片与视频

### 7.1 生图方式选择

#### 方式A：单镜生成
逐个分镜单独生成图片（适合精细控制）

#### 方式B：合并生成（推荐）
将多个分镜合并批量生成，生成后的图片会自动分配到对应的每一个分镜上。

> 💡 **推荐使用「合并生成」**，生成效率更高，风格更统一。
