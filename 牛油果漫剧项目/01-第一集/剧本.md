# 牛油果漫剧 第1集

## 剧本：牛油果能不能放微波炉？

**时长**：约 90 秒
**主题**：科普牛油果储存/加热知识
**核心冲突**：漠小漠要把牛油果放微波炉

---


### 场景1：开场 Hook（0-5秒）

**【餐厅厨房 - 日】**

漠小漠站在微波炉前，双手叉腰，自信满满。

```
漠小漠（OS）："今天天气不错，适合...加热！"
```

漠小漠（自信）："今天我来个大胆的创新！把牛油果放微波炉里，三秒即热！"

**【特写】** 微波炉屏幕显示 "30秒"

---

### 场景2：作死进行（5-30秒）

**【厨房 - 日】**

漠小漠拿起一颗牛油果，仔细端详。

```
漠小漠："不就是加热嘛，难道还会炸？"
```

紫薯精从旁边探出头来。

```
紫薯精："我有一个大胆的想法..."
紫薯精："要不...放个鸡蛋进去？一起加热！"
```

漠小漠（犹豫）："不至于吧？牛油果而已..."

紫薯精（兴奋）："试试嘛！不试怎么知道！"

漠小漠（被说服）："好！就按你说的办！"

**【中景】** 漠小漠把牛油果和鸡蛋一起放进微波炉，关上门。

---

### 场景3：悲惨后果（30-45秒）

**【微波炉特写】**

屏幕显示倒计时：10...9...8...

漠小漠和紫薯精后退几步，探头观察。

```
漠小漠："怎么没声音？"
紫薯精："可能还在酝酿..."
```

**【特写 - 漠小漠表情】**

漠小漠突然意识到什么，眼睛凸出。

```
漠小漠："等等！我好像忘记按——"
```

**【BOOM 特效】**

微波炉光芒大作！

**【全幅定格】**

漠小漠全身焦黑，头发（果柄）竖起，直挺挺倒下。

```
漠小漠："我裂开了！！！"(画外音)
```

---

**【餐厅 - 日】**

玫博士戴着博士眼镜，手持放大镜，严肃地走来。

```
玫博士（冷静）："根据研究显示..."
玫博士："牛油果的含水量高达73%！"
```

**【知识卡片动画】**

```
│                                 │
│  💡 正确吃法：                  │
```

玫博士（继续）："微波炉加热会让内部水分瞬间蒸发，产生高压..."

紫薯精（举手）："那...鸡蛋呢？"

紫薯精（抱头）："啊这...不关我事啊！"

## 知识点

1. 牛油果含水量高达 73%
2. 微波炉加热会导致内部水分急剧蒸发
3. 高压会导致牛油果爆裂
4. 鸡蛋更不能在微波炉里加热
5. 正确方式：常温保存或熟后冷藏
