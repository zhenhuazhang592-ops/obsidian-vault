## 一、画风与基调（baoyu-comic 风格系统）

```
【画风】manga - 日漫风格
- 线条：流畅有轻重变化 (1.5-2px)
- 眼睛：大而传神，多高光点
- 表情：丰富情绪符号（汗珠、感叹号、星星）
- 动态：夸张肢体语言，速度线

【基调】energetic - 活力为主，warm - 温馨为辅
- 色彩：高饱和度，明亮清新
- 情绪：夸张搞笑，突出"死亡"定格
- 科普：玫博士专业冷静 vs 漠小漠活泼

【布局】cinematic - 电影感竖屏
- 16:9 横屏适配
- 特写→中景→全景节奏
- 知识卡片：扁平化设计
```

| 死亡类型 | 提示词 |

## 十、单集结构提示词（漠小漠版 + 电影感布局）

```
【开场Hook - 0-5秒】
漠小漠在漠玫餐厅出场，立flag要尝试某种"黑暗料理"
镜头：漠小漠自信近景特写，背景是漠玫餐厅
台词："今天我来个大胆的创新！"

【作死进行 - 5-30秒】
步骤清晰、行为夸张，可能有其他角色出现
镜头：漠小漠动作中景 + 道具特写 + 配角反应
台词：漠小漠的作死独白 + 配角的吐槽

【悲惨后果 - 30-45秒】
视觉效果夸张搞笑，漠小漠死亡瞬间
镜头：死亡瞬间定格特写 + 配角的惊讶反应
台词：漠小漠"我裂开了！" + 配角惊呼

【死因鉴定 - 45-70秒】
玫博士出现，进行"死亡鉴定"和科普
镜头：知识卡片动画 + 玫博士特写 + 叽叽提问
台词：玫博士"根据研究显示..." + 科普知识点

【结尾收束 - 70-90秒】
漠小漠"复活" + 下集预告
镜头：漠小漠满血复活近景
台词："再给我一次机会！下期更精彩～"
```
