## 二、素材制作流程

### 2.1 第一步：AI生成基础素材

```
1. 使用Gemini生成漠小漠三视图
   Prompt示例：
   "深绿色牛油果拟人，胖乎乎椭圆形，两个黑色圆点眼睛，
   永远睡不醒的眼神，顶部有果核凸起，短小四肢。
   卡通动画风格，暖色调，透明背景。
   分别生成：正面站姿、侧面站姿、背面站姿"

2. 选定最佳版本作为基础模板
```

### 2.2 第二步：表情素材制作

```
1. 基于三视图，变化表情
2. 6种死亡表情需要特写镜头
3. 每个表情3个角度：正面/侧面/特写
```

### 2.3 第三步：动作素材制作

```
1. 关键帧动画
2. 每个动作8-12帧
3. 使用PNG序列格式
```

## 三、素材使用规范

### 3.1 AI生成时的引用

```
生成新分镜时：
1. 引用基础三视图
2. 指定当前表情
3. 指定当前动作
4. 指定seed值
```

### 3.2 后期合成时的使用

```
视频后期：
1. 死亡瞬间 → 使用对应表情素材
2. 动作表演 → 使用动作序列
3. 特写镜头 → 使用表情特写
```

## 七、参考实现（基于魔因漫创）

```typescript
// 角色参考图绑定
interface CharacterReference {
  characterId: string;
  images: {
    type: 'front' | 'side' | 'back' | 'expression' | 'action';
    url: string;
    description: string;
  }[];
  seedValue?: string;
}

// 使用参考图生成
async function generateWithReference(
  prompt: string,
  references: CharacterReference[]
): Promise<string> {
  // 将参考图URL加入prompt
  const enhancedPrompt = `
    ${prompt}

    参考图：
    ${references.map(r => r.images.map(i => i.url)).flat().join('\n')}
  `;

  return await aiImage.generate(enhancedPrompt);
}
```
