### 动态漫画制作流程

```
1. 分镜设计
   ↓
2. 生成背景场景图（AI）
   ↓
3. 角色PNG素材叠加
   ↓
4. 添加动作动画（After Effects）
   ↓
5. 真人配音录制
   ↓
6. 字幕制作
   ↓
7. 音效配乐
   ↓
8. 合成输出
```

### 视频生成详细方案

```
【第1种方案：动态漫画】（推荐初期）
• 优点：制作快、成本低、角色一致
• 缺点：动画感较弱
• 适合：快速验证、测试市场

【第2种方案：AI视频增强】
• 使用Seedance生成关键动作
• 优点：动作更自然
• 缺点：排队时间长、成本高
• 适合：成熟期

【第3种方案：混合模式】
• 静态画面 + AI动态效果
• 死亡瞬间使用AI视频
• 优点：平衡效果和成本
• 推荐：正式运营后使用
```

```typescript
// TTS服务封装
class TTSService {
  private providers: Map<string, TTSProvider>;

  async generateVoice(params: TTSParams): Promise<TTSResult> {
    const { provider, text, voice_id, speed, pitch } = params;

    switch (provider) {
      case 'elevenlabs':
        return this.generateWithElevenLabs(text, voice_id, { speed, pitch });
      case 'cosyvoice':
        return this.generateWithCosyVoice(text, voice_id, { speed, pitch });
      case 'gpt-sovits':
        return this.generateWithGPTSovits(text, voice_id, { speed, pitch });
      case 'xunfei':
        return this.generateWithXunFei(text, voice_id, { speed, pitch });
      default:
        throw new Error(`Unknown TTS provider: ${provider}`);
    }
  }

  // 批量生成配音
  async batchGenerate(dialogues: Dialogue[]): Promise<AudioFile[]> {
    const results: AudioFile[] = [];
    for (const dialogue of dialogues) {
      const audio = await this.generateVoice({
        provider: this.defaultProvider,
        text: dialogue.text,
        voice_id: this.getVoiceId(dialogue.character),
        speed: this.getSpeed(dialogue.character),
        pitch: this.getPitch(dialogue.character)
      });
      results.push({ ...audio, startTime: dialogue.startTime });
    }
    return results;
  }
}

interface TTSParams {
  provider: string;
  text: string;
  voice_id: string;
  speed?: number;
  pitch?: number;
  volume?: number;
}

interface TTSResult {
  audio_url: string;
  duration: number;  // 时长（秒）
  format: string;
}
```

```typescript
// AI服务商适配器
class AIProviderAdapter {
    private providers: Map<string, ProviderConfig>;

    async call(provider: string, prompt: string, options: any): Promise<any> {
        const config = this.providers.get(provider);
        if (!config) throw new Error(`Provider ${provider} not found`);

        // 多Key轮询
        const key = this.getNextKey(config.keys);
        return this.execute(provider, prompt, options, key);
    }
}

// 任务队列
class TaskQueue {
    private queue: Task[] = [];
    private processing: number = 0;
    private maxConcurrent: number = 5;

    async add(task: Task): Promise<void> {
        this.queue.push(task);
        this.process();
    }

    private async process() {
        while (this.queue.length > 0 && this.processing < this.maxConcurrent) {
            const task = this.queue.shift();
            this.processing++;
            try {
                await this.execute(task);
            } catch (error) {
                // 自动重试
                if (task.retries < 3) {
                    task.retries++;
                    this.queue.push(task);
                }
            } finally {
                this.processing--;
            }
        }
    }
}
```
