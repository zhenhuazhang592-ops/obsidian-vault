# 漠玫牛油果漫剧项目 - 核心Agent实现

## 一、剧本生成Agent（Script Agent）

### 1.1 架构概述

```
用户请求
    ↓
WebSocket /script/generate
    ↓
ScriptAgent.call()
    ↓
┌────────────────────────────────────────────────────────────┐
│                     Main Agent                              │
│  - 协调 AI1(场景师)、AI2(剧本师)、director(导演)          │
│  - 管理对话历史                                            │
│  - 构建角色上下文                                          │
└────────────────────────────────────────────────────────────┘
    ↓
┌────────────────────────────────────────────────────────────┐
│                    Tool System                             │
│  - getTopic / getCharacter                                │
│  - saveScript / updateScript                              │
│  - generateShot                                            │
└────────────────────────────────────────────────────────────┘
```

### 1.2 三Agent协作流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│    AI1      │     │    AI2      │     │  director   │
│  (场景师)   │     │  (剧本师)   │     │   (导演)    │
├─────────────┤     ├─────────────┤     ├─────────────┤
│ 分析选题    │     │ 生成剧本    │     │ 审核质量    │
│ 匹配角色    │────▶│ 融入台词    │────▶│ 80分及格    │
│ 设定场景    │     │             │     │             │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 1.3 核心Prompt

#### script-main（主调度Agent）

职责：
- 协调场景师(AI1)、剧本师(AI2)、导演(director)工作流程
- 强制执行阶段转换规则
- 管理用户确认环节
- 禁止自行生成/修改剧本内容

#### script-scene（场景师）

职责：
- 调用 getTopic 获取选题信息
- 分析选题对应的真实场景
- 确定出场角色

分析维度：
- 场景匹配：漠玫轻食餐厅的哪个区域
- 角色搭配：根据选题类型选择合适配角
- 时段设定：午餐/下午茶/晚餐

#### script-writer（剧本师）

核心方法论：

| 法则 | 说明 |
|-----|------|
| 黄金前3秒 | 开场必须有冲突/悬念 |
| 情绪过山车 | 作死→自信→打脸→科普 |
| 台词生活化 | 角色台词必须像真人说话 |
| 科普自然融入 | 不能说教，要像聊天 |
| 死亡定格 | 死亡必须有视觉冲击 |
| 复活彩蛋 | 片尾复活形成记忆点 |

#### script-director（导演）

职责：
- 审核剧本质量
- 检查知识点准确性
- 确保角色性格一致
- 80分及格线

## 五、任务队列系统

### 5.1 队列架构

```typescript
class TaskQueue {
  private keys: string[];
  private queue: Task[];

  async submit(task: GenerationTask): Promise<TaskResult> {
    // 1. 轮询选择 Key
    const key = this.roundRobin();

    // 2. 提交任务
    const result = await this.execute(task, key);

    // 3. 失败重试
    if (result.status === 'failed' && task.retries < 3) {
      return this.submit({ ...task, retries: task.retries + 1 });
    }

    return result;
  }
}
```

### 5.2 并发控制

```typescript
const CONCURRENCY_LIMIT = 5;  // 最大并发数

async function batchGenerate(tasks: Task[]): Promise<Result[]> {
  const queue = new PQueue({ concurrency: CONCURRENCY_LIMIT });

  const promises = tasks.map(task =>
    queue.add(() => generate(task))
  );

  return Promise.all(promises);
}
```
