# 漠玫牛油果漫剧项目 - 数据库设计

## 数据库初始化

数据库初始化在 `src/lib/initDB.ts` 中完成，使用 better-sqlite3 创建表结构。

## 核心表结构

### 1. t_project（项目表）

```typescript
interface t_project {
  id: number;
  name: string;           // 项目名称，如"牛油果日常第一季"
  intro: string;          // 项目简介
  season: number;         // 季数
  episodeCount: number;   // 集数
  status: string;         // draft/active/completed
  createTime: number;
  updateTime: number;
}
```

### 2. t_topic（选题表）

```typescript
interface t_topic {
  id: number;
  projectId: number;      // 关联项目
  episode: number;        // 集数
  title: string;          // 选题标题，如"冻死"
  knowledge: string;      // 知识点
  category: string;       // 分类：保存不当/挑选失误/搭配禁忌/吃法作死/玄学死亡
  pattern: string;        // 剧情模式
  status: string;        // pending/generated/approved
  createTime: number;
}
```

### 3. t_script（剧本表）

```typescript
interface t_script {
  id: number;
  topicId: number;        // 关联选题
  content: string;        // 剧本正文(JSON格式)
  scenes: string;         // 场景列表(JSON)
  characters: string;     // 出场角色(JSON)
  duration: number;       // 时长(秒)
  status: string;        // draft/approved
  createTime: number;
  updateTime: number;
}
```

**content 字段结构：**
```json
{
  "topicId": 1,
  "title": "冻死",
  "duration": 75,
  "acts": [
    {
      "act": 1,
      "title": "开场",
      "duration": 5,
      "shots": [
        {
          "shot": 1,
          "time": "00:00-00:05",
          "shotType": "特写",
          "scene": "漠玫轻食餐厅门口",
          "action": "雅琴姐推门进入",
          "dialogue": "老板，给我做个牛油果沙拉！",
          "lipSync": "正常"
        }
      ]
    }
  ]
}
```

### 4. t_character（角色表）

```typescript
interface t_character {
  id: number;
  name: string;           // 角色名：漠小漠/玫博士/紫薯精等
  role: string;           // 角色类型：主角/配角/客串
  bible: string;          // 6层锚点信息(JSON)
  referenceImages: string; // 参考图URLs(JSON数组)
  seedValue?: string;     // 种子值(用于保持一致)
  createTime: number;
}
```

**bible 字段结构：**
```json
{
  "identity": "漠小漠、牛油果、盲目自信",
  "appearance": "胖乎乎椭圆形，深绿色果皮，两个黑色圆点眼睛",
  "costume": "天然果皮纹理，无装饰",
  "expression": "永远睡不醒的眼神，紧张时果皮表面渗出水珠",
  "action": "短腿小碎步、自信心叉腰、倒地抽搐",
  "viewpoint": "俯视45度，牛油果顶部特写"
}
```

### 5. t_shot（分镜表）

```typescript
interface t_shot {
  id: number;
  scriptId: number;       // 关联剧本
  topicId: number;       // 关联选题
  sceneIndex: number;    // 场景序号
  shotIndex: number;     // 分镜序号
  timeRange: string;     // 时间范围，如"00:00-00:05"
  shotType: string;      // 镜头类型：特写/中景/全景等
  scene: string;         // 场景描述
  action: string;        // 动作描述
  characters: string;    // 出场角色(JSON)
  prompt: string;        // AI图像生成提示词
  imageUrl?: string;     // 生成的图片URL
  videoUrl?: string;     // 生成的视频URL
  status: string;        // pending/generating/completed
  createTime: number;
}
```

### 6. t_video（视频表）

```typescript
interface t_video {
  id: number;
  topicId: number;        // 关联选题
  scriptId: number;      // 关联剧本
  fileUrl: string;       // 视频文件URL
  duration: number;      // 时长(秒)
  resolution: string;    // 分辨率，如"1080x1920"
  size: number;          // 文件大小(字节)
  status: string;        // generating/completed/failed
  createTime: number;
}
```

### 7. t_task（任务表）

```typescript
interface t_task {
  id: number;
  type: string;          // 任务类型：script/character/shot/video
  targetId: number;      // 关联目标ID
  status: string;        // pending/processing/completed/failed
  progress: number;      // 进度0-100
  result?: string;       // 生成结果
  error?: string;        // 错误信息
  retries: number;       // 重试次数
  startedAt?: number;
  completedAt?: number;
}
```

### 8. t_prompt（提示词模板表）

```typescript
interface t_prompt {
  id: number;
  name: string;           // 模板名称
  type: string;          // 模板类型：script/character/shot/video
  content: string;        // 提示词内容
  variables: string;      // 变量定义(JSON)
  version: number;       // 版本号
  isDefault: boolean;    // 是否默认模板
  createTime: number;
}
```

## 表关系

```
t_project
  │
  ├── t_topic (1对多)
  │     │
  │     ├── t_script (1对1)
  │     │     │
  │     │     └── t_shot (1对多)
  │     │
  │     ├── t_video (1对1)
  │     │
  │     └── t_task (1对多)
  │
  └── t_character (1对多)
```

## 核心数据流

```
1. 创建项目 → t_project 表
2. 添加选题 → t_topic 表
3. 生成剧本 → t_script 表 → t_shot 表
4. 生成角色 → t_character 表
5. 生成分镜图 → t_shot 表 (更新 imageUrl)
6. 生成视频 → t_video 表
7. 任务追踪 → t_task 表
```
