## 三、核心问题：情绪标注双轨问题

### 问题描述

- `manzhou-voice.md` 定义了 **11个VO情绪标签**：冷峻/嘲讽/暴怒/哽咽/颤抖/平静/温柔/绝望/紧绷/警觉/克制
- `manzhou-bgm.md` 定义了 **12个BGM情绪标签**：悬疑/压迫/甜蜜/史诗/欢快/紧张/悲伤/神秘/浪漫/战斗/低沉/诡异

两套系统**语义高度重叠但标签不同**：
- VO说"紧绷"，BGM说"紧张"
- VO说"绝望"，BGM说"悲怆"
- 八维情感向量（EmoVec）已定义并与VO标签建立了 cross_map 映射

### 影响

AI填写分镜时，VO情绪和BGM情绪可能不一致，且无自动推导机制。

### 1. manzhou.config.yaml（主配置）

```yaml
# AI漫剧生产系统 - 统一配置
version: "2.0.0"
last_updated: "2026-03-25"

# 项目结构
project:
  base_path: "AI漫剧生产/"
  template:
    - "00-项目信息/"
    - "01-IP档案/"
    - "02-剧本/"
    - "03-分镜/"
    - "04-Prompts/"
    - "05-资产库/"
    - "07-音频包/"

# 角色ID体系
character:
  id_format:
    protagonist: "protagonist_XX"    # protagonist_01, protagonist_02
    antagonist: "antagonist_XX"
    supporting: "supporting_XX"
    cameo: "cameo_XX"
  fingerprint:
    versions: ["V1", "V2", "V3", "V4", "V5"]
    suffix_format: "_V{n}"          # LinFeng_V1, LinFeng_V2

# 角色标记（统一格式）
markup:
  character: "【【{name}】】"        # 【【LinFeng】】
  fingerprint: "{name}_{V{n}}"       # LinFeng_V1
  prohibited:
    - "外貌描述"                      # 分镜禁止描述角色外貌
    - "..."                          # 禁止占位符
    - "等"                           # 禁止"等"

# 景别规范
shot_size:
  WS: "Wide Shot / 全景"
  MLS: "Medium Long Shot / 中全景"
  MS: "Medium Shot / 中景"
  MCU: "Medium Close-Up / 中近景"
  CU: "Close-Up / 特写"
  ECU: "Extreme Close-Up / 大特写"
  POV: "Point of View / 主观视角"

# 镜头时长标准（统一）
timing:
  standard_scene: "3-5秒"
  dialogue_scene: "5-8秒"
  action_scene: "2-4秒"
  transition: "1-2秒"

# 情绪向量（EmoVec）
emotion_vector:
  dimensions: 8
  labels: ["喜", "怒", "哀", "惧", "厌恶", "低落", "惊喜", "平静"]
  range: [0.0, 1.0]
```

### 5. audio.schema.yaml（音频标签格式）

```yaml
# 音频标签统一格式

tags:
  voice:
    format: 'voice:({情绪}/{语速})"{台词}"'
    example: 'voice:(温柔/慢)"我等你很久了"'
    emotion_source: "emotion.schema.yaml#vo_emotions"

  bgm:
    format: "[BGM: {情绪描述}]"
    example: "[BGM: 甜蜜]"
    emotion_source: "emotion.schema.yaml#bgm_standalone"

  sfx:
    format: "[SFX: {音效}]"
    example: "[SFX: 玻璃碎裂]"
    sfx_categories:
      - 环境音
      - 动作音
      - 情绪音
      - 转场音
```
