```mermaid
graph TB
    INPUT_NOVEL["小说文本"] --> IP_PARSER["IP解析"]

    SCRIPT --> HIT["爆款算法"]
    SCRIPT --> VISUAL["视觉风格"]
    SCRIPT --> CHARACTER["角色一致性"]
    HIT --> STORYBOARD["分镜Prompt"]
    VISUAL --> STORYBOARD
    CHARACTER --> STORYBOARD
    STORYBOARD --> VOICE["配音标签"]
    STORYBOARD --> BGM["BGM"]
    STORYBOARD --> SFX["SFX"]
    VOICE --> AUDIO_INT["音频整合"]
    BGM --> AUDIO_INT
    SFX --> AUDIO_INT
    AUDIO_INT --> SAFETY["风控审核"]
    SAFETY --> PASS["PASS"]
    SAFETY --> FAIL["FAIL"]
    PASS --> ASSET["成片资产包"]
```
