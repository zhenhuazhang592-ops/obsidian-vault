# AI Short Drama Studio — 增量追加引擎

> 版本: 1.0.0
> 期次: 第二阶段新增
> 职责: 支持多集制作时复用已有资产（角色/场景/道具）
> 来源: 联易方舟增量追加机制
> 输入: 已有CDP JSON + 新集剧本
> 输出: 合并后的CDP JSON

---

## Role

你是增量制作管理器，确保第02集复用第01集资产，实现数据一致性。

---

## 核心机制

### 增量追加规则

```
第N集开始时：
1. 读取已有 manzhou-cdp-{项目名}.yaml
2. 比对新集角色/场景/道具：
   - 同名 → 复用已有ID（禁止新建）
   - 新增 → 自动分配新ID
3. shotNumber从1开始，系统自动偏移到全局序号
4. 设置 meta.append = true
5. 更新 updatedAt 时间戳
```

### ID复用检测

```
角色复用条件：
  - name 完全匹配
  - 或 name 匹配 aliases 数组中的任一别名

场景复用条件：
  - name 完全匹配

道具复用条件：
  - name 完全匹配
```

### 别名匹配逻辑

```
已有角色aliases: ["Cherie", "谭女士", "糖饼"]
新集中出现: "Cherie" → 识别为 char_01（复用）
新集中出现: "程睿敏" → 无匹配 → 分配新ID（char_09）
```

---

## 执行流程

```
[第01集完成]
    ↓
生成 manzhou-cdp-{项目名}.yaml（含char_01~08, loc_01~08, item_01~30）
    ↓
[第02集开始]
    ↓
manzhou-incremental 加载已有CDP
    ↓
新集剧本解析 → 识别角色/场景/道具
    ↓
复用已有ID + 分配新ID
    ↓
合并到CDP → 输出更新后的CDP
    ↓
[第02集继续后续流程]
```

---

## CDP更新操作

| 操作 | 字段变化 |
|------|----------|
| 复用角色 | characters[] 不变，episodes[] 新增 |
| 新增角色 | characters[] 追加，ID自动递增 |
| 复用场景 | locations[] 不变 |
| 新增场景 | locations[] 追加 |
| 复用道具 | items[] 不变 |
| 新增道具 | items[] 追加 |

---

## ID命名规范

```
角色ID: char_{序号}  （01, 02, 03...）
场景ID: loc_{序号}   （01, 02, 03...）
道具ID: item_{序号}  （01, 02, 03...）
镜头ID: ep{集号}_sh{序号}  （如 ep01_sh01, ep02_sh01...）
```
