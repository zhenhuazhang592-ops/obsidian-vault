## 一、竞品全链路对比

```
联易方舟 V3 六步流程（完整链路）：
Step1 全局设置 → Step2 故事脚本 → Step3 角色/场景/物品资产
```

## 二、核心差距根因分析

### 2.1 最大的3个缺口

**缺口1：角色/场景/物品资产层（Step3）完全缺失**
- 联易方舟 Step3 = 独立资产库（character/location/item）
- 漫舟：IP解析提取了数据，但没有生成任何图片资产
- 后果：分镜 Prompt 里写 `[ID: TanBin_V1]` —— **但没有参考图**，AI 生成视频时人物随机

**缺口2：分镜两步（ImagePrompt + VideoPrompt）分离**
- 联易方舟每个 shot 有两个独立 Prompt：
  - `imagePrompt` → 生成分镜图（3×3九宫格）
  - `videoPrompt` → 基于分镜图生成视频
- 漫舟：只有 VideoPrompt，没有 ImagePrompt
- 后果：视频生成没有一致性参考，图生视频 > 文生视频的质量差距巨大

**缺口3：短剧化改编刀（Step0）不存在**
- 小说原文直接进剧本，没有压缩/改编
- 联易方舟剧本正文 Prompt 要求：开场5秒抓人，台词≤15字
- 漫舟第1集：2分37秒，小说原文直接搬，节奏拖沓

### 2.2 次要缺口

- 全局设置（风格/时长/画幅）没有让用户选择
- 九宫格分镜图（角色一致性神器）缺失
- 导出到剪映/ZIP 缺失
- TTS 配音合成缺失

## 三、优化方案

### 3.1 完整链路设计

```
【Step 0】全局设置（用户必选）
  ├── 风格预设（11选1）：anime / cn_anime / cn_3d / ink / cyber / us_comics / real / horror / pixar / shinkai / miyazaki
  ├── 画幅比例：9:16（竖屏）/ 16:9（横屏）
  ├── 单镜头时长：8s / 10s / 15s（默认15s）
  └── 目标集数：N集（默认12集）

【Step 1】小说 → 短剧化改编（新增）
  ├── 调用 manzhou-novel-adapter（新增Skill）
  ├── 应用"八大编剧法则"：剃刀法则/视觉外化/情绪过山车
  ├── 台词≤15字限制
  └── 输出：压缩后的短剧脚本（按集拆分）

【Step 2】IP解析（已有，增强）
  ├── 提取角色/场景/物品 → CDP JSON
  ├── 角色数量限制（主角≤3，反派≤2，配角≤5）
  └── 增量追加模式（续集复用已有资产）

【Step 3】资产设计（新增，核心）
  ├── manzhou-character-design（新增Skill）
  │   ├── 6层锚点：身份/外貌/服装/表情/动作/视角
  │   ├── 角色卡生成Prompt（PromptTemplate）
  │   ├── 九宫格定妆照（正面/侧面/背面/多表情）
  │   └── 角色DNA手册输出
  ├── manzhou-scene-design（新增Skill）
  │   ├── 场景基底图Prompt
  │   └── 场景光影规格
  └── manzhou-item-design（新增Skill）
      ├── 道具图Prompt（与角色风格统一）
      └── 道具复用规则

【Step 4】剧本生成（增强）
  ├── 时长校准：单集目标 = 镜头数 × 单镜头时长
  │   └── 15s × 8镜 = 120s = 2分钟
  ├── 台词限制：单句≤15字（联易方舟规则）
  └── 每集结构：开场5秒抓人 + beats + 结尾强钩子

【Step 5】分镜脚本（重写）
  ├── 每个shot输出：
  │   ├── shot_id: "P01"
  │   ├── durationSec: 15
  │   ├── script: 动作+场景描述
  │   ├── dialogue: [{"speaker": "c_c1", "text": "..."}]
  │   ├── imagePrompt: 九宫格分镜图Prompt（新增！）
  │   └── videoPrompt: Seedance/Kling VideoPrompt（增强）
  ├── 九宫格分镜表（3×3单图）
  │   └── 单张包含9个镜头的机位变化
  └── 180度轴线规则强制执行

【Step 6】分镜图生成（新增）
  ├── 调用 Gemini/SD 生成九宫格分镜图
  ├── 九宫格约束：3×3网格、清晰边框、每格右上角标签
  └── 角色一致性：注入角色DNA手册 + --cref参考图

【Step 7】视频生成（增强）
  ├── 图生视频（推荐）：九宫格分镜图作为垫图
  ├── 视频模型：支持 Seedance / Kling / Veo / Sora2
  └── 批量生成 + 进度追踪

【Step 8】音频制作（新增）
  ├── TTS配音：台词 → 语音（唇形同步）
  ├── BGM生成：情绪曲线 → 音乐描述Prompt
  └── SFX音效表

【Step 9】预览导出（新增）
  ├── 镜头预览（已生成/待处理）
  ├── 一键导出剪映草稿
  └── ZIP打包下载（含视频/分镜图/音频）
```

## 六、联易方舟Prompt模板直接复用

### 6.1 剧本正文Prompt（联易方舟SCRIPT_WRITING规则）

```
【格式要求 必须严格遵守】
- 开头第一行：【第${episodeNumber}集】
- 每集3-6场，每场：时间+地点+人物+动作对白
- 开场5秒必须抓人（对峙/撞破/翻车/打脸）
- 台词要求：口语化、短句、不超过15字
- 结尾强钩子：新证据/新威胁/身份翻面/关键人物闯入
- 镜头提示仅限括号内短提示（特写/切快/停顿），每场不超过2处
- 只输出剧本正文，禁止Markdown格式
```

### 6.2 剧本大纲Prompt（联易方舟SCRIPT_OUTLINE规则）

```
【核心约束】
- title：不超过200字
- characters：2-4人，每集hook/twist/endingHook均不超过30字
- beats：每集3-5条，每条不超过20字
- 第1集必须立刻抛出主冲突与目标
- 每5集一个小高潮，每10集一个大反转
- 反转机制要多样化（身份翻转/立场背刺/证据反杀/误会反转至少两种）
```

## 八、短剧节奏标准（核心约束固化）

| 参数 | 标准值 | 说明 |
|------|--------|------|
| 单集时长 | 2分钟（120s） | 联易方舟标准 |
| 单镜头时长 | 15秒（默认） | 可选8s/10s/15s |
| 每集镜头数 | 8个 | 120÷15=8 |
| 开场抓人 | ≤5秒 | 必须冲突已爆发 |
| 台词上限 | ≤15字/句 | 联易方舟强制 |
| 小高潮间隔 | ≤45秒 | 每45秒一个爽点 |
| 结尾钩子 | ≥5秒悬念 | 停在动作中段 |
| 反转频率 | 每2-3分钟一个 | 身份翻/证据反杀/误会 |
