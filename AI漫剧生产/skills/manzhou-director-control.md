# 漫舟导演控制塔 · manzhou-director-control

> 版本：v1.0.0
> 职责：Step 4 → Step 7 之间的**导演分析层**（剧本→导演思维→分镜脚本）
> 依赖：Step 4 剧本完成
> 前置条件：CDP角色/场景已建立（Step 2）

---

## 核心职责

**把剧本翻译成导演语言**——不是重写剧本，而是从导演视角分析剧本，输出分镜师和AI导演必须遵循的指令。

三个核心产出：
1. **场景情绪地图**（Scene Emotion Map）— 每场戏的情绪定位
2. **节拍追踪表**（Beat Tracker）— 爽点/反转/钩子的时空分布
3. **运镜意图指令**（Directing Intents）— 为什么这个镜头要这样拍

---

## 导演分析工作流（4个阶段）

### 阶段D1：情绪基调定义

```
输入：剧本（第X集）
输出：情绪基调卡

格式：
## 第X集 · 情绪基调卡

- **情绪类型**：爽 / 虐 / 甜 / 悬疑 / 复仇 / 逆袭 / 甜宠 / 虐恋
- **基调色温**：冷 / 暖 / 明 / 暗 / 对比强烈 / 柔和
- **叙事节奏**：快节奏紧凑 / 中速叙事 / 慢速沉浸
- **本集核心情绪**：[一句话描述，如"压抑中的希望""]
- **情绪转折点**：[列出本集3个情绪转折位置]
```

### 阶段D2：场景节拍分析（必做！）

```
输入：剧本（逐场）
输出：场景节拍表

## 第X集 · 场景节拍表

| 场景 | 场景名 | 功能 | 情绪值 | 节拍位置 | 核心动作 |
|------|--------|------|--------|---------|---------|
| S01 | 会议室 | TENSION（对峙） | L3 | B06 | 曾婵贞宣布 |
| S02 | 茶水间 | MOOD（情绪过渡） | L2 | B07 | 方芳安慰 |
| S03 | 停车场 | REVEAL（揭露） | L4 | B10 | 程睿敏警告 |
| ... | ... | ... | ... | ... | ... |

### 场景功能类型（必填）

- **TENSION**：制造冲突、对抗升级（对话场景）
- **MOOD**：情绪铺垫、氛围营造（独处场景）
- **REVEAL**：揭露关键信息（反转点）
- **ACTION**：推动情节发展（动作场景）
- **TRANSITION**：过渡连接（转场）
- **CLIFFHANGER**：制造悬念（结尾钩子）
```

### 阶段D3：节拍追踪（Beat Tracker）

```
输入：场景节拍表
输出：节拍追踪（逐镜）

## 第X集 · 节拍追踪

| 时间点 | 镜头 | 情绪曲线 | 节拍类型 | 导演意图 |
|--------|------|---------|---------|---------|
| [00:00-00:08] | P01 | L1→L2 | B01开场 | 建立职场压抑感 |
| [00:08-00:16] | P02 | L2→L3 | B04催化剂 | 镜头跟随潭斌反应 |
| [00:16-00:24] | P03 | L3 | B05辩论 | ECU瞳孔放大 |
| ... | ... | ... | ... | ... |

### 情绪曲线符号

- L1（平静）：无动作，冷场
- L2（克制）：内心波动，外表平静
- L3（隐忍）：明显压抑情绪
- L4（爆发）：情绪外化，行动激进
- L5（高潮）：最高强度，持续动作
```

### 阶段D4：运镜意图指令（Directing Intents）

```
输入：节拍追踪
输出：运镜意图指令（分镜师必须遵循）

## 第X集 · 运镜意图指令

### 镜头P01（[00:00-00:08]）

**情绪状态**：L1平静
**节拍位置**：B01开场画面
**运镜意图**：
- 建立镜头（Establishing Shot）→ WS全景
- 冷蓝月光 + 台灯暖黄对比 → 突出孤独感
- 镜头缓慢推进（dolly in）→ 引导视线聚焦潭斌

**禁止**：
- ❌ 不要在此镜头使用ECU（情绪未到位）
- ❌ 不要用快速剪辑（节奏需要慢）

### 镜头P02（[00:08-00:16]）

**情绪状态**：L2→L3隐忍
**节拍位置**：B04催化剂
**运镜意图**：
- 侧脸特写 → 捕捉潭斌收到邮件瞬间
- 屏幕蓝光 + 冷白光线 → 科技感冲击
- 短促cut → 情绪快速收紧

**禁止**：
- ❌ 不要用WS（太远，情绪传递不到位）
```

## 导演控制塔输出文件规范

```
## 第X集 · 导演控制塔输出

### 文件名：03-导演分析/第X集-导演控制塔.md

### 内容结构：

1. 情绪基调卡
2. 场景节拍表
3. 节拍追踪表
4. 运镜意图指令

### 必须包含的决策点：

- 每场戏的情绪定位（MOOD/TENSION/REVEAL/ACTION/TRANSITION/CLIFFHANGER）
- 每个节拍的情绪值（L1-L5）
- 每个镜头的运镜意图（为什么这样拍）
- 180度轴线约束（双人对话场景必须标注）
- 运镜节奏指令（快切/慢推/静态）

### 禁止项：

- ❌ 不允许导演控制塔描述角色外貌（外貌归CDP管）
- ❌ 不允许导演控制塔写台词（台词归剧本管）
- ❌ 不允许导演控制塔跳过场景功能标注
- ❌ 不允许情绪曲线跳变超过2级（L1→L4禁止）
```

## 与分镜脚本的关系

**导演控制塔 → 分镜脚本的约束传递**：

```
导演控制塔输出
    ↓
[运镜意图] → manzhou-shot-script.md 的 camera_action 字段
[场景功能] → manzhou-shot-script.md 的 emotion_level 字段
[节拍位置] → manzhou-shot-script.md 的 节拍# 字段
[轴线约束] → manzhou-shot-script.md 的 180度轴线 字段
[情绪曲线] → manzhou-shot-script.md 的 emotion_curve 字段
```

**正确的调用顺序**：
```
Step 4 剧本生成
    ↓
Step 4.5 导演控制塔（NEW！本Skill）
    ↓
Step 7 分镜脚本（manzhou-shot-script）
    ↓
    manzhou-shot-script.md 必须引用 @导演控制塔/@节拍表
```
