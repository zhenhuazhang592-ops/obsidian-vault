## 逐分钟BGM设计

### 00:00 - 00:30 【建立·都市夜】

**音乐类型**：简约钢琴旋律线（右手单音）
**情绪**：平静，都市夜晚，职业日常
**音乐元素**：
- 单一钢琴音（A音），每4秒一个单音
- 极淡的城市环境底噪（混音电平-30dB）
- 无低音提琴，无鼓点

**推荐曲库参考**：
- Hans Zimmer - "Time" 前奏变体（去掉弦乐）
- Ludovico Einaudi - "Nuvole Bianche"（降速50%）
- 原声创作：[A] [C] [E] 降调循环，60BPM

**混音**：
```
BGM 音乐: -18dB（极轻背景）
SFX: 键盘声（主导）+ 城市底噪
VO: 无（静音段）
```

---

### 00:30 - 01:00 【转折·邮件降临】

**音乐类型**：钢琴骤停 + 低频弦乐铺垫（骤升）
**情绪**：平静打破，紧张潜伏
**音乐元素**：
- 第40秒：钢琴旋律突然停止（1秒静音）
- 第45秒：低弦乐群骤然进入（staccato，升降走向）
- 弦乐：G♭ → A → B♭ 不协和走向
- 节奏：60BPM → 突然加速到72BPM（心率模拟）

**推荐曲库参考**：
- Hans Zimmer - "Why So Serious" 变体（去除鼓点）
- 原创：B♭小调弦乐群，staccato，渐强

**混音**：
```
BGM: +3dB 渐强（-15dB → -12dB）
SFX: 邮件提示音（+3dB，单独出现）
VO: 旁白淡入（00:35处）
```

---

### 01:00 - 02:00 【核心·震惊与焦虑】

**音乐类型**：低频弦乐 + 钢琴不协和音
**情绪**：震惊，焦虑，强撑冷静
**音乐元素**：
- 低弦乐：持续嗡鸣（B1-B♭1-A1）
- 钢琴：单音不协和（#F4 / B4 / E♭5，交替出现）
- 无固定节拍，模拟内心混乱
- 第01:15：弦乐短暂消退（余永麟电话场景）

**推荐曲库参考**：
- Jóhann Jóhannsson - "The Theory of Everything" 变体
- Max Richter - "On the Nature of Daylight"（降速30%）

**混音**：
```
BGM: -12dB
VO: TanBin对话为主
SFX: 电话拨出音 + 背景嘈杂（余永麟场景）
```

---

### 02:00 - 03:00 【情绪引爆·邮件揭示时刻】

**音乐类型**：无调性弦乐 + 极简钢琴
**情绪**：情绪峰值，震惊
**音乐元素**：
- 极简钢琴：单音C♯5，重复，每1.5秒一次
- 弦乐群：低频嗡鸣骤停
- 短暂无声（第02:10-02:15）
- 随后：极低频B♭0音效（次声，模拟心跳）

**推荐曲库参考**：
- Krzysztof Penderecki - "Threnody" 变体
- Clint Mansell - "The Conspiracy of the General" 变体

**混音**：
```
BGM: -6dB（相对电平）
VO: 旁白独白（压低）
SFX: 无（制造听觉真空）
```

---

### 03:00 - 04:00 【尾声·暴风雨前的平静】

**音乐类型**：单一钢琴音 + 城市夜色
**情绪**：悬念，余韵，暴风雨前
**音乐元素**：
- 单一钢琴音（A4），每3秒一次，逐渐变轻
- 弦乐群淡入：极轻，C大调，暗示某种慰藉（与震惊形成反差）
- 第03:30：钢琴音停止
- 最后30秒：完全寂静（除城市夜景环境音）

**推荐曲库参考**：
- Ryuichi Sakamoto - "Merry Christmas Mr. Lawrence" 结尾变体
- 原创：钢琴单音 A4 渐弱至无声

**混音**：
```
BGM: 渐弱（-12dB → -30dB → 完全无声）
环境音: 城市夜声（+3dB，主导最后30秒）
VO: 无
SFX: 无
```
