| 1 | 追热点 | 蹭热点同款效果 |

## 1. 追热点 - 飞驰人生3同款

**技巧**:
1. 给一段同款视频
2. 实拍一段关门视频
3. 把关键帧截出来作为强调
4. 房间的门作为赛车在赛道上行驶

**要点**:
- 用不涉及真人版权的素材
- 截取关键帧强调画面
- 替换关键元素

## 2. 商业广告 - 运动饮料

**提示词**:
```
为图中产品生成一个精美高级的运动饮料广告，
注意分镜编排，明快的节奏和快剪，高级的商业广告。
```

**特点**:
- 一次性做好配乐和文字slogan输出
- 所有分镜中保持产品一致性
- 好的分镜编排能力

---

## 3. 品牌宣传 - 无印良品

**提示词**:
```
帮我生成一个讲述无印良品这个品牌的宣传片，
中间植入这个台灯
```

**特点**:
- 直接告诉品牌名字，自动匹配品牌调性
- 5秒时长也能呈现完整状态

---

## 4. 穿搭变装

**提示词**:
```
让一个女生依次换上@图1 @图2 @图3 @图4 @图5 @图6 六套服装
进行卡点变装展示。
每套服装需要包含半身走位和整体穿搭全身的展示。
运镜要求使用不同景别流畅切换，
加上符合调性的广告音乐
```

**技巧**:
- 用 `@图N` 引用多张服装图片
- 明确 `半身走位` + `全身展示`
- 指定 `不同景别`

---

## 5. 直播带货 - SK-II面霜

**提示词**:
```
生成一段 15 秒带货口播视频，产品为图中面霜。
要求人物亲手涂手上，给出近景展示，侧脸转动展示细节，
镜头从半身到特写切换 3 次。
口播要包含卖点，最后给出强行动号召。
自动生成字幕，节奏紧凑，带轻微环境音。
```

**特点**:
- 识别产品（SK-II）
- 配上对应口播（高浓度PITERA、五胜肽）
- 口播匹配视频

---

## 6. 动态海报

**提示词**:
```
一个15秒竖屏 9:16 的卡点音乐短片，
背景音乐使用@音频1，视频全程保持固定机位景别不变，
视频中的元素陆续按@图片1中的九宫格分镜依次显现，
从左上角第一个镜头作为开始从左到右、从上到下依次推进。
```

**流程**:
1. 用 **Nano Banana Pro** 生成九宫格分镜图
2. 让 **Seedance 2.0** 生成动态效果

**Tips**:
- 补充更详细的信息明确元素出现顺序

---

## 7. 广告复刻 - 无人机

**提示词**:
```
模仿【@视频1】的分镜设计，
把视频中所有产品都替换成【@图片1】的无人机，
制作的视频完全是围绕【@图片1】的无人机进行多角度的展示，
同时更换配音旁白和音乐为介绍无人机的内容，
画面主要颜色使用蓝色和黑色
```

**Tips**:
- 某镜头效果不好时，用 Nano Banana Pro 生成该分镜图片
- 告诉 Seedance 2.0 替换指定镜头

## 8. 真人短剧 - 豪门恩怨

**提示词**:
```
【风格】豪门恩怨、真假千金、极致反转、撕绿茶、高定礼服、美艳御姐

【角色】
真千金（烈焰红唇，黑天鹅高定礼裙，气场全开）
假千金（小白花扮相，泪眼装可怜）

【全局要求】
9:16 竖屏，电影质感，奢华宴会厅水晶灯与香槟塔，光影高级。
真千金与假千金人物一致性稳定，脸不变，礼服不变。
口型与字幕逐字完全一致，字幕即台词本身。
每句台词控制在短句，清晰可读。

"[00:00-00:05] 奢华宴会厅中景，假千金故意撞翻桌边古董花瓶，清脆碎裂，
她立刻坐地抱住碎片边缘假哭，抬手指向真千金，周围宾客围成半圈，纷纷侧目。
口型与字幕：姐姐，你为什么这样"

"[00:05-00:10] 真千金近景，冷艳俯视，红唇微扬带嘲讽，抬手甩出一份文件
砸到假千金面前。镜头切文件特写，画面只需要清晰看到大字 DNA 与红色印章 无血缘，
不要密集小字。假千金抬眼，泪停住，脸色发白。
口型与字幕：演够了吗"

"[00:10-00:15] 全场反应一瞬，宾客捂嘴惊呼，镜头立刻切回真千金。
真千金走到主位旁，从假千金头上干脆取下皇冠，稳稳戴回自己头上，
转身落座主位，抬眼扫全场。两名保安出现把假千金拖走，
只给她被拖走的背影与无力挣扎。真千金定住女王姿态。
口型与字幕：这是我家，滚"
```

**要点**:
- 非常准确抓住短剧节奏
- 人物一致性稳定
- 口型与字幕一致

## 9. AI漫剧 - 武侠

**提示词**:
```
帮我根据下面的小说剧情要求生成动漫，
将画风动作打斗表现严格对齐@视频1 的风格。

老者身形如鹤，袖袍一抖便卷起劲风，逼得年轻剑客连退三步。
后者骤然低喝，剑尖挽出七朵虚影，正是"七星照月"的杀招。
老者却似早有所料，枯瘦五指如鹰爪扣住剑身，内力震旦——长剑寸寸崩断！
年轻人弃剑疾退，反手抽出腰间软鞭，鞭梢如毒蛇吐信直取老者双目
```

**技巧**:
- 找一段画风视频/图片给 Seedance 参考
- 能直接做出参考风格的动漫
