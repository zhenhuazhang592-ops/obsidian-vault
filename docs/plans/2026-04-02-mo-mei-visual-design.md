## 一、定位与目标

### 1.1 核心定位

**漠玫视觉**是运行在 Claude Code 内的 AI 视觉资产生产 Agent，基于漠玫（MoMei）品牌视觉规范，让运营人员上传生鲜实拍图后，一键产出全平台电商规格的视觉资产。

### 1.2 品牌视觉约束来源

所有 AI 生成的 prompt 必须内嵌以下品牌约束：

| 维度 | 规范 |
|------|------|
| **色彩** | 漠玫绿 `#2E7D32` / 牛油果绿 `#8BC34A` / 米白 `#FDFBF7` / 暖金 `#D4A853` / 墨色 `#1A1A1A` |
| **摄影风** | Apple 产品摄影感，自然光，浅景深，主体占画面 60-70%，留白 30%+ |
| **禁止** | 微商滤镜 / emoji 堆砌 / 过度锐化 / 荧光色 / 卡通风格 |
| **字体** | 思源宋体（标题）+ 思源黑体（正文），禁止圆润儿童字体 |

> 来源：`docs/plans/2026-03-29-momo-healthy-food-ecommerce-design.md` 第二节

## 二、输入与输出

### 2.1 输入

```
· 1-N 张实拍图（水果产品，JPG/PNG）
· 产品信息（JSON 或自然语言）：
  {
    "品名": "墨西哥哈斯牛油果",
    "品类": "avocado | durian | blueberry | other",
    "产地": "墨西哥米却肯州",
    "核心卖点": "奶油般绵密口感，油脂含量高达20%",
    "规格": "1kg / 2kg",
    "价格": "68-128元",
    "风格偏好": "minimal | origin | lifestyle |道具"  // 可选
  }
```

### 2.2 输出

**每个 SKU 输出以下资产：**

#### A. 主图（4 场景 × 全平台尺寸）

| 场景风格 | 描述 | 适用场景 |
|---------|------|---------|
| 极简净色 | 米白/浅灰背景，Apple 摄影感，光影干净 | 京东白底图、淘宝主图 |
| 原产地场景 | 农场/果园/山脉氛围，强调"源头直采"故事感 | 淘宝详情页Banner |
| 生活场景代入 | 现代厨房/餐桌，融入生活氛围，有代入感 | 抖音/小红书 |
| 极简+精致道具 | 净色背景+刀叉/瓷盘/亚麻布，克制高级感 | 品牌官网/公众号 |

**全平台尺寸：**
- 淘宝/天猫：800×800（1:1）、800×1066（3:4）
- 京东：800×800 白底精修图
- 拼多多：1:1 主图 + 3:4 长图
- 抖音小店：9:16 竖版主图

#### B. 详情页配图（5-8 张）

- 营养成分展示图（数据可视化风格）
- 产地故事图（1-2 张）
- 选购指南图（切面/熟度判断）
- 储存方法图
- 食用场景图（1-2 张）

#### C. 品牌海报（2 张）

- 横版（1920×800）：公众号/官网用
- 竖版（1080×1920）：朋友圈/抖音用

## 三、技术架构

### 3.1 执行流程

```
用户上传实拍图 + 产品信息
         ↓
┌─────────────────────────────────────────────┐
│ Step 1：品类识别 + 质量分析                   │
│ · 识别品类（牛油果/榴莲/蓝莓/其他）          │
│ · 分析实拍图：构图/光线/主体位置              │
│ · 输出风格推荐 + 场景关键词                   │
└─────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────┐
│ Step 2：场景合成（调用 baoyu-image-gen）      │
│ · 4 种场景各生成 1 张基础合成图               │
│ · 实拍图作为 Reference Image                  │
│ · 叠漠玫品牌 prompt 约束                      │
│ · 模型：Doubao-Seedream-4.5（推荐）          │
│        Google Gemini 3 Pro（备选）            │
└─────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────┐
│ Step 3：智能裁切（Fabric.js / Konva.js）    │
│ · 基础合成图 → 全平台尺寸批量输出             │
│ · 主体居中，保持构图比例                      │
│ · 边缘安全区保护（重要元素不切边）            │
└─────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────┐
│ Step 4：海报合成（Fabric.js 叠加）            │
│ · 最优合成图作为主视觉                       │
│ · 叠加：品名（思源宋体）/价格标签/品牌水印   │
│ · 输出：横版 + 竖版                          │
└─────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────┐
│ Step 5：详情页文案 + HTML 排版               │
│ · 根据品类生成：营养成分/产地故事/选购指南    │
│ · 调用 baoyu-markdown-to-html 输出           │
└─────────────────────────────────────────────┘
```

## 四、场景 Prompt 规范

### 4.1 通用约束（所有场景必须嵌入）

```
品牌调性：克制 · 精致 · 有呼吸感
色彩体系：漠玫绿 / 牛油果绿 / 米白 / 暖金 / 墨色
摄影风格：Apple 产品摄影感，自然光，浅景深
构图：主体占画面 60-70%，留白 30%+
禁止：emoji / 水印 / 过度锐化 / 荧光色 / 卡通风格 / 微商感滤镜
```

### 4.2 品类特色约束

| 品类 | 专属色彩关键词 | 专属场景元素 |
|------|-------------|-----------|
| 牛油果 | 奶绿色 / 奶油白 / 杏色 | 原木砧板 / 刀叉餐具 / 牛油果切面 |
| 榴莲 | 深金黄 / 棕褐色 / 黑色 | 芭蕉叶 / 热带水果刀 / 榴莲切面金黄果肉 |
| 蓝莓 | 深紫蓝 / 果粉白 / 翠绿 | 白色瓷盘 / 玻璃杯 / 酸奶碗 |
| 其他生鲜 | 米白 / 品牌绿 | 对应食材道具 |

### 4.3 四种场景 Prompt 示例

**极简净色场景：**
```
将实拍图中的[品类]合成到浅米白色背景中（#FDFBF7），
Apple产品摄影风格，自然侧光，主体居中，
留白30%以上，无任何道具，
漠玫品牌调性：克制·精致·有呼吸感。
禁止：emoji、文字水印、过度锐化。
```

**原产地场景：**
```
将实拍图中的[品类]合成到[产地名]农场/果园氛围中，
自然光包含清晨薄雾感，浅景深，
背景为远山或果树轮廓，地面有浅景深虚化，
漠玫品牌调性，强调"源头直采"故事感。
```

## 五、全平台尺寸规格

| 平台 | 图片类型 | 尺寸 | 比例 |
|------|---------|------|------|
| 淘宝/天猫 | 主图 | 800×800 | 1:1 |
| 淘宝/天猫 | 长图 | 800×1066 | 3:4 |
| 京东 | 白底主图 | 800×800 | 1:1 |
| 京东 | 副图 | 480×480 | 1:1 |
| 拼多多 | 主图 | 800×800 | 1:1 |
| 拼多多 | 长图 | 800×1200 | 2:3 |
| 抖音小店 | 主图 | 800×1066 | 3:4 |
| 抖音小店 | 竖版主图 | 1080×1920 | 9:16 |

**裁切优先级：**
1. 主体水果必须在安全区内（边距 ≥ 10%）
2. 主体中心点落在画面中心 ± 15%
3. 优先保留上方空间（文字/标签常在顶部）

## 六、海报合成规范

### 6.1 横版海报（公众号/官网）

```
尺寸：1920×800px（2.4:1）
结构：
  · 背景：合成主图（虚化度 20%，做底）
  · 底部色块：漠玫绿 #2E7D32，高度 200px，透明度 85%
  · 品名：思源宋体 Bold，72px，白色，居中
  · 副标题：思源黑体，36px，米白色，居中
  · 右下角：品牌 Logo + ©漠玫
```

### 6.2 竖版海报（朋友圈/抖音）

```
尺寸：1080×1920px（9:16）
结构：
  · 背景：合成主图（全出血）
  · 顶部渐变遮罩：黑→透明，透明度 40%
  · 品名：思源宋体 Bold，80px，白色，居中偏上
  · 核心卖点：思源黑体，36px，米白色，居中
  · 底部色块：漠玫绿 #2E7D32，高度 160px
  · 价格：思源黑体 Bold，48px，暖金色 #D4A853
  · 底部：品牌 Logo
```

## 七、详情页文案规范

### 7.1 内容模块

每个 SKU 详情页包含以下内容模块（自动生成，可人工调整）：

```
1. 产品头图（Step 2 产出，1:1 主图）
2. 品类标签 + 品名（H1）
3. 产地溯源（产地故事，100-150字）
4. 核心卖点（3-5 条，带图标）
5. 规格选择（SKU 卡片）
6. 营养成分表（数据可视化图）
7. 选购指南（图文）
8. 储存方法（图文）
9. 食用建议（图文）
10. 品牌背书（产地认证/质检报告说明）
11. CTA：私域导流（企微二维码）
```

### 7.2 文案风格约束

```
语气：专业但亲切，像朋友分享，不是广告
禁止：极限词（最好/第一/全网最低）/ 无来源的"研究表明"
SEO：在 H2、小标题中自然融入品类关键词
字数：每个模块 100-200 字
CTA：引导关注公众号，不直接强推购买
```

## 八、规模化生产能力

### 8.1 批量模式

支持一次处理多个 SKU：
```
输入：
  /mo-mei-visual --batch
  [
    {品名, 实拍图路径, 产品信息},
    {品名, 实拍图路径, 产品信息},
    ...
  ]

输出：
  output/
  ├── avocado-hass/
  │   ├── main-1:1.png          # 各尺寸主图
  │   ├── main-3:4.png
  │   ├── poster-v.png          # 竖版海报
  │   ├── poster-h.png          # 横版海报
  │   ├── detail/               # 详情页配图
  │   └── index.html            # 详情页
  ├── durian-monthong/
  │   └── ...
  └── blueberry-premium/
      └── ...
```

### 8.2 增量模式

支持单 SKU 追加产出：
```
/mo-mei-visual --sku avocado-hass --add-poster-style lifestyle
```
