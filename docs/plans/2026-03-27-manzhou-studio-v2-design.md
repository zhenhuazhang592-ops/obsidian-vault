# 漫剧工业化创作站 v2.0 设计文档

> 日期：2026-03-27
> 版本：v2.0
> 状态：已批准，待实施

---

## 一、设计目标

将现有 `manzhou-studio/index.html` 从单流程文本生成工具，重构为具备以下能力的多模块创作平台：

1. **文件上传**：支持 .txt/.md 小说文件（≤10万字）直接上传
2. **双风格体系**：动漫风格库（12种）+ 电影风格库（11种），支持多选
3. **视频比例选择**：9:16 / 16:9 / 1:1 / 4:3
4. **IP 智能解析**：从小说内容自动提炼角色/场景列表，支持手动增删改
5. **角色&场景可视化展示**：每个资产有独立卡片，含 DNA 锚点、一致性 Prompt
6. **分镜脚本两层分离**：L1 分镜图 Prompt → L2 视频生成 Prompt
7. **全局一致性机制**：角色 DNA + 场景 DNA 贯穿全流程

---

## 二、工作流重构

```
Step 00 项目配置 ⚙️
  ├─ 项目名称 / 类型 / 平台 / 时长（保留）
  ├─ 视觉风格体系（新增：动漫 + 电影风格多选）
  ├─ 视频比例选择（新增）
  └─ 风格锁定后自动生成全局 DNA 锚点

Step 01 小说改编 📖
  ├─ 文件上传区（新增：拖拽 + 点击，≤10万字）
  ├─ 文本粘贴区（保留）
  ├─ 字数统计 + 超出截断提示
  └─ AI 提炼剧本改编稿

Step 02 IP 解析 🧬
  ├─ 角色数量 / 场景数量设置（保留）
  ├─ 角色列表（从小说智能提炼，支持增删改）
  ├─ 场景列表（从小说智能提炼，支持增删改）
  └─ 每个资产自动生成 DNA 锚点 + YAML 档案

Step 03 剧本生成 🎬
  ├─ 导演要求备注（保留）
  ├─ AI 生成三合一剧本（剧本 + 导演意图 + BGM）
  └─ 全局 DNA 锚点注入

Step 04 角色 & 场景 🎭（重构为展示 + 生成层）
  ├─ 角色卡片网格（每个角色一张卡片）
  │   ├─ 角色名称 + 定位标签
  │   ├─ 外貌描述摘要
  │   ├─ 角色 DNA 锚点（关键词）
  │   ├─ 一致性生图 Prompt（中英双语）
  │   └─ 参考图说明（用于 LibTV 等工具）
  ├─ 场景卡片网格（每个场景一张卡片）
  │   ├─ 场景名称 + 时代/地域标签
  │   ├─ 氛围描述摘要
  │   ├─ 场景 DNA 锚点
  │   ├─ 场景生图 Prompt
  │   └─ 参考图说明
  └─ 全局一致性面板（角色色调汇总 + 光影风格 + 构图规则）

Step 05 分镜脚本 🎞️（Prompt 两层分离）
  ├─ L1 分镜图生成 Prompt
  │   └─ [角色DNA] + [场景DNA] + [运镜描述] → 生成参考图
  └─ L2 视频生成 Prompt
      └─ [分镜图Prompt] + [时间/节奏] + [运镜] → 送入可灵/即梦等

Step 06 操作手册 📄
  └─ 导出完整 Markdown 手册（含所有 Prompt + 资产索引）
```

## 五、全局一致性机制

### 角色 DNA 锚点

```yaml
character_dna:
  name: "角色名"
  core_keywords: "核心外貌关键词 ≤20字"
  clothing_style: "服装风格关键词"
  color_palette: "主色调关键词"
  lighting_preference: "光影偏好"
  proportion: "身高/体态比例"
  consistency_prompt_zh: "中文一致性生图Prompt"
  consistency_prompt_en: "英文一致性生图Prompt"
```

### 场景 DNA 锚点

```yaml
scene_dna:
  name: "场景名"
  era_location: "时代/地域标签"
  color_palette: "主色调关键词"
  composition_style: "构图风格（开阔/封闭/纵深）"
  lighting_type: "光源类型（自然光/人工光/霓虹）"
  atmosphere_keywords: "氛围关键词"
  consistency_prompt_zh: "中文场景Prompt"
  consistency_prompt_en: "英文场景Prompt"
```

### 全局一致性面板

- **色调锁定**：从所有角色/场景提取主色调，形成全局调色板
- **光影规则**：统一的光源方向和明暗对比度
- **构图规则**：统一的镜头距离感和画面比例感
- **以上三者自动注入每个分镜 Prompt**

## 六、文件上传设计

### 支持格式
- `.txt`（纯文本）
- `.md`（Markdown，含 YAML frontmatter）

### 限制
- 最大 10万字（约 200KB）
- 超出时前端提示并截断至10万字
- 上传后自动检测字数并显示

### 交互
- 拖拽上传区 + 点击上传按钮
- 上传后显示文件名 + 字数统计
- 预览文本前 500 字（可展开）

## 七、技术实现要点

1. **单文件架构**：继续使用 `index.html` 内嵌 React + Babel，无需构建
2. **状态管理**：所有 Step 数据存入 `localStorage`，字段按 Step 分离
3. **API 调用**：沿用 DashScope OpenAI 兼容接口，Prompt 按新流程重构
4. **样式**：保持现有暗色主题，逐步将硬编码 style 抽离为组件
5. **性能**：10万字文本不做全量处理，Prompt 阶段自动摘要切片
