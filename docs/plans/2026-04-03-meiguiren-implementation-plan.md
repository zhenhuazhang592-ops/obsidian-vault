## 制作命令参考

### AI图像生成（baoyu-image-gen / Doubao-Seedream）

**标准照提示词（日系治愈风）：**
```
日系治愈风动漫女性角色，慵懒低马尾发型，暖摩卡发色，
耳边一缕碎发不听话，奶油白肌肤，淡淡红晕，耳畔佩戴永生玫瑰（干玫瑰形态），
珍珠耳钉一颗，玫瑰金细腕链，
丝质高领衫+阔腿裤，日常从容表情，眼神微垂嘴角浅浅上翘，
落地窗晨光背景，暖调日系光影，#E8A0B4玫瑰粉主色调
```

**表情特写提示词：**
```
日系治愈风，玫贵人角色，极端面部特写，[情绪描述]表情，
内心戏气泡（薰衣草色#C4A8D4），奶油白肌肤，暖摩卡发色，
耳边永生玫瑰，珍珠耳钉，近景，暖调光线
```

### 短视频制作工具推荐

| 用途 | 工具 | 说明 |
|------|------|------|
| 角色动画 | Pika / Runway Gen-2 | 让静态角色"活起来" |
| 视频剪辑 | CapCut（剪映） | 日更必备，高效 |
| 口型同步 | D-ID / HeyGen | 给角色加口型 |
| 字幕动画 | 剪映自动字幕 | 配合内心戏气泡 |
| 背景音乐 | 剪映音乐库 | 治愈系BGM |
