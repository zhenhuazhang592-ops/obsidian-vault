## 一、系统定位

**定位**：人机协作的AI漫剧工业化生产系统

**核心目标**：将任何输入的小说或创意IP，转化为100%可直接复制执行的"电影级AI漫剧生产资产"。

**用户角色**：用户（制片人/创作者）作为决策者，在关键节点（剧本大纲、前3集分镜）进行人工审核，其余环节由AI自动完成。

**技术栈**：
- 前端：React + Vite
- 创作引擎：Claude Code (多Agent协同)
- 内容存储：Obsidian Vault (Markdown)
- 结构化存储：SQLite

## 三、核心参数

| 参数 | 值 |
|------|-----|
| 单集时长 | 2-3 分钟 |
| 输出语言 | 中英双语（剧本中文，Prompt英文） |
| 画幅 | 16:9 |
| 人工审核节点 | 剧本大纲、前3集分镜 |
| 集数范围 | 默认12集（可配置） |

## 四、Agent职责矩阵

| Agent | 职责 | 输入 | 输出 | 存储 |
|-------|------|------|------|------|
| **IP解析Agent** | 分析小说世界观、背景、核心设定、核心矛盾 | 小说文本 | 世界观文档、核心设定表 | Obsidian + SQLite |
| **人物系统Agent** | 提取角色外貌/性格/欲望/恐惧/人物弧线，生成视觉特征Tag | 小说文本 | 角色锚点表（含视觉Tag、Reference ID占位） | Obsidian + SQLite |
| **场景设计Agent** | 分析主要场景类型，生成场景描述库 | 小说文本 | 场景类型表、场景描述库 | SQLite |
| **剧情Agent** | 重构影视结构、爆款算法、情绪曲线 | 世界观+人物+场景 | 分集大纲、情绪曲线、爆点设计 | Obsidian |
| **导演Agent** | 分镜设计、镜头语言、节奏控制 | 剧本 | 分镜脚本（含运镜指令） | Obsidian |
| **视觉Agent** | 视觉风格匹配、生成可直接用的英文Prompt | 分镜+角色锚点 | 完整英文Prompt | Obsidian |
| **声音Agent** | BGM/SFX/配音标签设计 | 分镜 | 声音设计表 | Obsidian + SQLite |

## 五、工作流

### 阶段一：并行初稿（同时进行）

```
用户上传小说IP
    │
    ├──▶ IP解析Agent ──▶ 世界观文档.md
    ├──▶ 人物Agent ────▶ 角色锚点表.md + 角色表.json
    └──▶ 场景Agent ────▶ 场景库.md + 场景表.json
```

### 阶段二：串行精调

```
【剧情Agent】
输入：世界观 + 人物 + 场景
输出：剧本大纲.md（含30集大纲）
用户审核：剧本大纲 ✅
    │
    ▼
【导演Agent】
输入：剧本大纲
输出：分镜脚本.md（前3集）
用户审核：前3集分镜 ✅
    │
    ▼
【视觉Agent + 声音Agent】并行
输入：分镜脚本
输出：
  - 每集分镜脚本.md
  - 每镜头Prompt表.md
  - 声音设计表.md
```

## 七、爆款算法规则

### 7.1 前3秒防滑走机制
- 每集第1个镜头必须是"极具视觉冲击力的动态画面"或"极度悬疑的视觉奇观"
- 禁止用静态镜头开场
- 视觉冲击类型：巴掌、泼水、急刹车、爆炸、角色突然抬头等

### 7.2 情绪节奏
- 每集必须有：爽、怒、紧张、期待、反转、释放
- 2-3分钟一集：3分钟一个高潮，5分钟一个反转
- 每集结尾必须有悬念钩子

### 7.3 爆款元素库
- 身份打脸、豪门对抗、逆袭、复仇、爱情修罗场、权力斗争

## 八、视觉风格库

| 风格名称 | 适用场景 | 视觉特征 |
|---------|---------|---------|
| 好莱坞史诗风 | 大场面、高潮戏 | 大场景、强光影、IMAX |
| 王家卫情绪风 | 情感戏、独白 | 高ISO颗粒、霓虹灯、慢镜头 |
| 丹尼斯维伦纽瓦 | 科幻、史诗 | IMAX 70mm、巨大空间、压迫感 |
| 中国短剧爽剧风 | 逆袭、打脸 | 强情绪、快剪辑、高对比 |
| UGC真实纪录风 | 日常、vlog | 手机镜头、真实感、生活场景 |

## 九、角色一致性保障

### 9.1 全局参考矩阵
每个核心角色必须预设一张标准定妆照（Reference Image），存储其Seed/Reference ID。

### 9.2 固定特征Tag
角色设定表必须包含精确的视觉Tag，系统强制要求所有涉及该角色的Prompt必须携带这些Tag。

示例：
```
(messy black hair:1.2)
(worn-out grey hoodie:1.3)
(stubbles:1.1)
```

### 9.3 权重规则
- 容貌特征权重：1.0-1.3
- 服装特征权重：1.2-1.5
- 配饰特征权重：1.0-1.2

## 十、视频Prompt结构

### 必须包含的参数（禁止省略）
1. **角色特征绝对锁定参数**：(详细视觉Tag + 权重)
2. **动作细节**：具体的人物动作和表情变化
3. **环境光影**：场景描述、光影设计
4. **摄像机运镜**：镜头类型、运动方式
5. **视觉风格后缀**：风格参考 + 画质参数

### 输出格式
```
[镜头类型] [运镜方式]. [角色特征Tag]. [动作描述]. [环境光影]. [情绪表达]. [背景虚化]. [画质参数]. --ar 16:9
```

### 示例
```
Extreme Close-Up shot, push in camera movement. A handsome 25-year-old Asian man, (messy soaked black hair:1.2), (black formal suit drenched in rain:1.3), water dripping from his chin. His expression transitions from deep despair to extreme coldness and anger, staring intensely into the camera. Cinematic lighting, high contrast dramatic lighting, a sudden flash of blue lightning illuminates half of his face. Heavy rain night, cyberpunk city street background blurred in bokeh. 8k resolution, photorealistic, IMAX 70mm, Dennis Villeneuve style, cinematic color grading, high emotional intensity. --ar 16:9
```

## 十一、声音设计

### 11.1 配音情绪标签
每个镜头必须带有明确的配音情绪标签：
- [VO_Emotion: 咬牙切齿]
- [VO_Emotion: 哽咽]
- [VO_Emotion: 冷笑]
- [VO_Emotion: 颤抖]
- [VO_Emotion: 平静]

### 11.2 BGM/SFX设计
每个场景必须带有BGM和音效提示：
- BGM类型（如：沉重的低音大提琴）
- SFX音效（如：雷暴音效、心跳声）
- 情绪转换提示（如：BGM瞬间停止）

### 11.3 情绪曲线绑定
视觉情绪必须与听觉设计绑定：
- 高潮戏 → 激昂BGM + 关键SFX
- 情感戏 → 温柔BGM + 环境音效
- 悬疑戏 → 低沉BGM + 尖锐SFX

## 十二、反占位符规则（强制执行）

以下词汇**禁止**在任何输出中出现：
- "..."、"等"、"以此类推"
- "（此处省略详细动作）"
- "自行补充"
- "类似"（必须精确描述）

**规则**：如果要求输出12集大纲，必须完整输出第1集到第12集的所有内容，不许省略。
