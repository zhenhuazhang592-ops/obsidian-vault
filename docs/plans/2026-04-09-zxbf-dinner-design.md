## 2. 视觉风格

### 2.1 风格定位

**半写实动漫 × 金继美学 × 当代华人情感叙事**

| 维度 | 规范 |
|------|------|
| **人物脸型** | 半写实动漫脸，写实五官比例，漫画式表情夸张 |
| **人物身体** | 写实比例身体，姿态自然，表演节奏复刻原片 |
| **色彩体系** | 深墨底色 + 24K金粉描线 + 器物裂纹金勾缝 |
| **场景** | 金继修复工坊，暖光，墙上挂满金继修复的宋代陶瓷 |
| **情绪符号** | 裂纹从茶杯蔓延到桌面，象征人物内心裂缝 |
| **金继美学** | 破碎→修复，用器物修复隐喻中年情感修复 |

### 2.2 角色设计

**老K（蓝青峰 → 裂裱师）**
- 外形：50岁，光头，留短须，穿深色中式棉麻衫
- 气质：外冷内热，有匠人沉稳，也有江湖老炮的狡黠
- 视觉符号：手里总在把玩一件碎裂后金继修复的茶盏

**老林（朱潜龙 → 求医者）**
- 外形：45岁，蓄须，穿深色中山装（款式略当代）
- 气质：表面精明企业主，实则迷茫中年人
- 视觉符号：袖口露出半截金继修复的手串

### 2.3 场景设计

**金继修复工坊**
- 布局：两人对坐于工作台前，台面散落金继工具
- 墙上：挂满金继修复的宋代茶盏、明代瓷盘
- 核心道具：桌面中央有一只正在修复的宋代茶盏，裂纹用金粉描缝
- 光线：暖黄工作灯 + 窗外透进的天光

## 4. 执行计划

### Pipeline 阶段

```
Stage 0: 故事线     → storyline.json        [跳过：直接使用本设计文档]
Stage 1: 大纲       → outline.md            [生成：项目总览+视觉圣经]
Stage 1.5: 资产图   → assets/老K.png, 老林.png, 工坊.png  [Doubao API]
Stage 2: 分镜脚本   → shots.md              [生成：31个镜头脚本]
Stage 3: 镜头生成   → shots/shot_01.png...  [Doubao 图生视频]
Stage 4: 后期剪辑   → output/中年人修复术_final.mp4
Stage 5: 报告生成   → production_report.md [自动触发]
```

### 执行命令

```bash
cd AI工具箱/huage888
python3 scripts/run_episode_pipeline.py \
  --episode E00 \
  --project 中年人修复术 \
  --script docs/plans/2026-04-09-zxbf-dinner-design.md \
  --report-level stage
```
