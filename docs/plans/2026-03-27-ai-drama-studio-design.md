# AI 漫剧智能创作系统 · 设计文档

> 版本：v1.0.0
> 日期：2026-03-27
> 状态：草稿

---

## 1. 愿景与目标

打造一个**规范驱动**的 AI 漫剧智能创作系统。用户输入小说原文，系统输出完整的短剧制作文档包（5 步），覆盖全局设置 → CDP 资产包 → 资产库 → 分镜脚本 → 视频生成提示词。

**核心原则：规范先行、链式传递、零自由发挥。** 每一步的输出都是下一步的输入，每个字段有 Schema 约束，模型不能留空、不能模糊、不能瞎猜。

---

## 2. 系统架构

### 2.1 整体架构

```
用户输入: 小说原文 (TXT / Obsidian 笔记路径)
    ↓
┌─────────────────────────────────────────────┐
│          AI 漫剧智能创作系统 (Agent)           │
│                                             │
│  S0: 解析小说                                │
│    → 提取: 时代背景 / 故事基调 / 章节结构        │
│                                             │
│  S1: 全局设置 [规范锚点]                       │
│    → 输出: 风格指南 (视觉/色调/运镜/音效/角色设计) │
│                                             │
│  S2: CDP 资产包 [硬约束层]                     │
│    → 输出: 角色DNA / 场景DNA / 道具DNA          │
│                                             │
│  S3: 资产库                                   │
│    → 输出: 角色图提示词 / 场景图提示词 / 道具图提示词 │
│                                             │
│  S4: 分镜脚本                                 │
│    → 输出: 每镜脚本 + 分镜图提示词                │
│                                             │
│  S5: 视频生成                                 │
│    → 输出: Kling 版 + Seedance 版 视频提示词    │
│                                             │
└─────────────────────────────────────────────┘
    ↓
输出: 项目文件夹 (完整文档包)
```

### 2.2 链式数据流与引用规范

| 上一步 | 输出物 | 下一步引用规范 |
|--------|--------|--------------|
| S0 | 时代背景/故事基调/章节结构 | S1 必须引用 S0 的时代背景确定风格 |
| S1 | 风格指南 | S2/S3/S4/S5 所有提示词必须引用 S1 的风格规范 |
| S2 | 角色DNA/场景DNA/道具DNA | S3/S4/S5 每条记录必须引用对应 DNA ID |
| S3 | 角色图/场景图/道具图提示词 | S4/S5 每条提示词必须引用 S3 生成的资产ID |
| S4 | 分镜脚本 | S5 每条视频提示词必须引用 S4 的运镜参数 |

**引用强制规则：任何步骤生成的提示词，必须在头部注明引用了哪些上游 ID 和规范。**

## 3. 各步骤详细规范

### 3.0 S0: 解析小说

**输入**: 用户粘贴小说原文，或指定 Obsidian 笔记路径

**输出**: `S0-解析报告.md`
```
- 时代背景: [年代/地域/社会环境]
- 故事基调: [悲情/温暖/悬疑/热血等]
- 章节结构: [章节列表 + 每章核心事件]
- 主要角色: [姓名 + 一句话描述]
- 关键场景: [场景名 + 一句话描述]
- 故事主线: [一句话概括核心冲突]
```

**Schema 约束**: 所有字段不能为空，必须从原文提取而非推断。

---

### 3.1 S1: 全局设置（规范锚点）

**输入**: S0 解析报告

**输出**: `00-全局设置.md`

| 配置项 | 值 | 来源 |
|--------|-----|------|
| 风格 | [如: 写实/动漫/水墨...] | S0 故事基调和目标平台决定 |
| 画幅 | 9:16 | 短视频平台标准 |
| 单镜时长 | 15秒 | 短视频节奏标准 |
| 色调规范 | [色板描述，如: 暖黄/冷灰...] | S0 时代背景确定 |
| 光线规范 | [如: 自然光/硬光/柔光...] | 风格决定 |
| 运镜规则 | [镜头运动规范列表] | 统一定义 |
| 音效基调 | [背景乐风格/音效类型] | S0 故事基调决定 |
| 角色设计原则 | [设计禁忌/强化特征...] | S0 角色特点决定 |

**风格指南文件**: `S1-风格指南.md` — 这是全局锚，后续所有步骤必须引用此文件的规范编号。

---

### 3.2 S2: CDP 资产包（硬约束层）

**输入**: S0 + S1 输出

**输出**: `01-CDP资产包/CDP-JSON.md`

#### 3.2.1 角色 DNA

每条角色记录包含：

```yaml
char_xxx:
  id: char_xxx                    # 固定格式 char_xxx
  name: 角色名
  gender: male / female
  age_range: "x-x"
  visual:
    face_shape: [S1规范引用]        # 脸型
    skin_tone: [S1规范引用]         # 肤色
    eye_features: [S1规范引用]      # 眼部特征
    body_type: [S1规范引用]         # 体型
    clothing:                      # 各年龄段服装（必须有）
      young: [S1规范引用]
      middle: [S1规范引用]
      old: [S1规范引用]
    palette: [角色专属色板]          # 引用S1色调规范
  expression_normal: [标准表情]     # 日常表情库
  expression_strong: [强烈表情]     # 悲伤/愤怒/喜悦等
  constraints:                     # 禁止项
    - [禁止: 如"不能画年轻时有皱纹"]
    - [禁止: 如"不能画XX朝代后的发型"]
  reference_prompt: [生成角色参考图的完整提示词]  # 引用S1+S2所有字段
  used_in_scenes: [scene_xxx, ...]  # 引用场景ID
```

#### 3.2.2 场景 DNA

```yaml
scene_xxx:
  id: scene_xxx
  name: 场景名
  era: [年代]                       # 必须匹配S0时代背景
  description: [场景描述]
  visual:
    space_type: [室内/室外/半室内]
    architecture: [建筑风格]          # 引用S1时代背景
    lighting: [主光源类型]
    color_temperature: [暖/冷/中性]  # 引用S1色调规范
    key_props: [关键道具列表]        # 引用道具DNA
  constraints:
    - [禁止: 如"不能出现现代物品"]
    - [禁止: 如"不能画空调/电线"]
  reference_prompt: [生成场景参考图的完整提示词]  # 引用S1+S2所有字段
```

#### 3.2.3 道具 DNA

```yaml
item_xxx:
  id: item_xxx
  name: 道具名
  era: [年代]                       # 必须匹配S0时代背景
  description: [描述]
  visual:
    material: [材质]
    color: [颜色]                   # 引用S1色调规范
    size: [尺寸]
  constraints:
    - [禁止: 如"不能画塑料材质"]
  reference_prompt: [生成道具图的完整提示词]
```

---

### 3.3 S3: 资产库

**输入**: S2 CDP 资产包

**输出**: `02-资产库/`

```
02-资产库/
├── 资产库总览.md       # 角色/场景/道具一览表
├── 角色资产.md         # 角色图生成提示词（含参考图链接字段）
├── 场景资产.md         # 场景图生成提示词
└── 道具资产.md         # 道具图生成提示词
```

**输出规范**: 每条提示词头部必须注明引用来源：

```
# [角色名] 参考图生成提示词

**引用**: S1-风格指南 v1.0, S2-char_xxx (角色DNA)
**资产ID**: char_xxx
**生成工具**: [LibTV / Midjourney / Stable Diffusion]

## 提示词

[完整图像生成提示词，必须包含:]
- S1 风格规范描述
- S2 角色DNA 的 visual 字段全部内容
- 角色专属色板引用
- 禁止项遵守声明

## 参考图要求
[角度/光线/背景等具体要求]
```

---

### 3.4 S4: 分镜脚本

**输入**: S1 + S2 + S3 输出

**输出**: `03-分镜脚本/`

```
03-分镜脚本/
├── 分镜脚本总览.md     # 全集镜头一览表
├── 第XX集-分镜脚本.md  # 每集一份
└── 运镜规范表.md       # 统一运镜规则（引用S1）
```

**每镜脚本结构**:

```yaml
shot_01:
  shot_number: 01
  duration: 15秒
  location_id: scene_xxx              # 引用S2场景DNA
  character_ids: [char_xxx, ...]     # 引用S2角色DNA
  item_ids: [item_xxx, ...]          # 引用S2道具DNA

  script:
    action: [画面描述，必须引用角色/场景/道具DNA]
    dialogue:                         # 如有对白
      - speaker: char_xxx
        text: "对白内容"
    inner_thought: [内心独白/旁白]      # 如有

  image_prompt:                       # 分镜图生成提示词
    content: [画面描述，引用S1/S2/S3]
    style: [引用S1风格指南规范编号]
    composition: [构图规则]

  video_prompt_ref:                   # 视频提示词占位（引用S5）
    status: pending

  consistency_check:
    style_ref: S1-风格指南 ✓
    character_ref: [char_xxx DNA] ✓
    scene_ref: [scene_xxx DNA] ✓
    constraint_violations: none
```

---

### 3.5 S5: 视频生成

**输入**: S1 + S2 + S3 + S4 输出

**输出**: `04-视频生成/视频任务清单.md`

**每镜输出两个版本**:

```yaml
shot_01_kling:
  shot_number: 01
  platform: Kling
  model: [具体模型]
  prompt:
    global_context: |
      [全局语境描述，引用S1风格指南，注明: 无文字/无字幕/无音乐]
    shot_content: |
      Shot 1 / Duration: 15秒 / Scene: [引用S4脚本action]
      [运镜参数，引用S1运镜规范]
      [角色描述，引用S3资产提示词 + S2角色DNA]
      [场景描述，引用S3场景提示词 + S2场景DNA]
      [光影，引用S1光线规范]
      [色调，引用S1色调规范]
      [音效指令，引用S1音效基调]
  references:
    character_image: [S3 char_xxx 参考图路径]
    scene_image: [S3 scene_xxx 参考图路径]
    style_guide: S1-风格指南

shot_01_seedance:
  [同上结构，适配Seedance平台规范]
```

## 4. 一致性保障机制

| 一致性维度 | 保障方式 |
|-----------|---------|
| **画面风格** | S1 输出风格指南（含色调/光线/构图规则），S2-S5 每步强制引用规范编号 |
| **人物一致** | S2 输出角色 DNA（含外观/服装/表情规范），S3-S5 每条提示词引用角色 ID |
| **场景一致** | S2 输出场景 DNA（含空间/道具/光线规范），S3-S5 每条引用场景 ID |
| **音效一致** | S1 输出音效基调，S5 视频提示词含音效指令字段 |
| **运镜一致** | S4 分镜脚本含统一运镜规则表，S5 每条视频提示词引用运镜规范 |

## 5. 断点恢复机制

每步完成后，Agent 必须将状态写入：

```
AI漫剧项目/{项目名}/.manzhou/
├── state.json          # 当前状态机位置
├── checkpoint.json     # 每步输出摘要（用于恢复时快速定位）
└── logs/               # 详细执行日志
```

**恢复逻辑**: Agent 启动时读取 `state.json`，如果状态非初始，则从最后一个完成步骤的下一阶段继续，引用 `.manzhou/` 下的文件而非重新生成。

## 6. 与现有 manzhou-agent 的关系

| 组件 | 处理方式 |
|------|---------|
| `manzhou/state_machine.py` | 扩展现有状态机，从 S0-S7 调整为 S0-S5 |
| `manzhou/schema.py` | 复用 CDP Schema，补充角色DNA/场景DNA/道具DNA 字段 |
| `manzhou/quality_gate.py` | 复用，每步完成后触发一致性检查 |
| 新增: `manzhou/style_guide.py` | S1 风格指南生成器 |
| 新增: `manzhou/chain_ref.py` | 链式引用追踪器（检查每步是否正确引用上游） |
| 新增: `manzhou/recovery.py` | 断点恢复模块 |

## 8. 实现优先级

| 优先级 | 模块 | 说明 |
|--------|------|------|
| P0 | S0-S1 基础流程 | 小说解析 + 全局设置 |
| P0 | CDP Schema 扩展 | 角色/场景/道具 DNA 字段定义 |
| P0 | 链式引用追踪 | 检查引用完整性 |
| P1 | S2-S3 资产库 | 基于 CDP 生成提示词 |
| P1 | S4 分镜脚本 | 带引用规范的分镜输出 |
| P1 | 断点恢复 | state.json + checkpoint |
| P2 | S5 视频生成 | Kling + Seedance 双版本 |
| P2 | 音效规范 | 扩展到音效/配乐提示词 |

## 9. 成功标准

- [ ] 输入一篇小说，完整输出 5 步文档包，无步骤缺失
- [ ] 每条提示词头部有引用声明，可追溯上游 ID
- [ ] 断电/重启后能从 checkpoint 恢复，不重新生成已完成步骤
- [ ] 同一角色的所有提示词引用同一个角色 DNA ID
- [ ] 同一场景的所有提示词引用同一个场景 DNA ID
