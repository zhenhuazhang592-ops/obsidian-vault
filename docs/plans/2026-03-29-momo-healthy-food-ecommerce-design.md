## 二、视觉设计规范

### 2.1 色彩体系

| 角色 | 色名 | Hex | 用途 |
|------|------|-----|------|
| 主色 | 漠玫绿 | `#2E7D32` | 品牌标识、CTA 按钮、主要链接 |
| 辅色 | 牛油果绿 | `#8BC34A` | 分类标签、hover 状态、装饰元素 |
| 背景 | 米白 | `#FDFBF7` | 全站背景，替代纯白 |
| 强调 | 暖金 | `#D4A853` | 特价标签、重要提示、VIP 高亮 |
| 正文 | 墨色 | `#1A1A1A` | 正文标题，深黑非纯黑 |
| 次要文字 | 灰调 | `#6B6B6B` | 副标题、说明文字 |
| 卡片背景 | 象牙白 | `#FFFFFF` | 卡片、模态框、浮层 |

> **注意**：不要使用荧光绿、薄荷绿等"微商感"颜色。全站绿色不超过两种（主色 + 辅色）。

### 2.2 字体规范

| 用途 | 字体 | 字重 | 大小建议 |
|------|------|------|---------|
| H1 主标题 | 思源宋体（Noto Serif SC） | Bold / 700 | 40–56px |
| H2 副标题 | 思源宋体 | SemiBold / 600 | 28–36px |
| H3 段落标题 | 思源黑体（Noto Sans SC） | Medium / 500 | 20–24px |
| 正文 | 思源黑体 | Regular / 400 | 16–18px |
| 按钮 / 标签 | 思源黑体 | SemiBold / 600 | 14–16px |
| 英文装饰 | Playfair Display | Regular | 品牌 Slogan |

> **字体来源**：Google Fonts 免费字体，通过 Next.js 加载。
> 禁止使用：华文行楷、方正粗宋等"机关风"字体；圆润儿童字体；非中文优化字体（如思源黑体优于苹方）。

### 2.3 按钮样式

**Primary CTA（主按钮）**

```
背景色：#2E7D32（漠玫绿）
文字色：#FFFFFF
圆角：8px
字重：SemiBold
高度：48px
字间距：0.5px
hover：背景加深10%（#1B5E20），轻微上移2px（transform: translateY(-2px)）
```

**Secondary CTA（次按钮）**

```
背景色：透明
边框：1.5px solid #1A1A1A
文字色：#1A1A1A
圆角：8px
hover：背景填充 #F5F5F5
```

**Ghost Button（文字按钮）**

```
无背景无边框
文字色：#2E7D32
hover：下划线出现
```

### 2.4 间距体系（8px 基准）

| 层级 | 间距值 | 使用场景 |
|------|--------|---------|
| XS | 8px | 标签内间距、图标与文字间距 |
| SM | 16px | 列表项间距、紧凑模块 |
| MD | 24px | 模块内部元素间距 |
| LG | 40px | 模块之间间距 |
| XL | 64px | 页面段落间距（Section gap） |
| XXL | 96px | 首页大模块之间间距 |

### 2.5 图片规范

| 类型 | 规格 | 格式 | 说明 |
|------|------|------|------|
| Hero 背景 | 1920×800px | WebP | 首页大图，必须高清 |
| 产品图 | 800×800px | WebP | 1:1 方形，背景纯白或透明 |
| 博客配图 | 1200×630px | WebP | 16:9 封面图 |
| 头像 / Logo | 200×200px | PNG / SVG | 提供透明背景版本 |

**图片风格要求**：
- 产品图参考：Apple 产品图风格（纯色背景、光影干净、主体突出）
- 食材摄影：自然光、浅景深、食材本身是主角，禁止过度 PS
- 禁止使用：微商风格微距图、emoji 堆砌、过度锐化

### 2.6 动效规范

使用 **Framer Motion** 实现，以下场景必须有动效：

| 场景 | 动效 | 时长 |
|------|------|------|
| 页面进入 | 各模块依次 fade-in + 上移 20px | 400ms ease-out，间隔 80ms |
| 卡片 hover | scale(1.02) + 轻微阴影加深 | 200ms ease |
| 按钮 hover | 背景加深 + 上移 2px | 150ms ease |
| 图片加载 | 骨架屏 → 淡入 | 300ms |
| 滚动视差 | Hero 图轻微视差 | scroll-driven |

> 禁止：页面加载全屏 loader（用骨架屏）、花哨的粒子动画、任何让用户感觉"这个站很卡"的动效。

## 四、技术架构

### 4.1 整体架构

```
用户 → Vercel CDN → Next.js 14（ISR 静态生成）
                      ↓
               页面内容：MDX 文件（Contentlayer 管理）
                      ↓
               图片资源：Vercel Blob / 第三方 CDN
                      ↓
               私域导流：固定模块（企微二维码 / 小程序码）
```

**架构原则**：
- **无后端**：不需要 Node.js 服务端、不需要数据库
- **MDX 内容管理**：所有文章、产品内容以 `.mdx` 文件存储在 `/content/` 目录
- **静态生成**：文章和产品页面使用 Next.js 的 ISR（增量静态再生成），文章更新后自动重新生成页面
- **托管**：Vercel（免费版足够初期使用）

### 5.2 文章生成标准 SOP

```
Step 1: 关键词提取

Step 2: AI 生成文章
  使用下方「文章生成提示词模板」
  → 输出 MDX 格式文章

Step 3: 人工审核
  检查：事实准确性、品牌语气、内容长度
  → 修改通过

Step 4: AI 生成配图
  根据文章主题生成 1-2 张配图
  → 存储到 /public/images/blog/

Step 5: 发布到项目
  将 MDX 文件放入 /content/blog/
  → Vercel 自动重新生成页面（ISR）

Step 6: 同步私域
  将文章摘要 + 链接推送到公众号草稿
  → 企微社群发送文章

### 5.4 文章生成提示词模板

```
你是一个专注于健康生活的食品内容编辑，擅长撰写既专业又有温度的科普文章。

## 输入信息
- 核心关键词：{keyword}
- 目标读者：对健康饮食有兴趣但非专业人士的都市消费者
- 品牌调性：专业、克制、亲切，拒绝夸大宣传

## 输出要求
1. 字数：1200-1800字
2. 结构：
   - H1 标题（含关键词，吸引点击）
   - 150字以内的引言（引发共鸣）
   - 4-5个 H2 段落（含关键词自然融入）
   - H2 包含：科普知识点、食谱/实用技巧、选购/储存建议
   - 结尾 CTA（引导关注漠玫公众号）
3. 语言风格：书面语但不死板，有生活感，避免"研究表明"类无来源引用
4. SEO 要求：
   - 关键词在标题、H2、小标题中自然出现
   - 不堆砌关键词（密度 <3%）
5. 输出格式：Markdown/MDX

## 文章类型适配

**科普型**（营养/产地/对比）：
> 标题要有信息量，让读者知道看完能得到什么
> 结构：引言→知识点拆解→与生活关联→总结

**实操型**（食谱/选购/储存）：
> 标题要有行动感（"怎么X" "X步学会X"）
> 结构：引言→步骤/要点→注意事项→相关推荐

## 品牌植入规则
- 可以在结尾推荐相关产品，不超过2处
- 语气：像朋友分享，不是广告
- 禁止：夸大功效、使用"最好""第一"等极限词

## 十、待华哥确认事项

1. **企微二维码**：上线前需要准备企微客服二维码和社群二维码
2. **公众号关联**：文章内嵌商品卡指向小程序还是企微？（建议小程序已有则用小程序，无则用企微）
3. **第一批20篇关键词**：上述关键词库是否合适？是否需要调整优先级？
4. **Logo 方向**：需要确认设计风格——A. 极简字母 logo（Mo Mei）；B. 中文+英文组合；C. 抽象图形 logo
5. **内容运营归属**：文章由谁审核发布？（你自己 / 运营人员 / 全权外包？）
