# 玫贵人 IP 设计方案

> 品牌：漠玫 | 产品：树熟哈斯牛油果 | 受众：30-40岁高净值都市女性
> 日期：2026-04-03 | 状态：已确认 | 版本：v1.0

---

## 一、角色核心定位

### 定位声明

**「玫贵人」** —— 一个"假装轻松"的都市精致女性IP。

外表岁月静好，实际上卷到飞起。她的"松弛感"是一种精心维护的成果。

**核心受众**：30-40岁高净值都市女性
**核心共鸣**：看到她就等于看到自己——原来我不用解释自己有多努力

### IP人设卡

| 字段 | 内容 |
|------|------|
| 名字 | 玫贵人 |
| 昵称 | 玫玫 / 贵人 |
| 年龄感 | 32岁，永远28 |
| 职业 | 生活方式博主（模糊，保持想象空间） |
| 口头禅 | "随便啦~"（每次说这话时刚完成一件大事） |
| 签名档 | 岁月从不败美人，但美人也没少花功夫 |
| 核心矛盾 | 想展示真实的累 vs 必须维持"松弛感"的体面 |
| 品牌关系 | 漠玫品牌拟人化：外表优雅淡然，底色是极致的认真和讲究 |

## 二、视觉识别系统

### 配色方案

| 用途 | 色名 | 色值 | 说明 |

| 主色 | 玫瑰粉 | `#E8A0B4` | 品牌色，IP视觉锚点 |
| 辅色 | 玫瑰金 | `#EFC9B5` | 温暖过渡，调和用 |
| 辅色 | 奶油白 | `#FFF8F0` | 背景/留白，高端感 |
| 点缀 | 浅薰衣草 | `#C4A8D4` | 内心戏/情绪气泡专用 |

| 高光 | 月光银 | `#F0EDE8` | 珍珠/金属质感配件 |

### 主体外观

- **发型**：慵懒低马尾，发质看起来像刚做完护理，耳边永远有一缕碎发不听话
  - 发色：暖摩卡 `#7B5E4F`
- **脸型**：日系动漫脸，下巴尖但不过分，眼大但眼神淡定（治愈系核心）
- **皮肤**：奶油白，有淡淡红晕
- **标志配件**：
  - ① 耳畔永生玫瑰（干玫瑰形态，永远定格在最绽放的瞬间）
  - ② 珍珠耳钉（一颗，不过分贵气）
  - ③ 手腕：玫瑰金细链
- **服装基础款**：
  - 缎面睡袍（慵懒时刻）
  - 高领真丝衫+阔腿裤（通勤/精致）
  - 廓形西装（气场时刻）

### 视觉记忆锚点（一眼认出）

1. **一朵永生玫瑰 = 玫贵人**
   不同于普通玫瑰，有干花瓣质感，永远定格在最绽放的瞬间。她身上唯一的"花"，也是品牌的视觉符号。

2. **整理耳边碎发 + 微微挑眉**
   标志动作二号，适用于所有"从容应对"场景。

3. **缎带般的低马尾**
   发型即Logo，发丝质感是日系治愈风的核心。

| 情绪 | 视觉表现 | 适用场景 |

| 脆弱瞬间 | 眼角微湿，碎发散落 | 情感共鸣内容 |
| 得意瞬间 | 挑眉，嘴角上扬，碎发飞扬 | 好物到手/完成任务 |

## 三、内容策略

### 核心内容公式

```
玫贵人内容 = 表面（松弛感）+ 实际（卷到飞起）+ 共鸣钩子
```

### 内容矩阵（全平台适配）

| 内容类型 | 占比 | 目的 | 示例 |
|---------|------|------|------|
| 反差日常 | 50% | 引发共鸣，制造话题 | "我的早晨：4:30起床，假装刚醒" |
| 精致种草 | 30% | 植入品牌，产生转化 | "这个牛油果熟得刚刚好，像我的状态" |
| 内心独白 | 20% | 深度连接，塑造人设 | "你看到的是松弛，我经历的是计算" |

### 爆款短视频模板（30秒）

**【场景一：早晨】**
镜头：落地窗晨光，闹钟显示5:00
玫贵人已经化好全妆，慵懒地喝咖啡
字幕："自然醒的早晨～"
内心戏气泡："（凌晨4:30的闹钟响了三遍了）"

**【场景二：冰箱】**
镜头：打开冰箱，整齐排列的牛油果和西兰花
玫贵人："我的快乐就是这么简单～"
内心戏气泡："（精确到克的沙拉和偷偷藏的巧克力）"

**【场景三：健身房】**
镜头：练完瑜伽，状态满分
玫贵人擦汗："就随便动动～"
内心戏气泡："（今天第三次训练了）"

**【场景四：收快递】**
镜头：一堆包装精美的包裹
玫贵人（惊喜）："又是为自己努力的一天～"
内心戏气泡："（本月第三个牛油果订单）"

### 金句文案库

1. 你以为我松弛，其实我在拼命精致
2. 岁月静好，是因为有人在凌晨偷偷努力
3. 我的牛油果，永远熟得刚刚好——包括我自己
4. 不将就，是我最将就的事
5. 好东西，值得等；好状态，值得卷
6. 每一个看起来轻松的背后，都有一份认真的清单

## 四、与闹海三角色的关系

**完全独立运营**

- 视觉调性冲突：暗黑水墨风 vs 日系治愈风
- 受众不完全重叠：闹海三角偏00后/二次元硬核粉，玫贵人打30+高净值女性
- 品牌资产保护：玫贵人代表漠玫品牌调性，不能和暗黑角色混在一起

未来如玫贵人做起来，可出一集"穿越到漠玫宇宙遇见三角色"特别篇增加话题性。

## 五、制作优先级

### Phase 1（第1-2周）：角色定稿 + 首批视觉资产
- 输出：标准照6张（正面/侧面/全身/表情特写/手持产品/场景照）
- 输出：首套16张表情包/场景图
- 用途：小红书图文笔记、抖音封面、头像

### Phase 2（第3-4周）：短视频模板化生产
- 建立动态模板：表情逐帧 + 口型动画 + 场景切换
- 产出：首批10条短视频素材
- 重点测试：哪种反差场景互动率最高

### Phase 3（第5-8周）：内容放大 + 粉丝积累
- 数据复盘 → 优化内容方向
- 考虑跨界联动（同调性品牌）

### 日更短视频制作模式

```
玫贵人日更解法 = 1套"角色库" + 3套"场景模板" + 灵活组合

【角色库】
· 6个标准表情（逐帧可替换）
· 手部动作6种（拿杯/整理头发/托腮/比心/叉腰/捧脸）
· 全身姿态5种（站/坐/靠/躺/走）

【场景模板】
· A模板：早晨·卧室·落地窗（松弛开场）
· B模板：厨房·打开冰箱（反差展示）
· C模板：客厅·精致下午茶（种草场景）

每条视频 = 选1角色表情 + 选1场景模板 + 填入产品/文案
制作时间：30分钟以内/条（熟练后）
```

## 六、风险预警

| 风险 | 描述 | 对策 |
|------|------|------|
| "绿茶"感 | 过度凡尔赛会让受众反感 | 内心戏气泡必须真实/自嘲，不能全是炫耀 |
| 量产压力 | 日更对团队消耗大 | Phase 1先跑通模板化制作，再提速 |
| 品牌绑定 | 玫贵人和产品太远，缺乏带货属性 | 每3条内容绑定1次产品场景植入 |
| 竞品模仿 | 治愈系赛道拥挤 | 差异化在于"反差真实感"，不是纯粹的甜 |
