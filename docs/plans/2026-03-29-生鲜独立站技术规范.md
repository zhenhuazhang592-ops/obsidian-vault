## 第 1 章：项目概览与验收标准

### 1.1 一句话定位

展示型品牌增长系统：通过 Next.js ISR + Strapi CMS + AI 自动化，实现 50 个城市 GEO 落地页秒开、SEO 95+、内容日更、私域零摩擦引流。

### 1.2 UI 视觉方案锁定：「极致纹理」(Macro Purity)

**已选定方案：方案一 — 极致纹理（Macro Purity）**

| 维度 | 规范 |
|------|------|
| 视觉核心 | 食材微距摄影，强调新鲜到呼吸感 |

| 标题字体 | Playfair Display，字重 600，字号 ≥ 48px |
| 标题文案 | 「生于自然，止于纯粹」（首页 Hero 固定文案） |
| 副标题 | 思源宋体，≤ 24px，1-2 行，字间距宽松 |
| 产品图风格 | Midjourney 极致纹理 Prompt（见下） |

## 第 2 章：系统架构

### 2.1 整体数据流

```
用户请求
    │
    ▼
CDN（腾讯云/七牛云全球加速节点）
    │  命中缓存 → 直接返回静态文件（< 100ms）
    │  未命中 → 回源 Next.js SSR/ISR 服务器
    ▼
Next.js 14 App Router（Vercel / 腾讯云 Lighthouse）
    │
    ├── ISR 城市页：城市模板 + Strapi 城市数据 → 静态 HTML
    │                    ↑ 每 24h 或 CMS webhook 触发增量再生
    │
    ├── 动态页面：产品详情 / 博文 → SSR
    │
    └── API Routes：留资表单 / IP 定位
           │
           ▼
Strapi v5 CMS（独立服务器，PostgreSQL 数据库）
    │
    ├── 城市页面数据（CityPage Collection）
    ├── 文章内容（Article Collection，含 AI 生成标记）
    ├── 产品数据（Product Collection）
    ├── 管家配置（WeComQR / CityManager）
    └── AI 审核箱（草稿→发布工作流）
           │
           ▼
企微（WeCom）——用户扫码 → 添加管家 → 进私域
           │
           ▼
AI 自动化层（Node.js Cron Job，独立部署）
    │
    ├── 每日 06:00 执行 OpenAI API → 生成 SEO 文章
    │                    ↓
    ├── Stable Diffusion API / MJ API → 生成配图
    │                    ↓
    └── 上传至 Strapi → 状态设置为 draft → 通知审核员
```

| 组件 | 推荐方案 | 最低要求 | 备注 |

## 第 5 章：核心组件规格

### 5.1 企微动态二维码组件（WeComQRWidget）

**位置**：固定浮动在页面右下角（移动端底部悬浮条），可收起/展开。

**显示逻辑（优先级顺序）：**

```
1. 检查 URL 参数 `?manager=beijing` → 精确匹配城市
2. 检查用户 IP 定位（调用 /api/geo 或腾讯地图 API）
   → 若定位到「北京市」→ 展示北京管家二维码
3. 默认兜底 → 展示「全国通用管家」二维码
```

**二维码配置表（示例）：**

| 城市 | 二维码图片 | 管家称呼 | 自动回复文案 |
|------|-----------|---------|-------------|
| 上海 | shanghai-qr.webp | 小沪 | 您好！我是上海专属管家，很高兴为您服务。回复「1」获取今日入库实拍图。|
| 北京 | beijing-qr.webp | 小京 | 您好！我是北京专属管家，很高兴为您服务。回复「1」获取今日入库实拍图。|
| 默认 | default-qr.webp | 小鲜 | 您好！感谢关注我们的高端生鲜服务。回复「1」了解更多。|

**埋点事件：**
- `wecom_qr_shown` — 展示次数（含城市参数）
- `wecom_qr_clicked` — 点击「添加管家」次数
- `wecom_qr_expanded` — 展开二维码大图次数

### 5.2 留资表单组件（LeadCaptureForm）

### 7.1 JSON-LD 注入规则

```json
  "address": { "@type": "PostalAddress", "addressLocality": "{{城市名}}" },
  "areaServed": "{{城市名}}",
  "priceRange": "¥¥¥",
  "openingHours": "Mo-Su 08:00-22:00"
}
+ BreadcrumbList（首页 → 城市页）
```

**产品页（`/products/[slug]`）：**
```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "{{产品名}}",
  "image": "{{产品图URL}}",
  "description": "{{产品描述}}",
  "brand": { "@type": "Brand", "name": "品牌名" },
  "offers": { "@type": "Offer", "price": "{{价格}}", "priceCurrency": "CNY" }
```

```json
  "image": "{{封面图URL}}",
  "author": { "@type": "Person", "name": "{{作者}}"},
  "datePublished": "{{发布时间}}",
  "publisher": { "@type": "Organization", "name": "品牌名" }
}
```

### 7.2 Sitemap 自动更新

- 触发时机：Strapi 中新增/修改 CityPage 或 Article 时，通过 webhook 通知 Next.js
- Next.js API Route（`/api/revalidate`）接收 webhook → 调用 `revalidatePath()`
- 重新生成 `sitemap.xml` → 提交到百度搜索资源平台 + 搜一搜
- 频率：每城市页/文章变更后 5 分钟内更新

### 7.3 性能规范

| 规范项 | 要求 |
|--------|------|
| 图片格式 | WebP，Hero 图品质 85%，配图品质 80% |
| 图片尺寸 | 明确 width/height（防止 CLS） |
| 首屏图片 | `loading="eager"`，其余 `loading="lazy"` |
| 字体加载 | `font-display: swap`，预连接 Google Fonts |
| CSS | TailwindCSS purge 后单页 CSS < 15KB |
| JS Bundle | 单页 JS < 150KB（gzip） |
| CDN 缓存 | 静态资源 Cache-Control: public, max-age=31536000, immutable |
| ISR 缓存 | 城市页：revalidate = 86400（24h）；文章页：revalidate = 86400 |
