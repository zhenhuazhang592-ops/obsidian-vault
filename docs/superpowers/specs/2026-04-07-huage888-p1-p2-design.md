## 一、整体架构

```
outline (P0已有)
        │
        ▼ Step 1: generate_asset_prompts.py
┌─────────────────────────────────────────────────────┐
│  qwen-max 润色 → 生成角色卡/场景卡/道具卡草稿         │
│  方式：结构化模板填空（B方案）                       │
│  输出：assets/library/[name]/character_card.md 等    │
└─────────────────────────────────────────────────────┘
        │
        ▼ Step 2: generate_reference_images.py
┌─────────────────────────────────────────────────────┐
│  Doubao-Seedream 生成参考图（建立资产库）             │
│  读取 character_card.md → 拼接 ②③④⑤(默认)        │
│  调用 Doubao API → PNG → assets/library/           │
│  更新 manifest.json                                 │
└─────────────────────────────────────────────────────┘
        │
        ▼ shots (P0已有)
        │  characters/scene/props 引用
        │
        ├──► generate_shot_images.py (P1)
        │     逐 shot 调用 Doubao 图生图，注入参考图
        │
        └──► batch_image_pipeline.py (P2)
              9 shot → 宫格 → API → grid_split → shot_01.png...
```

## 四、核心脚本设计

### 4.1 asset_library.py — 资产库管理

**位置**：`scripts/asset_library.py`

```python
class AssetLibrary:
    """资产库管理器，跨项目复用"""

    def __init__(self, base_dir: Path):
        self.base_dir = base_dir  # assets/library/

    def register(self, name: str, asset_type: str, metadata: dict) -> Path:
        """注册新资产：创建目录 + manifest.json"""

    def resolve(self, name: str, asset_type: str) -> list[str]:
        """查询某资产的参考图文件路径列表"""

    def list_by_project(self, project: str) -> dict:
        """列出某项目的所有资产"""

    def resolve_shot(self, shot: Shot) -> dict[str, list[str]]:
        """
        为单个 shot 查找相关资产文件路径
        输入: Shot 对象
        输出: {
            "characters": ["/path/to/漠玫_ref_01.png"],
            "scenes": ["/path/to/西湖断桥_ref_01.png"],
            "props": ["/path/to/电子令牌_ref_01.png"]
        }
        """
```

**resolve_shot 关键逻辑：**
1. 读取 outline.json 中的 assets 列表
2. 对 shot.characters/scene/props 中的每个名称
3. 查 manifest.json，找对应文件路径
4. 若无 manifest，跳过（不报错）

### 4.3 generate_reference_images.py — Step 2

**位置**：`scripts/generate_reference_images.py`

**输入**：`assets/library/*/manifest.json` + `*_card.md`

**输出**：`assets/library/[name]/images/*.png`

|---------|------------|

### 4.4 generate_shot_images.py — P1

**位置**：`scripts/generate_shot_images.py`

**输入**：`outputs/S01E01-shots.md` + `assets/library/`

**输出**：`outputs/S01E01-shots/images/`（每 shot 一张 PNG）

**调用方式**：
```bash
python3 scripts/generate_shot_images.py \
  --shots outputs/S01E01-shots.md \
  --outline outputs/S01E01-outline.md \
  --output-dir outputs/S01E01-shots/images/ \
  --provider doubao \
  --model doubao-seedream-4.5
```

**流程**：
1. 读取 shots + outline + asset_library
2. 对每个 shot：
   - `resolve_shot(shot)` → 相关资产文件路径

3. 调用 `doubao_pipeline.py --image --prompt "..." --img-ref <file>`
4. 下载 → `shot_{index:02d}.png`
5. 更新 shot JSON（写入 `shot.image_url`）

### 4.5 batch_image_pipeline.py — P2

**位置**：`scripts/batch_image_pipeline.py`

**输入**：`outputs/S01E01-shots.md`（前 9 个 shot）

**输出**：`outputs/S01E01-shots/grid/`（`shot_01.png` ~ `shot_09.png`）

**调用方式**：
```bash
python3 scripts/batch_image_pipeline.py \
  --shots outputs/S01E01-shots.md \
  --outline outputs/S01E01-outline.md \
  --rows 3 --cols 3 \
  --output-dir outputs/S01E01-shots/grid/ \
  --provider doubao \
  --model nanobanana  # 支持宫格的模型
```

**流程**：
1. 读取前 N 个 shots（N = rows × cols）
2. 对每个 shot：resolve_shot → 参考图 base64 列表
3. 合并所有参考图为一张（Sharp 拼接，最多 6 张）
4. 构建宫格 prompt（AI 润色，或直接拼接）
5. 调用 Doubao 宫格 API → 单张宫格图
6. `grid_split.py` → 切割为 N 张
7. 命名：`shot_01.png` ~ `shot_0N.png`

**宫格布局**：

| 镜头数 | 布局 |
|--------|------|
| 1 | 1×1 |
| 2 | 2×1 |
| 3 | 3×1 |
| 4 | 2×2 |
| 5-9 | 3×3 |
| 10-16 | 4×4 |

## 七、资产一致性（与 P0 保持一致）

`check_asset_consistency.py`（P0 已有）约束：

- shot.characters 必须在 outline.characters 中
- shot.scene 必须在 outline.scenes 中
- shot.props 必须在 outline.props 中

新增补充规则：

- `generate_shot_images.py` 生成的 PNG 文件名记录 shot index
- `batch_image_pipeline.py` 输出的 `shot_NN.png` 对应 shots[N-1]
- manifest.json 中记录每个文件对应的 shot 绑定

## 八、错误处理

| 异常场景 | 处理 |
|---------|------|
| 资产库为空（无 manifest） | 提示先运行 Step 1+2，不阻断主流程 |
| 参考图文件不存在 | 跳过参考图，仅用 prompt 生成 |
| Doubao API 超时 | 重试 3 次，exit 1 并打印 shot index |
| grid_split 数量不匹配 | 以 shot index 为准，报错不一致 |
| manifest 文件损坏 | 视为空资产，重新注册 |

## 十、与 Toonflow 对照

| 功能 | Toonflow | huage888 P1+P2 |
|------|----------|----------------|
| 资产存储 | t_assets (SQLite) + OSS | manifest.json + 本地文件 |

| 适配器注册 | 多厂商（volcengine/kling/...） | Doubao + Kling（已有 adapters/） |
