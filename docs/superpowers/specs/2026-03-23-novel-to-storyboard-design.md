# 小说转剧本+分镜工具 设计规格

> 日期：2026-03-23
> 状态：已批准

---

## 一、项目概述

**目标**：实现一个 Claude Skill，调用 Kimi API 将小说转换为剧本，再将剧本生成分镜表格

**技术路径**：
- 模型：Kimi (Moonshot) - 200K 上下文
- 两步流程：小说 → 剧本 → 分镜表格

---

## 二、工作流程

```
Step 1: 小说 → 剧本
├── 输入：TXT/DOCX 文件内容
├── 模型：moonshot-v1-8k（支持长文本）
├── 输出：Markdown 格式剧本
│   ├── 故事梗概
│   ├── 分集大纲
│   └── 角色设定

Step 2: 剧本 → 分镜表格
├── 输入：Step 1 生成的剧本
├── 模型：moonshot-v1-8k
├── 输出：Markdown 表格 + JSON 文件
```

---

## 三、分镜表格格式（19列）

| 字段 | 说明 |
|------|------|
| 镜号 | 镜头序号 |
| 时长 | 持续时间（秒） |
| 画面描述 | 场景视觉描述 |
| 角色1 | 第一个角色名 |
| 角色描述1 | 角色外貌/特征 |
| 角色图1 | 角色参考图（留空/URL） |
| 角色2 | 第二个角色名 |
| 角色描述2 | 角色外貌/特征 |
| 角色图2 | 角色参考图（留空/URL） |
| 参考 | 视觉参考 |
| 景别 | 特写/中景/全景/远景 |
| 角色动作 | 角色行为描述 |
| 情绪 | 情绪标签 |
| 场景标签 | 场景分类 |
| 光影氛围 | 光线/氛围描述 |
| 音效 | 背景音/特效音 |
| 对白 | 台词内容 |
| 分镜提示词 | AI 生图提示词 |
| 视频运动提示词 | 视频生成提示词 |

---

## 四、输出文件

### 4.1 剧本输出

- 文件名：`{小说名}_剧本.md`
- 格式：Markdown
- 内容：故事梗概 + 分集大纲 + 角色设定

### 4.2 分镜输出

- 文件名：`{小说名}_分镜表.md`
- 格式：Markdown 表格

- 文件名：`{小说名}_分镜表.json`
- 格式：JSON 数组，每行一个对象

## 六、Prompt 设计

### 6.1 小说转剧本 Prompt

```
你是一个专业的剧本创作助手。请将以下小说内容转换为一个完整的分集剧本。

要求：
1. 提取故事核心梗概（200字以内）
2. 生成分集大纲（根据用户设定的集数）
3. 创建角色设定表（包含角色名、年龄、外貌、性格、背景）
4. 每集剧本包含：
   - 场景、时间、地点
   - 角色动作和表情提示
   - 对话内容
   - 镜头语言建议

剧本格式示例：
【第一集】
场景：现代都市 · 咖啡馆 · 日
角色：林晚（女，28岁）、陆深（男，30岁）

[场景描述]
...

[镜头：特写]
林晚的手指轻轻敲击桌面。

[对白]
林晚：...

请开始转换以下小说：
```

### 6.2 剧本转分镜 Prompt

```
你是一个专业的分镜师。请将以下剧本转换为一个详细的分镜表格。

输出格式要求：
- 19列结构化表格
- 每行一个镜头
- 分镜提示词需要详细、具体，适合用于AI生图
- 视频运动提示词描述镜头运动方式

字段说明：
- 镜号：镜头序号
- 时长：建议时长（秒）
- 画面描述：场景视觉描述
- 角色1/2：出现的角色
- 角色描述：外貌特征
- 角色图：留空或参考URL
- 参考：视觉参考描述
- 景别：特写/中景/全景/远景
- 角色动作：角色行为
- 情绪：情绪标签
- 场景标签：室内/室外/白天/夜晚等
- 光影氛围：光线描述
- 音效：背景音/特效
- 对白：台词
- 分镜提示词：详细生图描述
- 视频运动：镜头运动方式

请转换以下剧本：
```

## 九、限制与风险

1. **Token 限制**：moonshot-v1-8k 最大 8K tokens，长篇小说需分段
2. **API 成本**：按调用次数计费
3. **格式依赖**：完全依赖 Kimi 模型输出格式
