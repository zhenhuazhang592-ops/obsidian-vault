## 核心要点总结

### 技术选型
- **后端**: Node.js + Express + TypeScript
- **AI SDK**: Vercel AI SDK
- **数据库**: SQLite
- **实时通信**: WebSocket

### Agent 架构
- **多 Agent 协作**: 主 Agent 调度 + 子 Agent 执行 + 导演审核
- **工具系统**: 使用 `tool()` 定义可调用工具
- **流式响应**: 实时推送 token 级别的响应

### 核心流程
```
小说上传 → 故事线生成 → 大纲生成 → 资产生成 → 分镜生成 → 视频生成
```

### 关键设计
- Prompt 存储在数据库，支持动态配置
- WebSocket 长连接，支持实时流式输出
- 异步任务处理，不阻塞主流程
