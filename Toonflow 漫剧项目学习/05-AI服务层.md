## 文本生成 (AIText)

### 支持的模型

通过 `src/utils/ai/text/modelList.ts` 配置：

| 模型 | 说明 |
|-----|------|
| OpenAI | GPT 系列模型 |
| Claude | Anthropic Claude 模型 |
| Gemini | Google Gemini 模型 |

### 使用方式

```typescript
import AIText from "@/utils/ai/text/index";

// 调用文本生成
const result = await AIText.generate({
  model: "claude-3-5-sonnet",
  messages: [
    { role: "system", content: "你是一个助手" },
    { role: "user", content: "你好" }
  ]
});
```

### 支持的模型

| 模型 | 来源 | 说明 |
|-----|------|------|
| Nano Banana Pro | 自有 | 主要使用的图像生成模型 |
| Stable Diffusion | ModelScope | 开源图像模型 |
| DALL-E | OpenAI | OpenAI 图像模型 |
| Gemini | Google | Google 图像模型 |
| Kling | 快手 | 视频生成，也支持图像 |

### 适配器模式

```typescript
// src/utils/ai/image/adapter/volcengine.ts
export default class VolcanoEngineImageAdapter {
  async generate(params: ImageGenerateParams): Promise<ImageResult> {
    // 调用火山引擎 API
    const response = await fetch("https://visual.volcengineapi.com/v1/image/generation", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${this.apiKey}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        model: params.model,
        prompt: params.prompt,
        ...
      })
    });
    return response.json();
  }
}
```

### 分镜图生成流程

```typescript
// src/agents/storyboard/generateImageTool.ts
async function generateImageTool(
  prompts: Array<{ prompt: string }>,
  scriptId: number,
  projectId: number
): Promise<Buffer> {
  // 1. 合并所有提示词为宫格图片提示词
  const combinedPrompt = combinePrompts(prompts);

  // 2. 调用 AI 图像生成
  const imageBuffer = await AIImage.generate({
    model: "nano-banana-pro",
    prompt: combinedPrompt,
    aspectRatio: "16:9"
  });

  // 3. 返回图片 Buffer
  return imageBuffer;
}
```

### 视频生成流程

```typescript
// src/routes/video/generateVideo.ts
router.post("/generateVideo", async (req, res) => {
  const { projectId, storyboardId, prompt, model } = req.body;

  // 1. 调用视频生成服务
  const videoJob = await AIVideo.generate({
    model: model || "kling",
    prompt: prompt,
    firstFrame: firstFrameImage,  // 可选：第一帧图片

  // 2. 返回任务ID，供后续查询进度

    success: true,
    jobId: videoJob.id,
    status: videoJob.status
  });
});
```

### 动态加载 Prompt

```typescript
// src/utils/getPromptAi.ts
export default async function getPromptAi(configKey: string) {
  // 获取 Prompt 配置
  const promptConfig = await u.db("t_setting")
    .where({ id: 1 })
    .first();

  // 获取 AI 模型配置
  const languageModel = JSON.parse(promptConfig?.languageModel || "{}");

  // 返回模型配置
  return {
    model: languageModel.defaultModel || "claude-3-5-sonnet-20241022",
    apiKey: languageModel.apiKey,
    baseUrl: languageModel.baseUrl
  };
}
```

## 流式响应处理

### 服务器端

```typescript
const { fullStream } = await u.ai.text.stream(
  {
    system: systemPrompt,
    tools: toolsObject,
    messages: history,
    maxStep: 100
  },
  { model: "claude-3-5-sonnet", apiKey: "xxx" }
);

for await (const item of fullStream) {
  if (item.type === "text-delta") {
    // 实时推送
    ws.send(JSON.stringify({ type: "stream", data: item.text }));
  }
  if (item.type === "tool-call") {
    // 工具调用
    ws.send(JSON.stringify({ type: "toolCall", data: item.title }));
  }
}
```

### 客户端接收

```javascript
const ws = new WebSocket("ws://localhost:60000/outline/agentsOutline");

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);

  if (data.type === "stream") {
    // 流式文本
    appendToUI(data.data);
  } else if (data.type === "toolCall") {
    // 工具调用中
    showToolLoading(data.data);
  } else if (data.type === "response_end") {
    // 响应结束
    finishUI();
  }
};
```
