# Toonflow 项目概述

## 项目简介

**Toonflow** (AI短剧工厂) 是一款利用 AI 技术将小说自动转化为短剧的 AI 工具，实现了从文本到影像的全流程智能化创作。

## 核心功能

| 功能模块     | 说明                           |
| -------- | ---------------------------- |
| **角色生成** | 自动分析小说文本，识别并生成角色设定（外貌、性格、身份） |
| **剧本生成** | 基于章节和事件，自动生成结构化剧本（对白、场景、剧情）  |
| **分镜制作** | 根据剧本生成分镜提示词与画面设计             |
| **视频合成** | 集成 AI 图像与视频技术，生成最终视频         |

## 技术栈

| 层级 | 技术选型 |
|-----|---------|
| 后端框架 | Node.js + Express + TypeScript |
| AI SDK | Vercel AI SDK (`ai` package) |
| 数据库 | SQLite (better-sqlite3) |
| 实时通信 | WebSocket |
| 桌面端 | Electron |
| 图片处理 | Sharp |

## 快速开始

```bash
# 安装依赖
yarn install

# 启动开发模式（仅后端）
yarn dev

# 启动 Electron 桌面客户端（推荐）
yarn dev:gui

# 打包
yarn build
yarn dist:win  # Windows
yarn dist:mac  # macOS
yarn dist:linux # Linux
```
