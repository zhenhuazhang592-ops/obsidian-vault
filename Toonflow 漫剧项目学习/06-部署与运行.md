# Toonflow 部署与运行

## 环境要求

| 环境 | 要求 |
|-----|------|
| Node.js | 23.11.1+ (推荐 24.x) |
| 内存 | 2GB+ |
| 数据库 | SQLite (内置) |
| AI 服务 | 需要配置 API Key |

## 前置配置

### 1. 配置 AI 服务

在系统设置中配置：

```typescript
// t_setting 表
{
  tokenKey: "xxx",
  languageModel: JSON.stringify({
    defaultModel: "claude-3-5-sonnet-20241022",
    apiKey: "sk-xxx",
    baseUrl: "https://api.anthropic.com"
  }),
  imageModel: JSON.stringify({
    defaultModel: "nano-banana-pro",
    apiKey: "xxx"
  })

```

### 2. 环境变量（可选）

```bash
# .env 文件
NODE_ENV=prod
PORT=60000
OSSURL=http://127.0.0.1:60000/
```

## 部署方式

### 方式一：直接运行（开发/测试）

```bash
# 安装依赖
yarn install

# 启动后端服务（端口 60000）
yarn dev

# 或启动 Electron 桌面客户端
yarn dev:gui
```

### 方式二：Docker 部署

```bash
# 在线构建并启动
docker-compose -f docker/docker-compose.yml up -d --build

# 使用 Gitee 源（国内更快）
GIT=gitee docker-compose -f docker/docker-compose.yml up -d --build

# 指定版本
TAG=v1.0.6 docker-compose -f docker/docker-compose.yml up -d --build
```

**端口说明：**

| 端口 | 用途 | 映射 |
|-----|------|------|
| 80 | 前端页面 | 随机:80 |
| 60000 | 后端 API | 60000:60000 |

### 方式三：服务器部署

```bash
# 1. 安装 Node.js
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 24

# 2. 安装依赖
npm install -g yarn pm2

# 3. 克隆项目
git clone https://github.com/HBAI-Ltd/Toonflow-app.git
cd Toonflow-app
yarn install
yarn build

# 4. 配置 PM2
cat > pm2.json << 'EOF'
{
  "name": "toonflow-app",
  "script": "build/app.js",
  "instances": "max",
  "exec_mode": "cluster",
  "env": {
    "NODE_ENV": "prod",
    "PORT": 60000,
    "OSSURL": "http://127.0.0.1:60000/"
  }
}
EOF

# 5. 启动服务
pm2 start pm2.json
pm2 startup
pm2 save
```

## 打包发布

```bash
# 构建 TypeScript
yarn build

# 打包为可执行文件
yarn dist:win    # Windows
yarn dist:mac    # macOS
yarn dist:linux  # Linux
```

打包产物位于 `release` 目录。

## 常用命令

```bash
# 查看进程
pm2 list

# 查看日志
pm2 logs toonflow-app

# 重启服务
pm2 restart all

# 监控面板
pm2 monit

# Docker 相关
docker-compose -f docker/docker-compose.yml ps
docker-compose -f docker/docker-compose.yml logs -f
docker-compose -f docker/docker-compose.yml down
```
