## 核心数据流

```
1. 用户上传小说 → t_novel 表
2. 调用 OutlineScript Agent → 生成故事线 → t_storyline 表
3. 调用 OutlineScript Agent → 生成大纲 → t_outline 表
4. 调用 generateAssets → 生成资产 → t_assets 表
5. 调用 Storyboard Agent → 生成片段 + 分镜 → t_storyboard 表
6. 调用 generateShotImage → 生成图片 → OSS 存储
7. 调用 AIVideo → 生成视频 → t_video 表
```
