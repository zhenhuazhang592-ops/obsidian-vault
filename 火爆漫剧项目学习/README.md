## 核心要点总结

### 技术选型
- **后端**: Go + Gin + GORM
- **数据库**: MySQL/PostgreSQL/SQLite
- **前端**: Vue 3 + TypeScript + Vite
- **AI 服务**: OpenAI/Gemini/火山引擎/MiniMax

### 架构模式
- **分层架构**: Handler → Service → Domain → Infrastructure
- **适配器模式**: 统一接口 + 多厂商实现
- **任务队列**: 异步任务 + 状态追踪

### 核心流程
```
创建项目 → 上传剧本 → AI提取角色 → AI生成角色图
       → AI提取场景 → AI生成场景图 → AI生成分镜
       → AI生成视频 → FFmpeg合并 → 最终视频
```

### 关键设计
- **多厂商 AI**: 通过适配器支持多种 AI 服务商
- **异步任务**: 长时间运行任务后台执行，前端轮询状态
- **FFmpeg 集成**: 视频合并在服务端完成
- **前端内置**: 前端构建产物直接打包到 Go 二进制

## 对比 Toonflow

| 维度 | Toonflow | 好剧生成器 |
|-----|----------|------------|
| 后端 | Node.js + Express | Go + Gin |
| 数据库 | SQLite | MySQL/PostgreSQL/SQLite |
| 前端 | Electron 内置 | Vue 3 独立 |
| AI 调用 | Vercel AI SDK | 自定义适配器 |
| 实时通信 | WebSocket | HTTP 轮询 |
| Agent 模式 | 多 Agent 协作 | 单次 AI 调用 |
