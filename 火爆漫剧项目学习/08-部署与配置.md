# 好剧生成器 部署与配置

## 环境要求

| 环境 | 要求 |
|-----|------|
| Go | 1.23+ |
| Node.js | 18+ |
| MySQL/PostgreSQL/SQLite | 任意一种 |
| FFmpeg | 需要安装 |

## 配置说明

### 配置文件

项目使用 Viper 加载配置，支持多种配置源：

```yaml
# config.yaml
app:
  name: "Drama Generator"
  version: "1.0.0"
  debug: true

server:
  port: 8080
  cors_origins: "*"

database:
  driver: "sqlite"
  dsn: "./data.db"

storage:
  type: "local"
  local_path: "./uploads"
  base_url: "http://localhost:8080"
```

### 环境变量

```bash
# 可以通过环境变量覆盖配置
export DATABASE_DRIVER=sqlite
export DATABASE_DSN=./data.db
export STORAGE_TYPE=local
export STORAGE_LOCAL_PATH=./uploads
export STORAGE_BASE_URL=http://localhost:8080
```

## 部署方式

### 1. 直接运行

```bash
# 克隆项目
git clone https://github.com/drama-generator/backend.git
cd backend

# 编译
go build -o drama-generator main.go

# 运行
./drama-generator
```

### 2. Docker 部署

```dockerfile
# Dockerfile
FROM golang:1.23-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN go build -o drama-generator main.go

FROM alpine:latest
WORKDIR /app
COPY --from=builder /app/drama-generator .
COPY --from=builder /app/web/dist ./web/dist

EXPOSE 8080
CMD ["./drama-generator"]
```

```bash
# 构建镜像
docker build -t drama-generator .

# 运行
docker run -p 8080:8080 -v ./data:/app/data -v ./uploads:/app/uploads drama-generator
```

### 3. Docker Compose 部署

```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
      - ./uploads:/app/uploads
    environment:
      - DATABASE_DRIVER=sqlite
      - DATABASE_DSN=/app/data/data.db
      - STORAGE_LOCAL_PATH=/app/uploads
```

## 前端部署

```bash
# 安装依赖
cd web
pnpm install

# 开发模式
pnpm dev

# 构建
pnpm build

# 构建产物在 web/dist 目录
```

## 数据库迁移

### 自动迁移

项目使用 GORM 的 AutoMigrate 功能自动创建表：

```go
// main.go
func main() {
    db, err := database.NewDatabase(cfg.Database)
    if err != nil {
        log.Fatal(err)
    }

    // 自动迁移
    if err := database.AutoMigrate(db); err != nil {
        log.Fatal(err)
    }
}
```

### 手动迁移

```bash
# 使用 migrate 工具
go run cmd/migrate/main.go
```

## FFmpeg 安装

### macOS

```bash
brew install ffmpeg
```

### Ubuntu/Debian

```bash
sudo apt update
sudo apt install ffmpeg
```

### Windows

下载 FFmpeg 官方编译版本并添加到 PATH。

## 存储配置

### 本地存储

```yaml
storage:
  type: local
  local_path: ./uploads
  base_url: http://localhost:8080
```

### OSS（对象存储）

可以通过修改 storage 相关代码来支持阿里云 OSS、AWS S3 等。

## 常用命令

```bash
# 启动服务
go run main.go

# 后台运行
nohup ./drama-generator &

# 使用 PM2
pm2 start drama-generator

# 查看日志
pm2 logs drama-generator

# 重启
pm2 restart drama-generator
```
