# 好剧生成器 (huobao-drama) 项目概述

## 项目简介

**好剧生成器** 是一款 AI 驱动的短剧/视频创作平台，支持从剧本到视频的全流程 AI 化生产。

## 核心功能

| 功能模块 | 说明 |
|---------|------|
| **项目管理** | 创建、编辑、删除短剧项目 |
| **剧本管理** | 上传剧本、AI 生成角色和场景 |
| **角色库** | 角色图片生成与管理 |
| **分镜生成** | AI 自动生成分镜脚本 |
| **图片生成** | AI 生成场景图、角色图、道具图 |
| **视频生成** | AI 生成视频片段 |
| **视频合成** | FFmpeg 合并视频片段 |
| **AI 配置** | 支持多种 AI 服务商配置 |

## 技术栈

### 后端

| 技术 | 说明 |
|-----|------|
| Go 1.23+ | 编程语言 |
| Gin | Web 框架 |
| GORM | ORM 框架 |
| MySQL/PostgreSQL/SQLite | 数据库 |
| FFmpeg | 视频处理 |

### 前端

| 技术 | 说明 |
|-----|------|
| Vue 3 | 框架 |
| TypeScript | 语言 |
| Vite | 构建工具 |
| Tailwind CSS | 样式 |
| Pinia | 状态管理 |
| Vue Router | 路由 |

### AI 服务

| 服务 | 类型 |
|-----|------|
| OpenAI | 文本/图像/视频 |
| Google Gemini | 文本/图像 |
| 火山引擎 | 图像/视频 |
| MiniMax | 视频 |
| ChatFire | 视频 |

## 项目地址

- **后端**: Go + Gin
- **前端**: Vue 3 + TypeScript

## 快速开始

```bash
# 后端
cd huobao-drama-master
go run main.go

# 前端
cd web
pnpm install
pnpm dev
```

## 默认配置

- 端口: 8080
- 数据库: SQLite (默认)
- 存储: 本地文件系统
