# 好剧生成器 数据库设计

## 数据库概览

项目使用 GORM 作为 ORM，支持 MySQL、PostgreSQL、SQLite 三种数据库。

## 核心表结构

### 1. dramas（剧集表）

```go
type Drama struct {
    ID            uint           // 主键
    Title         string         // 剧集标题
    Description   *string        // 简介
    Genre         *string        // 类型
    Style         string         // 风格 (realistic/ghibli/anime)
    TotalEpisodes int            // 总集数
    TotalDuration int            // 总时长(秒)
    Status        string         // 状态 (draft/planning/production/completed/archived)
    Thumbnail     *string        // 封面图
    Tags          datatypes.JSON // 标签
    Metadata      datatypes.JSON // 元数据

    // 关联
    Episodes   []Episode   // 剧集
    Characters []Character // 角色
    Scenes     []Scene     // 场景
    Props      []Prop      // 道具
}
```

### 2. episodes（章节表）

```go
type Episode struct {
    ID            uint           // 主键
    DramaID       uint           // 所属剧集
    EpisodeNum    int            // 集号
    Title         string         // 标题
    ScriptContent *string        // 剧本内容
    Description   *string        // 描述
    Duration      int            // 时长(秒)
    Status        string         // 状态
    VideoURL      *string        // 最终视频URL

    // 关联
    Storyboards []Storyboard // 分镜列表
    Characters  []Character  // 角色
    Scenes      []Scene      // 场景
}
```

### 3. characters（角色表）

```go
type Character struct {
    ID              uint           // 主键
    DramaID         uint           // 所属剧集
    Name            string         // 角色名
    Role            *string        // 角色类型 (主角/配角/反派)
    Description     *string        // 描述
    Appearance      *string        // 外貌描述
    Personality     *string        // 性格
    VoiceStyle      *string        // 声音风格
    ImageURL        *string        // 角色图片URL
    LocalPath       *string        // 本地路径
    ReferenceImages datatypes.JSON // 参考图片
    SeedValue       *string        // 种子值

    // 多对多关联

}
```

### 4. scenes（场景表）

```go
type Scene struct {

    ImageURL        *string        // 场景图片URL
    LocalPath       *string        // 本地路径

```

### 5. storyboards（分镜表）

```go

    ID               uint           // 主键
```

## 数据库初始化

```go
// infrastructure/database/database.go
func NewDatabase(cfg config.Database) (*gorm.DB, error) {
    // 支持 MySQL, PostgreSQL, SQLite
    switch cfg.Driver {
    case "mysql":
        return gorm.Open(mysql.Open(cfg.DSN), &gorm.Config{})
    case "postgres":
        return gorm.Open(postgres.Open(cfg.DSN), &gorm.Config{})
    case "sqlite":
        return gorm.Open(sqlite.Open(cfg.DSN), &gorm.Config{})
    }
}

// 自动迁移
func AutoMigrate(db *gorm.DB) error {
    return db.AutoMigrate(
        &models.Drama{},
        &models.Episode{},
        &models.Character{},
        &models.Scene{},
        &models.Storyboard{},
        &models.Prop{},
        &models.ImageGeneration{},
        &models.VideoGeneration{},
        &models.AIConfig{},
        &models.Task{},
    )
}
```
