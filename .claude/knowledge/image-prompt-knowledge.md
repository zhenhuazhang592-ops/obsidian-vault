# 图像生成提示词知识体系

> 来源：awesome-nano-banana (JimmyLv/awesome-nano-banana) 深度拆解
> 参考：100+案例，Gemini 2.5 Flash Image + GPT-4o 对比
> 适配：赛博墨韵 / 漫剧分镜 / 角色设计 / 产品图

---

## 一、Prompt 结构总纲（5种核心句式）

### 句式 A：模板变量式 — 最通用的公式

```
一张[媒介]的[主体]，采用[风格]风格，[详细描述]。
```

**核心特征：** 用【】或[ ]标注可替换变量，模型可自由发挥变量以外的内容。

| 变量 | 作用 | 示例 |
|------|------|------|
| `[媒介]` | 图片类型 | 海报、照片、插画、封面、图标 |
| `[主体]` | 画面核心元素 | 人物、产品、动物、建筑 |
| `[风格]` | 艺术风格锚点 | 赛博朋克、国风水墨、皮克斯3D |
| `[详细描述]` | 材质/光线/构图约束 | 磨砂玻璃、柔和打光、2:3宽高比 |

**案例：**
```
一张纵向（3:4）4K分辨率的极简未来主义展览海报，背景为超浅冷灰。
海报中心有一枚流体3D metaball，形态为【立体可口可乐经典汽水瓶】，
材质磨砂玻璃并带细腻颗粒噪点。
```

---

### 句式 B：图生转换式 — 角色/照片风格迁移

```
将照片中的[角色/主体]转换为[目标风格]风格，
[保留/改变哪些特征]，[场景描述]，[参考来源]。
```

**核心特征：** 先指定输入（图），再描述目标输出，包含"保持什么 + 改变什么"。

| 阶段 | 内容 | 示例 |
|------|------|------|
| 输入 | 上传照片的类型和质量要求 | 半身或全身单人照片，清晰五官 |
| 角色映射 | 保留哪些特征 | 保留原图所有细节，如服饰、发型、五官 |
| 风格映射 | 变成什么 | 3D Q版人物 / 动漫手办 / 针织玩偶 |
| 场景约束 | 环境是否变化 | 场景换成求婚 / 背景换成中式婚礼 |

**案例：**
```
将场景中的角色转化为3D Q版风格，同时保持原本的场景布置和服装造型不变。
```
```
将照片里的两个人转换成Q版3D人物，
中式古装婚礼，大红颜色，背景"囍"字剪纸风格图案。
服饰要求：写实，男士身着长袍马褂，主体为红色，
上面以金色绣龙纹图案，彰显尊贵大气。
```

---

### 句式 C：图参叠加式 — 参考图 + 指令双轨

```
[参考图描述]，以[拍摄方式/视角]，
[具体动作/交互]，[氛围描述]。
```

**核心特征：** 图片本身承载80%视觉信息，Prompt只给构图/情绪指令。
适合：角色同框、风格迁移、产品与场景融合。

**案例：**
```
以手机随手拍摄的日常风格，桌面上摆放着一款【成龙】动漫手办，
动作夸张帅气，装备齐全。
同时，真实世界的对应人物也出现在镜头中，
与手办摆出相似的姿势，形成手办与真实人物同框的有趣对比效果。
```
```
将照片里的角色做成 Funko Pop 公仔包装盒的风格，
以等距视角（isometric）呈现，并在包装盒上标注标题为"JAMES BOND"。
```

### 句式 D：多格叙事式 — 漫画/分镜专用

```
第 N 格：
- 表情/动作：[具体描述]
- 文字框："[台词]"
- 场景：[背景描述]
---
第 N+1 格：
- [同上结构]
```

**核心特征：** 分格描述，每格独立设置表情+动作+台词+场景。
适合：分镜脚本、漫画封面、故事板。

**案例：**
```
创建一张日系萌系双格漫画，上下排列，主题：少女总统的工作日常。
第一格:
- 表情: 委屈巴巴，沮丧的表情，单手托腮
- 文字框: "肿么办嘛！他不跟我通话！(；´д｀)"
- 场景: 暖色调办公室，背后美国国旗，桌上放着一堆汉堡，
一个复古红色转盘电话，人物在画面左边，电话在右边。
第二格:
- 表情: 咬牙切齿，暴怒，脸涨红
- 动作: 猛拍桌子，汉堡震得跳起来
- 文字泡: "哼！关税加倍！不理我是他们的损失！( `д´ )"
```

---

### 句式 E：纯指令式 — 极简风格锚定

```
[极简短语] + [1-2个核心变量]
```

**核心特征：** 极短Prompt，靠风格词触发模型最佳表现。
适合：Pixar、Ghibli、赛博朋克等强风格词。

**案例：**
```
以皮克斯 3D 风格重绘这张照片。
```
```
35 毫米胶片风格的照片：莫斯科漂浮在天空中的飞行岛屿上。
```
```
微型立体场景呈现，运用移轴摄影的技法，
呈现出Q版【孙悟空三打白骨精】场景。
```

## 三、Gemini vs GPT-4o 核心差异（Prompt设计启示）

> 来源：100个案例的双模型对比结果

| 维度 | Gemini 2.5 Flash | GPT-4o |
|------|-----------------|--------|
| **文字渲染** | 强，文字可精确嵌入 | 弱，文字常出错 |
| **风格迁移** | 对参考图理解更深 | 更依赖Prompt文字 |
| **中文理解** | 优秀 | 一般，需英文更好 |
| **写实人像** | 光影自然，但可能过于柔和 | 锐利，但有时失真 |
| **3D/CG风格** | 出色，材质感真实 | 出色，色彩更饱和 |
| **复杂构图** | 分层理解好，遮挡关系准 | 有时混淆前后关系 |
| **情绪/氛围** | 氛围渲染能力强 | 偏向清晰还原 |

**设计启示：**
- **中文场景 → 优先用 Gemini**（中文理解更强）
- **需要精确文字 → 必须用 Gemini**
- **风格迁移 + 参考图 → 两模型均可，Gemini对图理解更深**
- **强烈风格词（Pixar/Ghibli） → 两模型均强，GPT-4o饱和度更高**
- **复杂多元素场景 → Gemini遮挡关系更准**

## 四、赛博墨韵风格适配

> 核心风格：东方禅意 + 赛博朋克 = 信息禅者

### 4.1 风格锚定词

```
赛博墨韵 / Cyber-Ink
= 赛博朋克元素（霓虹、数据流、废土城市场景）
+ 国风水墨元素（流动墨滴、水墨笔触、留白禅意）
+ 数字禅意（金色瞳孔数据流、道姑髻+数据簪）
```

### 4.2 推荐句式组合

**角色设计（句式B变体）：**
```
将照片中的角色转换为赛博墨韵风格：
保留原图五官特征，
服饰改为道姑髻发型+数据簪装饰，
双眼改为金色瞳孔+数据流效果，
皮肤融入青蓝水墨眼线，
整体呈现东方禅意与赛博朋克的融合。
背景为水墨晕染的数字城市，
主体细节采用流动墨滴笔触。
```

**场景设计（句式A变体）：**
```
一张16:9横屏场景图，
主体为赛博墨韵风格的漠玫角色，
采用水墨流动笔触渲染人物轮廓，

点缀金色数据流光芒，
整体氛围：禅意、神秘、东方赛博。

**分镜封面（句式E极简版）：**

赛博墨韵风格：漠玫立于断桥，
水墨笔触+霓虹光晕，

```

## 五、变量插槽设计（Template Variables）

> 来自 Case 100, 41, 71 的核心发现：
> **将Prompt写成模板，关键变量用【】标注，可无限复用**

### 5.1 角色转绘模板

```
将照片中的角色转换为【目标风格】风格。
参考照片类型：【照片类型要求，如：半身或全身单人照片】。
保留元素：原图五官、发型轮廓。
改变元素：服饰→【目标服饰描述】、材质→【目标材质描述】。
场景：【场景描述，如：保留原场景/换成XX场景】。
输出比例：【如：16:9 / 3:4 / 2:3】。
```

### 5.2 场景生成模板

```
一张【宽高比】【分辨率】的【媒介类型】。
主体：【核心视觉元素】。
风格：【艺术风格词】。
材质：【关键材质描述】。
光线：【打光方式】。
氛围：【情绪/氛围词】。
构图：【视角/构图约束】。
比例：【如：16:9横屏】。
```

### 5.3 分镜脚本模板

```
第【N】镜：【时间/镜头描述】
- 角色动作：【动作描述】
- 表情：【情绪状态】
- 台词/文字：【对白或字幕】
- 场景：【背景环境】
- 风格：【本镜艺术风格】
- 比例：【16:9】
```

## 六、Gemini 特有优势（Prompt可针对性利用）

| 能力 | Prompt利用方式 |
|------|--------------|
| **中文精确理解** | 中文描述 > 英文翻译，直接用中文写Prompt |
| **遮挡关系理解** | 强调"被遮挡部分呈现XX效果" |
| **文字渲染** | 文字内容单独指定：顶部/中部，字体颜色 |
| **参考图深度理解** | "参考图风格"比"详细描述"更准 |
| **多图组合** | "图A的角色+图B的场景+图C的色调" |

## 七、避坑指南

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 角色不像 | 参考图不够清晰 | 指定"上传清晰五官照片" |
| 风格走偏 | 风格词太泛 | 加材质词："磨砂玻璃质感"比"质感好"更准 |
| 文字乱码 | 两模型均不稳定 | Gemini可精确指定，GPT-4o避免文字 |
| 构图太满 | 没指定留白 | 加"留白干净"、"简约背景" |
| 色调偏灰 | 没指定主色调 | 加"Coca-Cola红 #E41C23"精确色值 |
| 透视出错 | 没指定视角 | 加"等距视角"、"俯视45度"、"2:3宽高比" |
