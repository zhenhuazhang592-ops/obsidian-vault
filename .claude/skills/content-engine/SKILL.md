# 内容引擎 · Content Engine

把一个想法变成各平台的最强版本，不是在各平台发同一份内容。

## 何时激活

- 写小红书、抖音、公众号、B站视频脚本
- 把文章、播客、演示适配成分发内容
- 围绕一个产品/事件/话题设计内容日历
- 做跨平台宣传活动

## 激活前先确认

- **源内容**：我们要适配什么？（文章/视频/产品/事件）
- **目标平台**：哪些平台？（小红书/抖音/公众号/知乎/微博/视频号）
- **受众**：谁看？（职场人/大学生/创业者/特定圈层）
- **目标**：涨粉/引流/转化/品牌/互动？

## 核心规则

1. **每个平台原生适配** — 不跨平台发同一份内容
2. **钩子比内容更重要** — 没人点进来，再好的内容也白搭
3. **每条内容只讲一件事** — 一个核心点，不要贪多
4. **用具体细节** — 不要口号，要场景、数字、情绪
5. **CTA 要小且明确** — 不要"欢迎留言"，要具体行动

## 平台规格（中文平台）

| 平台 | 核心 | 长度 | 关键 |
|------|------|------|------|
| **小红书** | 种草/生活方式 | 标题 20 字内 + 正文 500-800 字 | 封面图 + 前 3 行是生死线 |
| **抖音/视频号** | 情绪/猎奇/有用 | 脚本 1-3 分钟 | 前 3 秒必须抓住注意力 |
| **公众号** | 深度/观点/信任 | 1000-3000 字 | 标题打开，正文留存 |
| **知乎** | 专业/数据/稀缺视角 | 500-2000 字 | TLDR + 结构化 |
| **微博** | 实时/观点/热梗 | 140 字内 | 蹭热点要快，不要废话 |
| **微博长文** | 观点展开 | 1000-2000 字 | 第一屏决定转发 |

## 适配工作流

```
源内容（文章/视频/产品）
     ↓
提取 3-7 个原子想法
     ↓
每个想法 → 各平台原生版本
     ↓
去重复（同一想法不重复发）
     ↓
对齐 CTA（平台意图不同，CTA 不同）
```

## 平台要点详解

### 小红书

**钩子类型**：
- 数字型："3 个方法，我用了 2 年"
- 情绪型："家人们谁懂啊..."
- 结果型："从 X 到 Y，我只用了..."
- 反差型："月薪 3 千和 3 万的人，差在哪"

**格式**：
```
标题（带关键词）
空行
前 3 行（核心信息 + 情绪）
正文分段
结尾互动引导
标签 #话题1 #话题2 #话题3
```

### 抖音/视频号

**前 3 秒脚本**：
```
第 1 秒：抛出问题或反差
第 2 秒：给出一个反常识答案
第 3 秒：承诺"结尾有彩蛋/方法/答案"
```

**脚本结构**：
```
0-3s：钩子（必须强）
3-15s：建立期待（why you should care）
15-60s：核心内容（一个点讲透）
60-90s：反转或深化（optional）
最后 5s：CTA + 关注引导
```

### 公众号

**选题判断**：
- 有没有独特视角？（不是老调重弹）
- 有没有具体数据/案例？
- 读者读完后能做什么？

**结构推荐**：
```
开头（痛点/场景/数字）
问题界定
核心观点（一个）
支撑（故事/数据/案例）× 3
结论（读者能做什么）
CTA
```

## 内容复用示例

**源：一篇关于"时间管理"的文章**

| 平台 | 适配 |
|------|------|
| 小红书 | "我试了 30 天，时间反而变多了：一个反直觉的时间管理法" |
| 抖音 | "时间不够用？很多人第一步就做错了"（30s 视频） |
| 公众号 | 完整方法论 + 数据支撑 + 操作清单 |
| 知乎 | "有哪些反直觉但有效的时间管理技巧？"（回答形式） |

## 质量门控

- [ ] 每个平台版本在该平台读起来自然
- [ ] 钩子够强（不是标题党，有实质内容）
- [ ] 无空洞词和废话
- [ ] 跨平台内容不重复（每个有独立价值）
- [ ] CTA 和平台意图对齐
- [ ] 标签/话题选择正确

## 写作质量保障（来自 article-writing）

### 禁止模式（Banned Patterns）

发现以下内容，直接删掉重写：
- 空洞开头："在当今快速发展的时代..."
- 废话连接词："此外"、"更重要的是"、"综上所述"
- AI 腔调："值得注意的是"、"毋庸置疑"、"令人欣喜的是"
- 虚假权威："权威研究表明"、"专家称"（无来源时）
- 无来源数据："大量用户反馈"、"众多读者表示"
- 无实质标题党："你绝对不知道..."、"99% 的人..."

### 声音捕捉流程

如果指定了声音风格，收集：已发布文章、社交媒体帖子、风格指南。

提取以下要素：
- 句子长度和节奏感
- 语气：正式 / 口语 / 犀利 / 温和
- 修辞手法：括号、断句、问句、反问、感叹
- 对观点/争议的态度：敢不敢说逆耳话
- 格式化习惯：标题层级、列表使用、引用块

**没有声音参考时**，默认使用**直接、有观点、有实例**的风格。

### 写作流程

1. **确认读者和目的** — 谁读？想让他做什么？
2. **搭骨架** — 每段只做一件事，一个中心句
3. **从证据/故事/数字开始** — 不要从观点开始
4. **只扩写值得扩写的地方** — 每句都要问自己"这句话可以删吗？"
5. **删掉听起来像模板的内容** — 自夸的、总结性的、喊口号的
