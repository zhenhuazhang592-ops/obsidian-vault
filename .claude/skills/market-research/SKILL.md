# 市场调研 · Content Creator Research

做**支撑决策**的调研，不做调研表演。

## 何时激活

- 确定目标读者（谁在读？）
- 分析同类账号/内容（竞品研究）
- 了解行业趋势（蹭热点要有底气）
- 验证创作选题是否有市场
- 准备商业合作时的品牌调性调研

## 创作研究标准

1. **每个重要结论要有来源** — 数据/引用/可验证案例
2. **标注数据时效** — 陈旧数据要明确说明
3. **包含反面证据** — 不只找支持自己观点的信息
4. **结论导向** — 调研后要能回答"所以呢？"
5. **区分事实/推断/建议** — 不要混在一起

## 常见创作研究模式

### 受众画像

收集：
- 人口统计：年龄/职业/地域/收入
- 内容偏好：看什么平台/什么类型内容
- 痛点：有什么问题需要被解决
- 消费习惯：愿意为什么付费
- 信息获取方式：主动搜索还是被动刷到

### 竞品账号研究

收集：
- **内容reality**（不是账号写的）：真实在发什么
- **粉丝互动**：评论区在说什么（比点赞数更有价值）
- **更新频率和节奏**：日更/周更，内容配比
- **变现方式**：广告/带货/知识付费/打赏
- **优势/弱点/定位空白**：这个账号没覆盖什么？

### 趋势研究

收集：
- 平台算法当前在推什么（近期爆款内容类型）
- 行业热点事件
- 受众情绪变化（焦虑/躺平/反卷/治愈系...）
- 竞品最近在追什么热点

### 选题验证

结构化评估一个选题：
```
吸引力：读者看到标题会不会点进来？
独特性：这个角度有多少账号在做？
可执行性：我有没有足够的素材/案例支撑？
差异化：我能做，别人不能做的是什么？
商业潜力：有没有变现路径？
```

## 输出格式

### 快速调研（30 分钟内）

```
## 调研结论：[一句话]

## 核心发现（3 条）
1. ...
2. ...
3. ...

## 对创作的启示
- 可以蹭的点：...
- 要避开的点：...
- 差异化角度：...

## 风险和局限
- 数据可能过时
- 受众可能有变化

## 建议行动
- 下一步做什么
```

### 深度调研（2 小时+）

```
1. 执行摘要（1 段，结论先行）
2. 关键发现（分主题，每条有来源）
3. 对创作的具体启示
4. 风险和反面证据
5. 结论和建议
6. 来源清单（标注时效）
```

## 质量门控

- [ ] 所有数据标注来源和时效
- [ ] 时效性数据不超过 6 个月
- [ ] 包含反面证据和风险
- [ ] 结论让决策更容易（有具体行动建议）
- [ ] 不做调研表演（不堆砌信息，有筛选）

## 与其他技能的关系

- `content-engine` — 调研结论 → 内容选题 → 多平台适配
- `article-writing` — 调研完成后，写作成文
- `market-research` → 选题验证 → `content-engine` → `article-writing`

## 禁止模式

- 只找支持自己观点的信息
- 用无来源数据（如"研究表明..."）
- 时效性内容用 2 年前的数据
- 调研完了没有结论和建议
