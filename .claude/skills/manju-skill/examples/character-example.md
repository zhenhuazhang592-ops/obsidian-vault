## 一、主角

### 陈默

**基础信息**

| 项目 | 内容 |
|------|------|
| 性别 | 男 |
| 年龄 | 28岁 |
| 职业/身份 | 表面：无业游民（上门女婿）/ 实际：默氏集团CEO |
| 外貌特征 | 普通面孔，平时穿着随意，但骨相硬朗，换上正装秒变"总裁感" |
| 标志性动作 | 低头，单手插兜，眼神从地上缓缓抬起（隐藏身份时的习惯性压制气场） |
| 常见服装 | 便宜夹克+牛仔裤（日常）/ 定制黑色西装（身份暴露时刻） |

**人物背景**

- **出身**：商业世家，父亲陈远是默氏集团创始人，8年前遭遇"意外"去世
- **过去经历**：为查清父亲死亡真相，主动消除一切痕迹，以普通人身份潜伏，入赘林家是为了接近某个关键线索
- **当前处境**：被岳母嫌弃，被妻子疏远，每天忍受各种羞辱，背地里运营3000亿集团
- **隐藏身份/秘密**：父亲并非意外死亡，幕后主谋是他的叔父陈国梁

**性格设定**

- **核心性格**：沉稳、隐忍、偶尔冷酷（暴露真实身份时）
- **优点**：商业嗅觉极强，对关心的人高度忠诚，越被逼越冷静
- **弱点**：不善言辞解释，导致误会积累；对林晓雨有情感盲点，容易被她影响
- **底线**：有人当面侮辱林晓雨时，必定出手，无论代价

**金手指详情**

- **能力名称**：商业帝国掌控力（"一个电话可以改变任何商业格局"）
- **触发条件**：主动选择出手，或林晓雨/重要人物受到威胁
- **具体效果**：在任何商业场景中，陈默的一个指令能让对方的合同废止、员工离职、资金断链
- **限制条件**：不能主动暴露身份（因为正在查父亲案子），每次出手都要伪装成"巧合"
- **成长路线**：EP01-EP10 暗中出手 → EP11-EP20 开始半公开 → EP21-EP30 全面爆发
- **视觉表现**：低调摸出手机，一个电话；或者推开会议室大门，全场起立

**情感关系**

- **对林晓雨**：真心爱，但因隐情无法解释，只能默默保护。被误会时也不辩解，因为解释需要暴露全局
- **对陈国梁**：表面尊重，内心深处是追查三年的仇恨，极度克制
- **对盟友**：待下属如同事，不摆架子，但出错决不姑息

**人物弧线**

```
第1集状态：卑微上门女婿，唯唯诺诺，忍气吞声
↓
第10集变化：第一次在商业场合以真实身份出现，开始不再完全掩藏
↓
第20集状态：已被林晓雨半接受，但身份危机升级，陷入最难抉择
↓
第30集结局：真相大白，真正意义上的"家"第一次建立
```

## 二、CP对象

### 林晓雨

**基础信息**

| 项目 | 内容 |
|------|------|
| 性别 | 女 |
| 年龄 | 27岁 |
| 职业/身份 | 林氏贸易公司财务总监 |
| 外貌特征 | 清秀，职业感强，眼神清澈但带着倔强 |
| 标志性特征 | 压力大时会咬下唇，情绪激动时说话很快 |

**人物定位**：主线CP，被母亲影响对陈默产生偏见，但骨子里公平善良，剧情推进中逐步看清陈默真面目

**对主角的态度变化**：
- 初见（回忆）：一见钟情后闪婚，相信他与众不同
- 中期（EP01-EP18）：受母亲影响，认为陈默真的是废物，开始提离婚
- 转折（EP15）：雨夜偶然见到陈默的另一面，重新怀疑自己的判断
- 结局：全力支持陈默，并为三年的误解道歉

**关键戏份**：EP05雨夜被李峰纠缠时陈默出现、EP15雨中争吵后的真情流露、EP28知道全部真相后的哭戏

## 三、主要反派

### 李峰（一级阻碍）

**基础信息**：男，30岁，林晓雨前男友，某中型企业CEO  
**与主角关系**：情敌 + 商业竞争对手  
**核心动机**：觉得林晓雨嫁给废物是委屈，想趁机夺回前女友；同时眼红默氏集团合作机会  
**手段特点**：利用社交场合当众羞辱陈默，在林晓雨面前贬低对方；在商业上试图挖默氏客户  
**弱点**：眼高手低，真实商业能力远不如包装，一旦陈默亲自出手立刻崩盘  
**结局**：EP22，公司资金链断裂，当众下跪求饶，被陈默大度放过

---

### 陈国梁（终极BOSS）

**基础信息**：男，55岁，表面：陈家族长、知名慈善家；实际：当年谋害陈远的主谋  
**隐藏时长**：EP24之前以"关心侄子"的慈祥长辈形象出现  
**核心动机**：当年嫉妒兄长陈远的商业天赋，联合竞争对手设局害死陈远，随后掌控部分家族产业  
**与主角的真实关系**：叔侄，但实为父仇人  
**最终对决**：EP27，陈默公开掌控集团，利用陈国梁自己埋下的法律漏洞将其绳之以法  
**结局**：EP28，被依法逮捕，商业版图被清算

## 四、重要配角

### 王秀梅（定位：搅局者→转变者）

**信息**：女，55岁，林晓雨母亲，全职家庭主妇  
**与主角关系**：岳母，主要施压者  
**主要戏份**：EP01-EP20 持续输出对陈默的嫌弃和羞辱，EP21 开始逐渐转变，EP27 知道陈默真实身份后态度180度转变（戏剧化反差爽点）  
**记忆点**：台词"你一个吃软饭的，有什么资格……"在EP27被录像回放时变成最大笑点

---

### 张浩（定位：主角心腹助手）

**信息**：男，32岁，默氏集团实际运营总监，陈默最信任的人  
**与主角关系**：十年老友，只有他知道陈默真实计划  
**主要戏份**：在陈默需要时出现，提供信息和商业执行支持，偶尔贡献幽默感  
**记忆点**：每次陈默出手，张浩的反应总是"老板，您真的不打算解释一下吗"
