# 写作风格规范

## 核心风格定义

**华哥剧本创作风格 = 视觉化 × 快节奏 × 情绪强冲击**

本风格标准提炼自SkyScript-100M数据集中6,660部热门短剧，代表当前短剧市场最受欢迎的内容表达方式。

---

## 镜头语言规范

### 场景描述格式
每个场景必须包含以下四要素：
```
【场景】地点 + 时间（选填）
【镜头】镜头类型（特写/中景/全景/移动镜头）
【画面】具体视觉描述（人物、道具、背景）
【BGM】情绪标签（浪漫/紧张/悲伤/爽快/史诗）
```

### 镜头类型使用规则

| 镜头类型 | 英文 | 使用场景 | 情绪目的 |
|---------|------|---------|---------|
| 特写 | Close-Up | 情绪爆发、关键道具、眼神交锋 | 强化情绪冲击 |
| 中景 | Medium Shot | 日常对话、行走、动作 | 信息传递 |
| 全景 | Wide Shot | 场景建立、重大时刻 | 视觉震撼 |
| 推镜头 | Push-In | 揭露秘密、身份揭晓 | 制造张力 |
| 拉镜头 | Pull-Back | 落幕、转场 | 情感沉淀 |
| 俯拍 | Top-Down | 主角弱势时 | 增强压迫感 |
| 仰拍 | Low Angle | 主角强势时 | 彰显气势 |

## 对白写作规则

### 基本原则
- **短**：单句不超过20字，整段不超过50字
- **快**：两人对话你来我往，不拖沓
- **冲**：对白要有张力，不说废话
- **爽**：反击台词要让观众拍案叫绝

### 对白格式
```
人物名（情绪标注）：对白内容
```

### 禁止用法
```
❌ "你知道吗，其实我一直觉得，我们之间的关系可能……"（太长太模糊）
✅ "你以为我不知道你做了什么？"（简短有力）

❌ "我心里百感交集，不知道该如何是好。"（心理描写）  
✅ "（攥紧拳头，声音颤抖）：我等这天，等了三年。"（外化动作）

❌ 大段独白超过3句话
✅ 独白最多2句，必须推动情节
```

### 经典爽文台词模板（参考使用）

**打脸时刻**：
> "你说得对，我是没有钱。但他们——"（主角一挥手，门外进来N个保镖/高管）

**身份揭露**：  
> "李总，这位就是……集团幕后真正的掌控者。"

**冷傲反击**：
> "这点钱，我一天的零花钱。"

**威胁警告**：
> "你有三秒钟，把刚才的话吞回去。"

## 节奏控制

### 单集节奏结构（三幕式）

```
开场钩子（约200字）：
  - 直接抛出冲突或悬念
  - 禁止缓慢建立背景（观众会划走）
  - 前30字必须让人想继续看

冲突升级（约900-1200字）：
  - 反派施压→主角应对→局势紧张
  - 至少包含2次小的情绪起伏
  - 中间安排1次主爽点或小爽点

结尾悬念（约300字）：
  - 必须有一个让人想看下一集的钩子
  - 类型：反转/揭露/危机/告白
  - 最后一句话要有力量
```

### 场景切换规则
- 单集场景切换 ≤ 3次
- 每次切换必须有明确的叙事目的
- 切换方式：硬切（直接跳）> 转场字幕 > 淡入淡出

## 人物情绪表达

### 情绪外化原则
**不写内心，只写外表**——让镜头来传达情绪

```
❌ "她感到无比委屈和愤怒。"（内心描写）
✅ "（紧抿嘴唇，眼眶泛红，手指掐进掌心）"（外化动作）

❌ "他掩饰住内心的震惊。"
✅ "（停顿0.5秒，眼神微闪，迅速恢复平静）"
```

### VAD情绪模型标注（选用）
关键场景可标注人物情绪值，辅助演员表演：
- **V（Valence）**：情绪积极性 1-10（1=极负面，10=极正面）
- **A（Arousal）**：情绪激烈度 1-10（1=平静，10=极度激动）  
- **D（Dominance）**：掌控感 1-10（1=完全被动，10=完全主导）

## 禁止清单（质量红线）

| 禁止内容 | 原因 |
|---------|------|
| 心理内白超过2句 | 短剧靠行动和对白推进，不靠内心戏 |
| 场景描述超过3行 | 读者/观众注意力有限 |
| 同一集出现超过3个新人物 | 信息量过载 |
| 金手指能力前后不一致 | 设定崩坏，观众流失 |
| 对白用"地、得、着、了"的书面表达 | 短剧对白要口语化 |
| 回忆插叙超过1次/集 | 打断节奏 |
| 连续2集无爽点 | 观众弃剧风险极高 |
| 说教式台词 | "你要学会宽恕……" 这类台词观众会跳过 |
