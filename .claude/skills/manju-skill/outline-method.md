# 大纲创作方法论

## 整体结构：三幕式布局

短剧大纲采用三幕式结构，总集数建议30集：

```
第一幕（1-8集）：建立世界 + 展示困境 + 金手指觉醒
第二幕（9-22集）：爽点升级 + 敌我对决 + 中间低谷
第三幕（23-30集）：终极对决 + 高光时刻 + 圆满收尾
```

---

## 核心三要素

### 1. 主角起点设定（憋屈值）

主角在第1集必须处于人生低谷，让观众感同身受：

**常见起点类型（按热度排序）**：
- 被家人抛弃/忽视的灰姑娘/赘婿
- 被公司/上司PUA的普通职员  
- 被渣男/渣女欺骗的善良主角
- 重生/穿越到悲剧结局前的知情者
- 被看不起的"废物"（实则隐藏强者）

**设定要求**：
- 憋屈必须具体可感，不能模糊
- 欺压者必须令人愤恨（言辞傲慢+行为过分）
- 观众必须在第1集内说出"这也太欺负人了"

### 2. 金手指设定（爽点来源）

金手指是主角反击的核心工具，需满足：

| 维度 | 要求 |
|------|------|
| 唯一性 | 只有主角拥有，他人无法复制 |
| 成长性 | 能力随剧情升级，给观众期待感 |
| 规则性 | 有明确限制，不能无敌到没意义 |
| 视觉性 | 使用时有明显的外在表现（镜头可拍） |

**常见金手指类型**：
- **信息类**：读心术、预知未来、看到他人数据面板
- **能力类**：古武传承、商业天才、医术奇才
- **身份类**：隐藏身份（总裁、王子、世界级大佬）
- **重生类**：知道所有结局，提前布局

### 3. 对立关系设计

每个主角需要对应的阻碍层级：

```
一级阻碍：日常刁难者（家人/同事/前任）—— 第1-5集
二级阻碍：中层反派（公司竞争者/情敌） —— 第6-15集  
终极BOSS：幕后黑手（家族/商业帝国/敌对势力）—— 第16-30集
```

## 爽点设计公式

### 基础爽点结构（每集必备）
```
憋屈积累（2-3幕）→ 爽点触发（1幕）→ 反派反应（1幕）
```

### 五种核心爽点类型

**1. 打脸型**（最常用）
> 反派当众羞辱主角 → 主角展示真实实力 → 反派当场社死

**2. 身份揭露型**（高潮必备）  
> 反派小看普通人主角 → 真实身份被揭露 → 全场震惊跪地

**3. 预知反击型**（重生/预知金手指）
> 反派设下陷阱 → 主角提前布局 → 反派自投罗网

**4. 贵人相助型**（配角联动）
> 主角被围攻 → 意外盟友出现 → 形势逆转

**5. 实力碾压型**（能力金手指）
> 反派自以为胜券在握 → 主角展示降维打击能力 → 反派瑟瑟发抖

## 情感线设计（选配）

**主线CP设计原则**：
- 男女主第1集必须有戏剧性相遇（最好是误解/冲突开场）
- 相互吸引但有明显阻碍（身份/误会/三角关系）
- 情感进度与事业线交织推进
- 高甜时刻分布：第5集、第15集、第28集

**情感弧线**：
```
相遇（冲突）→ 相处（暗生情愫）→ 误会（分离危机）→ 和解（携手对敌）→ 在一起
```

---

## 世界观与境界体系（功能型金手指必备）

如果故事包含修炼/能力体系，必须明确定义：

```
境界等级：（例）普通人→觉醒者→精英→大师→宗师→传说
等级标志：每个等级的能力表现差异
晋级条件：如何升级，需要什么代价
上限设定：主角当前最高能达到哪个层次
```

---

## 大纲写作要求

1. **开篇必须有钩子** - 第1集结尾必须有让人想看第2集的悬念
2. **每5集一个里程碑** - 标记重要转折点
3. **结局要有反转** - 最终BOSS不能一开始就是最终BOSS
4. **情感与事业并行** - 不能只有打脸没有情感，或只有情感没有爽点
5. **前因后果自洽** - 每个重要事件都要有铺垫
