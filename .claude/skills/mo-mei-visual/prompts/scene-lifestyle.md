# 生活场景代入 Prompt

## 模板

将实拍图中的[品类]作为主体，
合成到现代简约风格的厨房/餐桌场景中，
自然窗光，温暖氛围，
[品类]放置在画面中央偏下，
配套道具：[品类对应道具]，
整体氛围：让人想象"购买后的美好生活"。

漠玫品牌调性：克制·精致·有呼吸感，
自然光，浅景深，主体突出。

禁止：场景过于凌乱、emoji、文字水印、过度锐化、微商感滤镜。

## 品类道具适配表

| 品类 | 推荐道具 |
|------|---------|
| 牛油果 | 白色瓷盘，原木砧板、银色刀叉、亚麻布桌布、咖啡杯 |
| 榴莲 | 木质砧板、热带水果刀、芭蕉叶、白色餐盘 |
| 蓝莓 | 白色瓷碗、透明玻璃杯、酸奶、白色亚麻布、浆果勺 |
| 其他 | 白色餐盘、简洁餐具、亚麻布桌布 |

## 示例输出（蓝莓）

将实拍图中的蓝莓作为主体，
合成到现代简约风格的白色厨房场景中，
自然窗光，温暖氛围，
蓝莓放置在白色瓷碗中，画面中央偏下，
配套道具：透明玻璃杯、原味酸奶、白色亚麻布桌布，
整体氛围：让人想象"购买后的美好健康生活"。

漠玫品牌调性：克制·精致·有呼吸感，
自然光，浅景深，主体突出。

禁止：场景过于凌乱、emoji、文字水印、过度锐化、微商感滤镜。
