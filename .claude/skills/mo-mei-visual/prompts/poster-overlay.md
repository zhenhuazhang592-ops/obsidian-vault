# 海报合成 Prompt

> Step 4 调用 Fabric.js 叠加文字和色块时使用。
> 指导如何在生成的场景图上叠加品牌元素。

---

## 输入说明

**调用方式：**
```
读取 scripts/poster-compose.ts + prompts/poster-overlay.md
+ 已生成的场景底图路径
+ 产品信息（品名/价格/品牌水印）
```

**输入：**
```
底图路径：output/<slug>/scene-<type>.png
品名：[品名]
价格标签：[价格区间]
品牌水印：漠玫生鲜
```

---

## 横版海报 Prompt（1920 × 800 px）

> 用途：公众号 Banner、官网大图

### 底图要求

- 尺寸：1920 × 800 px
- 比例：2.4:1
- 底图安全区：左右各留 192px（10%），上下各留 80px（10%）
- 主体水果位于画面中央 ± 15%
- 背景为生成好的场景图（minimal/origin/lifestyle/daoju 任意）

### 叠加结构

```
┌──────────────────────────────────────────────────────────────────────┐
│                                                                      │
│                         [底图：场景图]                                │
│                                                                      │
│                                                                      │
├──────────────────────────────────────────────────────────────────────┤
│  ██████████████████████ 底部色块（漠玫绿 #2E7D32） 高度：180px       │
│                                                                      │
│  品名（大字）          副标题（中字）              品牌水印（右对齐） │
│  产地标注（小字）       价格标签（暖金底 #D4A853）  漠玫生鲜           │
└──────────────────────────────────────────────────────────────────────┘
```

### 文字层级规格

| 元素 | 字体 | 字重 | 字号 | 颜色 | 位置 |
|------|------|------|------|------|------|
| 品名 | 思源宋体 Bold | Bold | 72px | #FFFFFF | 底部色块左侧 |
| 副标题 | 思源黑体 | Regular | 28px | #FDFBF7 | 品名右下方 |
| 产地标注 | 思源黑体 | Regular | 20px | #FDFBF7 80%透明度 | 副标题下方 |
| 价格标签 | 思源黑体 | Bold | 36px | #1A1A1A（暖金底） | 底部色块中部偏右 |
| 品牌水印 | 思源黑体 | Regular | 18px | #FDFBF7 | 底部色块最右侧 |

### 底部色块规格

```
颜色：#2E7D32（漠玫绿）
高度：180px
宽度：100%（全出血）
圆角：上方 0px，下方 0px（底部对齐画面）
透明度：100%（实色）
```

### 价格标签色块规格（暖金价格标签）

```
形状：圆角矩形
圆角：8px
内边距：12px 24px
颜色：#D4A853（暖金）
字体：思源黑体 Bold，36px，#1A1A1A
```

### 副标题生成规则

根据品类和卖点生成，格式：`[口感/规格描述] · [产地简称]`
- 牛油果：`"绵密奶香 · 墨西哥进口"`
- 榴莲：`"金枕榴莲 · 泰国直采"`
- 蓝莓：`"花青素满满 · 智利进口"`

## 竖版海报 Prompt（1080 × 1920 px）

> 用途：朋友圈封面、抖音竖版视频封面

### 底图要求

- 尺寸：1080 × 1920 px
- 比例：9:16
- 主体水果位于画面上半部分（高度 30%-70% 区域）
- 顶部安全区：留 108px（10%）

### 叠加结构

```
┌────────────────────────┐
│  [顶部渐变遮罩]         │  高度：300px
│  从透明渐变到 #2E7D32   │  保留产地/品牌信息
├────────────────────────┤
│                        │
│   [底图：场景图]        │  全出血，延伸到底部
│   主体水果在 30-70% 高度 │
│                        │
├────────────────────────┤
│  [底部半透明遮罩]        │  高度：500px
│  从透明渐变到 80% #1A1A1A │
├────────────────────────┤
│                        │
│  品名（大字，居中）       │  思源宋体 Bold，80px，#FFFFFF
│  副标题（中字，居中）     │  思源黑体，32px，#FDFBF7
│                        │
│  [价格标签]             │  暖金底圆角矩形，居中
│                        │
│  品牌水印（底部居中）     │  思源黑体，20px，#FDFBF7 70%
└────────────────────────┘
```

### 顶部渐变遮罩

```
类型：线性渐变（从上到下）
起点：rgba(0, 0, 0, 0)
终点：rgba(46, 125, 50, 0.85)  ← #2E7D32
高度：300px
宽度：100%
```

### 底部半透明遮罩

```
类型：线性渐变（从上到下）
起点：rgba(26, 26, 26, 0)
终点：rgba(26, 26, 26, 0.8)
高度：500px
宽度：100%
```

### 文字层级规格（竖版）

| 元素 | 字体 | 字重 | 字号 | 颜色 | 位置 |
|------|------|------|------|------|------|
| 品名 | 思源宋体 Bold | Bold | 80px | #FFFFFF | 底部区域居中 |
| 副标题 | 思源黑体 | Regular | 32px | #FDFBF7 | 品名下方居中 |
| 价格标签 | 思源黑体 | Bold | 42px | #1A1A1A（暖金底） | 副标题下方居中 |
| 品牌水印 | 思源黑体 | Regular | 20px | #FDFBF7 70% | 底部最下方居中 |

### 价格标签规格（竖版）

```
形状：圆角矩形
圆角：10px
内边距：16px 40px
颜色：#D4A853（暖金）
字体：思源黑体 Bold，42px，#1A1A1A
```

## 品牌色彩规范（必须严格遵守）

| 色名 | Hex | 使用场景 |
|------|-----|---------|
| 漠玫绿 | `#2E7D32` | 底部色块、顶部渐变遮罩、CTA 元素 |
| 牛油果绿 | `#8BC34A` | 装饰元素（仅极少量使用） |
| 米白 | `#FDFBF7` | 文字主色（深色背景上）、整体页面背景 |
| 暖金 | `#D4A853` | 价格标签背景、特价提示 |
| 墨色 | `#1A1A1A` | 正文标题、价格标签文字（非暖金底时） |
| 灰调 | `#6B6B6B` | 副标题、次要说明文字 |

### 禁止色

```
荧光绿
薄荷绿
纯黑 #000000
纯白 #FFFFFF（用于文字时）
```

---

## 字体规格

| 字体 | 字重 | 使用场景 | 字体文件 |
|------|------|---------|---------|
| 思源宋体 | Bold | 品名主标题 | NotoSerifSC-Bold |
| 思源黑体 | Regular | 副标题、说明文字 | NotoSansSC-Regular |
| 思源黑体 | Bold | 价格标签、功能文字 | NotoSansSC-Bold |

### 字体使用约束

- 禁止：华文行楷、方正粗宋、圆润儿童字体
- 文字与背景的对比度 ≥ 4.5:1（WCAG AA 标准）
- 字号下限：20px（低于此值不可用于重要信息）

## Fabric.js 叠加参数参考

```typescript
// 横版海报叠加配置
const posterH = {
  width: 1920,
  height: 800,
  bottomBar: {
    color: '#2E7D32',
    height: 180,
  },
  textLayer: [
    {
      text: '[品名]',
      fontFamily: 'NotoSerifSC-Bold',
      fontSize: 72,
      fill: '#FFFFFF',
      left: 60,
      top: 800 - 180 + 40,
    },
    {
      text: '[副标题]',
      fontFamily: 'NotoSansSC-Regular',
      fontSize: 28,
      fill: '#FDFBF7',
      left: 60,
      top: 800 - 180 + 40 + 80,
    },
  ],
  priceTag: {
    text: '[价格区间]',
    bgColor: '#D4A853',
    textColor: '#1A1A1A',
    fontFamily: 'NotoSansSC-Bold',
    fontSize: 36,
    rx: 8,
    padding: '12px 24px',
  },
  brandWatermark: {
    text: '漠玫生鲜',
    fontFamily: 'NotoSansSC-Regular',
    fontSize: 18,
    fill: '#FDFBF7',
    right: 60,
    bottom: 30,
  },
};

// 竖版海报叠加配置
const posterV = {
  width: 1080,
  height: 1920,
  topGradient: {
    height: 300,
    colorStops: [
      { offset: 0, color: 'rgba(0,0,0,0)' },
      { offset: 1, color: 'rgba(46,125,50,0.85)' },
    ],
  },
  bottomGradient: {
    height: 500,
    colorStops: [
      { offset: 0, color: 'rgba(26,26,26,0)' },
      { offset: 1, color: 'rgba(26,26,26,0.8)' },
    ],
  },
  textLayer: [
    {
      text: '[品名]',
      fontFamily: 'NotoSerifSC-Bold',
      fontSize: 80,
      fill: '#FFFFFF',
      originX: 'center',
      left: 540,
      top: 1920 - 700,
    },
    {
      text: '[副标题]',
      fontFamily: 'NotoSansSC-Regular',
      fontSize: 32,
      fill: '#FDFBF7',
      originX: 'center',
      left: 540,
      top: 1920 - 700 + 100,
    },
  ],
  priceTag: {
    text: '[价格区间]',
    bgColor: '#D4A853',
    textColor: '#1A1A1A',
    fontFamily: 'NotoSansSC-Bold',
    fontSize: 42,
    rx: 10,
    padding: '16px 40px',
    originX: 'center',
    left: 540,
    top: 1920 - 700 + 180,
  },
  brandWatermark: {
    text: '漠玫生鲜',
    fontFamily: 'NotoSansSC-Regular',
    fontSize: 20,
    fill: 'rgba(253,251,247,0.7)',
    originX: 'center',
    left: 540,
    bottom: 80,
  },
};
```

## 质量检查清单（Fabric.js 合成后）

- [ ] 横版底部色块高度 = 180px，颜色 = #2E7D32
- [ ] 竖版顶部渐变遮罩高度 = 300px，终点颜色 rgba(46,125,50,0.85)
- [ ] 价格标签底色 = #D4A853，文字 = #1A1A1A
- [ ] 品名使用思源宋体 Bold
- [ ] 副标题和说明文字使用思源黑体
- [ ] 无纯黑 #000000 或纯白 #FFFFFF 文字
- [ ] 文字对比度 ≥ 4.5:1
- [ ] 横版品名字号 = 72px，竖版品名字号 = 80px
- [ ] 价格标签横版字号 = 36px，竖版字号 = 42px
- [ ] 底部安全区留白 ≥ 80px（横版）或 ≥ 100px（竖版）
