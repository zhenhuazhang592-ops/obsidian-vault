# /learn — 提取创作模式

## 触发

在任意会话节点运行，当解决了非平凡的问题时。

## 什么值得提取

1. **节奏调整**
   - 什么节奏问题出现了？
   - 怎么调整的？
   - 这个调整可复用吗？

2. **角色处理**
   - 角色行为是否符合预期？
   - 用户纠正了什么？
   - 发现了什么新模式？

3. **结构问题**
   - 什么结构问题被解决了？
   - 用的是什么手法？
   - 适用其他集/项目吗？

4. **叙事发现**
   - 什么视觉叙事手法有效？
   - 什么对话节奏被验证？
   - 观众情感线怎么处理？

## 输出格式

在当前项目本能目录下创建文件（如 `.claude/instincts/格子间女人/角色弧线/my-pattern.yaml`）：

```yaml
---
id: <唯一ID：中文描述-YYYYMMDD>
trigger: "当 [触发条件] 时"
confidence: 0.5
domain: 角色弧线  # 剧本结构 / 角色弧线 / 对话节奏 / 视觉叙事 / 观众情感 / 技术实现
source: session-observation
scope: 格子间女人
---

# <中文标题>

## 行为
[具体做什么，不要空洞原则]

## 证据
- 观察时间：YYYY-MM-DD
- 观察来源：[具体场景/对话/调整]
- 用户确认：[有/无]

## 适用边界
- 适用于：[具体场景]
- 不适用于：[边界条件]
```

## 执行步骤

1. 回顾当前会话，找出最有价值的模式
2. 确认该模式未在本能库中（避免重复）
3. 草拟本能文件
4. 向用户确认后保存
5. 提示是否运行 `/evolve`

## 注意事项

- **不要提取**：打字错误、简单修正、一次性问题
- **要提取**：反复出现的模式、经过验证的调整、值得跨集复用的手法
- **保持原子**：一个本能 = 一个 trigger，一个 action
- **中文优先**：ID 和 trigger 用中文，保持 vault 一致性

## 自动触发逻辑

除了手动运行 `/learn`，以下情况自动触发本能提取：

1. **复杂任务完成** — 5+ 工具调用成功执行
2. **用户纠正** — 用户明确纠正了 AI 的行为方式
3. **错误克服** — 通过非平凡工作流解决了错误

自动触发时，Claude 会：
1. 分析当前会话中的关键模式
2. 草拟本能文件
3. 在回复末尾提示："检测到可提取的模式，是否保存？"
