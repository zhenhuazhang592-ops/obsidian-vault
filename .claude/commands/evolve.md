# /evolve — 本能进化

## 双模式

### 手动模式
```
/evolve
```

### 自动模式（无需命令）
- 会话结束时自动检查
- 置信度 >= 0.9 的本能 → 自动建议升级为 Skill
- 多个相同 domain 本能（>=2，confidence >= 0.7）→ 自动聚类建议

## 进化条件

| 条件 | 触发 |
|------|------|
| 单一本能，confidence >= 0.9 | 直接建议升级 |
| 同一 domain 多个本能，>= 0.7 | 聚类生成统一 Skill |

## 输出示例

```
检测到 1 个本能达到进化阈值：
- [本能名] (confidence: 0.9)

是否升级为 Skill？ (y/n)

检测到 1 个可聚类的本能组：
- domain: 角色弧线
- 本能: [主角觉醒时机, 对手戏张力节奏]

是否聚类生成统一 Skill？ (y/n)
```
