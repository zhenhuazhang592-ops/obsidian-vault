# /evolve — 本能进化

## 触发

当本能库积累了 5+ 个本能后运行，或当需要整理本能时。

## 执行步骤

### Step 1：扫描本能库

扫描 `.claude/instincts/global/` 和 `.claude/instincts/<当前项目>/`

统计：
- 全局本能数 / 项目本能数
- 按 domain 分组
- 按 scope 分组
- 高置信度（≥0.7）本能列表

### Step 2：识别聚类

寻找具有相同或相似 trigger 的本能：

```
识别模式：
- 本能 A trigger: "当设计角色成长时" + 本能 B trigger: "当写觉醒戏时"
  → 聚类为：角色成长弧线 族

- 本能 C trigger: "当节奏拖沓时" + 本能 D trigger: "当对话太长时"
  → 聚类为：节奏控制 族
```

### Step 3：识别进化候选

| 条件 | 进化为 |
|------|--------|
| 2+ 本能有相同 domain，且 trigger 互补 | **Skill 更新** |
| 多个本能描述一个完整工作流 | **Command 候选** |
| 本能描述复杂多步过程（≥3 步） | **Subagent 候选** |
| 同一本能出现在 2+ 项目，置信度 ≥ 0.8 | **Promotion 候选**（项目 → 全局）|

### Step 4：输出分析报告

```
============================================================
EVOLVE 分析报告 · 格子间女人
============================================================

项目本能：12 个
全局本能：5 个
高置信度（≥0.7）：6 个

## SKILL 候选
1. 角色弧线 skill（更新）
   来源本能：
   - 主角觉醒时机（0.8，格子间女人）
   - 对手戏张力（0.7，格子间女人）
   建议：合并入 manju-skill/角色弧线/

## COMMAND 候选
1. /检查节奏
   - 拖沓检测本能（0.9）
   - 对话长度本能（0.7）

## PROMOTION 候选（项目 → 全局）
- 潜台词原则（0.85）
  出现在：格子间女人

## 已进化（.claude/instincts/evolved/）
（暂无）
```

### Step 5：执行进化（--generate 时）

```
.evolved/skills/<新或更新>/  # 写入 skill 文件
.evolved/commands/           # 写入 command 文件
```

## 生成 Skill 文件格式

```yaml
---
name: <新 skill 名称>
description: <一行描述>
evolved_from:
  - instinct-1
  - instinct-2
  confidence_avg: 0.75
---

# <标题>

## 核心原则
[从本能的"行为"字段合并]

## 使用时机
[合并本能的 trigger]

## 操作指南
[具体步骤]

## 边界条件
[合并本能的适用/不适用]
```

## 注意事项

- 进化前必须向用户确认
- 原本能文件**不移除**，保留作 evidence
- 新生成的 skill 初始 confidence = 来源本能平均值
- 如果 skill 存在，只建议更新，不强制覆盖
