# 上下文隔离原则

> 来源：learn-claude-code s04 Subagent
> 目的：探索性/批量任务不污染主上下文

## 规则

1. **探索性任务用子代理处理，结果摘要进主上下文**
   - 适用场景：研究工具链、研究风格参考、批量文件分析、长文本总结
   - 子代理中间过程不进入主对话
   - 工具：使用 Agent 工具 + isolation: "worktree"

2. **子代理设计原则**
   - 独立上下文（全新 messages[]）
   - 安全限制：最大轮次 30
   - 无 Task 工具（禁止递归子代理）

3. **以下情况直接在主上下文处理**
   - 单文件编辑/创建
   - 用户直接交互的任务
   - 决策性任务（需要主上下文记忆）

## 违反处理

发现主上下文出现大量中间探索结果 → 主动总结压缩，保留结论。
