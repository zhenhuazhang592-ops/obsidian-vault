# 连续学习规则 · Instinct 系统

> 来源：ECC continuous-learning-v2，适配漫剧创作
> 核心原则：不塞满 system prompt，让模型"遇到时"才学到

---

## 什么是本能（Instinct）

一个**原子级**学到的小行为，附有置信度：

```yaml
---
id: 三幕结构-主角觉醒
trigger: "当设计角色成长弧线时"
confidence: 0.8
domain: 角色弧线
source: session-observation
scope: 格子间女人
project_id: gezijianjian
---

# 三幕结构 · 主角觉醒

## 行为
主角觉醒点应放在第二幕中段（约全文 50-60% 处），而非结尾。

## 证据
- 从 EP03 观察到的节奏模式
- 用户确认"觉醒太晚会拖节奏"
```

**属性：**
- **Atomic** — 一个 trigger，一个 action
- **Confidence** — 0.3=试探 / 0.7=强烈 / 0.9=核心行为
- **Domain** — 剧本结构 / 角色弧线 / 对话节奏 / 视觉叙事 / 观众情感 / 技术实现
- **Scope** — `global`（跨项目）或 `格子间女人`（项目级）
- **Evidence-backed** — 记录观察来源

## 目录结构

```
.claude/
└── instincts/
    ├── registry.json              # 本能注册表（ID → metadata）
    ├── global/                    # 全局本能（跨项目通用）
    │   ├── 角色弧线.yaml
    │   ├── 对话节奏.yaml
    │   └── 视觉叙事.yaml
    ├── 格子间女人/              # 项目级本能
    │   ├── 角色弧线.yaml
    │   ├── 分镜节奏.yaml
    │   └── 场景转换.yaml
    └── evolved/                  # 进化后的 skills
        ├── skills/
        └── instincts/
```

**Scope 判定规则：**

| 模式类型 | Scope |
|---------|-------|
| 跨作品的创作规律 | **global** |
| 单个项目的节奏偏好 | **项目名** |
| 角色特定行为模式 | **项目名** |
| 通用工作流习惯 | **global** |

## 工作流

```
创作者遇到模式
     ↓
运行 /learn
     ↓
提取为 Instinct（0.3-0.9 置信度）
     ↓
存入 instincts/（project 或 global）
     ↓
运行 /evolve
     ↓
聚类 → 生成新 Skill / 更新现有 Skill
```

---

## 置信度演化

| 分数 | 含义 | 行为 |
|------|------|------|
| 0.3 | 试探 | 建议但不强制 |
| 0.5 | 中等 | 相关时应用 |
| 0.7 | 强烈 | 自动批准应用 |
| 0.9 | 核心 | 视为第一性原则 |

**升置信度：** 模式被反复观察到 + 用户未纠正
**降置信度：** 用户明确纠正了建议的行为

---

## 进化规则（Instinct → Skill）

| 条件 | 进化为 |
|------|--------|
| 多个本能描述用户主动发起的行动 | **Command**（/xxx） |
| 本能描述应自动触发的行为 | **Skill** |
| 本能描述复杂多步流程，需要隔离执行 | **Subagent** |

---

## 与 Skill Loading 的关系

- **Instinct** = 模型"观察到"的行为模式（轻量，即时）
- **Skill** = 知识包（完整，可复用）
- Instinct 进化成 Skill 后，原本能文件保留作 evidence
