## 二、核心学习要点

### 2.1 Toonflow - 多Agent协作系统

**三Agent协作模式**：
```
AI1(故事师) → AI2(大纲师) → director(导演)
   ↓              ↓              ↓
 分析小说      生成大纲       审核质量(75分及格)
```

**八大编剧法则**：
| 法则 | 说明 |
|------|------|
| 剃刀法则 | 删除冗余，3章压缩为1集 |
| 视觉外化 | 禁止心理描写，改用动作/表情 |
| 情绪过山车 | 压抑→爆发→打脸→获益 |
| 黄金节奏 | 前3秒冲突，15秒矛盾，45秒高潮 |
| 身份势能 | 阶级落差、身份反转 |
| 群像压迫 | 多对一格局 |
| 道具图腾化 | 道具承载情感 |
| 台词利刃化 | 金句≤15字 |

### 2.2 好剧生成器 - 完整工作流

**核心流程**：
```
创建项目 → 上传剧本 → AI提取角色 → AI生成角色图
       → AI提取场景 → AI生成场景图 → AI生成分镜
       → AI生成视频 → FFmpeg合并 → 最终视频
```

**关键设计**：
- 多厂商AI适配器（OpenAI/Gemini/火山引擎/MiniMax）
- 异步任务处理（后台执行，前端轮询）
- FFmpeg服务端视频合并

### 2.3 魔因漫创 - 6层身份锚点

**角色一致性6层锚点**：
```
┌─────────────────────────────────────────────────┐
│  第6层: 视角锚点     ── 俯视45度、特写角度    │
│  第5层: 动作锚点     ── 招牌动作、姿态       │
│  第4层: 表情锚点     ── 微表情、情绪变化      │
│  第3层: 服装锚点     ── 服装配饰、纹理       │
│  第2层: 外貌锚点     ── 脸型、体型、发色     │
│  第1层: 身份锚点     ── 名字、性格、背景     │
└─────────────────────────────────────────────────┘
```

**提示词三层融合**：
1. **动作描述** - 核心动作序列
2. **镜头语言** - 景别/角度/运动/转场
3. **对白唇形** - 口型同步要求
