# 角色一致性最佳实践

> 来自魔因漫创的 6 层身份锚点系统

## 核心设计

角色一致性是 AI 漫剧创作的核心难点。魔因漫创通过 **6 层身份锚点** 确保角色在不同分镜中保持一致。

## 6 层锚点详解

```
┌─────────────────────────────────────────────────────────────┐
│                    角色身份锚点金字塔                         │
├─────────────────────────────────────────────────────────────┤
│  第6层: 视角锚点     ── 摄影角度、光线一致性               │
│  第5层: 动作锚点     ── 招牌动作、习惯姿势                │
│  第4层: 表情锚点     ── 习惯表情、微表情                  │
│  第3层: 服装锚点     ── 服装造型、装饰细节                │
│  第2层: 外貌锚点     ── 面部特征、身材                    │
│  第1层: 身份锚点     ── 姓名、身份、年龄                  │
└─────────────────────────────────────────────────────────────┘
```

## 数据结构

```typescript
interface CharacterBible {
  // 第1层：身份
  identity: string;           // "豪门总裁，30岁"
  role: 'protagonist' | 'antagonist' | 'supporting';

  // 第2层：外貌
  appearance: string;       // "剑眉星目，身高187cm"

  // 第3层：服装
  costume: string;         // "黑色高定西装"

  // 第4层：表情
  expression: string;      // "冷笑时单挑眉"

  // 第5层：动作
  action: string;          // "手指转动婚戒"

  // 第6层：视角
  viewpoint: string;       // "永远仰视45度"
}
```

## 提示词构建

### 基础角色描述

```
Name: [角色名]
Identity: [身份]
Role: [主角/配角/反派]
```

### 完整锚点描述

```
[角色名]
- 身份: [身份描述]
- 外貌: [外貌特征描述]
- 服装: [服装描述]
- 表情: [习惯表情]
- 动作: [招牌动作]
- 视角: [摄影角度偏好]
```

### 实际示例

```
陈昊 (主角)
- 身份: 豪门总裁，30岁，陈氏集团继承人
- 外貌: 剑眉星目，身高187cm，轮廓分明
- 服装: 黑色高定西装，袖扣为家族徽章
- 表情: 冷笑时单挑眉，愤怒时眯眼睛
- 动作: 手指转动婚戒，整理袖扣
- 视角: 仰视45度，气场压迫感
```

## 生成时的使用

### 角色参考图绑定

```typescript
// 每个角色可绑定多个参考图
interface Character {
  id: string;
  name: string;
  referenceImages: string[];  // 参考图 URLs
  seedValue?: string;         // 种子值
  bible: CharacterBible;      // 锚点信息
}
```

### 提示词融合

```typescript
function buildCharacterPrompt(shot: Shot, character: Character): string {
  return `
    ${character.name}, ${character.bible.appearance}
    ${character.bible.costume}
    ${character.bible.expression}
    ${shot.shotType}, ${shot.angle}
  `.join(', ');
}
```

## 一致性校验

### 自动检测

```typescript
function validateConsistency(
  previousShot: Shot,
  currentShot: Shot,
  character: Character
): boolean {
  // 检查外貌一致性
  const appearanceMatch = checkTextSimilarity(
    previousShot.prompt,
    currentShot.prompt,
    character.bible.appearance
  );

  // 检查服装一致性
  const costumeMatch = checkTextSimilarity(
    previousShot.prompt,
    currentShot.prompt,
    character.bible.costume
  );

  return appearanceMatch > 0.8 && costumeMatch > 0.8;
}
```

## 学习要点总结

1. **6 层锚点设计**: 从身份到视角，层层递进
2. **结构化存储**: CharacterBible 数据结构
3. **多参考图**: 绑定 3+ 张参考图
4. **种子值**: 使用 seed 值保持一致性
5. **自动校验**: 前后分镜一致性检测
