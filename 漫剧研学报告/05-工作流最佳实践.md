## 任务队列系统

### 魔因漫创 - 多 Key 轮询

```typescript
class TaskQueue {
  private keys: string[];

  async submit(task: GenerationTask): Promise<TaskResult> {
    // 1. 轮询选择 Key
    const key = this.roundRobin();

    // 2. 提交任务
    const result = await this.execute(task, key);

    // 3. 失败重试
    if (result.status === 'failed' && task.retries < 3) {
      return this.submit({ ...task, retries: task.retries + 1 });
    }

    return result;
  }

  private roundRobin(): string {
    const index = this.currentIndex % this.keys.length;
    this.currentIndex++;
    return this.keys[index];
  }
}
```

async function batchGenerate(tasks: Task[]): Promise<Result[]> {
  const queue = new PQueue({ concurrency: CONCURRENCY_LIMIT });

  const promises = tasks.map(task =>

### 自动重试

```typescript
async function withRetry<T>(
  fn: () => Promise<T>,
  options = { maxRetries: 3, delay: 1000 }
): Promise<T> {
  for (let i = 0; i < options.maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (i === options.maxRetries - 1) throw error;
      await delay(options.delay * Math.pow(2, i));  // 指数退避
    }
  }
}
```

## 学习要点总结

1. **板块清晰**: 剧本→角色→场景→导演→S级
2. **自动流转**: 每步产出自动流入下一步
3. **AI 校准**: 二次深化提升质量
4. **批量生成**: 并发+队列管理
5. **多 Key 负载**: 轮询+重试
6. **参数校验**: 遵守平台限制
