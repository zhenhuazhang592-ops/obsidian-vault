# 视频生成提示词最佳实践

> 来自魔因漫创的三层融合 + Awesome Seedance 风格模板

## 三层融合核心架构

魔因漫创的 S 级板块采用 **三层融合** 技术，自动将分镜信息合成为高质量提示词：

```
┌─────────────────────────────────────────────────────────────┐
│                     三层融合架构                              │
├─────────────────────────────────────────────────────────────┤
│  第一层: 动作描述                                           │
│  ─────────────────────────────────────────────────────     │
│  主体动作、关键动作、运动轨迹                                │
│  例: "男主抓住女主手腕，眼中含泪"                           │
├─────────────────────────────────────────────────────────────┤
│  第二层: 镜头语言                                          │
│  ─────────────────────────────────────────────────────     │
│  景别 + 角度 + 运动 + 构图                                │
│  例: "中景, 平视, 轻微推近, 浅景深"                       │
├─────────────────────────────────────────────────────────────┤
│  第三层: 对白唇形同步                                       │
│  ─────────────────────────────────────────────────────     │
│  对话内容 + 口型标注                                        │
│  例: "[Lip-sync] '放开我'"                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
                   最终融合提示词
```

## 三层融合实现

```typescript
function buildThreeLayerPrompt(shot: Shot): string {
  // 第一层：动作描述
  const action = shot.action;

  // 第二层：镜头语言
  const cinematography = [
    shot.shotType,     // ECU/CU/MS/WS/EWS
    shot.angle,        // high/low/eye
    shot.movement,     // fixed/push/pull/pan
    shot.composition   // rule of thirds/center
  ].join(', ');

  // 第三层：对白唇形
  const dialogue = shot.dialogue
    ? `[Lip-sync] "${shot.dialogue}"`
    : '';

  // 融合
  return [
    action,
    cinematography,
    dialogue
  ].filter(Boolean).join('\n');
}
```

## 学习要点总结

1. **三层融合**: 动作 + 镜头 + 对白唇形
2. **时间轴**: `[00:00-00:05]` 格式
3. **镜头语言**: 景别 + 角度 + 运动
4. **口型同步**: `[Lip-sync]` 标注
5. **情绪标签**: 快速定位风格
6. **参数校验**: 遵守平台限制
