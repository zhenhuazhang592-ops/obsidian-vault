## 核心学习要点

### 1. 角色一致性

```
6层身份锚点 = 身份 + 外貌 + 服装 + 表情 + 动作 + 视角
```

### 2. 分镜提示词

```
[时间轴] Shot N: [景别]
[场景] + [动作] + [Dialogue lip-sync]
```

### 3. 视频提示词

```
三层融合 = 动作 + 镜头语言 + 对白唇形同步
```

### 4. 工作流

```
剧本 → 角色 → 场景 → 分镜 → 视频 → 合并
```

### 5. 技术栈

| 层级 | 最佳方案 |
|-----|----------|
| 桌面 | Electron + React + Vite |
| 状态 | Zustand |
| 后端 | Go + Gin |
| AI | 适配器模式 |

## 适合我们牛油果漫剧项目的建议

### 优先级排序

1. **高优先级**
   - [ ] 角色一致性系统（6层锚点）
   - [ ] 分镜提示词模板（专业电影级）
   - [ ] 视频提示词（三层融合）

2. **中优先级**
   - [ ] AI 二次校准机制
   - [ ] 工作流自动化
   - [ ] 任务队列系统

3. **低优先级**
   - [ ] 多 Key 轮询
   - [ ] 本地存储方案
   - [ ] 技术架构升级
