## 桌面应用架构

### 最佳方案：Electron + React + Vite

魔因漫创采用 Electron 30 + React 18 + Vite 5 + Zustand 5

│  └──────────┘ └──────────┘ └──────────┘                 │

├─────────────────────────────────────────────────────────────┤
│  Renderer Process (React)                                   │
│  ┌──────────────────────────────────────────────────┐     │
│  │  UI Layer (Radix UI + Tailwind CSS)              │     │

│  │  State Layer (Zustand)                           │     │
│  ├──────────────────────────────────────────────────┤     │

### 技术选型对比

| 方案 | 优点 | 缺点 | 适用场景 |
|-----|------|------|----------|
| Electron + React | 成熟、跨平台、生态丰富 | 体积大 | 生产级应用 |

### 分层架构原则

```
Handler: 处理 HTTP 请求，调用 Service
  ↓
Service: 业务逻辑，编排多个 Model
  ↓
Model: 数据结构和数据库操作
  ↓
Infrastructure: 数据库、存储、外部服务
```

import { create } from 'zustand';

interface ScriptState {
  script: Script | null;
  scenes: Scene[];
  characters: Character[];

  // Actions
  setScript: (script: Script) => void;
  parseScript: (text: string) => Promise<void>;
  calibrateScenes: () => Promise<void>;

export const useScriptStore = create<ScriptState>((set, get) => ({
  script: null,
  scenes: [],
  characters: [],

  setScript: (script) => set({ script }),

  parseScript: async (text) => {
    const parsed = await scriptParser.parse(text);
    set({
      script: parsed,
      scenes: parsed.scenes,
      characters: parsed.characters
    });
  },

  calibrateScenes: async () => {
    const { scenes } = get();
    const calibrated = await aiService.calibrateScenes(scenes);
    set({ scenes: calibrated });

## 本地存储方案

### 最佳方案：IndexedDB / OPFS

```typescript
// 存储服务
class StorageService {
  private db: IDBDatabase;

  async init() {
    this.db = await openDB('moyin-creator', 1, {
      upgrade(db) {
        // 项目表
        if (!db.objectStoreNames.contains('projects')) {
          db.createObjectStore('projects', { keyPath: 'id' });
        }
        // 媒体表
        if (!db.objectStoreNames.contains('media')) {
          db.createObjectStore('media', { keyPath: 'id' });
        }
      }
    });
  }

  async saveProject(project: Project) {
    return this.db.put('projects', project);
  }

  async getProject(id: string): Promise<Project> {
    return this.db.get('projects', id);
  }
}
```

### 大文件存储 (OPFS)

```typescript
// 大文件用 OPFS
async function saveLargeFile(file: File): Promise<string> {
  const root = await navigator.storage.getDirectory();
  const handle = await root.getFileHandle(file.name, { create: true });
  const writable = await handle.createWritable();
  await writable.write(file);
  return handle.name;
}
```

## AI 任务队列

### 最佳方案：轮询 + 重试 + 并发控制

```typescript
classAITaskQueue {
  private queue: PQueue;
  private keys: string[];

  constructor() {
    this.queue = new PQueue({ concurrency: 5 });
  }

  async submit(task: Task): Promise<Result> {
    return this.queue.add(async () => {
      const key = this.selectKey();

      try {
        return await this.executeWithKey(task, key);
      } catch (error) {
        if (this.isRetryable(error)) {
          return this.submit(task); // 重试
        }
        throw error;
      }
    });
  }

  private selectKey(): string {
    // 负载均衡：选择最少使用的 Key
    const usage = this.getKeyUsage();
    return usage.sort((a, b) => a.count - b.count)[0].key;
  }
}
```
