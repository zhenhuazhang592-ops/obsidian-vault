### 1.3 6种死亡表情锚点

| 死亡类型 | 视觉描述 |
|----------|----------|
| 震惊死 | 眼睛凸出成大圆点、嘴巴O型占画面1/3、果柄竖起 |
| 痛苦死 | 眼睛眯成两条缝、嘴角下撇、冷汗三滴、果皮渗出 |
| 无语死 | 眼睛变成蚊香旋转、嘴巴微张、灵魂出窍 |
| 安详死 | 眼睛紧闭、嘴角微微上扬、果皮变淡 |
| 冤枉死 | 眼泪汪汪、嘴巴委屈下撇、果皮变深绿 |
| 蒙圈死 | 眼睛变成两个空洞、果柄吐出、舌头宕机 |

### 1.4 单集时长结构

```
[0-5秒]   开场Hook      - 漠小漠出场，立flag
[5-30秒]  作死进行      - 步骤清晰、紫薯精拱火
[30-45秒] 死亡瞬间      - 视觉效果夸张、"我裂开了！"
[45-70秒] 科普鉴定      - 玫博士出场，用1-2句话解释原理
[70-90秒] 结尾收束      - 漠小漠复活 + 下集预告
```

### 6.2 剪辑流程

```
Step 1: 导入素材
  - 导入所有分镜图序列（按镜号排序）
  - 导入配音音频
  - 导入音效素材
  - 导入背景音乐

Step 2: 剪辑排布
  - 设置每个分镜的时长（按分镜脚本）
  - 调整顺序确保流畅

Step 3: 添加转场
  - 场景切换：硬切
  - 死亡瞬间：闪黑效果
  - 科普环节：淡入淡出

Step 4: 添加配音
  - 对齐台词与画面
  - 调整音量

Step 5: 添加音效
  - 开门声
  - 冷冻室嗡嗡声
  - 破裂声
  - 倒地声

Step 6: 添加音乐
  - 轻快背景音乐
  - 科普环节转舒缓

Step 7: 添加字幕
  - 逐字同步
  - 字体：思源黑体
  - 位置：底部居中
  - 样式：半透明背景

Step 8: 调色统一
  - 整体色调：暖黄
  - 死亡场景：黑白/冷色

Step 9: 导出
  - 抖音：1080x1920，30fps，MP4
  - B站：1920x1080，30fps，MP4
```

### 6.4 字幕规范

```

大小：40-50pt（确保手机上能看清）
```

## 八、常见问题

### Q1: LLM输出不是JSON格式怎么办？

A: 在Prompt末尾加强调"请直接输出JSON，不要其他内容"，如果还是不行，手动提取关键信息整理成JSON。

### Q2: 角色图不一致怎么办？

A: 保持提示词中的"外貌描述"部分不变，只修改"表情"和"动作"部分。

### Q3: 视频生成失败怎么办？

A: 调整提示词，去除复杂的动作描述，保留核心画面元素；或使用图生视频工具的分段生成功能。

### Q4: 时长超出60-90秒怎么办？

A: 减少分镜数量，合并相邻分镜；或精简台词。
