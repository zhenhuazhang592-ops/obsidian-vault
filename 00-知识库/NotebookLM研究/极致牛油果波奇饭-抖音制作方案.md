## 二、抖音算法优化策略

### 2.1 核心算法因素

| 因素 | 权重 | 优化策略 |
|------|------|----------|
| **完播率** | 30% | 前3秒强吸引，节奏紧凑，58秒内结束 |
| **点赞率** | 25% | 结尾引导点赞，设计记忆点 |
| **评论率** | 20% | 设置互动话题，引发讨论 |
| **转发率** | 15% | 提供实用价值，鼓励收藏 |
| **关注转化** | 10% | 统一风格，形成系列 |

### 2.2 黄金3秒法则

```
开场必须抓住注意力：
├─ 视觉吸引：牛油果角色夸张表情/动作
├─ 声音吸引：元气配音 + 背景音效
└─ 内容吸引：直接展示诱人的波奇饭成品
```

### 2.3 抖音热门标签建议

```
#牛油果 #波奇饭 #轻食 #减脂餐 #教程
#夏威夷美食 #健康饮食 #一人食 #快手菜
```

## 四、详细制作规范

### 4.1 视频规格参数

| 参数 | 规格 | 说明 |
|------|------|------|
| 分辨率 | 1080x1920 | 抖音竖版9:16 |
| 帧率 | 30fps | 兼顾流畅与文件大小 |
| 码率 | 8-12Mbps | 抖音推荐值 |
| 时长 | 55-60秒 | 黄金完播区间 |
| 格式 | MP4 (H.264) | 兼容性最佳 |
| 音轨 | AAC 128kbps | 抖音标准 |

### 4.2 角色设计规范

#### 牛油果动漫形象设定

| 属性 | 设计值 |
|------|--------|
| 主体色 | 牛油果绿 #6B8E23 |
| 肤色 | 淡绿 #9ACD32 |
| 眼睛 | 黑色圆点 + 高光 |
| 腮红 | 粉色 #FFB6C1 |
| 头顶叶子 | 深绿 #556B2F |
| 服装 | 白色小围裙 + 橙色围裙带 |
| 表情 | 元气满满的笑容 |
| 特点 | 圆润身材，大眼睛，小嘴巴 |

> [!tip] 角色稳定性方案
> 由于AI视频生成角色一致性难以保证，建议：
> 1. 角色仅在开场、结尾、过渡镜头出现（3-4个固定镜头）
> 2. 中间烹饪步骤用食材动画代替角色演示
> 3. 固定角色形象作为贴图/PNG使用

### 4.3 视觉风格规范

| 元素 | 规范 |
|------|------|
| 主色调 | 牛油果绿 + 奶白色 |
| 强调色 | 橙色（食欲感）、粉色（可爱感） |
| 字体 | 圆润可爱风格（如：站酷快乐体） |
| 线条 | 粗线条动漫风 |
| 背景 | 浅色纯色或简约纹理 |

## 七、音效与配乐规范

### 7.1 BGM选择建议

| 类型 | 风格 | 用途 |
|------|------|------|
| 主BGM | 轻快流行 / 抖音热曲 | 全程背景 |
| 开场 | 活泼打击乐 | 0:00-0:05 |
| 高潮 | 节奏加强 | 0:25-0:35 |
| 结尾 | 舒缓淡出 | 0:50-1:00 |

**推荐BGM特征：**
- 节奏：100-120 BPM
- 情绪：阳光、活力、正能量
- 版权：抖音热歌榜 / 版权音乐库

### 7.2 音效清单

| 场景 | 音效类型 | 建议 |
|------|----------|------|
| 角色登场 | 跳跃/弹性音效 | "Bounce" |
| 食材落下 | 轻微碰撞声 | "Pop" / "Ding" |
| 倒液体 | 水/液体流动声 | "Pour" |
| 撒调料 | 沙沙声 | "Sprinkle" |
| 淋酱汁 | 粘稠液体声 | "Squeeze" |
| 口味切换 | 卡片滑过声 | "Swipe" |
| 营养展示 | 魔法音效 | "Sparkle" |
| 结尾 | 渐弱音效 | "Fade out" |
