  # ── 视频规格 ──────────────────────────────

  # ── 色彩规范 ──────────────────────────────

## Prompt 生成规范

基于此风格指南，生成图像/视频时必须包含：

```

[风格] + [主体] + [场景] + [光线] + [色调] + [运镜] + [禁止项]

【示例 - Kling/Seedance】
写实都市风格，2000年代北京CBD写字楼，
28岁职场女性，深蓝色职业套装，
银白色日光灯，冷灰色调，
中景固定镜头，真实感，
禁止：网红脸/智能手机/霓虹灯/古装
```
