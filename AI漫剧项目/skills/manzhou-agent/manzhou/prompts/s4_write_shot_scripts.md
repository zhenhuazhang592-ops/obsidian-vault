# S4: 分镜脚本（运镜规范层）

## 任务

基于 S2 CDP 资产包 + S3 资产库，生成每集分镜脚本，包含运镜规范和画面描述。

## 输入

- S0-解析报告.md
- S1-风格指南.md
- S2-CDP资产包/CDP-JSON.md
- 02-资产库/资产库.md

## 输出文件

- `03-分镜脚本/分镜脚本总览.md`
- `03-分镜脚本/第XX集-分镜脚本.md`（每集一个）

## 引用声明

```yaml
引用声明:
  上游步骤: S0-解析报告.md, S1-风格指南.md, S2-CDP资产包/CDP-JSON.md
  引用ID列表: [char_xxx, scene_xxx, item_xxx]
  风格指南版本: [v1.0.0]
  资产库路径: 02-资产库/资产库.md
```

## 输出内容：分镜脚本格式

```yaml
# 第XX集 分镜脚本

集数: XX
集名: [集主题]
总镜头数: X
总时长: XX秒

## 分镜大纲

### 镜 1
- 镜号: SHOT_01
- 场景ID: [scene_xxx]
- 场景名: [场景名]
- 内景/外景: [INT/EXT]
- 时段: [日/夜/晨/昏]
- 角色IDs: [[char_xxx, char_yyy]]
- 角色名: [角色名列表]

运镜:
  - 景别: [远景/全景/中景/近景/特写]
  - 角度: [平视/俯视/仰视]
  - 运动: [固定/推/拉/摇/移/跟/升降]
  - 速度: [慢/中/快]

画面描述:
  [详细的画面描述，引用 S2 场景DNA 和 S3 资产库]

对白/独白:
  [角色对白或旁白]

音效/音乐:
  - BGM: [背景音乐描述]
  - SFX: [音效描述]

时长: X秒
过渡: [硬切/淡入淡出/叠化]

## 镜 2
[同上格式]
```

## 约束

- 每镜必须引用 S2 的 location_id, character_ids, item_ids
- 运镜规范必须符合 S1 的 camera_rules
- 画面描述必须引用 S2 的场景 DNA
- 角色描述必须引用 S2 的角色 DNA
- 不能出现未在 S2 中定义的 ID
- 每集分镜完成后，统计总时长
