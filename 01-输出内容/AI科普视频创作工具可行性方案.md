## 1. 项目概述

### 1.1 项目背景

| 项目 | 内容 |
|------|------|
| 原有项目 | Toonflow-app（AI 短剧漫剧工具） |
| 改造目标 | AI 知识科学科普视频创作工具 |
| 核心输入 | 科普文章（文本） |
| 核心输出 | 科普视频（形象+配音+字幕+动态画面） |
| 现有技术栈 | Electron + TypeScript + Express + SQLite |
| 部署偏好 | 网页或更轻便的方式 |

### 1.2 核心价值主张

将专业的科学知识通过 AI 自动转化为生动有趣的科普视频，降低视频创作门槛，让科普工作者、研究人员、教育者能够快速将文字内容转化为可视化视频内容。

### 1.3 目标用户

- 科普作家和科学传播者
- 中小学及高校教师
- 科研机构宣传部门
- 自媒体科普创作者
- 企业技术布道师

### 3.3 详细功能说明

#### 3.3.1 文章解析器

- **输入格式**: Markdown、纯文本、HTML
- **处理能力**:
  - 自动识别章节结构
  - 提取关键术语和概念
  - 生成知识要点摘要
  - 评估内容适合的视频风格

#### 3.3.2 脚本生成器

- **LLM 调用流程**:
  1. 提示词工程：设计系统提示词控制输出格式
  2. 分镜规划：将文章切分为 N 个视频片段
  3. 脚本生成：每个片段生成讲解词、场景描述、时长估算
  4. 审查优化：用户可编辑调整生成的脚本

- **输出格式**:
```json
{
  "scenes": [
    {
      "id": 1,
      "duration": 15,
      "script": "开场白...",
      "visual": "场景描述...",
      "voice": "配音文字..."
    }
  ]
}
```

#### 3.3.3 角色形象库

- **预设角色**: 科学家、主持人、卡通形象（免费使用）
- **自定义角色**: 用户描述 → AI 生成 → 保存至个人库
- **形象参数**: 外观、服装、表情、动作库

#### 3.3.4 配音引擎

- **TTS 配置项**:
  - 语音选择（多语言、多音色）
  - 语速调节（0.5x - 2x）
  - 音调调整
  - 情感参数（高兴、严肃、亲切）
- **字幕格式**: SRT、VTT、ASS
- **口型同步**: 可选增强功能

#### 3.3.5 视频合成器

- **渲染引擎**: FFmpeg（服务端）
- **输出格式**: MP4（H.264）、WebM（VP9）
- **分辨率**: 720p、1080p、竖版（9:16）
- **特效**: 转场、背景音乐、字幕样式

## 4. AI 能力选型建议

### 4.1 AI 服务矩阵

| 能力 | 推荐方案 | 备选方案 | 成本级别 | 备注 |
|------|----------|----------|----------|------|
| **LLM 脚本生成** | OpenAI GPT-4o | Claude 3.5 / 通义千问 | 中 | 按 token 计费 |
| **图像生成** | DALL-E 3 | Midjourney / Stable Diffusion | 中-高 | 场景、配图 |
| **角色生成** | Midjourney | Stable Diffusion XL | 高 | 质量优先 |
| **视频生成** | Runway Gen-2 | Pika / Luma | 极高 | 口型、动态 |
| **TTS** | ElevenLabs | Azure TTS / 阿里云 | 中 | 情感自然 |
| **语音克隆** | ElevenLabs | Coqui | 中 | 品牌一致性 |

### 4.2 成本优化策略

| 策略 | 描述 | 适用场景 |
|------|------|----------|
| **API 阶梯用量** | 量大时谈判批发价 | 成熟期产品 |
| **模型分级使用** | 简单任务用小模型 | 批量处理 |
| **素材复用** | 同一主题素材库 | 系列内容 |
| **缓存策略** | 相同内容不重复生成 | 热门术语解释 |
| **开源模型自建** | Stable Diffusion 私有部署 | 成本敏感长期运营 |

### 4.3 多供应商策略

- **主供应商**: OpenAI + ElevenLabs（质量优先）
- **备份供应商**: Anthropic + Azure（稳定性保障）
- **降级方案**: 纯文本输出（API 全挂时的保底）

### 5.4 安全架构

- **API 密钥管理**:
  - 使用 AWS Secrets Manager 或 HashiCorp Vault
  - 环境变量 + 加密存储
  - 密钥轮换策略

- **内容安全**:
  - 输入内容过滤（敏感词检测）
  - 输出内容审核（可选第三方审核服务）
  - 用户举报机制

- **数据安全**:
  - 传输加密（HTTPS）
  - 存储加密（敏感数据）
  - GDPR 合规设计
