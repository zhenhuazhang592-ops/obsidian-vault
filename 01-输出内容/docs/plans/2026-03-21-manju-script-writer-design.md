# 漫剧编剧搭档智能体 - 架构设计

## 一、智能体概述

**名称**：漫剧编剧搭档（manju-script-writer）

**定位**：对话式剧本创作智能体，你的虚拟编剧搭档，帮你把"一个想法"打磨成"一集完整剧本"

**输出路径**：`漫剧制作/04-剧本生成/`

**输出格式**：双轨输出
- Markdown阅读版（人读）
- JSON结构化版（工具链读取）

---

## 二、核心工作流程

```
用户输入想法 → AI追问澄清 → 初稿创作 → 审查报告 → 迭代打磨 → 双轨输出
```

### 阶段详解

#### 阶段1：想法输入
用户描述一个故事方向

#### 阶段2：AI追问（如果需要）
智能体追问关键细节：
- "这集想表达什么？讽刺盲目加热还是知识科普？"
- "主角的性格是什么样的？"
- "你想要几分反转？"

#### 阶段3：初稿创作
生成第一版剧本（Markdown + JSON）

#### 阶段4：审查报告
自动生成六大要素审查 + 三个问题回答，随剧本附带

#### 阶段5：迭代打磨
用户反馈 → 针对性修改 → 再次审查（如需要）

#### 阶段6：双轨输出
- `xx集-剧本-版本.md` — 人读剧本
- `xx集-剧本-版本.json` — 结构化数据

## 四、审查报告格式

随剧本附带，作为文档的一部分：

```markdown
## 剧本审查报告

### 六大核心要素评分
| 要素 | 评分 | 说明 |
|------|------|------|
| 高概念钩子 | ⭐⭐⭐⭐☆ | 开场3秒抓住注意力 |
| 社交货币 | ⭐⭐⭐☆☆ | 笑点中等，传播性一般 |
| 节奏管理 | ⭐⭐⭐⭐☆ | 60秒节奏紧凑 |
| 共情代入 | ⭐⭐⭐⭐☆ | 主角作死有共鸣 |
| 二创空间 | ⭐⭐⭐⭐⭐ | 梗可二创 |
| 类型/反类型 | ⭐⭐⭐☆☆ | 套路但有反转 |

### 三个问题回答
1. **一句话安利**：冰箱里的牛油果被微波炉加热后会怎样？
2. **截图时刻**：主角眼睛凸出的那一帧
3. **代入感**：主角说"不至于吧"的时候我也会这么说

### 风险提示
⚠️ 第30秒节奏略拖，建议压缩
⚠️ 对白偏长，可精简
```

## 五、交互节点

| 节点 | AI行为 | 用户行为 |
|------|--------|----------|
| 启动 | 问"你想写什么故事？" | 输入故事方向 |
| 澄清 | 追问细节（可选） | 回答问题 |
| 初稿 | 输出剧本+审查报告 | 阅读，给反馈 |
| 修改 | 针对性修改 | 继续提意见或说"可以了" |
| 定稿 | 输出双轨文件到 `04-剧本生成/` | 确认完成 |

## 六、技术实现

- 单个Skill文件（`.md`格式）
- 内置few-shot examples教AI怎么写剧本
- 内置审查清单作为子流程
- 审查触发：初稿完成后自动触发
- 输出：直接写入 `漫剧制作/04-剧本生成/`

---

## 七、Skill文件结构

```
manju-script-writer.md
├── 角色定义（system prompt）
│   ├── 身份：你是一个漫剧编剧搭档
│   ├── 六大要素清单
│   └── 三个问题清单
├── Few-shot examples（3-5个示例剧本）
├── 审查子流程
│   ├── 六大要素检查表
│   └── 三个问题回答生成
├── 输出格式模板
│   ├── Markdown模板
│   └── JSON模板
└── 对话引导词
```
