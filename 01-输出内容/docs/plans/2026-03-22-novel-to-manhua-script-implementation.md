## Task 4: 完善爆款思维与审查机制

**文件：**
- 修改: `01-输出内容/AI智能体/novel-to-manhua-script-writer.md`

**步骤1: 填充爆款思维**

```markdown
## 爆款思维

### 黄金3秒法则
- 第1秒：视觉冲击——画面直接抓住眼球
- 第2秒：悬念建立——"这是怎么回事？"
- 第3秒：情绪共鸣——"我懂这种感觉！"

### 心跳节奏
- 每15秒 ≈ 一个"情绪事件"（反转/冲突/共鸣/梗）
- 一集60秒 = 4个心跳点
- 一集90秒 = 6个心跳点

### 结尾钩子类型
- "评论区告诉我，如果是你，你怎么办？"
- "下集更精彩..."
- "这一幕，我赌你没见过"

### 改编策略
**要砍掉的：**
- 长篇环境描写（用画面带过）
- 内心独白堆砌（用表情和动作外化）
- 缓慢铺垫（直接切炸点）

**要强化的：**
- 开场即冲突
- 每一场戏一个核心情绪
- 台词要有"截图欲"——金句、梗、反转
```

**步骤2: 填充审查机制**

```markdown
## 审查机制

### 6要素审查
改编完每一集，必须确认：
1. 极致的高概念钩子
2. 强烈的"社交货币"属性
3. 精准的节奏管理
4. 极致的共情与代入感
5. 天然的二创空间
6. 类型化的确定性与反类型的新鲜感

### 3问题自问
1. 如果用一句话向朋友安利这个故事，这句话是什么？
2. 观众看完后，最想截图发朋友圈的是哪句台词或哪个画面？
3. 这个故事里，有没有一个角色是观众会想"如果是我，也会这么做"的？

### 爆款7问自检清单
```
□ 第1秒画面够不够炸？
□ 前3秒有没有钩子？
□ 每15秒有没有情绪事件？
□ 结尾钩子够不够引发评论？
□ 有没有一句"必须截图"的台词？
□ 节奏够不够快，不够快就砍？
□ 有没有"如果是我也会这么做"的代入点？
```
```
