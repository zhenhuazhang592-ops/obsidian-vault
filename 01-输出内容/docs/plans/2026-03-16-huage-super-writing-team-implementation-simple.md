# 华哥超级写作工作团智能体 - 实施方案

> **核心理念**：不搭建服务器，利用 Claude Code 原生能力，用 Prompt 直接编排工作流

---

## 一、架构设计

### 工作原理

```
用户输入
    ↓
huage-super-writing-team（主智能体）
    ↓
根据状态判断，调用对应Skill
    ↓
Skill执行 → 返回结果 → 继续下一步
    ↓
最终输出
```

**关键**：主智能体本身就是编排器，通过 Prompt 指令它按流程工作

### 所需文件

| 文件                                  | 作用               |
| ----------------------------------- | ---------------- |
| `AI智能体/huage-super-writing-team.md` | 主智能体Prompt（编排中心） |

**不需要**：服务器、额外的代码文件

---

## 二、详细工作流

### 完整流程（7个阶段）

```
用户输入
    ↓
阶段0: 选题推荐（无主题时）→ huage-hot-analysis
    ↓
阶段0.5: 模式选择（自动判断）
    ↓
    ├─ 秒出模式（热点）：直接生成 → 确认 → humanizer-zh必选 → 生图 → 输出
    ├─ 轻量模式（日常）：直接生成 → 确认 → humanizer-zh必选 → 生图 → 输出
    └─ 深度模式：轻研究 → 生成 → 确认 → humanizer-zh可选 → 生图 → 输出
```

---

## 三、调用逻辑

### 编排中心职责

主智能体 `huage-super-writing-team` 的 Prompt 中已包含：

1. **状态判断**：根据用户输入判断当前状态
2. **Skill调用**：使用 `Skill` 工具调用对应技能
3. **流程控制**：根据上一步结果决定下一步
4. **用户交互**：在关键节点请求用户确认

### Skill调用示例

```
// 主智能体判断需要选题推荐
→ 使用 Skill 工具调用 huage-hot-analysis
→ 接收结果，推荐选题给用户

// 用户确认主题后判断模式
→ 根据话题类型选择：秒出/轻量/深度

// 需要研究时
→ 使用 Skill 工具调用 huage-deep-research
→ 接收研究摘要

// 需要创作时
→ 使用 Skill 工具调用 huagexiaohongshu
→ 接收初稿内容

// 需要生图时
→ 使用 Skill 工具调用 huage-xhs-image-gen
→ 接收生成的图片

// 需要存档时
→ 使用 Skill 工具调用 obsidian-markdown
→ 接收存档结果
```

## 四、涉及Skill清单

| 阶段 | 调用的Skill | 作用 | 调用方式 |
|------|-------------|------|----------|
| 选题 | huage-hot-analysis | 热点查询+选题推荐 | 按需 |
| 研究 | huage-deep-research | 快速补充资料 | 按需 |
| 创作 | huagexiaohongshu | 生成初稿 | 必选 |
| 优化 | humanizer-zh | 降AI味 | 可选 |
| 生图 | huage-xhs-image-gen | 生成5张爆款图 | 必选 |
| 存档 | obsidian-markdown | 知识库归档 | 必选 |

---

## 五、爆款输出要素

### 内容结构

```
📝 笔记初稿
├─ 标题：3个备选（含推荐）
├─ 正文：黄金开头 + 干货 + 互动引导
├─ 标签：带热度分析（蓝海/红海）
├─ 配图：5张（封面+预告+干货+收藏+金句）
└─ 发布时间：最佳时段建议
```

### 配图5张策略

| 位置 | 类型 | 作用 |
|------|------|------|
| P1 | 吸睛首图 | 决定点击 |
| P2 | 内容预告 | 吸引看完 |
| P3 | 核心干货 | 展示价值 |
| P4 | 收藏总结 | 提升收藏 |
| P5 | 金句分享 | 引导传播 |
