# 华哥超级写作工作团智能体 - 架构设计（优化版）

> **设计理念**：快、准、狠——像小红书运营一样追求效率

---

## 一、核心问题诊断

| 问题 | 严重程度 | 影响 |
|------|----------|------|
| 研究阶段过重 | 🔴 高 | 丧失热点时效性 |
| 用户交互节点4个 | 🔴 高 | 流程断裂，体验差 |
| 降AI味丢失风格 | 🟡 中 | 内容同质化 |
| 生图不接地气 | 🟡 中 | 不符合平台审美 |
| 缺爆款验证 | 🟡 中 | 盲目创作 |

---

## 二、优化后的核心流程

```
用户输入 → 【选题推荐】（可选） → 【模式选择】 → 创作 → 确认 → 生图 → 输出
```

**三种工作模式**：
| 模式 | 触发条件 | 时长 | 研究 |
|------|----------|------|------|
| 秒出模式 | 热点话题/蹭流 | 3分钟 | 不研究 |
| 轻量模式 | 日常种草 | 5分钟 | 按需 |
| 深度模式 | 知识科普 | 15分钟 | 补充研究 |

**变化**：从9个阶段 → 6个阶段，从4个交互节点 → 1个确认节点

---

## 三、详细流程设计

### 阶段0: 选题推荐（前置环节）

**触发条件**：
- 用户说"不知道写什么"
- 用户说"有什么推荐"
- 用户说"最近有什么热点"

**执行方式**：
```
IF 用户没有明确主题：
    查询近期小红书热门话题/标签趋势
    结合用户历史创作领域
    推荐3-5个具体选题（含热度数据和竞争程度）

    ❓ 请选择选题：
    A. [选题1] 🔥热度高 竞争激烈
    B. [选题2] 🔥热度中 竞争适中
    C. [选题3] 🔥热度低 蓝海机会
    D. [自定义主题]
ELSE：
    跳过选题环节，直接进入模式选择
```

**输出示例**：
```
📊 今日推荐选题：

A. #牛油果神仙吃法  🔥120w浏览  竞争激烈（红海）
B. #牛油果测评  🔥35w浏览  竞争适中 ⭐推荐
C. #健身党牛油果  🔥8w浏览  蓝海机会 ✅首选

❓ 请选择一个，或输入自定义主题
```

---

### 阶段0.5: 模式选择

**自动判断**：
```
IF 检测到热点话题（近期热搜/爆款）：
    推荐"秒出模式"（不研究，快）
ELSE IF 用户选择科普/深度内容：
    推荐"深度模式"
ELSE：
    默认"轻量模式"

❓ 请确认模式：
A. 秒出模式（热点/蹭流，3分钟）
B. 轻量模式（日常，5分钟）
C. 深度模式（科普，15分钟）
```

---

### 阶段1: 轻研究（按需触发）

**触发条件**：
- 用户明确要求"帮我查一下xxx"
- 话题涉及最新热点/数据
- 主题是知识科普类（需要准确性）

**不触发**：
- 日常种草、经验分享类
- 纯个人观点输出
- 老话题新写（之前做过研究的）

**执行方式**：
```
IF 需要研究：
    调用 huage-deep-research 快速补充（10分钟内）
    生成精简版研究摘要（不超过300字）
    保存到知识库备查
ELSE：
    直接进入创作阶段
```

---

### 阶段2: huagexiaohongshu 生成初稿

**输入**：
- 用户主题
- 研究摘要（如果有）
- 用户历史风格偏好（如果有）
- 选择的模式（秒出/轻量/深度）

**输出**：
- 3个备选标题（含推荐）
- 正文初稿
- 5-8个标签组合（带热度数据）
- 生图需求描述

**特点**：
- 生成即带有"网感"，不需要二次优化
- 标题直接给选项，不让用户自己起
- **标签带热度参考**（蓝海/红海/竞争程度）

---

### ⚠️ 阶段3: 用户确认（唯一交互节点）

**展示内容**：
```
📝 笔记初稿已生成

【标题】（推荐）
A. 后悔没早知道！牛油果就是"植物黄油"
B. 健身党必看！一颗牛油果=三代营养
C. 别再误会牛油果了！它其实是"超级食物"

【正文预览】（前100字）
xxx...

【标签】（带热度分析）
#牛油果  🔥120w浏览  竞争激烈（红海）
#超级食物  🔥35w浏览  竞争适中 ⭐推荐
#健身饮食  🔥8w浏览  蓝海机会 ✅首选
#营养科普  🔥5w浏览  蓝海

【配图需求】
- 封面：大字报风格 + 牛油果特写
- 卡片：金句图"一颗牛油果=3个鸡蛋"

❓ 请确认：
[A] 完美，直接生成终稿
[B] 调整标题
[C] 调整内容
[D] 调整风格
[E] 重新选题
```

**创新点**：
- 一次性展示所有内容
- 修改意见即时响应
- 老用户可选择"一键通过"

---

### 阶段4: humanizer-zh 优化（可选）

**默认**：不触发，由 huagexiaohongshu 生成时就带有人感

**触发场景**：
- 用户明确要求"再自然一点"
- 内容涉及专业术语需要解释
- 检测到明显的车轱辘话

**执行方式**：
```
IF 用户要求优化 OR 检测到AI痕迹明显：
    调用 humanizer-zh 进行局部优化
    保留原有风格和核心观点
ELSE：
    跳过此阶段
```

---

### 阶段5: baoyu-xhs-images 生图

**爆款配图策略（5张最佳）**：

| 位置 | 图片类型 | 作用 | 数量 |
|------|----------|------|------|
| P1 | 吸睛首图 | 决定点击，视觉冲击 | 1张 |
| P2 | 内容预告 | 让用户知道能学到什么 | 1张 |
| P3 | 核心干货 | 展示价值，数据/对比 | 1张 |
| P4 | 收藏总结 | 一张图看懂全篇，方便收藏 | 1张 |
| P5 | 金句分享 | 引导转发分享 | 1张 |

**输出规格**：
| 类型 | 尺寸 | 风格 | 作用 |
|------|------|------|------|
| 封面 | 1920x2560 (3:4) | 大字报/对比/真人出镜 | 决定点击 |
| 预告 | 1920x2560 (3:4) | 目录式/步骤式 | 吸引看完 |
| 干货 | 1920x2560 (3:4) | 数据图表/对比/实物 | 展示价值 |
| 收藏 | 1920x2560 (3:4) | 一张图读懂 | 提升收藏 |
| 金句 | 1920x1920 (1:1) | 金句文案 | 引导分享 |

**与旧版对比**：
| 旧版 | 新版 | 爆款价值 |
|------|------|----------|
| 1封面+2卡片 | **5张完整配置** | 首图点击+收藏+传播 |
| 配图是辅助阅读 | 收藏图提升收藏率 | **提升收藏** |
| 通用素材风 | 小红书网感风 | 符合平台审美 |

---

### 阶段6: 一键输出 + 存档

**输出格式**：
- 完整Markdown（含图片链接）
- 纯文字版（可复制到小红书）
- 话题标签包（可直接复制）

**输出必须包含（爆款要素）**：

1. **互动引导语**（结尾必须有）：
   - 收藏引导："收藏起来慢慢看"
   - 评论引导："你们觉得怎么样？评论区聊聊"
   - 分享引导："转给需要的朋友"

2. **最佳发布时间建议**：
   ```
   📅 建议发布时间：
   - 午餐时段：12:00-13:00
   - 下班时段：18:00-20:00
   - 睡前时段：21:00-22:00
   - 周五周六：流量更大
   ```

3. **配图排版建议**：
   ```
   📸 配图顺序：
   P1 封面 → P2预告 → P3干货 → P4收藏 → P5金句
   ```

**存档内容**：
- 研究资料（如果有）
- 终稿内容
- 标签组合
- 生图记录

## 四、两种工作模式

### 模式A：轻量模式（默认）

```
用户输入 → 生成初稿 → 用户确认 → 输出
```

- 适用：日常种草、经验分享、热点蹭流
- 时长：3-5分钟
- 交互：1次

### 模式B：深度模式

```
用户输入 → 轻研究 → 生成初稿 → 用户确认 → 优化 → 生图 → 输出
```

- 适用：知识科普、深度测评、专题内容
- 时长：10-15分钟
- 交互：1-2次

## 五、与用户交互节点

| 节点 | 阶段 | 交互内容 | 目的 |
|------|------|----------|------|
| 1 | 创作后 | 确认初稿+修改意见 | 一次性完成确认 |

**对比旧版**：
- 旧版：4个节点（开始→方向→初稿→终稿）
- 新版：1个节点（创作后确认）

## 八、核心改进点总结

| 改进点 | 旧版 | 新版 | 效果 |
|--------|------|------|------|
| 研究阶段 | 必选+重 | 按需+轻 | 效率提升50% |
| 交互节点 | 4个 | 1个 | 用户体验提升 |
| 降AI味 | 强制 | 可选+保留风格 | 内容更有特色 |
| 生图 | 1+4通用 | 1+卡片 | 更适合传播 |
| 模式 | 单一 | 轻量/深度双模式 | 适应不同场景 |

## 标签热度策略（新增）

### 热度等级

| 标识 | 热度范围 | 竞争程度 | 建议 |
|------|----------|----------|------|
| 🔥100w+ | >100万浏览 | 红海 | 慎用，难出头 |
| 🔥30-100w | 30-100万浏览 | 橙海 | 竞争较大 |
| 🔥10-30w | 10-30万浏览 | 黄海 | 适中，可用 |
| 🔥5-10w | 5-10万浏览 | 蓝海 | **推荐** |
| 🔥<5w | <5万浏览 | 深蓝海 | **首选，容易爆** |

### 标签组合策略

**最佳组合**：
- 1个蓝海标签（主标签）+ 2个黄海标签（辅助）+ 1个热度标签（蹭流）

**示例**：
```
#牛油果神仙吃法  🔥8w（蓝海，主推）
#早餐灵感  🔥25w（黄海，辅助）
#快手早餐  🔥15w（黄海，辅助）
#牛油果  🔥120w（红海，蹭流）
```
