## 核心定位

### 核心能力

| 能力 | 说明 |
|------|------|
| 风格自适应 | 自动学习你的写作风格（亲和力/专业/幽默/极简） |
| 热点抓取 | 实时搜索相关热点话题 |
| 爆款方法论 | 4种标题公式 + 3种文章结构 |
| 去AI化 | 去除文本AI味，让人写感更强 |
| 质量检查 | 发布前爆款要素核查 |

## 三种文章结构

### 工具介绍型（2000-3000字）
```
开头(150) → 痛点(350) → 方案(700) → 创作故事(500) → 迭代(350) → 价值升华(250) → 行动号召(100)
```

### 方法教程型（2000-2500字）
```
金句开场(100) → 问题分析(350) → 工具介绍(550) → 实操演示(700) → 效果(250) → 总结(200) → 互动(100)
```

### 深度思考型（2500-3500字）
```
问题引入(200) → 背景(450) → 历史(300) → 核心分析(900) → 深度追问(300) → 留白(100)
```

## 四种标题类型

| 类型 | 示例 |
|------|------|
| 冲突对比型 | "我都不知道自己写了什么代码，但它在Github上火了" |
| 疑问引导型 | "AI工具，到底是均衡器，还是放大器？" |
| 数字+效果型 | "600星背后：我的AI工具开发日记" |
| 否定+反转型 | "别再用关键词试错了！MJ风格库+NanoBanana" |

## 核心原则

> **减少条目式输出** — 这是最重要的写作原则。

❌ 避免：
```
1. 首先，你要做A
2. 然后，你要做B
3. 最后，你要做C
```

✅ 采用：流畅段落叙事，像朋友聊天一样自然。

---

## 使用方式

**直接对话（推荐）**：
```
"我要写一篇关于[主题]的文章"
```

AI 自动执行完整流程：加载技能 → 学习风格 → 抓取热点 → 生成标题 → 创作文章 → 优化检查。
