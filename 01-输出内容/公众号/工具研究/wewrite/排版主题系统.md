# 排版主题系统

> 来源：wewrite-main/toolkit/theme.py 及 themes/*.yaml

## 主题加载机制

```python
# theme.py 核心逻辑
def load_theme(name: str, themes_dir: str = None) -> Theme:
    theme_path = os.path.join(themes_dir, f"{name}.yaml")
    with open(theme_path, "r", encoding="utf-8") as f:
        data = yaml.safe_load(f)
    return Theme(
        name=data["name"],
        description=data["description"],
        base_css=data["base_css"],
        colors=data.get("colors", {}),
    )
```

CSS 变量替换：CSS 中的 `var(--primary)` 会替换为 `colors.primary` 的值。

## YAML 主题格式

```yaml
name: "theme-name"
description: "主题描述"
colors:
  primary: "#2563eb"
  secondary: "#3b82f6"
  text: "#333333"
  text_light: "#666666"
  background: "#ffffff"
  code_bg: "#1e293b"
  code_color: "#e2e8f0"
  quote_border: "#2563eb"
  quote_bg: "#eff6ff"
  border_radius: "8px"
base_css: |
  body {
    font-family: ...;
    font-size: 16px;
    ...
  }
  h1 { ... }
  h2 { ... }
```

## 4 套预置主题

### professional-clean（专业简洁）

**描述**：干净专业的企业公众号风格，适合大多数商业内容

**主色**：#2563eb（蓝色）

**适用场景**：企业号、科技号、干货号

### tech-modern（科技现代）

**描述**：科技风，蓝紫渐变，适合技术/产品类账号

**主色**：#7c3aed（紫色）+ #3b82f6（蓝色）

**适用场景**：AI、代码、技术分析

### warm-editorial（暖色编辑风）

**描述**：暖色调编辑风格，适合生活、文化、情感类

**主色**：#d97706（暖橙）

**适用场景**：生活方式、文化号、人物故事

### minimal（极简黑白）

**描述**：黑白灰极简，适合文学、严肃内容

**主色**：#1a1a1a（近黑）

**适用场景**：深度长文、严肃评论、诗歌文学

## 主题 → 内联样式转换流程

```
YAML 主题文件
    ↓
cssutils 解析 base_css
    ↓
get_inline_css_rules() → {selector: {property: value}}
    ↓
BeautifulSoup 遍历 HTML 元素
    ↓
匹配选择器 → 添加 style 属性
    ↓
输出纯内联样式 HTML（无外部依赖）
```

## 注意事项

- 选择器必须是简单选择器（不支持 `:hover`、`@media` 等）
- 颜色值建议使用十六进制 `#ffffff` 格式，避免 rgba
- 避免使用微信不支持的 CSS 属性（参考 [[微信平台限制]]）
