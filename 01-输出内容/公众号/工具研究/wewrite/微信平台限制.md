# 微信公众号平台限制

> 来源：wewrite-main/references/wechat-constraints.md

## 核心技术限制

### 不支持外部CSS文件

微信编辑器不允许使用 `<link>` 标签或 `<style>` 标签中的 CSS 规则，只支持内联 `style` 属性。

**WeWrite 的解决方案**：`converter.py` 将所有 CSS 规则转换为内联样式。

### 不支持JavaScript

完全禁用所有 JavaScript 代码，不支持 `<script>` 标签和事件属性。

### 有限的CSS属性支持

**不支持**：
```css
position: fixed/sticky;  /* 固定/粘性定位 */
transform: rotate();     /* 3D变换 */
animation; @keyframes;   /* CSS动画 */
filter: blur();         /* 滤镜效果 */
backdrop-filter;         /* 背景滤镜 */
```

**支持**：
```css
color, background, background-color
font-size, font-weight, font-family
padding, margin, border
width, height, max-width, max-height
text-align, line-height, letter-spacing
border-radius, box-shadow
display, flex, justify-content, align-items
```

### 图片处理限制

- 不支持本地图片路径，必须上传到微信服务器
- 图片大小建议 < 5MB
- 支持格式：JPG、PNG、GIF

**WeWrite 的处理**：`cli.py publish` 自动调用 `upload_image()` 上传图片并替换 src。

## 排版限制

| 项目 | 限制 |
|------|------|
| 最大宽度 | ~750px（移动端） |
| 字体 | 系统字体（不支持自定义字体） |
| 表格列数 | 建议 ≤ 4 列（移动端友好） |
| 文章长度 | 最多 20,000 字 |
| 图片数量 | 最多 10 张 |

## 发布前检查清单

### 样式检查
- [ ] 所有样式都是内联的（无外部CSS）
- [ ] 没有使用不支持的CSS属性
- [ ] 颜色值使用十六进制格式
- [ ] 字体使用系统字体栈

### 内容检查
- [ ] 文章长度 < 20,000 字
- [ ] 图片数量 ≤ 10 张
- [ ] 图片已上传或使用稳定图床

### 格式检查
- [ ] 表格列数 ≤ 4 列
- [ ] 代码块格式正确
- [ ] 标题层级合理（H1 → H2 → H3）

### 移动端检查
- [ ] 字体大小 ≥ 15px
- [ ] 图片宽度自适应
- [ ] 表格可横向滚动

## 常见兼容性问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 粘贴后样式丢失 | 浏览器兼容性 | 使用 Chrome/Edge，复制 `<body>` 内 HTML |
| 代码块格式混乱 | 微信自动格式化 | 使用微信编辑器的"代码块"功能 |
| 表格显示不全 | 列数过多 | 拆分为多个小表格或用图片替代 |
| 图片无法显示 | 本地路径 | 在编辑器中重新上传 |
| 链接无法点击 | 公众号未认证 | 认证公众号或改用纯文本 |
