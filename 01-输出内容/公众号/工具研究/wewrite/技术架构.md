## 关键技术点

### 1. 内联样式转换（converter.py）

微信不支持外部 CSS，只支持内联 `style` 属性。核心流程：

```
YAML 主题 → CSS 字符串（base_css）
    ↓
cssutils 解析 → selector → {property: value}
    ↓
BeautifulSoup 遍历 HTML 元素
    ↓
匹配到的元素添加 style 属性
    ↓
最终 HTML（无外部依赖）
```

关键实现：`theme.py` 中的 `get_inline_css_rules()`，解析 CSS 并转换为内联样式字典。

### 2. access_token 缓存（wechat_api.py）

微信 access_token 有效期 2 小时，设置 5 分钟缓冲：

```python
_token_cache[appid] = TokenResult(
    access_token=access_token,
    expires_at=now + expires_in - 300,  # 提前5分钟刷新
)
```

### 3. 图片生成 Provider 抽象（image_gen.py）

```python
class ImageProvider(abc.ABC):
    def generate(self, prompt: str, size: str) -> bytes: ...

class DoubaoProvider(ImageProvider):
    # 豆包 Seedream via 火山引擎 Ark
    provider_key = "doubao"

class OpenAIProvider(ImageProvider):
    # DALL-E 3
    provider_key = "openai"

PROVIDERS = {"doubao": DoubaoProvider, "openai": OpenAIProvider}
```

尺寸预设：

| 预设 | Doubao | OpenAI |
|------|--------|--------|
| cover | 2952x1256 | 1792x1024 |
| article | 2560x1440 | 1792x1024 |
| vertical | 1088x2560 | 1024x1792 |
| square | 2048x2048 | 1024x1024 |

### 5. 微信 API 关键点（publisher.py）

- **必须** `ensure_ascii=False` + UTF-8 编码，否则中文变成 `\uXXXX` 导致标题超长
- thumb_media_id 必需，若无则上传 1x1 白色像素图

```python
resp = requests.post(
    "https://api.weixin.qq.com/cgi-bin/draft/add",
    params={"access_token": access_token},
    data=json.dumps(body, ensure_ascii=False).encode("utf-8"),
    headers={"Content-Type": "application/json; charset=utf-8"},
)
```
