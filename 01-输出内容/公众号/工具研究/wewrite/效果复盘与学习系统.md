# 效果复盘与学习系统

> 来源：wewrite-main/SKILL.md 效果复盘 + learn_edits.py

## 效果复盘

**触发条件**：用户问"文章数据怎么样"、"效果复盘"、"看看表现"

### 数据拉取

```bash
python3 scripts/fetch_stats.py --client {client} --days 7
```

脚本会：
1. 调微信数据分析 API 拉取最近 7 天的文章阅读数据
2. 匹配 history.yaml 中的文章记录
3. 回填 stats 字段（阅读量、分享量、点赞量、阅读率）

### 分析维度

回填后，分析数据并给出建议：
- **哪篇文章表现最好？** 为什么？（标题策略？选题热度？框架类型？）
- **哪篇表现不好？** 可能的原因？
- **对后续选题/标题/框架的调整建议**

这些分析会影响下次运行时 Step 2.5 的偏好参考。

## Playbook 学习

**触发条件**：用户说"我改了，学习一下"、"学习我的修改"

### 流程

**Step 1: 获取 draft 和 final**
- draft：`output/{client}/` 下最新的 .md 文件
- final：用户提供修改后的版本（粘贴或指定文件路径）

**Step 2: 运行 diff 分析**

```bash
python3 scripts/learn_edits.py --client {client} \
  --draft {draft_path} --final {final_path}
```

**Step 3: 分析并记录**

读取脚本输出的 diff 数据，对每个有意义的修改分类：

| 类型 | 示例 |
|------|------|
| 用词替换 | AI 用了"讲真"，人工改成"坦白说" |
| 段落删除 | 人工觉得某段多余 |
| 段落新增 | 人工补充了 AI 没写的内容 |
| 结构调整 | H2 顺序或分段方式的变化 |
| 标题修改 | 标题风格偏好 |
| 语气调整 | 整体语气的偏移方向 |

将分类结果写入 `lessons/` 下的 diff YAML 文件的 edits 和 patterns 字段。

**Step 4: Playbook 更新**

每积累 5 次 lessons，触发更新：

```bash
python3 scripts/learn_edits.py --client {client} --summarize
```

读取所有 lessons，找出反复出现的 pattern（≥2 次），将其固化到 `playbook.md` 的对应章节。

## Playbook 生成

**触发条件**：用户将历史推文放入 `corpus/` 后

```bash
python3 scripts/build_playbook.py --client {client}
```

脚本输出语料统计 + 分析指令。按指令逐批阅读文章，提取风格特征，生成 `playbook.md`。

建议至少 20 篇历史文章，50+ 篇效果更好。
