# WeWrite 安装指南

## 前置要求

- Python 3.8+
- 微信公众号 AppID + AppSecret（发布草稿箱必需）
- AI 图片生成 API key（二选一）：
  - **豆包 Seedream**（推荐）：[火山引擎 Ark 控制台](https://console.volcengine.com/ark)
  - **OpenAI DALL-E 3**：OpenAI API key

## 安装步骤

### 1. 克隆项目

```bash
git clone https://github.com/geekjourneyx/wewrite.git
cd wewrite
```

### 2. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

依赖包：

| 包 | 用途 |
|----|------|
| markdown | Markdown → HTML |
| beautifulsoup4 | HTML 解析 + 内联样式 |
| cssutils | CSS → 内联样式解析 |
| requests | HTTP 请求 |
| pyyaml | YAML 配置 |
| Pygments | 代码语法高亮 |
| Pillow | 图片压缩（微信5MB限制） |

### 3. 配置

```bash
cp config.example.yaml config.yaml
```

编辑 `config.yaml`：

```yaml
# 微信公众号 API（发布草稿 + 数据统计必需）
wechat:
  appid: "wx_your_appid"
  secret: "your_appsecret"
  author: ""  # 默认署名（可选）

# AI 图片生成
image:
  provider: "doubao"  # doubao | openai
  api_key: "your_api_key"

  # 豆包 Seedream（默认）
  # 获取 API key: https://console.volcengine.com/ark
  # model: "doubao-seedream-5-0-260128"
  # base_url: "https://ark.cn-beijing.volces.com/api/v3"

  # OpenAI DALL-E 3
  # provider: "openai"
  # api_key: "sk-..."
  # model: "dall-e-3"
  # base_url: "https://api.openai.com/v1"

# 默认排版主题
theme: "professional-clean"
```

### 4. 配置为 Claude Code Skill（可选）

```bash
# 方式 1：符号链接
ln -s "$(pwd)" ~/.claude/skills/wewrite

# 方式 2：复制
cp -r wewrite ~/.claude/skills/wewrite
```

配置后对 Claude 说「用 demo 的配置写一篇公众号文章」即可触发完整流程。

## CLI 独立使用

### 预览文章

```bash
python3 toolkit/cli.py preview article.md --theme professional-clean
```

### 发布到草稿箱

```bash
python3 toolkit/cli.py publish article.md \
  --cover cover.png \
  --title "文章标题"
```

### 查看可用主题

```bash
python3 toolkit/cli.py themes
```

### 抓热点

```bash
python3 scripts/fetch_hotspots.py --limit 20
```

### SEO 分析

```bash
python3 scripts/seo_keywords.py --json "AI大模型" "科技股"
```

## 常见问题

### 热点抓取全部失败

脚本使用公开 API，部分平台可能限流。降级方案：SKILL.md 中会改用 WebSearch 搜索热点。

### 图片上传失败

- 确认图片 < 5MB（`image_gen.py` 自动压缩）
- 确认图片格式为 JPG/PNG/GIF
- 检查 access_token 是否有效

### 发布到草稿箱失败

- 检查 AppID/AppSecret 是否正确
- 确认公众号已认证（有草稿箱 API 权限）
- 查看微信公众平台接口文档确认接口可用性
