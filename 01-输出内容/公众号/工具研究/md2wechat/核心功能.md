# md2wechat 核心功能

> 版本：v2.0.5

---

## 五大核心功能总览

| 功能 | 命令 | 说明 | 适合谁 |
|------|------|------|--------|
| **Markdown 转换** | `convert` | 将 Markdown 转换为微信格式 HTML | 所有用户 |
| **风格写作** | `write` | 用创作者风格辅助写作，自动生成文章和封面提示词 | 写作小白、内容创作者 |
| **AI 去痕** | `humanize` | 去除 AI 生成痕迹，让文章听起来更自然、像人写的 | AI 写作用户 |
| **小绿书** | `create_image_post` | 创建图片消息（小绿书），最多 20 张图片 | 图片内容创作者 |
| **草稿推送** | `convert --draft` | 一键发送到微信草稿箱 | 需要频繁发布的用户 |

---

## 1. Markdown 转换（convert）

### 基础命令

```bash
# 预览转换效果（不发送）
md2wechat convert article.md --preview

# 转换并保存为 HTML 文件
md2wechat convert article.md -o output.html

# 使用 AI 模式生成精美排版
md2wechat convert article.md --mode ai --theme autumn-warm --preview

# 显式覆盖标题、作者、摘要
md2wechat convert article.md --title "新标题" --author "作者名" --digest "摘要"

# 发送到微信草稿箱
md2wechat convert article.md --draft --cover cover.jpg
```

### 两种模式对比

| 模式 | API Key | 特点 | 输出 |
|------|---------|------|------|
| **API 模式** | 需要 md2wechat.cn API Key | 调用 API，秒级响应 | 微信格式 HTML |
| **AI 模式** | 不需要 | 生成 AI request/prompt | 需 Claude 等继续生成 |

### metadata 优先级

```
标题：--title → frontmatter.title → 正文首个 H1 → 未命名文章
作者：--author → frontmatter.author
摘要：--digest → frontmatter.digest/summary/description
```

### 长度限制

- 标题：最多 32 字符
- 作者：最多 16 字符
- 摘要：最多 128 字符

## 2. 风格写作（write）

### 基础命令

```bash
# 查看所有可用写作风格
md2wechat write --list

# 用指定风格写文章
md2wechat write --style dan-koe

# 润色现有文章
md2wechat write --style dan-koe --input-type fragment article.md

# 生成匹配的封面提示词
md2wechat write --style dan-koe --cover-only

# 同时生成文章和封面
md2wechat write --style dan-koe --cover
```

### 输入类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `idea` | 一个观点或想法 | "我觉得自律是个伪命题" |
| `fragment` | 内容片段，需要润色扩展 | 现有的草稿或未完成的文章 |
| `outline` | 文章大纲 | 有结构，需要填充内容 |
| `title` | 仅标题，围绕标题写作 | "自律是个谎言" |

### 内置风格：Dan Koe

| 特点 | 适合内容 |
|------|----------|
| 深刻但不晦涩 | 个人成长 |
| 犀利但不刻薄 | 观点文章 |
| 有哲学深度但接地气 | 评论 |

## 3. AI 去痕（humanize）

### 原理

去除 24 种 AI 写作模式：
- 夸大意义词（"作为、标志着、见证了"）
- 虚假归因（"行业数据显示、专家认为"）
- 否定式排比（"不仅...而且..."）
- 过度使用的 AI 词汇（"此外、至关重要、深入探讨"）
- 表情符号滥用
- 协作交流痕迹（"希望对您有帮助"）

### 输出效果

让文章听起来像真人写的，有观点、有态度、会变节奏。

## 4. 小绿书（create_image_post）

### 功能

创建图片消息（小绿书），最多支持 20 张图片。

### 用途

适合：
- 图片集分享
- 教程截图
- 产品展示
- 旅行日志

## 5. 草稿推送（draft）

### 完整发布流程

```bash
# 1. 先检查 metadata
md2wechat inspect article.md

# 2. 预览效果
md2wechat preview article.md

# 3. 发送到草稿箱
md2wechat convert article.md --draft --cover cover.jpg
```

### 确认层命令

在真正执行前，推荐先走确认层：

```bash
# 看系统最终会如何解释这篇文章
md2wechat inspect article.md

# 生成本地预览 HTML 文件
md2wechat preview article.md
```

**说明**：
- `inspect` 会输出标题、作者、摘要来源，以及 upload/draft readiness 和风险检查
- `preview` 第一版会生成一个本地 HTML 文件，不会触发上传或草稿副作用
