## 项目概述

md2wechat 是一个 **Markdown 转微信公众号格式** 的 CLI 工具，支持 Claude Code、OpenClaw、Obsidian Claudian 等 AI Coding Agent 平台。

**核心能力**：用 Markdown 写文章 → 一键转换 → 自动发到微信草稿箱

## 快速安装

```bash
# macOS - Homebrew
brew install geekjourneyx/tap/md2wechat

# 或 curl 安装
curl -fsSL https://github.com/geekjourneyx/md2wechat-skill/releases/download/v2.0.5/install.sh | bash

# Claude Code 中安装 skill
npx skills add https://github.com/geekjourneyx/md2wechat-skill --skill md2wechat
```

---

## 核心命令

```bash
# 检查系统能力
md2wechat capabilities --json

# 检查文章 metadata
md2wechat inspect article.md

# 本地预览
md2wechat preview article.md

# 转换为微信格式
md2wechat convert article.md --preview

# 发送到草稿箱
md2wechat convert article.md --draft --cover cover.jpg
```
