## v2.0.5 关键变更

> 日期：2026-03（具体日期见 CHANGELOG.md）

### 新增功能

- **风格写作系统**：内置 Dan Koe 等创作者风格
- **write 命令**：从想法到完整文章的 AI 辅助写作
- **封面提示词生成**：自动生成匹配文章风格的封面图提示词
- **Prompt Catalog 扩展**：humanizer / refine / image 三类 prompt

### 变更

- **平台适配层分离**：Claude Code skill 和 OpenClaw skill 分开维护
- **确认层强化**：inspect + preview 双层确认机制

### 技术改进

- **AssetPipeline 统一**：图片上传、生成、下载、回填统一管理
- **JSON envelope 标准化**：统一 `success / code / message / schema_version / status / retryable / data / error`

---

## v2.0 核心升级

- 从简单 CLI 工具升级为 **多平台 AI Agent 集成工具**
- 支持 Claude Code、OpenClaw、Obsidian Claudian
- 引入 **风格写作系统** 和 **AI 去痕系统**
- 新增 **小绿书（图片帖子）** 功能
