## 安装方式总览

| 方式 | 推荐场景 | 命令 |
|------|----------|------|
| **Homebrew** | macOS 用户首选 | `brew install geekjourneyx/tap/md2wechat` |
| **go install** | 已有 Go 环境 | `go install github.com/geekjourneyx/md2wechat-skill/cmd/md2wechat@v2.0.5` |
| **curl install.sh** | 其他场景 | `curl -fsSL .../install.sh \| bash` |

---

## macOS / Linux 安装

### 方式一：Homebrew（推荐）

```bash
brew install geekjourneyx/tap/md2wechat
```

### 方式二：curl 安装脚本

```bash
curl -fsSL https://github.com/geekjourneyx/md2wechat-skill/releases/download/v2.0.5/install.sh | bash
```

**默认安装路径**：
- macOS / Linux: `~/.local/bin/md2wechat`
- Windows: `C:\Program Files\md2wechat\md2wechat.exe`

**安装后配置 PATH**：

```bash
export PATH="$HOME/.local/bin:$PATH"
md2wechat version --json
```

```powershell
$env:MD2WECHAT_RELEASE_BASE_URL = "https://github.com/geekjourneyx/md2wechat-skill/releases/download/v2.0.5"

```

## 配置微信凭证

### 配置文件路径

运行 `md2wechat config init` 后会生成配置文件，按提示打开并填写：

| 配置项 | 是什么 | 在哪获取 |
|--------|--------|----------|
| AppID | 公众号唯一标识 | [微信开发者平台](https://developers.weixin.qq.com/platform) → 开发接口管理 |
| Secret | API 密钥 | 同上，需要管理员权限 |

### 凭证获取指南

详细说明见：[WECHAT-CREDENTIALS.md](https://github.com/geekjourneyx/md2wechat-skill/blob/main/docs/WECHAT-CREDENTIALS.md)

**注意事项**：
- 需要配置 IP 白名单
- AppSecret 需要管理员权限才能查看
- 配好后用 `md2wechat capabilities --json` 验证
