## 核心功能

审计并重写内容，移除 AI 写作痕迹（"AI-isms"）。支持 Claude Code / OpenClaw / agentskills.io 兼容智能体。

**输出四段式**：
1. **Issues found** — 识别每个 AI-ism，附原文引用
2. **Rewritten version** — 干净版本
3. **What changed** — 改动摘要
4. **Second-pass audit** — 第二轮复查，捕捉首轮遗漏

**技术亮点**：
- 109 词替换表（三层分级，降低误报）
- 36 类 AI 写作模式检测
- 两轮检测机制
- 节奏/均匀度检测
- 按场景（linkedin/blog/investor-email/docs）调整严格度

## 快速使用

安装到 Claude Code：

```bash
git clone https://github.com/conorbronsdon/avoid-ai-writing ~/.claude/skills/avoid-ai-writing
```

触发指令：
- "Remove AI-isms from this post"
- "Audit this draft for AI tells"
- "Make this sound less like AI"
