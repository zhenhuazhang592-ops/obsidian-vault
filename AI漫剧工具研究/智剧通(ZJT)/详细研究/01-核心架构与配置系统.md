# ZJT（智剧通）核心架构与配置系统详细研究报告

## 一、整体架构概述

ZJT 是一个基于 FastAPI 构建的 AI 短剧制作平台，核心文件 `server.py` 超过 7000 行，集成了视频生成、图片编辑、音频处理、数字人等多种 AI 能力。

### 1.1 项目定位
- **应用名称**：ComfyUI Qwen Image Edit Proxy（FastAPI 应用标题）
- **功能定位**：AI 短剧一站式制作平台，涵盖 AI 工具、剧本管理、视频工作流、剪映导出

### 1.2 技术栈
| 组件 | 技术选型 |
|------|---------|
| Web 框架 | FastAPI + Uvicorn |
| 数据库 | SQLite/PostgreSQL + Alembic 迁移 |
| 外部服务 | RunningHub、多米 API、Sora2、Vidu 等 |
| 监控告警 | Sentry |
| 调度器 | APScheduler（task/scheduler.py） |

### 2.2 文件上传处理

**`_write_and_validate_image` 函数**（行 86-100）：
```python
def _write_and_validate_image(content: bytes, save_path: str):
    """写入图片文件并用 PIL 验证完整性（同步函数，需在线程池中调用）"""
    tmp_fd, tmp_path = tempfile.mkstemp(dir=os.path.dirname(save_path), suffix='.tmp')
    try:
        with os.fdopen(tmp_fd, 'wb') as f:
            f.write(content)
        from PIL import Image
        with Image.open(tmp_path) as img:
            img.load()  # 验证图片完整性
        os.replace(tmp_path, save_path)
    except Exception:
        if os.path.exists(tmp_path):
            os.unlink(tmp_path)
        raise
```

**设计亮点**：
- 原子性写入：先写临时文件，验证通过后 `os.replace()`
- PIL 完整性校验：`img.load()` 会解码整个图片，损坏文件会抛出异常
- 异常清理：失败时自动删除临时文件

### 2.3 权限检查机制

**`_check_resource_permission` 函数**（行 140-158）：
```python
def _check_resource_permission(resource, user_id: int, action: str) -> bool:
    if Edition.is_community():
        if action == Action.DELETE:
            return getattr(resource, 'user_id', None) == user_id
        return True  # 社区版：非删除操作全部放行
    else:
        return getattr(resource, 'user_id', None) == user_id
```

**权限模型**：
| 版本 | 查看/编辑权限 | 删除权限 |
|------|-------------|---------|
| 社区版（Community） | 全部放行 | 仅创建者可删除 |
| 商业版（Enterprise） | 仅创建者可访问 | 仅创建者可删除 |

## 六、设计模式与架构亮点

### 6.1 声明式配置模式

**优点**：
- 所有任务类型集中在一个列表中定义，新增/修改任务无需改动代码逻辑
- 配置即代码，通过 `validate_configs()` 自动验证完整性
- 类型安全，使用 dataclass + 类型注解

### 6.2 算力抽象层

**两种计费模式**：
```python
# 固定算力
computing_power = 18  # 无论时长都是 18 算力

# 按时长计费
computing_power = {5: 38, 10: 70}  # 5秒=38算力，10秒=70算力
```

### 6.3 驱动工厂模式

```
任务类型 → DriverKey → DriverImplementation → 实际驱动类
```

### 6.4 前后端配置同步

前端通过 `/api/system/task-configs` 获取所有任务配置，无需硬编码。
