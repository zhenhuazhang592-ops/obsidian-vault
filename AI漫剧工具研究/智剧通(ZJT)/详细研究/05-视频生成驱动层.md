## 一、架构设计

### 1.1 三层工厂架构

```
VideoDriverFactory
├── 第一层：driver_type → UnifiedConfigRegistry → driver_name
├── 第二层：business_driver_name → implementation_driver_name
└── 第三层：implementation_driver_name → 驱动类实例
```

```python
class VideoDriverFactory:
    @classmethod
    def create_driver_by_type(cls, driver_type: int) -> Optional[BaseVideoDriver]:
        # 1. 获取任务配置 (UnifiedConfigRegistry)
        config = UnifiedConfigRegistry.get_by_id(driver_type)
        # 2. 获取业务驱动名称 (config.driver_name)
        business_driver_name = config.driver_name
        # 3. 获取实现驱动名称 (config.implementation)
        implementation_driver_name = UnifiedConfigRegistry.get_implementation(business_driver_name)
        # 4. 创建驱动实例
        driver_class = cls._registered_drivers.get(implementation_driver_name)
        return driver_class() if driver_class else None
```

## 四、RunningHub 并发控制

### 4.1 槽位机制

```python
class RunningHubSlotManager:
    def __init__(self, max_slots: int = 3):
        self.max_slots = max_slots
        self.used_slots = {}

    def acquire_slot(self) -> Optional[str]:
        """获取可用槽位，返回槽位ID"""
        for i in range(self.max_slots):
            slot_id = f"slot_{i}"
            if slot_id not in self.used_slots:
                self.used_slots[slot_id] = True
                return slot_id
        return None

    def release_slot(self, slot_id: str):
        """释放槽位"""
        if slot_id in self.used_slots:
            del self.used_slots[slot_id]
```

### 4.2 槽位等待

```python
def wait_for_slot(self, timeout: int = 300) -> bool:
    """等待可用槽位"""
    start_time = time.time()
    while time.time() - start_time < timeout:
        slot_id = self.acquire_slot()
        if slot_id:
            return True
        time.sleep(5)
    return False
```

    """轮询视频任务状态"""
    while True:
        status = self.driver.check_status(task_id)
        if status["status"] in [TaskStatus.SUCCESS, TaskStatus.FAILED]:
