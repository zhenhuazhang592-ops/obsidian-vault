# ZJT（智剧通）· 数据库模型层详细研究报告

## 一、数据库基础设施

### 1.1 技术选型

**PyMySQL + DictCursor**（返回字典而非元组）

### 1.2 核心方法

| 方法 | 用途 | 事务特性 |
|------|------|----------|
| `get_db_connection()` | Context Manager 获取连接 | 手动关闭 |
| `execute_query()` | SELECT 查询 | 隐式 commit |
| `execute_update()` | INSERT/UPDATE/DELETE | 显式 commit |
| `execute_insert()` | INSERT 并返回 lastrowid | 显式 commit |

## 六、关键设计模式

### 6.1 CRUD 模式统一

所有 Model 类遵循统一模式：
```python
class XxxModel:
    @staticmethod
    def create(...) -> int:          # 插入
    @staticmethod
    def get_by_id(id) -> Xxx:        # 单条查询
    @staticmethod
    def list_xxx(...) -> Dict:       # 分页查询
    @staticmethod
    def update(id, **kwargs) -> int: # 更新
    @staticmethod
    def delete(id) -> int:           # 删除
```

### 6.2 并发安全

使用 `INSERT ... ON DUPLICATE KEY UPDATE` 解决竞态条件（character/location/props/computing_power）。

### 6.3 分页统一返回格式

```python
{
    'total': int,      # 总记录数
    'page': int,       # 当前页
    'page_size': int,  # 每页大小
    'data': List[...]  # 数据列表
}
```

## 七、与漫舟系统的差异分析

| 维度 | ZJT 系统 | 漫舟系统 |
|------|----------|----------|
| **存储层** | MySQL 数据库，完整 CRUD | Markdown 文件，无数据库 |
| **角色参考图** | 存储为 URL/路径字符串 | 存于 Prompt 中，非持久化 |
| **场景树** | `parent_id` 自引用 + `get_tree_by_world()` | 无结构化存储 |
| **多集剧本** | `episode_number` 字段 + 分页查询 | 单一 Markdown 文件 |
| **算力系统** | 完整算力+日志+订单体系 | 无 |
| **任务队列** | `tasks` 表 + 状态机 + 延迟触发 | 无 |
| **数据隔离** | 商业版 `user_id` 过滤 | 无 |
| **事务支持** | PyMySQL 事务 | 无 |

**漫舟需要补齐的核心能力**：
- 数据库层（推荐 PostgreSQL 或 SQLite）
- 资产持久化存储（角色参考图、场景参考图）
- 算力/积分系统
- 异步任务队列
