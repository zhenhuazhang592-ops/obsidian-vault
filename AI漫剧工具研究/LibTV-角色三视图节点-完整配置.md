## 三、配置参数详解

### 3.1 params 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 模型 ID，如 `qwen-vl-plus` 或 `multiple-angles` |
| `scene` | string | 是 | 场景类型，如 `multiple-angles` |
| `prompt` | string | 否 | 生成提示词 |
| `aspectRatio` | string | 否 | 画面比例，如 `16:9`、`9:16`、`1:1` |
| `count` | number | 否 | 生成数量，默认 1 |
| `characterName` | string | 是 | 角色名称 |
| `characterDesc` | string | 是 | 角色详细描述（外貌、服装、表情等） |
| `refImage` | string | 否 | 参考图像 URL（用于角色一致性） |
| `imageList` | array | 否 | 输入图片来源 |
| `textList` | array | 否 | 输入文本来源 |

### 3.2 参考图像结构（推测）

```typescript
refImage: {
  url: string,           // 参考图 URL
  maskUrl?: string,      // mask 图 URL（用于局部一致）
  strength?: number       // 参考强度 0-1
}
```

## 六、角色一致性方案

### 6.1 多角度参考图方案（Qwen VL Plus）

基于截图观察，LibTV 使用 **Qwen VL Plus** 模型实现角色三视图：

```
┌─────────────────────────────────────────┐
│  参考图输入                              │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐       │
│  │正面 │ │侧面 │ │背面 │ │表情 │       │
│  └─────┘ └─────┘ └─────┘ └─────┘       │
│      ↓                                    │
│  Qwen VL Plus 多角度推理                  │
│      ↓                                    │
│  输出四视角一致的角色图                    │
└─────────────────────────────────────────┘
```

### 6.2 技术实现推测

1. **参考图输入**：用户上传一张角色参考图
2. **Prompt 控制**：通过详细的角色描述（服装、发型、特征）确保一致性
3. **多角度推理**：Qwen VL Plus 模型基于参考图和描述生成多视角
4. **可能的技术**：LoRA / IP-Adapter / ControlNet

### 6.3 角色描述模板

```
[角色名]
- 身份: [身份描述]
- 外貌: [面部特征、身材]
- 服装: [服装造型、装饰细节]
- 表情: [习惯表情、微表情]
- 视角: [摄影角度、光线一致性]

示例：
沈昭昭
- 身份: 唐朝宫女，翰林院才女
- 外貌: 鹅蛋脸，柳叶眉，双眸含情
- 服装: 淡绿色宫装，头戴珠翠
- 表情: 端庄典雅，偶尔微笑
- 视角: 正面/侧面/背面，光线柔和
```

## 九、总结

LibTV 的角色三视图节点是一个基于 **Qwen VL Plus** 模型的智能角色多角度生成器，核心特点：

1. **输入灵活**：支持角色名称、参考图、详细描述
2. **多角度生成**：一次生成正面、侧面、背面的角色图
3. **角色一致性**：通过参考图确保多张图片的角色一致性
4. **可视化配置**：通过配置面板选择模型、设置比例、管理参考图
5. **实时预览**：生成结果直接在节点内预览
