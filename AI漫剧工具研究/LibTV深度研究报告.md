## 核心发现

### 一、产品定位：一站式创作基础设施

LibTV 并非简单的"文生视频"工具，而是一个**定位为"人类创作者 + AI Agent"双入口的一站式内容创作社区**。

**核心特点：**
- **双入口结构：** 从产品设计第一天起，就将人和智能体（Agent）视为平等的调用者
- **从线性到结构化：** 不同于传统对话式AI，采用**"无限画布 + 节点式工作流"**，将漫剧创作的剧本、分镜、角色设定、剪辑等环节整合在同一空间
- **平台化野心：** LiblibAI 致力于构建 AI 创作基础设施，整合行业内分散的模型、工具与流程

**公司背景：**
- LiblibAI 成立于2023年
- 2025年10月完成**1.3亿美元B轮融资**（国内AI应用赛道最大一笔）
- 目前聚集超过**2000万创作者**，拥有超**10万款**原创风格模型

### 二、核心功能：解决漫剧创作痛点

LibTV 提供了多项行业首创或独家的专业功能：

| 功能 | 描述 | 解决的问题 |
|------|------|-----------|
| **角色三视图生成** | 仅需一张参考图，即可生成稳定的正面、侧面、背面视图 | 解决镜头切换时角色"换脸"问题 |
| **9/25宫格连贯分镜** | 一键生成海量故事板，支持切分为独立图片 | 提高镜头语言规划效率 |
| **剧情推演（-3秒/+5秒）** | 基于参考图自动补全叙事链 | 解决画面连贯性问题 |
| **专业级镜头/打光控制** | 内置摄像机控制，支持焦距、光圈、水平环绕、垂直俯仰调节 | 模拟真实影视机位调度 |
| **多宫格切分器** | 独家功能，一键切分9宫格/25宫格多角度分镜 | 批量选择镜头生成视频 |
| **工作流复用** | 将节点串联打包为工作流模板，添加到工具箱 | 复刻爆款风格，快速批量生产 |

### 三、工作流：人类审美与Agent执行的协同

#### 人类创作者工作流
```
故事大纲 → 创意脚本生成 → 批量生成分镜图 → 选择图像模型生成 → 分镜转视频 → 配乐 → 剪辑导出
```

- 在无限画布上通过节点（文本、图片、视频、音频、脚本）自由连线
- 支持对单一分镜的反复重跑和局部修改
- 工作流可打包复用，形成可沉淀的"生产线"

#### Agent 自动工作流（OpenClaw等）
```
一句话指令 → Agent自动创建项目 → 搭建节点 → 编排分镜 → 完成渲染 → 人类验收
```

### 四、API能力：libtv-skills

LibTV 开发了专门针对 AI Agent 的 **libtv-skills**：

**核心指令集：**
- `create_session` - 创建/发送消息
- `query_session` - 查询进展
- `change_project` - 切换项目
- `upload_file` - 上传素材
- `download_results` - 批量下载结果

**安装方式：**
```bash
npx skills add libtv-labs/libtv-skills --skill libtv-skill
```

**配置方式：**
```bash
export LIBTV_ACCESS_KEY="your-access-key"
```

**支持的Agent平台：**
- OpenClaw（小龙虾）
- Autoclaw（澳龙）
- Kimi Claw
- MaxClaw
- QClaw
- ClawHub

| 维度 | 漫剧工坊 | LibTV |

| **定价** | 需自备各平台API | 平台整合，低价量大 |

**LibTV核心优势：**
1. **Agent原生支持** - 从第一天就考虑人和Agent双入口
2. **工作流可复用** - 一次调试，长期复利
3. **独家功能** - 多宫格切分、剧情推演等专业工具
4. **模型整合** - 集成全网顶级模型，一站式调用
