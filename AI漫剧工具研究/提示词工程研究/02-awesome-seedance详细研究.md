## 一、项目定位

**Awesome Seedance 2.0** 是字节跳动 **Seedance 2.0（即梦）** 视频生成平台的优质提示词精选集。

### 核心能力矩阵
| 能力维度 | 描述 |
|---------|------|
| 电影级分镜 | 多镜头时序编排、导演级运镜指令 |
| 角色一致性 | 参考图维持角色外观稳定 |
| 口型同步 | 字幕与唇形精确匹配 |
| 风格迁移 | 动漫/写实/梵高风等多种风格 |
| 商业应用 | 广告/带货/短剧等9大商用场景 |

## 二、Seedance提示词核心设计模式

### 2.1 标准结构模板

```markdown
【风格】风格定义（好莱坞/短剧/动漫等）
【时长】X秒

【人物】角色描述（含外貌/服装/表情特征）

[00:00-00:05] 镜头1：景别（特写/中景/远景）
场景：环境描述
动作：角色行为
关键细节：视觉焦点
【口型/字幕】："对白内容"

[00:05-00:10] 镜头2：景别
...
```

### 2.2 七大结构要素

| 要素 | 语法 | 示例 |
|------|------|------|
| **风格定义** | `【风格】` 或 `[Film Style]` | 好莱坞专业赛车电影风格 |
| **时长控制** | `【时长】` | 15秒 |
| **时间轴** | `[00:00-00:05]` | 每镜头独立时间码 |
| **景别标注** | 镜头编号后标注 | 特写/中景/远景/极远景 |
| **动作描述** | `[Action]` | 主角紧握方向盘 |
| **对白标注** | `【口型/字幕】` 或 `Dialogue Cue` | 口型与字幕逐字一致 |
| **技术参数** | `[Technical Parameters]` | 浅景深/偏色/情感强烈 |

## 四、运镜指令集

### 运动类型
- **推（Zoom In）**：聚焦紧张感
- **拉（Zoom Out）**：揭示环境
- **摇（Pan/Tilt）**：扫描场景
- **移（Dolly/Tracking）**：跟随主体
- **旋转（Orbit）**：营造动感
- **手持（Handheld）**：伪纪录片感

### 速度控制
- **慢动作（Slow Motion）**：高潮时刻
- **快切（Fast Cut）**：紧张节奏
- **定格（Freeze）**：强调瞬间

### 特效词汇
- 运动模糊（Motion Blur）
- 抽帧效果（Frame Stepping）
- 慢速快门拖影（Slow-shutter Drag Shadow）

## 五、电影风格模板库

### 5.1 好莱坞勒芒风格

```markdown
风格：好莱坞专业赛车电影（勒芒风格），电影感夜晚，雨天，高风险运动。
时长：15秒。

[00-05s] 镜头1：内景/特写
雨水拍打着高科技赛车的挡风玻璃。老赛车手（戴头盔）看过来，冷静而专注。
对白提示：他微微点头，低声说："出发吧。"

[10-15s] 镜头3：远景动作
起跑灯变绿。两辆车在潮湿的沥青路面上同步加速。
运动模糊将体育场的灯光变成了长长的彩色线条。
```

### 5.2 维伦纽瓦史诗沙漠

```markdown
风格：IMAX 70mm胶片，维伦纽瓦风格，颗粒写实，史诗规模，低饱和度。
时长：15秒

[00-05s] 极远景（规模感）
巨大的沙尘暴吞没沙漠，装甲军用车队疯狂逃离。

[05-10s] 驾驶舱视角（恐慌）
镜头剧烈晃动，沙子拍打挡风玻璃。

[10-15s] 跳跃（高潮）
漫游车冲上沙丘腾空（慢动作），切黑落地。
```

### 5.3 王家卫雨夜情感戏（对漫舟最有参考价值）

```markdown
【电影风格】90年代香港艺术电影风格，复古胶片感，高ISO颗粒，
           暧昧的黄绿色调，抽帧效果，忧郁氛围。

【核心对白】"如果记忆是一个罐头，我希望它永远不会过期。"

[00:00-00:04] 镜头1：透过玻璃窥视
场景：雨覆盖的红色公共电话亭
视觉效果：透过玻璃折射，眼神空洞却饱含深情
技术参数：模拟手持摄影机，浅景深

[00:04-00:07] 镜头2：极端特写与微表情
情感映射：展现"想触碰却收回手"的极致克制与孤独

[00:07-00:10] 镜头3：招牌慢速快门拖影
视觉效果：抽帧效果+动态模糊，背景车灯形成拉长的光轨
```
