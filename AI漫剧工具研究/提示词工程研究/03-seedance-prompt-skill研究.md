## 一、项目定位

**Seedance Video Prompt Skill** 是一个 Claude Code 自定义 Skill，让 Claude 成为专业的 AI 视频提示词工程师，专为字节跳动 **Seedance 2.0（即梦）** 视频生成平台打造。

### 核心价值
- 用户用自然语言描述创意 → Skill自动生成结构化提示词 → 直接复制到即梦平台使用

---

## 二、十大核心能力

| # | 能力 | 说明 |
|---|------|------|
| 1 | **纯文本生成** | 无需任何参考素材，纯靠文字描述生成视频 |
| 2 | **一致性控制** | 上传参考图片，保持角色/产品/场景在多镜头间的统一 |
| 3 | **运镜与动作复刻** | 上传参考视频，精准复刻镜头语言、复杂动作和节奏变化 |
| 4 | **创意模板/特效复刻** | 模仿参考视频的创意转场、广告成片、电影片段 |
| 5 | **剧情创作/补全** | 根据分镜图片或脚本自动生成完整剧情 |
| 6 | **视频延长** | 对已有视频进行前向或后向平滑延长 |
| 7 | **声音控制** | 音色参考、对白生成、音效设计 |
| 8 | **一镜到底** | 生成连贯长镜头，从一个场景平滑过渡到另一个场景 |
| 9 | **视频编辑** | 基于已有视频进行角色替换、剧情颠覆、元素增减 |
| 10 | **音乐卡点** | 让画面节奏与音乐节拍精准匹配 |

## 三、四步工作流

```
第一步：描述创意 → "一段古风武侠打斗"
第二步：确认参数 → Claude询问时长、比例、参考素材、风格偏好
第三步：生成提示词 → ≤15秒生成2-3个版本，>15秒输出多段拼接方案
第四步：微调优化 → 调整时间段画面、镜头语言、台词、音效或风格
```

## 四、多模态引用系统

支持 Seedance 2.0 的 `@` 引用语法：

```
@图片1 ~ @图片9  — 角色参考、场景背景、首帧/尾帧控制
@视频1 ~ @视频3  — 运镜、动作、特效、节奏参考
@音频1 ~ @音频3  — 背景音乐、音色、音效参考
```

### 引用示例
```
@图片1中的可口可乐饮料，360度高速旋转2圈后，突然停住蓄力分裂成了3个部分进行展示。
参考素材：
- @图片1：可乐产品正面高清图
```

## 五、高级技巧

### 时间戳分镜法
按秒精确控制15秒视频的每个镜头：
```
0-3秒：低角度特写主角蓝袍衣摆被热浪吹得猎猎飘动...
4-8秒：环绕摇镜快切，主角旋身挥剑...
9-12秒：仰拍拉远定格慢放...
13-15秒：缓推特写主角落地收剑的姿态...
```

### 技术参数声明
在提示词开头声明画幅比、帧率、色调、镜头风格：
```
禁止项声明：明确排除不需要的元素（水印、字幕、Logo等）
```

### 超长视频分段拼接
超过15秒自动拆分多段，附带衔接点描述：
```
第1段（0-15秒）—— 正常生成
衔接点：本段结尾画面：剑修正面持剑站在山巅...
第2段（15-30秒）—— 视频延长（上传第1段为@视频1）
```

## 六、场景化提示词策略

| 场景类型 | 提示词策略 |
|---------|-----------|
| **电商/广告** | 产品360度旋转展示、爆炸分解、3D渲染特效 |
| **短剧/对白** | 剧本化场景，含角色台词、情绪标注和音效设计 |
| **仙侠/奇幻动画** | 电影级武打、法术特效、变身变装序列 |
| **科普教学** | 4K医学CGI、半透明人体结构可视化 |
| **MV/音乐卡点** | 宽银幕构图、多图卡点参考视频节奏 |

## 七、平台规格（Seedance 2.0）

| 维度 | 规格 |
|------|------|
| 图片输入 | jpeg/png/webp/bmp/tiff/gif，最多9张，单张<30MB |
| 视频输入 | mp4/mov，最多3个，总时长2-15秒，单个<50MB，分辨率480p-720p |
| 音频输入 | mp3/wav，最多3个，总时长≤15秒，单个<15MB |
| 文本输入 | 自然语言描述 |
| 文件上限 | 最多12个文件（图片+视频+音频合计） |
| 生成时长 | 4-15秒，可自由选择 |
| 声音输出 | 自带音效/配乐 |
| 分辨率 | 支持2K输出 |
| **禁止项** | 不支持上传写实真人脸部素材 |

## 八、最佳实践

1. **描述要具体有画面感** — "穿红风衣的女人走过雨后霓虹闪烁的街道"远比"一个女人在走路"效果好
2. **13-15秒视频使用时间戳分镜** — 按秒划分镜头，精确控制每段画面内容
3. **台词和音效单独描述** — 与画面描述分行书写，结构更清晰
4. **结尾添加禁止项** — 如"禁止出现水印、字幕、Logo"
5. **参考图片风格要匹配主题** — 古风用水墨风格，赛博朋克用科幻CG
6. **超过15秒自动拆分** — 每段之间附带画面衔接点描述
7. **台词用引号包裹** — 并标注角色名称和情绪（如"总裁，卑微慌乱"）
8. **情绪氛围不要忽略** — 情绪和氛围的描述对最终效果影响很大

## 九、对漫舟的对比分析

### 与漫舟v6.2 videoPrompt的对比

| 维度 | seedance-prompt-skill | 漫舟v6.2 |
|------|----------------------|---------|
| 引用系统 | `@图片1`-`@图片9` | CDP char_XX/loc_XX/item_XX |
| 时间轴 | `[00:00-00:05]` 秒级 | 有时长，无精确秒级 |
| 运镜 | 自然语言 | Yaw/Pitch/Dolly数值 |
| 口型同步 | 台词逐字+情绪标注 | Lip-sync viseme标注 |
| 音效 | 音效单独描述 | Audio Layer四分栏 |
| 情感 | 情感映射字段 | 情绪曲线 |

### 核心差距
1. **漫舟缺少秒级时间轴** — seedance的时间戳分镜比漫舟更精细
2. **漫舟CDP引用语法与Seedance不兼容** — 需要对齐`@`引用语法
3. **漫舟情感映射弱于seedance** — seedance有明确的"情感映射"字段
