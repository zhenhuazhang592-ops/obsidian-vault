## 一、产品定位

**StarVideo 2.0** 是 LibTV 推出的专业 AI 短剧制作工具，定位为**智能短剧工作台**。

slogan：**一键将小说转换为专业级短剧视频**

---

## 二、5步制作流程（核心价值链）

```
小说内容  →  一键转换为剧本
    ↓
脚本创作  →  智能生成分镜脚本
    ↓
分镜脚本  →  角色管理（角色库 / 形象参考 / 声音设定）
    ↓
角色管理  →  智能AI视频生成
    ↓
智能生成  →  后期剪辑（AI自动剪辑 / AI配乐 / AI音效）
```

### 2.1 步骤详解

| 步骤 | 输入 | 产出 | 关键技术 |
|------|------|------|----------|
| 1. 小说内容 | 原始小说文本 | 结构化剧本 | NLP 小说解析 |
| 2. 脚本创作 | 剧本 | 分镜脚本（镜头级） | 分镜生成模型 |
| 3. 分镜脚本 | 分镜 JSON | 角色库 + 形象参考 + 声音设定 | 角色一致性引擎 |
| 4. 角色管理 | 角色资产 | AI 生成视频片段 | StarVideo 2.0 底模 |
| 5. 智能生成 | 视频片段 | 成片（配乐+音效+字幕） | 自动剪辑引擎 |

## 三、5大高效工具

### 3.1 剧本大师
- **核心技术**：基于 StarVideo 2.0 底模
- **功能**：一键将小说转换为专业剧本
- **输入**：小说文本（.txt / .docx）
- **输出**：结构化剧本（场景/角色/对话）

### 3.2 分镜大师
- **核心技术**：智能理解镜头语言
- **功能**：自动将剧本拆解为分镜头脚本
- **输出**：镜头列表（景别/运镜/时长/台词）

### 3.3 角色大师
- **核心技术**：统一风格和细节
- **功能**：
  - 角色库管理
  - 形象参考（多角度定妆照）
  - 声音设定（音色/语速/语调）
- **核心挑战**：跨镜头角色一致性

### 3.4 AI角色视频
- **核心技术**：多角色一致性算法
- **功能**：在多个镜头中保持同一角色外观一致
- **支持**：群演分身（同一角色多次出现）

### 3.5 自动剪辑
- **功能**：
  - AI 自动剪辑
  - AI 配乐（情绪曲线匹配）
  - AI 音效（SFX 自动标注）
- **输出**：可发布的完整短剧视频

## 五、模型层详解（5大专用模型）

| 模型 | 职责 | 技术特点 |
|------|------|----------|
| 剧本分析模型 | 解析小说文本，提取场景/角色/冲突 | NLP 大语言模型 |
| 分镜理解模型 | 将剧本转换为镜头级分镜脚本 | 多模态理解 + 影视专业知识 |
| 角色一致性模型 | 保持同一角色跨镜头外观一致 | 参考图驱动 + DNA 特征提取 |
| 视频生成模型 | StarVideo 2.0 底模生成视频 | 自研底模 + 镜头级控制 |
| 智能剪辑模型 | 自动拼接 + 配乐 + 音效 | 时序推理 + 情绪识别 |

## 七、与漫舟系统的对比分析

| 维度 | LibTV StarVideo 2.0 | 漫舟 AI 漫剧工坊 |
|------|---------------------|------------------|
| **流程覆盖** | 5步全链路（小说→成片） | 13个Skill全链路 |
| **剧本解析** | 剧本分析模型 | manzhou-ip-parser |
| **分镜生成** | 分镜理解模型 | manzhou-storyboard |
| **角色一致性** | AI角色视频（多角色一致性） | manzhou-character-consistency（DNA三层锁） |
| **视频生成** | StarVideo 2.0 底模 | Prompt驱动（Seedance/Kling） |
| **后期剪辑** | 自动剪辑+AI配乐+AI音效 | manzhou-audio + manzhou-sfx + manzhou-bgm |
| **视频模型** | 自研 StarVideo 2.0 | 依赖第三方（Seedance/Kling/Wan） |
| **架构模式** | 单平台端到端 | Skill编排跨平台 |
| **存储** | 云端+本地 | Obsidian 本地 |
| **工具集** | 6大工具（批量/合成/画幅/字幕） | 需自建工作流 |

### 7.1 漫舟可借鉴点

1. **视频模型**：StarVideo 2.0 自研底模，深度定制镜头控制；漫舟目前依赖外部 API
2. **角色一致性**：LibTV 的多角色一致性算法值得研究，可补充到 manzhou-character-consistency
3. **自动剪辑**：AI 自动剪辑+配乐+音效三合一；漫舟的 manzhou-audio 可进一步整合
4. **批量生成**：支持批量生成视频片段，漫舟暂无此能力
5. **画幅调整**：内置 16:9 / 9:16 / 1:1 切换；分镜 Skill 建议增加此参数
6. **存储架构**：云端+本地双轨；漫舟可考虑混合存储方案

## 十、结论

StarVideo 2.0 是一个**高度集成的端到端短剧生产平台**，其核心优势在于：

1. **全链路闭环**：从小说文本到成片视频，一站式完成
2. **自研底模**：StarVideo 2.0 底模提供深度定制能力
3. **角色一致性**：多角色跨镜头一致性算法是核心技术壁垒
4. **智能后期**：自动剪辑+配乐+音效，大幅降低后期成本

对漫舟而言，建议优先研究 **角色一致性算法** 和 **自动剪辑模型** 的实现方案，可作为第二期 Skill 优化的重要参考。
