## 一、项目概览

### 1.1 节点结构图

```
                    ┌─ 剧本生成分镜脚本 ──┐
                    │  (AI智能解析)      │
脚本生成器 ─────────┤─ 视频参考生成分镜脚本├────→ 视频合成
  (AI生成)           │  (视频参考)        │         ↓
                    │─ 角色生成分镜脚本 ──┤      视频成片
                    └─ ↑ (角色参考) ────┘

  文本节点
  ├─ 自己编写内容  ────────────────────────────→ 首帧生成视频
  ├─ 文生视频      ──┐                               ↓
  ├─ 图片反推提示词─┤                               ↓
  └─ 文字生音乐   ─┴─────────────────────────────→ 首尾帧生成视频
                                                        ↓
                                                   视频合成
```

### 1.2 节点分组

| 位置 | 节点 | 类型 |
|------|------|------|
| **第一行（AI生成）** | 脚本生成器 | 智能生成 |
| **第二行（分镜转换）** | 剧本生成分镜脚本 / 视频参考生成分镜脚本 / 角色生成分镜脚本 | 转换 |
| **第三行（视频生成）** | 首尾帧生成视频 / 首帧生成视频 / 文生视频 | 生成 |
| **最右（合成）** | 视频合成 | 剪辑 |
| **左侧边栏（素材）** | 自己编写内容 / 图片反推提示词 / 文字生音乐 | 素材 |

## 三、节点间数据流

```
剧本（手动输入或小说导入）
      ↓ @引用素材
脚本生成器（AI生成结构化剧本）
      ↓ @引用素材
剧本生成分镜脚本（拆分为镜头）
首帧图片 ──→ 首帧生成视频 ──┐
      ↓                      ↓
角色三视图（3张角色参考）    ↓
      ↓                      ↓
视频参考 ──→ 视频参考生成分镜脚本
      ↓                      ↓
角色参考 ──→ 角色生成分镜脚本
      ↓ @引用素材            ↓
      └──────────────────────┴──→ 视频合成 → 成片
                                    ↑
首尾帧图片 ──→ 首尾帧生成视频 ──────┘
文字描述 ────→ 文生视频 ────────────┘
音乐描述 ────→ 文字生音乐 ────────────┘（可选配音）

参考音乐 ──→ 文字生音乐（提供风格参考）
参考图片 ──→ 图片反推提示词 → 生成新图片提示词
```

## 六、与漫舟系统的关键差异

| 维度 | LibTV StarVideo 2.0 | 漫舟 AI Drama Studio |
|------|---------------------|---------------------|
| **分镜节点** | 3种分镜节点（剧本/视频/角色）| 1个 manzhou-storyboard |
| **分镜生成** | AI自动拆分镜头 | Prompt 内描述 |
| **节点编排** | 可视化画布+节点+连线 | Skill 串行编排 |
| **节点间数据传递** | `@引用素材` 自动传递 | 手动复制粘贴 |
| **视频模型** | 可灵3.0+O1（内置音效/分镜）| Seedance/Kling（无内置）|
| **摄像机控制** | 可灵O3高级模式 6轴 | Prompt 内描述 |
| **时长控制** | 滑块 3-15秒 | Prompt 内描述 |
| **画幅设置** | 每节点独立设置 | Prompt 内指定 |
| **配音** | 无独立节点 | manzhou-voice VO标签 |
| **BGM** | 文字生音乐节点 | manzhou-bgm BGM标签 |
| **SFX** | 无独立节点 | manzhou-sfx SFX标签 |
| **声音克隆** | 无 | manzhou-voice 独立引擎 |
| **智能分镜** | 可灵O3 `smartStoryboard` | 无 |
| **自动剪辑** | 视频合成节点 | manzhou-audio 三轨整合 |
| **角色一致性** | 角色三视图节点 | manzhou-character-consistency |

## 七、对漫舟的借鉴价值

### 7.1 可直接复用的设计

1. **分镜节点三合一**：剧本/视频/角色三种分镜模式，漫舟可考虑在 manzhou-storyboard 中增加 `参考类型` 字段
2. **画幅/分辨率参数内化**：LibTV 在节点级别设置，漫舟应从 Prompt 内提取为独立字段
3. **智能分镜开关**：`smartStoryboard` = 可灵O3的AI自动分镜建议，漫舟可作为 manzhou-storyboard 的可选功能
4. **内置音效**：`enableSound` = 视频生成时自带音效，可作为 manzhou-storyboard 的一个选项

### 7.2 漫舟独有的优势

| 漫舟独有 | 说明 |
|---------|------|
| VO配音（`voice:`标签）| LibTV 无配音节点 |
| BGM情绪曲线（`[BGM:]`）| LibTV 文字生音乐=纯音乐生成，无情绪曲线 |
| SFX六维音效（`[SFX:]`）| LibTV 无音效节点 |
| 爆款算法（SRL/3-15-30）| LibTV 无此模块 |
| 风控审核（manzhou-safety）| LibTV 无此模块 |
| 声音克隆 | LibTV 无此功能 |
