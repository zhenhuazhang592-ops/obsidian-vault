# 漫舟 vs 智剧通(ZJT) 全面对比分析

> **分析日期**: 2026-03-25
> **分析目的**: 识别漫舟与行业标杆的差距与差异化优势

---

## 一、总览

| 维度 | 漫舟 (Manzhou) | 智剧通 (ZJT) |
|------|---------------|-------------|
| **产品形态** | AI漫剧生产智能体（Skill体系） | 商业SaaS平台 |
| **技术架构** | Markdown Skill + Claude Agent | FastAPI + MySQL + Vue前端 |
| **代码规模** | ~20个Skill文档 | 377个代码文件 |
| **目标用户** | AI/创意团队 | 普通创作者 |
| **商业模式** | 工具链（待商业化） | 算力付费（完整体系） |
| **进化能力** | ✅ 刚建立（进化系统P0-P2） | ❌ 无 |

---

## 二、核心能力对比

### 2.1 剧本解析

| 能力项 | 漫舟 | ZJT | 差距 |
|--------|------|-----|------|
| 解析入口 | `manzhou-shot-script.md` | `parse_script_to_shots()` (1100行) | 漫舟依赖LLM指令，ZJT代码化 |
| 输出格式 | Markdown + 双Prompt | JSON结构化 | ZJT更机器友好 |
| 镜头时长 | 固定15s/镜 | `max_group_duration` 参数可配 | ZJT更灵活 |
| 多人对话 | 合并描写 | **180度轴线+强制拆分** ⭐ | **ZJT领先** |
| 角色引用 | `[ID: TanBin_V1]` | `【【角色名】】` ⭐ | ZJT更直观 |
| 场景嵌套 | 扁平场景 | `parent_id`+树形层级 ⭐ | ZJT更结构化 |
| 道具关联 | 无 | `props_db_id` 数据库关联 ⭐ | ZJT完整 |
| 数据库关联 | 无 | `location_db_id` 强制校验 ⭐ | ZJT完整 |
| JSON健壮性 | 无 | 三层截断修复+日志系统 ⭐ | ZJT完整 |
| 旁白模式 | 无 | `narration_as_dialogue` ⭐ | ZJT完整 |

### 2.2 角色一致性

| 能力项 | 漫舟 | ZJT | 差距 |
|--------|------|-----|------|
| DNA体系 | `dnaAnchors`（配饰/外貌/服装） | `appearance`+`behavior` 分离 | 漫舟更细 |
| 参考图管理 | Prompt内引用，无持久化 | `reference_image` URL持久化 ⭐ | ZJT完整 |
| 情感音色 | `emotion_voices` JSON | `emotion_voices` JSON | 持平 |
| 角色标记 | ID引用 | **【【】】双括号标记** ⭐ | ZJT更标准 |
| 外貌一致性 | DNA锚点描述 | 严禁外貌描写进分镜 ⭐ | ZJT更强制 |
| 跨集复用 | CDP v2.0 (usage_count) ⭐ | world_id隔离 | 持平 |

### 2.3 视频生成

| 能力项 | 漫舟 | ZJT | 差距 |
|--------|------|-----|------|
| 驱动架构 | Prompt拼接 | **三层工厂模式** ⭐ | ZJT更工程化 |
| 供应商数量 | 即梦/可灵/海螺（待集成） | **Sora2/Kling/Vidu/VEO3/LTX2/Wan2.2/数字人** ⭐ | ZJT大幅领先 |
| 图片模式 | 固定首尾帧 | **三种模式（首尾/多参考/混合）** ⭐ | ZJT完整 |
| 宫格生图 | 2x2/3x3在Prompt中 | **宫格拆分+合并算法** ⭐ | ZJT完整 |
| 风格预设 | 16种 `stylePresetId` ⭐ | `visual_style` 字段 | 漫舟更精细 |
| 镜头分组 | 九宫格分镜表 | `shot_groups` 时长重组 ⭐ | ZJT更智能 |
| 并发控制 | 无 | **槽位机制** ⭐ | ZJT完整 |
| 状态轮询 | 无 | APScheduler + 轮询 ⭐ | ZJT完整 |

### 2.4 音频系统

| 能力项 | 漫舟 | ZJT | 差距 |
|--------|------|-----|------|
| TTS生成 | `manzhou-tts-voice.md` 规范 | 完整API+数据库记录 ⭐ | ZJT更工程化 |
| Lip-sync | 唇形同步标注 ⭐ | 无 | **漫舟领先** |
| BGM | Audio Layer注入VideoPrompt | 独立 `background_music` 字段 | ZJT更独立 |
| SFX | Audio Layer注入VideoPrompt | 独立字段 | ZJT更独立 |
| 情感控制 | 情感曲线标注 | **4种情感控制方法（0-3）** ⭐ | ZJT完整 |
| 音效独立 | 合并到Audio Layer | 独立音效轨 ⭐ | ZJT完整 |

### 2.5 剪映导出

| 草稿版本 | 规范定义 | **支持版本号（360000/110.0.0）** ⭐ | ZJT完整 |

## 五、差异化优势总结

### 漫舟独有优势 ⭐

| 优势项 | 说明 |
|--------|------|
| **进化飞轮** | P0(资产库)+P1(效果追踪)+P2(Prompt进化)三系统闭环，ZJT无 |
| **Lip-sync标注** | 分镜脚本内置唇形同步标注，ZJT无 |
| **双Prompt分离** | imagePrompt + videoPrompt 分离，ZJT合并 |
| **九宫格分镜图** | 内置9格故事板生成Prompt，ZJT无 |
| **风格预设精细化** | 16种stylePresetId + 风格后缀参数块，ZJT仅visual_style字段 |
| **效果评分体系** | w1=完播率0.4/w2=点赞率0.25/w3=评论率0.2/w4=分享率0.15，ZJT无 |
| **失败Prompt追踪** | 5类失败类型+防重复机制，ZJT无 |
| **场景类型速查表** | Audio Layer 情绪曲线映射，ZJT无 |
| **CDP全局资产库** | 跨项目ID复用+usage_count追踪，ZJT仅world隔离 |

### ZJT领先领域 ⚠️

| 差距项 | 说明 |
|--------|------|
| **工程化程度** | 377代码文件，完整前后端，漫舟仅Skill文档 |
| **数据库持久化** | MySQL+CRUD+事务，漫舟仅Markdown文件 |
| **多供应商集成** | 7种视频驱动工厂，漫舟待集成 |
| **前端编辑器** | 无限画布可视化，漫舟无 |
| **商业化体系** | 算力/支付/用户，漫舟无 |
| **JSON健壮性** | 截断修复+日志系统，漫舟无 |
| **多人对话拆分** | 180度轴线规则，漫舟无 |
| **多参考图模式** | 三种图片模式，漫舟仅首尾帧 |
| **剪映导出实现** | Python库已实现，漫舟仅规范文档 |

## 七、总结评分

| 维度 | 漫舟 | ZJT | 备注 |
|------|------|-----|------|
| 创意/分镜设计 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ZJT更工程化，漫舟更创意化 |
| 角色一致性 | ⭐⭐⭐ | ⭐⭐⭐⭐ | ZJT更强制，漫舟更描述性 |
| 视频生成 | ⭐⭐ | ⭐⭐⭐⭐⭐ | ZJT大幅领先 |
| 音频系统 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 漫舟Lip-sync领先 |
| 剪映导出 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ZJT已实现，漫舟规范先行 |
| 资产复用 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 漫舟CDP更通用 |
| 进化能力 | ⭐⭐⭐⭐⭐ | ⭐ | **漫舟独有优势** |
| 工程化程度 | ⭐⭐ | ⭐⭐⭐⭐⭐ | ZJT完整SaaS |
| 商业化 | ⭐ | ⭐⭐⭐⭐⭐ | ZJT完整体系 |
| **综合** | **⭐⭐⭐** | **⭐⭐⭐⭐** | ZJT是成熟商业产品，漫舟是智能体工具 |

**结论**: 漫舟在创意设计+Lip-sync+进化能力上有差异化优势；在工程化+商业化+多供应商上落后于ZJT。两者定位不同——ZJT是商业SaaS，漫舟是AI原生智能体工具链。
