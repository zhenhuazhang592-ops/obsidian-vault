## 剧本工作室 - 产品结构

### 三步流程设计

```
Step1: 元素+创意     ✅ 已完成
Step2: 生成大纲      🔄 当前步骤（需要捕获API）
Step3: 分集创作      ⬜ 未开始
```

### 核心UI元素

| 元素 | 说明 |
|------|------|
| 创意输入框 | 用户输入故事核心设定 |
| 集数设置 | 建议20-100集 |
| 模板提示词 | "短剧大纲专用"模板 + 自定义提示词 |
| 补充信息 | 可选补充信息 |
| 总大纲预览 | 生成后在此查看 |
| 生成人物小传 | 可独立生成角色设定 |

### 按钮列表

- 生成总大纲（主按钮，橙色）
- 生成人物小传
- 上一步 / 下一步
- 编辑创意
- 从提示词市场选择
- 刷新
- 查看正文

## 技术推测

### AI生成流程

```
用户输入创意
    ↓
拼接Prompt模板（"短剧大纲专用"模板）
    ↓
补充信息（可选）
    ↓
调用大模型API
    ↓
返回结构化大纲
```

### 提示词模板市场

- 存在"提示词市场"功能
- 可选择不同模板（如"短剧大纲专用"）
- 支持自定义提示词
