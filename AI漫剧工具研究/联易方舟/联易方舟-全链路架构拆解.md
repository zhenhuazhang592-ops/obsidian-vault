## 三、AI剧本创作模块架构

### 3.1 三步流程
```
Step 1: 元素+创意
  └── 用户输入核心故事设定（几百字）
  └── 支持模板提示词选择

Step 2: 生成大纲 ⭐ 核心
  └── 集数设置（20-100集）
  └── 模板提示词（"短剧大纲专用"）
  └── 自定义补充信息
  └── → 输出：总大纲 + 人物小传

Step 3: 分集创作
  └── 选中某集
  └── → 输出：详细剧本（对白+动作+场景）
```

### 3.2 关键技术
```
异步任务队列：
  1. POST 创建任务 → 返回 workflowId
  2. GET /api/workflow/status/{id} → 轮询
  3. 前端显示进度

Prompt拼接：
  模板Prompt + 用户创意 + 集数 + 补充信息
```

### 3.3 架构流程
```
┌──────────────────────────────────────────────────────────────┐
│                      React 前端                               │
├──────────────────────────────────────────────────────────────┤
│  三步引导UI                                                   │
│  Step1: 创意输入 → Step2: 大纲生成 → Step3: 分集剧本         │
│         ↓              ↓              ↓                       │
│    文本输入        异步轮询         AI生成                    │
└──────────────────────┬───────────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────────────┐
│                      API Gateway                               │
├──────────────────────────────────────────────────────────────┤
│  POST /api/workflow/create    → 创建生成任务                   │
│  GET  /api/workflow/status/* → 轮询状态                      │
│  GET  /api/scripts/state     → 脚本状态                      │
└──────────────────────┬───────────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────────────┐
│                      任务队列 (Redis推测)                      │
├──────────────────────────────────────────────────────────────┤
│  任务ID管理 → 状态存储 → 异步处理                            │
└──────────────────────┬───────────────────────────────────────┘
                       │
┌──────────────────────▼───────────────────────────────────────┐
│                      AI 模型层                                 │
├──────────────────────────────────────────────────────────────┤
│  统一AI网关 → 模型适配器 → 50+模型                           │
└──────────────────────────────────────────────────────────────┘
```

## 五、知识库一致性系统

### 5.1 核心功能
```
角色设定管理
世界观构建
力量体系定义
OOC检测（Out Of Character）
```

### 5.2 API支撑
```
/api/knowledge/folders     → 文件夹管理
/api/knowledge/entries      → 知识条目
/api/knowledge/import        → 导入
```

### 5.3 技术实现推测
```
RAG (Retrieval Augmented Generation)
  ├── 向量检索：角色/场景/物品
  ├── 上下文注入：在Prompt中注入相关设定
  └── 一致性校验：生成后检测是否偏离设定
```

## 七、与其他竞品对比

### 7.1 vs LibTV
| 维度 | 联易方舟 | LibTV |
|------|---------|-------|
| 架构 | 异步任务队列 | React Flow节点流 |
| 剧本 | 三步引导 | 可视化节点串联 |
| 知识库 | 独立RAG系统 | 嵌入节点配置 |
| 分镜 | 未集成 | 独立分镜节点 |
| 模型 | 统一AI网关 | 多模型适配器 |
| 交互 | 强引导 | 自由灵活 |

### 7.2 架构差异
```
联易方舟：
  引导式 → 降低门槛 → 适合新手
  固定流程 → 输出稳定

LibTV：
  节点式 → 灵活度高 → 适合专业
  自由串联 → 输出多样
```
