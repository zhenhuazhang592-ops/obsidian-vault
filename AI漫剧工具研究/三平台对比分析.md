# AI 漫剧制作平台三强对比分析

> 对比日期：2026-03-25
> 对比系统：LibTV StarVideo 2.0 / 联易方舟 V3漫剧工作台 / 漫舟 AI Drama Studio
> 研究深度：联易方舟 ⭐⭐⭐⭐⭐（API级）| 漫舟 ⭐⭐⭐⭐⭐（Skill级）| LibTV ⭐⭐（展示层）

---

## 一、系统概览

| 维度 | LibTV StarVideo 2.0 | 联易方舟 V3 | 漫舟 AI Drama Studio |
|------|---------------------|-------------|----------------------|
| **产品形态** | 专业短剧工作台（端到端） | 在线网页工具 | AI Agent Skill 编排系统 |
| **部署方式** | 云端 SaaS | 云端 SaaS | 本地 Obsidian + API 调用 |
| **核心架构** | 自研 StarVideo 2.0 底模 | Prompt 工程 + 第三方 API | 多 Agent 并行编排 |
| **研究深度** | 展示层（截图推断） | API Schema 级（已逆向） | Skill 接口级（全链路测试） |
| **定位** | 一键端到端生产 | Prompt 模板驱动 | AI Agent 智能编排 |

## 二、流程对比

### 2.1 三套系统的制作流程对照

```
【LibTV StarVideo 2.0】← 5步
小说内容 → 剧本 → 分镜脚本 → 角色管理 → AI视频生成 → 后期剪辑（成片）

【联易方舟 V3】← 6步（已知）
全局设置 → 故事脚本 → 资产库 → 分镜脚本 → 分镜视频 → 视频预览

【漫舟 AI Drama Studio】← 13个Skill
IP解析 → 三维剧本 → 分镜Prompt → 角色一致性 → 视觉风格
→ 配音标签 → BGM时间轴 → SFX标注 → 音频整合 → 风控审核
```

### 2.2 流程差异分析

| 环节 | LibTV | 联易方舟 | 漫舟 |
|------|-------|---------|------|
| **小说输入** | 文本导入 | 章节导入（支持多chapters） | 原文转录 |
| **剧本生成** | 一键转换（底模） | Prompt模板生成（CDP改编） | 三维一体剧本（角色/场景/情节） |
| **角色管理** | 角色库 + 形象参考 + 声音设定 | 8角色详细档案（含别名/年龄/外貌/服饰/道具） | DNA三层锁 + 九宫格定妆表 |
| **场景管理** | 未明确 | 8场景 + 30道具（精细化） | 场景Prompt + 视觉风格包 |
| **分镜生成** | 智能理解镜头语言 | 8镜头完整JSON（含imagePrompt/videoPrompt） | 22镜头 + 时长标注 |
| **视频生成** | StarVideo 2.0 底模 | Sora2 / Veo / Seedance（第三方） | Seedance / Kling / Wan（Prompt驱动） |
| **配音** | 声音设定 | 未集成 | 四维VO参数 + 角色配音模板 |
| **BGM** | AI配乐 | 未集成 | Suno/Udio Prompt + 情绪曲线绑定 |
| **音效** | AI音效 | 未集成 | 六维SFX参数 + 场景模板 |
| **后期剪辑** | AI自动剪辑 | 剪映ZIP导出 | 三轨时间轴整合 |
| **风控** | 未明确 | 未明确 | manzhou-safety 专项审核 |

## 三、数据结构对比（核心差异）

### 3.1 资产包结构

**联易方舟 CDP JSON（最完整）**
```json
{
  "meta": { "sourceType", "append", "chapters[]" },
  "settings": { "targetPlatform", "aspectRatio", "stylePreset", "shotDurationSec", "episodeDurationMin" },
  "characters": [{ "id", "name", "aliases[]", "gender", "age", "appearance", "clothing", "persona" }],
  "locations": [{ "id", "name", "description", "props[]" }],
  "items": [{ "id", "name", "description", "appearance" }],
  "shots": [{
    "id", "shotNumber", "durationSec",
    "locationId", "characterIds[]", "itemIds[]",
    "script",           // 镜头描述
    "dialogue[]",       // 对话（speakerId + text）
    "imagePrompt",      // 生图Prompt
    "videoPrompt",      // 生视频Prompt
    "objective",        // 镜头目的
    "action"            // 时序动作（0-5s/5-10s/10-15s）
  }]
}
```

**漫舟 Skill 资产包（分散式）**
```yaml
# 分散在多个独立文件
剧本: [场景/角色/情节]         # manzhou-script 输出
分镜: [镜头/景别/运镜/时长/Prompt]  # manzhou-storyboard 输出
角色: [DNA三层锁/九宫格定妆表]       # manzhou-character-consistency 输出
视觉: [风格包/四维度锚点]           # manzhou-visual-style 输出
配音: [VO参数/音色/语速/语调]        # manzhou-voice 输出
BGM: [情绪曲线/时间戳/Prompt]        # manzhou-bgm 输出
SFX: [音效类型/时长/触发点]          # manzhou-sfx 输出
音频: [三轨时间轴]                   # manzhou-audio 输出
```

**LibTV（数据格式未知，需实测）**

---

### 3.2 镜头结构对比

| 字段 | 联易方舟 | 漫舟 | 说明 |
|------|---------|------|------|
| 镜头ID | `sh_sh1` | `shot_01` | 命名规范不同 |
| 时长 | `durationSec: 15` | `duration: 5-10s`（范围） | 联易方舟固定15s，漫舟范围估算 |
| 角色引用 | `characterIds: ["c_c1"]` | `character: 谭斌` | 联易方舟ID引用，漫舟文本 |
| 场景引用 | `locationId: "l_l1"` | `location: MPL公司写字楼` | 同上 |
| 道具引用 | `itemIds: ["i_i1"]` | `props: ["邮件通知"]` | 联易方舟ID引用 |
| 镜头描述 | `script` | `scene_description` | 字段名不同 |
| 分镜Prompt | `imagePrompt` + `videoPrompt` | `image_prompt` + `video_prompt` | 语义一致，格式不同 |
| 时序动作 | `action: "0-5s...5-10s..."` | `action: "0-3s推入..."` | 联易方舟固定3段，漫舟灵活 |
| 镜头目的 | `objective` | `shot_objective` | 字段名不同 |
| 对话 | `dialogue[{speakerId, text}]` | `dialogue[]` | 联易方舟含speakerId引用 |

## 四、技术架构对比

### 4.1 视频模型层

| 维度 | LibTV | 联易方舟 | 漫舟 |
|------|-------|---------|------|
| **底模** | StarVideo 2.0（自研） | 第三方（gemini/Sora2/Veo等） | Prompt工程驱动 |
| **模型数量** | 单一自研 | 混合多模型 | 混合多模型 |
| **镜头控制** | 深度定制 | API参数控制 | Prompt注入 |
| **一致性** | AI角色视频（多角色） | 参考图机制 | DNA三层锁 |
| **批生成** | 支持批量生成 | 需手动逐条 | 暂无 |
| **画幅切换** | 内置16:9/9:16/1:1 | 固定16:9 | Prompt中指定 |

### 4.2 架构模式

| 系统 | 架构模式 | 优势 | 劣势 |
|------|---------|------|------|
| **LibTV** | 单体端到端 | 用户体验流畅，数据一致 | 封闭，定制受限 |
| **联易方舟** | Prompt模板 + 状态机 | 灵活，可扩展，API可逆向 | 依赖LLM质量，模板维护成本 |
| **漫舟** | 多Agent并行编排 | 可独立迭代，高度可定制 | 需要人工串联，接口契约复杂 |

### 4.3 存储架构

| 维度 | LibTV | 联易方舟 | 漫舟 |
|------|-------|---------|------|
| **存储位置** | 云端 + 本地 | 云端 | Obsidian本地 |
| **数据格式** | 未知 | CDP JSON（API可取） | Markdown + YAML |
| **版本管理** | 未知 | CDP版本历史 | Git兼容 |
| **导出能力** | MP4/MOV/GIF | 剪映ZIP | 需手动组装 |

### 5.3 分镜Prompt质量

以同一素材《格子间女人》P01为例：

**联易方舟**：
```
imagePrompt: 办公室夜景，中景拍摄，谭斌紧皱眉头看电脑屏幕，冷色调灯光下电脑界面清晰
videoPrompt: 中景推镜，谭斌挠头困惑，眼神紧张，手指轻点鼠标，电脑屏幕上邮件弹窗闪烁，氛围压抑。
```

**漫舟**（从测试结果推断）：
```
image_prompt: 办公室内景，深夜，谭斌坐在格子间，中景，冷色调，职业女性，焦虑神情，电脑屏幕发蓝光
video_prompt: 中景推近，谭斌皱眉，揉太阳穴，叹气，目光在屏幕和手机间切换，慢速镜头，压抑氛围
```

**对比**：联易方舟的Prompt更结构化（含景别/运镜/情绪关键词），漫舟的Prompt更注重氛围和情绪描述。

## 九、结论与建议

### 9.1 核心结论

1. **LibTV StarVideo 2.0**：产品体验最完整，但封闭黑盒，不可定制
2. **联易方舟 V3**：数据格式最规范（CDP JSON），API可逆向，是目前最接近"工程化"的方案
3. **漫舟 AI Drama Studio**：流程最完整（13 Skill覆盖全链路），但需要人工串联，资产分散在多个文件

### 9.2 漫舟的优化方向

基于对比分析，建议优化：

1. **接口契约统一**：制定标准资产包Schema，将分散的Skill输出整合为统一的JSON/YAML格式
2. **镜头时长精确化**：从"范围估算"升级为"固定秒数"（参考联易方舟的`durationSec`）
3. **角色ID引用机制**：从"文本名称"升级为"ID引用"（参考联易方舟的`characterIds[]`）
4. **批量生成能力**：补充到分镜Skill或新建`manzhou-batch.md`
5. **画幅参数内化**：从Prompt指定改为独立字段（参考LibTV内置16:9/9:16/1:1）
6. **自动剪辑模块**：当前为手动三轨整合，建议升级为自动时间轴对齐
