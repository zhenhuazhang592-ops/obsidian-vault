## 使用流程

### 创建新项目的步骤

1. **复制模板目录**：将上述目录结构复制到 `comic/` 下
2. **重命名项目文件夹**：如 `02-第二集/`
3. **填写设计文档**：参照模板，填入剧本分析结果
4. **生成角色锚点**：参照 `/_memory/characters/角色锚点模板.md`
5. **创建执行计划**：填入时间线和任务分解
6. **开始制作**：按执行计划逐 Chunk 执行
7. **更新索引**：完成后在 `/_memory/index.md` 添加项目记录

### 快速检查清单

- [ ] 设计文档已批准
- [ ] 所有角色锚点卡已完成
- [ ] 场景参考图已生成
- [ ] 视频生成操作手册已创建
- [ ] 索引已更新
