> 每次写新镜头前，必须回看上一镜的结束状态。

## 镜头衔接标注规则

### 规则1：动作连续性

```
上一镜：老布拿起罐头瓶 → 手在罐头盖上
本镜：老布的 手从罐头盖上移开 → 眉头皱起
     ↑
     起点必须和上一镜结尾一致
```

### 规则2：视线连续性

```
上一镜：老布看向门帘光
本镜：光从门帘透入 → 照在老布脸上
     ↑
     视线方向一致
```

### 规则3：位置连续性

```
上一镜：老布站在货架前
本镜：老布转身 → 仍然在货架前
     ↑
     同一场景，同一位置
```

## 完整示例

### 镜头01：开场

```
## 镜头01

### 基础信息
- **景别**：中景 MS
- **时长**：4秒
- **镜头类型**：固定镜头

### 上一镜衔接
- **上一镜结束状态**：无（开场镜头）
- **本镜起始动作**：无
- **衔接描述**：开场，直接进入场景

### 画面内容
- **场景**：超市生鲜区，傍晚
- **人物**：老布独自站在罐头货架前
- **道具**：罐头货架、暖黄门帘光
- **画面描述**：冷白荧光从头顶投射，暖黄门帘光从右侧斜射入，老布手插兜，目光落在罐头架上

### 动作序列
| 时间 | 动作 | 表情 | 镜头运动 |
|------|------|------|---------|
| 0-2s | 老布站在货架前，手插兜 | 微蹙眉 | 固定 |
| 2-4s | 目光缓缓从左移到右，停在罐头 | 若有所思 | 轻微推 |

### 台词与字幕
- **台词**：无
- **字幕**：无
- **口型标注**：无

### 情绪与节奏
- **情绪**：沉郁、纠结
- **节奏**：慢镜头
- **情绪外化**：冷暖光影对峙 → 对应内心矛盾

### 提示词
```
old_bu, 35-40岁中年男性，微胖圆脸，眼窝深，深灰洗旧卫衣，
手插兜，若有所思，站在超市罐头货架前，
冷白荧光从头顶，暖黄门帘光从右侧斜射入，
新海诚风格，日系动漫，文艺唯美，细腻描边，逆光轮廓光，
中景，人物偏右，左侧货架留白，景深虚化前景罐头瓶，
8K高清，电影感
```

### 备注
- **AI生成难点**：冷暖光影对峙的精确表达
- **需要参考图**：超市生鲜区氛围参考

## 镜头连续性自检清单

> 每个镜头完成后，填写此清单

- [ ] 动作连续性：当前镜头的起始动作 = 上一镜头的结束动作
- [ ] 视线连续性：视线方向在相邻镜头中一致
- [ ] 位置连续性：同一场景内位置一致
- [ ] 服装连续性：服装状态与上一镜头一致
- [ ] 光线连续性：同一场景的光线来源一致
- [ ] 情绪连续性：情绪变化平滑，无断层
