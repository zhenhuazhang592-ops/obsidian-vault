> 每个漫剧角色都必须填写此模板，作为全片一致性的最高保障。

## 使用说明

1. **新建项目时**：复制此模板到 `项目/02-角色/` 下
2. **生成参考图前**：先完成锚点卡文字部分
3. **生成视频时**：将锚点描述加入提示词前缀
4. **一致性检查**：每次生成前对照锚点，偏离即修正

## 示例：老布（草莓与罐头）

```markdown
┌─────────────────────────────────────────────────────────────────┐
│  角色：老布（顾客）                                              │
├─────────────────────────────────────────────────────────────────┤
│  被生活捶打过、渴望确定性的中年男人。                            │
│  代表"罐头"——每一口都是一样的甜，没有意外。                      │
├─────────────────────────────────────────────────────────────────┤
│  参考图：assets/老布-角色参考.png                                │
└─────────────────────────────────────────────────────────────────┘

## 基础信息

- **性别**：男
- **年龄段**：35-40岁
- **职业/身份**：普通上班族/中年顾客
- **性格关键词**：沉静、克制、略微无奈、内心渴望温暖

## 外貌锚点

- **脸型**：微胖圆脸，略带浮肿
- **体型**：微胖，略显疲态
- **发型/发色**：发际线略上移，深色短发
- **眼睛**：眼窝略深，目光温和但略带疲惫
- **其他显著特征**：无特殊饰品，朴素

## 服装锚点

- **上装**：深灰色洗旧卫衣，宽松，袖口略起球
- **下装**：深色休闲裤
- **鞋**：普通运动鞋
- **配饰**：无

## 表情系统

| 情绪 | 表情描述 |
|------|----------|
| 平静 | 微蹙眉，嘴角略微下压，若有所思 |
| 喜悦 | 眼尾微微上扬，但幅度极小 |
| 悲伤 | 眼睑下垂，目光向地面游离 |
| 困惑 | 眉心微皱，目光定在某处 |
| 坚定 | 眉头舒展，目光直视前方 |
| 犹豫 | 眼神游移，嘴唇微抿 |

## 动作习惯

- **站姿**：略微含胸，重心居中偏后
- **走姿**：步速中等，鞋底拖地感
- **手势习惯**：思考时常摸下巴或搓手指
- **其他**：拿起罐头时动作缓慢、仔细端详

## 声音特征

- **音色**：低沉、略带沙哑
- **语速**：偏慢，句子之间有停顿
- **情绪声线**：平静克制，即使激动也压着说

## 视觉符号

- **核心符号**：手握罐头，指尖轻触瓶身
- **色彩倾向**：灰色调，但手部/罐头有暖光
- **光线偏好**：侧光+轮廓光，强调立体感
```

## 示例：店员（草莓与罐头）

```markdown
┌─────────────────────────────────────────────────────────────────┐
│  角色：店员（年轻男性）                                          │
├─────────────────────────────────────────────────────────────────┤
│  年轻店员，代表生活的另一种声音。                                │
│  干净、热情，带着未被磨平的棱角。                                │
├─────────────────────────────────────────────────────────────────┤
│  参考图：assets/店员-角色参考.png                                │
└─────────────────────────────────────────────────────────────────┘

## 基础信息

- **性别**：男
- **年龄段**：25岁左右
- **职业/身份**：超市员工/店员
- **性格关键词**：热情、干净、略微理想主义

## 外貌锚点

- **脸型**：瘦削，下巴略尖
- **体型**：偏瘦，高挑
- **发型/发色**：黑色短发，整齐
- **眼睛**：明亮，眼镜框（黑框）增加书卷气
- **其他显著特征**：黑框眼镜

## 服装锚点

- **上装**：白色超市制服衬衫，干净平整
- **下装**：深色工作裤
- **鞋**：皮鞋或布鞋
- **配饰**：工牌

## 表情系统

| 情绪 | 表情描述 |
|------|----------|
| 平静 | 自然微笑，眼神温和 |
| 喜悦 | 眉眼弯起，露出真诚笑容 |
| 悲伤 | 很少悲伤状态 |
| 困惑 | 眨眼频率加快，轻歪头 |
| 坚定 | 挺直腰背，目光认真 |
| 犹豫 | 挠头或推眼镜 |

## 动作习惯

- **站姿**：挺直，双手常交叠于身前或背后
- **走姿**：步伐轻快
- **手势习惯**：说话时常用手比划
- **其他**：推荐商品时会主动拿起产品

## 声音特征

- **音色**：清亮、年轻
- **语速**：中等偏快，句子流畅
- **情绪声线**：热情但不聒噪

## 视觉符号

- **核心符号**：手中拿着鲜草莓或罐头
- **色彩倾向**：白色制服为主，但与草莓红形成对比
- **光线偏好**：正面光或侧面柔光，强调亲和感
```

## LoRA 训练参数参考

> 如果需要训练角色 LoRA 模型，使用以下参数作为基准。

### 训练数据准备

```
收集数量：15-30 张
角度覆盖：正面/侧面/3/4侧/背面
表情覆盖：平静/喜悦/悲伤/困惑/坚定
光线覆盖：正面光/侧光/逆光
背景：纯色/场景混合
分辨率：512×512 或 768×768
格式：PNG，透明背景优先
```

### LoRA 训练参数（参考）

```
模型基础：Stable Diffusion 1.5 / SDXL / Flux
训练步数：1500-3000 步
学习率：1e-4
Batch size：2-4
分辨率：512 或 768
触发词：[角色名英文] / [角色英文名]_style
正则化：使用同画风的其他角色图作为正则
```

### LoRA 触发词设置

```markdown
触发词命名规范：
- 英文优先：avocado_angel, old_bu, shop_clerk
- 带风格后缀：avocado_angel_v1, old_bu_anime

提示词中使用：
avocado_angel, green wings, medical bag, cute anime style
```

### 角色一致性检查清单

> LoRA 训练完成后，每个镜头生成前必须验证：

- [ ] LoRA 权重在 0.7-0.9 之间（过高会导致过拟合）
- [ ] 参考图放在提示词首部
- [ ] 避免与风格 LoRA 冲突
- [ ] 检查：发型是否一致？服装是否一致？脸型是否一致？

### LoRA 使用提示词模板

```
[LoRA触发词], [角色详细描述],

示例：
```

## 风格锚点

### 新海诚风格规范（默认）

- **光影**：逆光光晕、阳光穿透窗户、光污染城市夜景
- **色调**：低饱和度 + 高光溢出、天空蓝/橙渐变
- **天气**：雨、晨雾、夕阳光
- **材质**：玻璃/水面反光、水渍、烟尘
- **景深**：浅景深虚化背景
- **帧率感知**：流畅但有轻微顿挫感的慢镜头

> 当没有指定风格时，默认使用「新海诚风格规范」
