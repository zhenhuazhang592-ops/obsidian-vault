## AI视频生成工具适配指南

### 即梦 (Jimeng)

适用提示词格式：直接使用上方各镜头提示词作为画面描述，可在描述前添加风格标签：

```
风格：日系动漫电影感，新海诚风格，文艺唯美
角色：老布 - 35-40岁中年男性，深灰卫衣，眼窝深
角色：店员 - 25岁年轻男性，黑框眼镜，白色制服
场景：超市生鲜区，傍晚，冷白荧光+暖橙黄昏光
```

### Seedance / 即梦（首帧参考模式）

使用方法：以分镜图（`storyboard/Shot01-14.png`）作为首帧，提示词描述动态变化：

```
[参考首帧：Shot01.png]
保持角色外观、服装、场景完全一致
动画：从静止到微动（老布手抓后脑勺，呼吸起伏）
光影：保持侧逆光轮廓光效果
时长：3秒
```

### Kling（可灵）

提示词结构适配：

```
【主体】老布（中年男性，深灰卫衣，眼窝略深）
【场景】超市生鲜区，傍晚，冷白荧光灯
【运镜】中近景固定，俯视5度
【动作】单手抓后脑勺，侧身站立
【光效】侧逆光轮廓光，阴影打在半边脸
【氛围】冷调，疲惫纠结的情绪
【时长】3秒
```
