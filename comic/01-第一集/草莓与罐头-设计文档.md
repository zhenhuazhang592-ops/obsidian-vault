# 草莓与罐头 · 第一集漫剧设计文档

> 状态：已批准
> 版本：v1.0

---

## 一、核心创作理念

### 1.1 故事主题

**确定性 vs 可能性。**

老布代表一类人：经历过生活的捶打，渴望"一眼看到头"的安全感。罐头是确定性的隐喻——每一口都是一样的甜，没有意外，也没有惊喜。鲜草莓代表生活的另一种面貌：每天一个口感，每天一个味道，可能甜，可能酸，可能烂。

**核心金句**：
- 店员：「没意外。」
- 老布：「也没惊喜。」

### 1.2 风格定位

新海诚式文艺唯美动漫。冷暖光影对峙，情绪通过环境外化而非台词堆砌。大量留白、慢节奏推拉、光晕氛围贯穿全片。

### 1.3 产出目标

完整视频 + 分镜图卡 + 视频生成提示词 + 音效配乐 + 字幕文案全套交付。

## 二、角色全局一致性规范（约束条件）

> **⚠️ 最高优先级。整个制作过程中所有镜头必须严格遵循以下锚点，任何偏离都将导致角色失真。**

### 2.1 老布（顾客）—— 角色锚点卡

```
┌─────────────────────────────────────────────────────────────────┐
│  角色：老布（顾客）                                              │
├─────────────────────────────────────────────────────────────────┤
│  【身份锚点】                                                    │
│  姓名：老布                                                     │
│  年龄：35-40岁中年男性                                          │
│  性格：疲惫、纠结、执念深、倔强、内心渴望确定性安全感              │
│  背景：经历过生活捶打的中年人，站在人生选择的十字路口             │
├─────────────────────────────────────────────────────────────────┤
│  【外貌锚点】                                                    │
│  脸型：微胖圆脸，略憔悴                                           │
│  眼睛：眼窝略深，眼角有细纹，瞳孔反射灯光/草莓红光时特别标注       │
│  发型：深棕色短发，略有秃顶迹象，发际线后退                       │
│  体型：微胖，不修边幅                                             │
├─────────────────────────────────────────────────────────────────┤
│  【服装锚点】                                                    │
│  上衣：深灰色连帽卫衣，洗到发白，略显松垮                         │
│  下装：深色休闲裤                                                 │
│  鞋子：普通运动鞋                                                 │
│  配饰：无手表/首饰等干扰元素                                      │
├─────────────────────────────────────────────────────────────────┤
│  【表情锚点】                                                    │
│  纠结：眉头微皱，手抓后脑勺，嘴抿成一条线                         │
│  不甘：低头看物，眼睑下垂，阴影打在眼窝                           │
│  倔强：眼神放空但坚定，嘴角微抿                                   │
│  释然：眉头舒展，眼角纹路加深（皱纹反而是释然的体现）             │
│  落寞：背影特写，肩膀微驼，步态沉重                                │
├─────────────────────────────────────────────────────────────────┤
│  【动作锚点】                                                    │
│  纠结时：单手/双手抓后脑勺（招牌动作，全片出现≥3次）              │
│  思考时：低头凝视，目光在罐头和草莓之间游移                       │
│  执念时：单手捏起草莓端详，手指轻轻触碰草莓表面                   │
│  对峙时：身体略微前倾，与店员隔着柜台形成对峙线                   │
│  离去时：单手拎罐头，拨开塑料门帘，步态由犹豫转为确定             │
├─────────────────────────────────────────────────────────────────┤
│  【视角锚点】                                                    │
│  镜头角度：略微俯视5-10度，衬托疲惫感和被生活压住的状态           │
│  景别偏好：特写-中景为主，极少用全景，保持情绪亲密感              │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 道具一致性锚点

| 道具 | 外观描述 | 一致性要求 |
|------|---------|-----------|
| **草莓罐头** | 透明玻璃瓶，金属旋盖，内装红色草莓和糖水，标签为简洁白色 | 全片罐头外观完全一致，不可出现不同品牌/款式 |
| **鲜草莓** | 竹筐盛放，红绿叶相间，表面有水珠，色泽鲜红 | 草莓大小/成熟度每次出现必须一致 |
| **眼镜** | 黑框，镜片透明偏冷调，不可反光 | 店员眼镜全程不变，镜框形状固定 |
| **连帽卫衣** | 深灰色，洗旧感，领口/袖口略有起球 | 老布卫衣全程不变，领口松紧程度一致 |

## 三、场景一致性规范

### 3.1 场景概述

**地点**：社区超市生鲜区，傍晚时分（约17:30-18:00）

**光线特点**：
- 荧光灯：顶部的白色荧光灯管，光线冷白、均匀
- 逆光轮廓光：傍晚从超市门口透入的黄昏余晖，形成侧逆光
- 点缀暖光：背景中暖黄色灯球虚化，增加层次

### 3.2 场景元素锚点

```
┌─────────────────────────────────────────────────────────────────┐
│  【场景锚点清单】                                                │
├─────────────────────────────────────────────────────────────────┤
│  背景                                                           │
│  ├─ 冷柜玻璃：带轻微水汽凝结的玻璃柜门，反射荧光灯               │
│  ├─ 货架：金属货架，白色，深色边缘                                │
│  └─ 地面：浅灰色瓷砖，有轻微反光                                  │
├─────────────────────────────────────────────────────────────────┤
│  左侧货架（老布视角左手边）                                       │
│  └─ 竹筐盛放鲜草莓，红绿相间                                      │
├─────────────────────────────────────────────────────────────────┤
│  右侧货架/柜台                                                   │
│  └─ 整齐排列的草莓罐头，玻璃瓶身反射荧光灯                       │
├─────────────────────────────────────────────────────────────────┤
│  前景                                                           │
│  └─ 塑料门帘，暖黄色灯光从门帘外透入                              │
├─────────────────────────────────────────────────────────────────┤
│  远景                                                           │
│  └─ 超市出口，门外是黄昏街道（暖橙色天空）                        │
├─────────────────────────────────────────────────────────────────┤
│  色调分区                                                       │
│  ├─ 生鲜区核心：冷蓝灰 (#3A4A5C) + 工业白 (#E8E8E8)             │
│  ├─ 草莓筐附近：暖调渗入，#F5A623橙黄色                         │
│  └─ 门外/门帘附近：黄昏暖橙 #FFA500                             │
└─────────────────────────────────────────────────────────────────┘
```

### 3.3 色调一致性约束

| 段落 | 主色调 | 说明 |
|------|--------|------|
| 镜头1-3（纠结） | 冷蓝灰 | 荧光灯主光，人物阴影较重 |
| 镜头4-5（对比） | 冷暖交替 | 草莓筐附近暖调渗入 |
| 镜头6-11（对话） | 冷蓝灰+阴影 | 哲理输出，阴影打在半边脸 |
| 镜头12（天平失衡） | 冷暖快速切换 | 光影闪烁，表现内心挣扎 |
| 镜头13-14（高潮/离去） | 冷暖交汇→暖橙 | 门外暖光逐渐占据画面 |

## 五、声音设计

### 5.1 BGM 设计

| 段落 | 时长 | 音乐描述 | 情绪 |
|------|------|---------|------|
| 开场（镜头1-3） | 3s | 无BGM，只有低频环境音（超市冰柜嗡鸣） | 压抑、纠结 |
| 对比（镜头4-5） | 4s | Ambient缓缓切入，单音阶跳动 | 内心波动 |
| 理性对话（镜头6-10） | 30s | 稳定的电子脉冲律动，节奏缓慢 | 理性、哲理 |
| 挣扎（镜头11-12） | 23s | 极简钢琴点亮，略带忧伤 | 内心独白 |
| 高潮（镜头13） | 14s | 音乐戛然而止，留白 | 释然 |
| 离去（镜头14） | 23s | 沉重的脚步声，街道远处汽笛声 | 落寞 |

### 5.2 环境音效

| 音效 | 出现位置 | 描述 |
|------|---------|------|
| 冰柜嗡鸣 | 镜头1开场 | 低频持续，像生活的底噪 |
| 键盘敲击暂停 | 镜头2 | 店员操作的超市电子秤 |
| 细微呼吸声 | 镜头4 | 草莓特写时，背景若有若无 |
| 脚步声 | 镜头14 | 老布离去时的沉重脚步 |
| 汽笛声 | 镜头14结尾 | 街道远方的城市底噪 |
| 塑料门帘晃动 | 镜头14 | 门帘开合的塑料质感声音 |
