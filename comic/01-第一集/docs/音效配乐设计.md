### 段落音乐设计

| 段落 | 镜头 | 时长 | 音乐类型 | 情绪关键词 |
|------|------|------|---------|-----------|
| **开场** | 1-3 | 6s | 无BGM，只有环境音 | 压抑、纠结 |
| **对比** | 4-5 | 4s | Ambient缓缓切入，单音阶跳动 | 内心波动 |
| **理性对话** | 6-10 | 30s | 稳定电子脉冲律动，节奏缓慢 | 理性、哲理 |
| **挣扎** | 11-12 | 30s | 极简钢琴点亮，略带忧伤 | 内心独白 |
| **高潮** | 13 | 14s | 音乐戛然而止，留白 | 释然 |
| **离去** | 14 | 23s | 环境音为主：脚步声、汽笛声 | 落寞 |

## 二、环境音效清单

| 音效 | 时长 | 出现位置 | 描述 |
|------|------|---------|------|
| **冰柜嗡鸣** | 持续 | 镜头1开场 | 低频持续（50-100Hz），像生活的底噪 |
| **电子秤键盘声** | 1s | 镜头2 | 店员操作的超市电子秤，按下和松开 |

| **Ambient电子音** | 持续 | 镜头3-12 | 单音阶电子脉冲，节奏缓慢 |

| **门帘晃动** | 持续 | 镜头14 | 塑料门帘开合的质感声音 |
| **脚步声** | 持续 | 镜头14 | 老布离去的沉重脚步声 |
| **街道汽笛** | 2s | 镜头14结尾 | 城市远方的汽笛声 |

## 三、配乐风格参考

### 风格关键词（供AI配乐工具使用）

**主风格**：
- 新海诚电影OST
- Japanese Anime Film Score
- Piano + Ambient Electronics
- Cinematic Emotional

**参考作曲家/作品方向**：
- RADWIMPS（《你的名字》《铃芽之旅》OST）
- 久石让（《天空之城》《哈尔的移动城堡》）
- 横山克（日本动漫配乐）
- Satoru Kosaki（《四月是你的谎言》）
- 林友树（《逃避可耻》《Legal High》）

**具体音乐参考方向**：

| 情绪 | 搜索关键词 | 描述 |
|------|-----------|------|
| 理性对话 | 「RADWIMPS 冷静 思考」「久石让 钢琴 克制」 | 稳定电子脉冲 + 钢琴点缀 |
| 内心挣扎 | 「横山克 钢琴 忧伤」「四谎 配乐 钢琴」 | 极简钢琴，略带忧伤 |
| 高潮留白 | 「新海诚 OST 留白」「铃芽之旅 安静」 | 音乐骤停，只剩环境音 |
| 离去 | 「久石让 夕阳 离去」「告别 钢琴 街道」 | 沉重的钢琴，街道环境音 |

**AI配乐工具推荐**：
- **Suno**：输入风格描述词生成BGM
- **AIVA**：选择"日系动漫配乐"风格
- **Udio**：生成情绪化钢琴+电子混合配乐

## 四、音效生成提示词

### 冰柜嗡鸣（持续环境音）

```
生成一段持续的超市冰柜低频嗡鸣声，时长2分钟，频率在50-100Hz之间，
偶尔有压缩机的启动和停止声，环境白噪音风格。
```

### 超市电子秤音效

```
生成超市电子秤按键声：先是按键按下的机械声，然后是电子确认音，
清脆短促，带有轻微回响。
```

### 门帘晃动与环境音

```
生成塑料门帘被拨开的声音，接着是门帘碰撞的塑料声，然后是傍晚街道的环境音：
远处汽车经过、轻微风声、城市底噪。
```
