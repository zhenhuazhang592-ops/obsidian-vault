- 纯色背景（深蓝灰 #2C3E50 或暖橙 #E67E22）

- 上下两句话，中间隔一行空白

## 四、字幕设计规范

| 元素 | 规范 |
|------|------|
| 字体 | 思源黑体 / 思源宋体（推荐） |
| 字号 | 视频高度的 1/20（约40-50pt） |
| 颜色 | 白色 #FFFFFF 或浅米色 #F5F5DC |
| 描边 | 1-2px 黑色描边，便于在亮色背景上阅读 |
| 阴影 | 轻微投影，增加可读性 |
| 位置 | 底部居中，距离底部 10-15% |
| 对齐 | 居中对齐 |
| 行间距 | 1.5倍行距（长字幕分两行时） |
| 留白 | 核心对白（镜头13）字幕之间多留1秒空白 |
