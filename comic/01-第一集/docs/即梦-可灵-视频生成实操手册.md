## 四、后期合成（剪映）

### 步骤1：导入素材

1. 打开**剪映**（手机版或电脑版均可）
2. 点击「**开始创作**」
3. 点击「**导入**」，选择所有14个视频文件
4. 按顺序拖入时间轴

### 步骤2：确认顺序

时间轴上的顺序必须是：

```
Shot01 → Shot02 → Shot03 → Shot04 → Shot05
→ Shot06 → Shot07 → Shot08 → Shot09 → Shot10
→ Shot11 → Shot12 → Shot13 → Shot14
```

### 步骤3：导入字幕

1. 点击「**文本**」→ 「**新建文本**」
2. 在时间轴上拖动，调整每句字幕的出现时间
3. 对照 `docs/字幕时间轴.md` 中的时间
4. 字幕文案如下（直接复制粘贴）：

```
00:00.50  咱们这儿卖得最好的水果是什么呀？
00:03.00  草莓罐头。
00:04.50  最新鲜的？
00:06.00  草莓。
00:08.50  最甜的？
00:10.00  还是草莓。
00:13.00  那它就是最新鲜最甜的呀。
00:21.00  不一定。论新鲜的话，熟透的适合马上吃，偏生的适合放一放再吃。
00:42.00  有可能吃到没熟透酸的，也可能吃到熟过了烂的。
00:50.00  我要的是每一口都很新鲜，每一口都很甜。
00:59.00  一眼看到头。
01:22.00  没意外。
01:27.00  也没惊喜。
01:37.00  给你找个近期的。新鲜。
```

### 步骤4：添加BGM

1. 点击「**音频**」→ 「**导入**」
2. 选择下载好的BGM文件（参考 `docs/音效配乐设计.md`）
3. 或者在剪映「**音频库**」中搜索：
   - 关键词：「**新海诚」「钢琴」「氛围」「忧伤**」
   - 选择符合情绪的钢琴配乐

### 步骤5：导出视频

1. 点击右上角「**导出**」
2. 设置：
   - 分辨率：**1080P**
   - 帧率：**30fps**
   - 格式：**MP4**
3. 导出完成！

## 五、常见问题解决

### 问题1：角色外观不对（老布不像老布/店员不像店员）

**原因**：提示词中的角色描述不够强

**解决**：在提示词最前面加这段固定描述：

老布加这段：
> 「一位35-40岁中年男性，圆脸微胖，眼窝略深，穿深灰色洗旧连帽卫衣（领口略松），深棕色短发略有秃顶，表情疲惫纠结。角色参考：comic/01-第一集/assets/老布-角色参考.png」

店员加这段：
> 「一位25岁年轻男性，瘦削，黑框眼镜，白色超市制服衬衫，袖口挽起，表情平静通透。角色参考：comic/01-第一集/assets/店员-角色参考.png」

---

### 问题2：场景变成了水果店/便利店（不是超市生鲜区）

**原因**：场景描述不够具体

**解决**：在提示词中加入：
> 「背景：超市生鲜区生鲜冷柜，金属货架，白色荧光灯管从天花板垂下，冷柜玻璃门上有轻微水汽凝结。不是水果店，不是便利店。」

---

### 问题3：光线太亮/太暗/没有轮廓光

**原因**：光线描述不够明确

**解决**：提示词中加入：
> 「光线：冷白色荧光灯从头顶均匀照射，人物侧面有逆光轮廓光，半边脸在阴影中」

---

### 问题4：人物动作太大/太小/画面抖动

**原因**：镜头时长不够

**解决**：选择更长的时长（选10秒而非5秒），或者提示词中加入：
> 「轻微动作：微微的呼吸起伏、眼神轻微移动、手指轻触物体表面」

---

### 问题5：风格太写实/太卡通

**原因**：风格参数没选对

**解决**：
- 即梦：风格选「**3D动画**」（一致性最好）
- 如果想要更动漫感，选「**动画**」→「**日式动漫**」
- 提示词中加入：「日式动漫风格、二次元、动画渲染」
