## 一、色彩系统

### 1.1 主情绪色板

| 情绪/概念 | 代表色 | 色值（HEX） | 使用场景 |
|-----------|--------|------------|---------|
| **主色调** | 牛油果绿 | `#5A7247` | 哈斯妃主色、宫廷绿色基调 |
| **辅色调** | 古典金 | `#C4A35A` | 宫殿、皇家装饰、权力象征 |
| **辅色调** | 龙眼褐 | `#8B6914` | 龙眼大帝主色 |
| **强调色** | 榴莲黄 | `#DAA520` | 猫山王皇后、权力高潮 |
| **强调色** | 暗血红 | `#8B3A3A` | 惊悚时刻、宿命感 |
| **冷调辅色** | 暗夜紫 | `#4A3A5A` | 碎玉轩、神秘氛围 |
| **禁忌色** | 纯黑 `#000000` | 避免死黑，新海诚用暗部而非纯黑 |
| **禁忌色** | 荧光色 | 避免霓虹感，保持古典克制 |

### 1.2 色彩比例

```
主色：辅色：强调色 = 45%：40%：15%

例：冷蓝(60%) + 暖橙(30%) + 白(10%)  ← 新海诚常用比例参考
本项目调整为：
- 牛油果绿/古典金（暖调）= 45%
- 龙眼褐/暗夜紫（冷调）= 40%
- 榴莲黄/暗血红（强调）= 15%
```

### 1.3 情绪色彩映射

| 情绪 | 颜色倾向 | 具体色值 | 使用场景 |
|------|---------|---------|---------|
| 悲伤/孤独 | 冷灰绿 | `#7A8B6E` | 哈斯妃被嘲讽时 |
| 希望/温暖 | 暖金绿 | `#A8C4A0` | 杏花微雨场景 |
| 紧张/冲突 | 暗红 | `#8B3A3A` | 替身揭示时 |
| 平静/神秘 | 琥珀金 | `#D4C4A8` | 果林开场 |
| 震惊/冲击 | 暖橙 | `#E8A87C` | 龙眼大帝反应 |
| 威严/压抑 | 深褐金 | `#5A4A2A` | 选秀现场 |

### 1.4 色彩禁忌

- **不使用** 纯黑 `#000000` — 新海诚风格暗部用深紫/深蓝过渡
- **不使用** 高饱和荧光色 — 保持古典克制的色调
- **不使用** 纯白 `#FFFFFF` — 用米白/象牙白代替
- **避免** 大面积纯色平涂 — 需要渐变和光影层次

## 二、构图规则

### 2.1 景别序列

| 景别 | 代码 | 用途 | 使用场景 |
|------|------|------|---------|
| 远景 | EWS | 环境建置、世界观展示 | 果林、丁达尔效应 |
| 全景 | WS | 空间关系、人物位置 | 选秀现场全景、宫殿 |
| 中景 | MS | 对话、关系展示 | 角色对话为主，本集核心景别 |
| 近景 | CU | 情绪聚焦 | 龙眼大帝震惊、哈斯妃微颤 |
| 特写 | ECU | 表情细节、金句时刻 | "像...太像了"、猫山王捏紧扶手 |

**景别切换原则**：
- 对话常用 → `MS↔MS`，以中景为主保持稳定感
- 情绪高点常用 → `MS→CU→ECU` 逐级推进
- 转场常用 → `EWS→WS` 建立新空间
- 关键悬念 → `ECU` 定格

### 2.2 视线规则（180度法则）

```
轴线：相机在轴线一侧，保持180度规则
      角色A ←——————→ 角色B
                ↑
            相机在一侧

轴线规则：
- 龙眼大帝与哈斯妃对话时，相机始终在同一侧
- 哈斯妃位于画面左侧时，相机在左侧；位于右侧时，相机在右侧
- 打破轴线需用中性镜头（侧面MS）过渡
```

### 2.3 三分法应用

- **人物位置**：
  - 猫山王皇后：画面中央偏上（威严）
  - 龙眼大帝：画面右侧1/3（权力视角）
  - 哈斯妃：画面左侧1/3或边缘（被动/边缘化）
- **地平线位置**：上1/3处，留足天空/空间
- **留白规则**：人物朝右看时，右侧留白；朝左看时，左侧留白

### 2.4 构图类型清单

| 构图类型 | 何时使用 | 示例镜头 |
|---------|---------|---------|
| **三分法** | 日常对话、角色定位 | 选秀现场列队 |
| **框架构图** | 强调禁锢感 | 宫门、窗框 |
| **对称构图** | 权威场景 | 猫山王皇后高坐 |
| **对角线构图** | 动态/冲突 | 妃子笑贵妃嘲讽姿态 |
| **留白构图** | 情绪聚焦 | 哈斯妃独自站立 |
| **前景虚化** | 层次感 | 选秀现场前景用果树虚化 |

## 三、角色统一规则

### 3.1 画风锚点

> 本项目核心：水果拟人 + 新海诚细腻光影

- **水果形态**：保持水果基本形态特征（圆形/椭圆形）+人物结构
- **眼睛**：新海诚式大眼，黑瞳占60%，高光点缀
- **线条风格**：流畅细腻，描边用深色（`#2A2A2A`）2px
- **阴影风格**：渐变阴影，颜色偏向环境色
- **果皮质感**：半透明光晕效果，参考真实水果的光泽

### 3.2 角色比例参考

```
整体风格：四头身Q版造型（略萌但不失张力）

头部比例：1/4身高
眼睛位置：脸部1/2以下（可爱感+下垂感）
果柄高度：超出头顶15%（身份标识）

参考：《你的名字》水果角色版
```

## 四、镜头语言规范

### 4.1 镜头运动

| 运动类型 | 触发条件 | 使用场景 | 速度参考 |
|---------|---------|---------|---------|
| 推镜头（Zoom in） | 情绪聚焦 | 龙眼大帝"像...太像了" | 慢推，2秒 |
| 拉镜头（Zoom out） | 揭示环境 | 片尾建立空间 | 慢拉，3秒 |
| 摇镜头（Pan） | 扫视场景 | 选秀现场人物扫过 | 中速，1.5秒 |
| 移镜头（Dolly） | 角色移动 | 哈斯妃缓缓上前 | 极慢，4秒 |
| 跟镜头（Follow） | 角色行走 | 哈斯妃进入碎玉轩 | 中速跟随 |
| 固定镜头（Static） | 对话/情绪 | 猫山王皇后发话 | 静止 |

### 4.2 镜头时长规范

| 镜头类型 | 最短时长 | 最长时长 | 平均时长 |
|---------|---------|---------|---------|
| 静态对话 | 2秒 | 5秒 | 3秒 |
| 动态镜头 | 2秒 | 4秒 | 3秒 |
| 情绪特写 | 1秒 | 3秒 | 2秒 |
| 转场镜头 | 1.5秒 | 3秒 | 2秒 |
| B-roll | 2秒 | 5秒 | 3秒 |

### 4.3 转场方式

| 转场类型 | 何时使用 | 示例 |
|---------|---------|------|
| **硬切** | 同场景快速切换 | 妃子笑贵妃摇扇→哈斯妃低头 |
| **叠化** | 时间/地点跳转 | 选秀现场→碎玉轩黄昏 |
| **淡入淡出** | 大段时间跳转 | 片头/片尾 |
| **划入** | 强调过渡 | 旁白过渡 |
| **空间跳转** | 蒙太奇 | 多个场景快速交代 |

## 五、光影规范

### 5.1 主光设计

| 场景 | 主光类型 | 方向 | 强度 | 色温 |
|------|---------|------|------|------|
| 果林 | 丁达尔光柱 | 顶光+透射 | 强 | 暖白 5500K |
| 选秀现场 | 顶侧光 | 45度下压 | 中强 | 自然光 5000K |
| 碎玉轩 | 窗光 | 侧面 | 柔和 | 暖黄 3500K |

### 5.2 补光规则

- **室内**：自然光（窗户）+ 人工补光（灯笼光）
- **室外**：阳光直射 + 树叶散射
- **阴天**：散射光，无硬阴影

### 5.3 轮廓光/发光效果

> 新海诚风格核心：逆光轮廓光

| 场景 | 轮廓光颜色 | 强度 | 位置 |
|------|-----------|------|------|
| 果林 | 暖黄 `#FFE4B5` | 强 | 叶子边缘发光 |
| 选秀现场 | 金 `#FFD700` | 中 | 人物边缘 |
| 碎玉轩 | 橙黄 `#FFA500` | 弱 | 窗户透射 |

### 5.4 光影情绪表

| 情绪 | 光影处理方式 |
|------|-------------|
| 温暖希望 | 逆光光晕，暖黄透射，丁达尔光柱 |
| 沉郁孤独 | 侧光/顶光，冷调，影子拉长 |
| 紧张冲突 | 硬光，明暗对比强烈，深色阴影 |
| 平静释然 | 柔和散射光，无硬阴影 |
| 震惊冲击 | 突然的正面强光，留白 |

## 七、禁止事项

> 明确列出本项目美术执行中的红线

1. **不使用** 纯黑色暗部 — 必须用深紫/深蓝过渡，违者重画
2. **不使用** 高饱和荧光色 — 保持古典克制的色调
3. **不使用** 迪士尼式圆滑描边 — 必须用深色描边2px保持结构
4. **避免** 大面积纯色平涂 — 需要渐变和光影层次
5. **避免** 角色比例失真 — 保持四头身Q版比例
6. **避免** 水果形态过度简化 — 必须保持水果特征+人物结构的平衡
