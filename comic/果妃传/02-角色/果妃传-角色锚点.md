## 角色1：哈斯妃 `<hassi_princess>`

### 基础信息

| 字段 | 内容 |
|------|------|
| **名称** | 哈斯妃（哈小梨） |
| **物种** | 牛油果 |
| **形态** | 椭圆形，深绿色粗皮，两个黑色圆点眼睛 |
| **服装（本集）** | 墨绿粗布衣（对比其他水果的华丽服饰） |
| **Token** | `<hassi_princess>` |
| **身份** | 碎玉轩·哈氏，选秀入宫 |
| **心理位置** | 迷茫/自卑/被凝视 |

### 外貌锚点

```
外形：椭圆形牛油果，深绿色粗皮（非光滑），两个黑色圆点眼睛
高度：四头身Q版比例
果柄：超出头顶15cm，身份标识
皮肤质感：哑光+轻微纹理
眼睛：新海诚式大眼，黑瞳占60%，高光点缀
```

### 表情系统

| 表情 | 眼睛 | 嘴巴 | 身体语言 |
|------|------|------|----------|
| **默认** | 黑瞳圆点，微眨 | 微弧 | 略微低头 |
| **自卑** | 向下看 | 紧抿 | 肩膀内缩 |
| **震惊** | 眼睛凸出，高光点 | O型微张 | 身体僵住 |
| **空洞** | 蚊香眼/失去高光 | 微微张开 | 身体微颤 |

### 本集关键动作

- 00:30-00:45：站在角落，低头，被嘲讽
- 01:01-01:10：缓缓抬头上前，身体微颤
- 01:18-01:26：抬头直视龙眼大帝
- 02:20-02:28：被火龙果贵人接引，眼神逐渐空洞

### 本集台词

- "碎玉轩...哈氏。"（颤抖）
- *无声动作*：低头/抬首/身体微颤

### 视觉参考角度

| 角度 | 用途 | 数量 |
|------|------|------|
| 正侧面 | 角色卡/亮相 | 1张 |
| 低头视角 | 被嘲讽时 | 1张 |
| 抬头直视 | 与大帝对视 | 1张 |
| 震惊表情 | 龙眼大帝反应时 | 1张 |
| 空洞眼神 | 碎玉轩揭示后 | 1张 |

### 外貌锚点

```
外形：椭圆形榴莲，金黄色外壳，尖刺纹理（但视觉上不恐怖）
```

| 表情 | 眼睛 | 嘴巴 | 身体语言 |
|------|------|------|----------|

| **冰冷（内心）** | 细长，冰冷 | 紧闭 | 手指捏紧扶手 |
| **威胁** | 睁大 | 冷笑 | 身体前倾 |

### 本集关键动作

- 00:53-01:01：微笑，眼神冰冷，手指捏紧扶手
