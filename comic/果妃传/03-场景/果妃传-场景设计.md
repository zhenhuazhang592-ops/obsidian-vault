## 第1集场景详解

### S-01 果林

| 属性 | 内容 |
|------|------|
| **场景描述** | 阳光穿过茂密的果树林，形成丁达尔效应，光柱洒落在草地上 |
| **时间段** | 日间，阳光明媚 |
| **空间类型** | 户外森林，有纵深感 |
| **主要色调** | 暖金 `#D4C4A8` + 深绿 `#5A7247` |
| **情绪氛围** | 神秘/庄严/宿命感 |
| **主要光线** | 顶光+透射光，丁达尔光柱（核心视觉元素） |
| **环境元素** | 果树/光柱/草/蝴蝶/花瓣 |

**氛围描述（用于提示词）**：
```
A mystical fruit forest in anime style, sunlight streaming through dense foliage creating visible light rays (Tyndall effect), warm golden light casting through leaves, lush green canopy, soft atmospheric haze, cinematic composition, Studio Ghibli meets Makoto Shinkai aesthetic, ethereal and serene atmosphere
```

**拍摄建议**：
- 镜头1（00:10-00:20）：远景俯拍，光柱从树冠透射
- 镜头2：仰拍，光柱从天而降

## 场景生成公式

### 户外场景公式
```
[基本场景] + [时间] + [光线] + [情绪] + [构图] + [参考风格]

例：果林 + 日间 + 丁达尔 + 神秘庄严 + 远景俯拍 + 新海诚风格
```

### 室内场景公式
```
[基本场景] + [时间段] + [光源] + [情绪] + [构图] + [参考风格]

例：宫殿 + 日间 + 灯笼光 + 威严压抑 + 三分法 + 宫崎骏风格
```
