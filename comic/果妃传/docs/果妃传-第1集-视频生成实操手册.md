## 即梦操作步骤

### Step 1：登录即梦

1. 打开浏览器，访问 `https://jimeng.jianying.com`
2. 使用抖音账号登录
3. 进入「AI作图」或「AI视频」模块

### Step 2：生成图像

1. 选择「图片生成」
2. 在提示词框粘贴对应镜头的图像提示词
3. 比例选择：16:9（横版视频）
4. 模型选择：推荐「即梦 通用 Pro」
5. 点击「立即生成」
6. 等待3-5分钟，下载高清图片

### Step 3：生成视频（如需要）

1. 选择「视频生成」
2. 上传已生成的图片
3. 在提示词框描述镜头运动（如：缓慢推镜头）
4. 时长选择：5秒/10秒（根据分镜）
5. 点击「生成视频」
6. 等待10-15分钟，下载视频

## 可灵操作步骤

### Step 1：登录可灵

1. 打开浏览器，访问 `https://klingai.kuaishou.com`
2. 使用手机号/微信登录
3. 进入「AI视频」模块

### Step 2：生成视频

1. 选择「文生视频」或「图生视频」
2. 在提示词框粘贴对应镜头的视频提示词
3. 比例选择：16:9
4. 时长选择：5秒/10秒
5. 运镜控制：根据分镜选择镜头运动
6. 点击「立即生成」
7. 等待15-20分钟，下载视频

## 各镜头详细操作

### 镜头01：片头（文字动画）

**工具**：即梦
**操作**：文字动画生成

```
操作步骤：
1. 选择「图片生成」
2. 提示词：纯黑背景，水墨渐显《果妃传》中文剧名，中国水墨动画风格，古典留白，庄严神秘氛围，8K高清
3. 比例：9:16（竖版）或 16:9（横版）
4. 生成后，选择「生成视频」（如支持文字动画）
5. 如不支持，下载静态图，进入剪辑软件加动画效果
```

### 镜头04-09：角色镜头（即梦为主）

**操作要点**：
1. 每个角色镜头需保持角色一致性
2. 使用角色Token触发词
3. 表情/角度需符合分镜脚本

**示例（镜头08：龙眼大帝震惊）**：
```
1. 即梦图生视频
2. 提示词：Anime style close-up portrait, Longan Emperor (longan fruit character, golden-brown glossy shell, imperial dragon crown, golden-yellow robe) standing up abruptly from throne, eyes wide with shock and recognition, pupil constricted, mouth slightly open, warm golden lighting from front, dramatic chiaroscuro, Studio Ghibli meets Makoto Shinkai, cinematic intensity, ghostly memory flash effect, 8K HD
3. 比例：16:9
4. 生成后，可灵进行局部运镜优化
```

## 注意事项

1. **角色一致性**：每生成一个角色镜头，记录使用的提示词和种子
2. **镜头衔接**：生成后检查上一镜/下一镜的衔接是否流畅
3. **光线一致**：同一场景的不同镜头，光线来源需保持一致
4. **生成失败**：如某镜头生成失败，记录原因，更换工具重试

## 问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 角色不像 | Token未触发 | 提示词加入Token触发词 |
| 光影不自然 | 可灵更擅长 | 换用可灵生成 |
| 动作僵硬 | 视频时长太短 | 尝试10秒版本 |
| 画面模糊 | 分辨率不足 | 使用即梦Pro模式 |
