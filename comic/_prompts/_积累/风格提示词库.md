## 新海诚风格

### 核心标签（固定使用）

```
新海诚风格，日系动漫，文艺唯美
Makoto Shinkai style, Japanese anime
```

### 光影标签（选配）

```
逆光光晕、阳光穿透窗户、光污染城市夜景
天空蓝橙渐变、夕阳光晕效果
```

### 质感标签（选配）

```
细腻描边、空气感、低饱和度高光溢出
景深虚化、玻璃反光、水面反光
```

### 构图标签（选配）

```
电影感构图、大量留白、诗意画面
前景虚化、浅景深、电影感
```

### 完整风格串（草莓与罐头标准）

```
新海诚风格，日系动漫，文艺唯美，细腻描边，空气感，
逆光光晕，景深虚化，玻璃反光，冷暖光影对峙，
电影感构图，大量留白，低饱和度高光溢出
```

## 失败案例

### 风格冲突示例

```
❌ 新海诚风格 + 赛博朋克霓虹 + 宫崎骏森林
原因：三种风格互斥，画面混乱

✅ 新海诚风格 + 夕阳逆光 + 城市超市
原因：统一在现实主义诗意基调下
```

### 风格堆砌示例

```
❌ 新海诚风格，日系动漫，文艺唯美，电影感，
   细腻描边，空气感，逆光，景深，虚化，玻璃反光，
   水面反光，尘埃粒子，蓝橙渐变，光晕，诗意，
   留白，电影感构图...
原因：超过8个风格词导致风格漂移

✅ 新海诚风格，日系动漫，文艺唯美，细腻描边，
   逆光光晕，景深虚化，玻璃反光
原因：精选6个核心词，风格统一
```

## 风格词数量规则

| 风格词数量 | 效果 | 建议 |
|-----------|------|------|
| 3-5个 | ✅ 风格清晰 | 推荐 |
| 6-8个 | ✅ 可接受 | 允许 |
| 9个以上 | ⚠️ 风格漂移风险 | 精简 |
| 12个以上 | ❌ 风格混乱 | 禁止 |
