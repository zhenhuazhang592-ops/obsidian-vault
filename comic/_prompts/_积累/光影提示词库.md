# 光影提示词库

> 光线效果的正反例积累。

---

## 成功案例

### 冷暖对峙 · 超市标准光

```
冷白荧光从头顶均匀投射（顶光、冷调、硬光）
暖黄色门帘光从右侧斜射入（侧光、暖调、柔和）
两束光在罐头架前形成冷暖分界线
金属罐头盖产生高光反射
整体强度适中，无强烈阴影
```

**用于**：草莓与罐头 Shot01-14 全系列
**效果**：✅ 核心光影公式，贯穿全片

### 逆光诗意 · 剪影轮廓

```
夕阳透过超市玻璃门斜射入（侧逆光、暖调、柔和）
人物呈剪影状态，轮廓边缘有金黄色透光（轮廓光）
空气中尘埃粒子在光线中可见（光柱特效）
背景略微过曝，天空呈蓝橙渐变（高光溢出）
```

**用于**：Shot08（老布看向门外）
**效果**：✅ 诗意感强，情绪传递准确

## 规律总结

### 新海诚光影公式

```
[冷光来源] + [暖光来源] + [对峙分界线] + [反光材质] = 新海诚光影
例：冷白顶光 + 暖黄门帘光 + 罐头架前交汇 + 玻璃罐头反光
```

### 光源必须有来处

- 所有光线都要有明确的光源位置（窗户、灯泡）
- 无来处的光线显得不真实

### 冷暖对比是标志

- 新海诚风格 = 冷暖对比（通常8:2或7:3）
- 主光源一种，辅助光源一种，不要超过三种

