# 视频生成公式

> 用于可灵/即梦/Veo 等视频生成工具。

---

## 公式模板

```
[图像描述主体] + [镜头运动] + [时长/节奏] + [风格]
```

---

## 逐项说明

### 图像描述主体

> 继承图像生成公式的描述，作为视频的第一帧/主体画面

```
35-40岁中年男性，深灰卫衣，手持罐头，站在超市货架前，
傍晚光线，冷暖光影交错，新海诚风格
```

### 镜头运动

| 运动类型 | 描述 |
|---------|------|
| 推镜头 | 缓慢推近人物面部（slow zoom in） |
| 拉镜头 | 从特写缓慢拉远（slow zoom out） |
| 固定 | 镜头静止，人物轻微动作（static, slight movement） |
| 横摇 | 镜头水平移动（slow pan left/right） |
| 竖摇 | 镜头上下移动（slow tilt up/down） |
| 手持 | 轻微晃动，模拟手持（handheld, slight shake） |
| 环绕 | 绕主体缓慢旋转（slow orbit） |
| 跟随 | 跟随人物行走（follow shot, walking） |

### 时长/节奏

| 描述 | 适用 |
|------|------|
| 3秒，慢镜头 | 情绪镜头，强调细节 |
| 5秒，舒缓 | 正常对话节奏 |
| 3秒，快切 | 转场、高潮点 |
| 8秒，静止 | 环境展示、情绪酝酿 |
| 2秒，卡顿感 | 梦境/回忆 |

### 风格

> 与图像风格词一致的视频版本

```
新海诚风格，慢节奏，电影感，
光影流动，景深变化，氛围感
```

## 镜头衔接公式

> 用于相邻镜头的衔接处理

```
镜头A结束动作 → 镜头B开始动作
       ↓
[衔接描述]：如"同一时刻，老布的手从货架上拿起罐头"
```

### 衔接示例

```
Shot06结束：老布拿起罐头瓶，端详
↓ 衔接
Shot07开始：老布（主观视角）→ 罐头瓶特写（金属盖反光）

Shot07结束：店员微笑
↓ 衔接
Shot08开始：店员的手将鲜草莓放入老布购物篮
```

## 动作描述优先级

> 视频生成中，动作描述按以下优先级：

1. **面部表情**：眼神变化 > 嘴角 > 眉毛
2. **手部动作**：手持物品 > 手势 > 静止
3. **身体动作**：转身 > 行走 > 呼吸起伏
4. **环境动作**：光线变化 > 物件移动 > 完全静止

---

## 常见错误

1. **动作描述过多**：一次最多描述2个主要动作
2. **运动方向模糊**："动一下"不如"头从左转到右"
3. **时长估计偏差**：新手容易低估生成时长需求
4. **忽略衔接**：相邻镜头要确保动作连贯

## 迭代记录

### 规律1：视频生成比图像难

- 视频生成对"动作"的描述要非常具体
- "微笑"不如"嘴角微微上扬，眼尾略弯"更精确

### 规律2：镜头运动宁少勿多

- 新手常犯：在一个镜头里叠加太多运动
- 建议：每个镜头只做一种运动

### 规律3：时长和节奏强相关

- 慢节奏 = 4-6秒
- 正常节奏 = 3-4秒
- 快节奏 = 1-2秒

### 规律4：首帧决定风格

- 视频生成工具通常以第一帧为参考
- 第一帧的构图和光线直接决定整个视频的基调
