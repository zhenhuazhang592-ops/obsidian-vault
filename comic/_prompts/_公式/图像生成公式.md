# 图像生成公式

> 将角色、场景、光影、构图组合为完整的图像生成提示词。

---

## 完整公式

```
[角色Token],
[角色描述],
[in/at + 场景描述],
[光线描述],
[风格标签],
[构图描述],
[质量词]
```

> **Token 必须放第一位**，这是 AI 识别角色的核心标识符。
> 提示词总词数控制在 **20-40词** 以内，越短越稳定。

```

```

> 参考「构图描述公式」

```

景深虚化背景，玻璃罐头瓶作为前景虚化元素
```

### 第六层：质量词

```
8K高清，超细节，电影感，景深虚化，
辛烷渲染风格，高质量渲染，真实感
```

## 中英混用规则

> 即梦/国产工具建议中英混用，英文部分确保风格精确

### 建议保留英文的词

```
新海诚风格 → 新海诚风格, Makoto Shinkai style
日系动漫 → 日系动漫, Japanese anime style
景深虚化 → bokeh, shallow depth of field
逆光 → backlight, rim light, contre-jour
光晕 → lens flare, light halo
电影感 → cinematic, film grain
8K高清 → 8K, ultra detailed
```

### 建议全中文的词

- 角色描述（确保精确）
- 场景描述（确保精确）
- 情绪词汇

## 负面提示词（Negative Prompt）

> 在支持的工具中使用（如 Midjourney / Stable Diffusion）

```
low quality, blurry, deformed, bad anatomy, bad hands,
extra fingers, missing fingers, wrong proportion,
anime screenshot, cheap, amateur,
oversaturated, too bright, garish colors,
realistic photo style, 3D render look
```

### 针对新海诚风格的负面词

```
不要迪士尼风格, 不要皮克斯风格, 不要宫崎骏风格,
不要番剧画风, 不要厚涂, 不要赛璐璐,
不要高饱和度, 不要鲜艳刺眼颜色
```

---

## 常见错误

1. **堆砌关键词**：不是越多越好，同类词选1-2个最优
2. **风格冲突**：不要同时写"新海诚"+"宫崎骏"+"赛博朋克"
3. **忽略主体**：角色描述要放在最前面，确保主体正确
4. **构图词缺失**：没有构图描述，AI会随机构图
5. **质量词过多**：超过3个质量词可能产生反效果

## 迭代记录

### 规律1：顺序很重要

最佳顺序：角色 → 场景 → 光线 → 风格 → 构图 → 质量
混乱顺序会降低主体识别准确率

### 规律2：分隔符使用

- 英文逗号：最通用
- 换行：结构更清晰，部分工具支持
- 中文逗号：适合中文工具

### 规律3：风格词精简

从实践中发现，风格词超过8个容易导致风格漂移。
最优数量：4-6个精选风格词

### 规律4：景深描述很重要

新海诚风格的标志性特征是前景虚化和浅景深。
每个提示词中至少包含一个景深相关的描述。
