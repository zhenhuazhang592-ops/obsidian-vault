# 结构化提示词模板

> 工业级提示词标准结构。适用于图片和视频生成。
> **固定结构 = 角色Token + 角色 + 动作 + 场景 + 镜头 + 风格 + 构图**
> 总词数控制在 20-40 词以内。

---

## 一、标准结构

```
<[角色Token]>, [角色描述],
[动作],
[场景],
[镜头],
[风格],
[构图]
```

---

## 二、模块说明

### 模块1：角色Token（必填，置顶）

```markdown
<[英文小写无空格]>

例：
<old_bu>
<shop_clerk>
<avocado_angel>
```

> Token 相当于角色的"身份证"，AI 看到 Token 就知道是谁。
> 固定格式：尖括号 + 英文小写 + 下划线

### 模块2：角色描述

```markdown
[年龄] + [性别] + [体型] + [服装] + [表情]

例：35-40岁中年男性，深灰洗旧卫衣，若有所思
```

> 从角色锚点卡的 Token 描述中提取关键特征。
> 不需要完整描述，每次只提取 3-5 个核心词。

### 模块3：动作

```markdown
[动作描述]

例：
手持罐头，指尖轻触瓶身
站立，手插兜，目光移向远方
微笑，手托腮，热情推荐
```

> 动作要具体，不要"站着"而要"手插兜站着"

### 模块4：场景

```markdown
[场景名], [时间], [光线]

例：超市生鲜区，傍晚，冷白荧光+暖黄门帘光
```

> 从场景描述公式中提取，固定场景用固定描述

### 模块5：镜头

```markdown
[景别], [镜头运动]

例：中景，固定
近景，轻微推进
中景，缓慢横摇
```

> 从构图描述公式中提取

### 模块6：风格

```markdown
[风格词1], [风格词2], [风格词3]

例：新海诚风格，日系动漫，文艺唯美，逆光光晕
```

> 从风格提示词库中提取，选 2-4 个核心词

### 模块7：构图

```markdown
[构图方式], [留白方向], [景深]

例：三分法，人物偏右留白，景深虚化前景
```

> 从构图描述公式中提取

## 三、负面提示词（必填）

> 在支持负面提示词的工具中使用（如 Midjourney / Stable Diffusion）

### 通用负面提示词

```
low quality, blurry, deformed, bad anatomy, bad hands,
extra fingers, missing fingers, wrong proportion,
anime screenshot, cheap, amateur,
oversaturated, too bright, garish colors,
realistic photo style, 3D render look
```

### 新海诚风格负面提示词

```
不要迪士尼风格, 不要皮克斯风格, 不要宫崎骏风格,
不要番剧画风, 不要厚涂, 不要赛璐璐,
不要高饱和度, 不要鲜艳刺眼颜色
```

### 即梦/可灵负面提示词

```
低质量, 模糊, 变形, 错误的人体结构,
多余手指, 缺失手指, 比例错误,
截图感, 廉价感, 业余感
```

### 负面提示词使用指南

| 工具 | 负面提示词位置 | 建议词数 |
|------|--------------|---------|
| Midjourney | `--no` 参数 | 5-10 个 |
| Stable Diffusion | negative prompt 字段 | 10-15 个 |
| 即梦 | 支持度有限 | 简化为 3-5 个 |
| 可灵 | 不支持 | 用正面词控制 |

## 五、视频生成完整示例

### 视频提示词模板

```
<[角色Token]>, [角色描述],
[动作],
[场景],
[镜头] + [镜头运动],
[风格],
[构图]

示例：
<old_bu>, 35-40岁中年男性，深灰卫衣，
手持罐头，目光从罐头移向远方，
超市生鲜区，傍晚，冷白荧光+暖黄门帘光，
中景，缓慢推镜头，
新海诚风格，日系动漫，慢节奏，情绪克制，
三分法，人物偏右，景深虚化
```

## 六、工业化 Prompt 配置文件

> 项目开始时填写，作为团队共享的提示词基准

```markdown
# [项目名] Prompt 配置

## 角色Token
| Token | 角色名 | 固定描述 |
|-------|--------|---------|
| <old_bu> | 老布 | 35-40岁中年男性，深灰卫衣，微胖圆脸，眼窝深 |
| <shop_clerk> | 店员 | 25岁年轻男性，黑框眼镜，白色制服，瘦削 |

## 场景Token
| Token | 场景名 | 固定描述 |
|-------|--------|---------|
| <supermarket_dusk> | 超市生鲜区 | 傍晚，冷白荧光+暖黄门帘光，冷暖对峙 |
| <doorway> | 超市入口 | 黄昏，门帘半开，暖黄夕阳光斜射 |

## 风格锁定
```
新海诚风格，日系动漫，文艺唯美，逆光光晕，景深虚化
```

## 构图锁定
```
三分法，人物偏右留白，前景虚化，简洁背景
```

## 镜头序列
| 类型 | 标注 |
|------|------|
| 远景 | wide shot, character in environment |
| 中景 | medium shot, character waist up |
| 近景 | close-up shot, facial focus |
| 特写 | extreme close-up, detail focus |

## 负面提示词
```
blurry, deformed, bad anatomy, extra limbs,
不要宫崎骏风格, 不要番剧画风, 不要高饱和度

## 七、快速生成检查清单

> 每个提示词生成前必须自检

- [ ] Token 在最前面
- [ ] 总词数 20-40 之间
- [ ] 风格词不超过 4 个
- [ ] 负面提示词已添加
- [ ] 角色描述与锚点卡一致
- [ ] 场景描述来自场景库
- [ ] 镜头类型明确
- [ ] 构图方式明确

---

## 八、常见错误

| 错误 | 问题 | 修正 |
|------|------|------|
| 风格词超过 8 个 | 风格漂移 | 精简到 2-4 个 |
| 提示词超过 60 词 | AI 失控 | 精简角色描述 |
| 没有 Token | 角色不稳定 | 添加 Token 并置顶 |
| 没有负面提示词 | 乱生成 | 添加通用负面词 |
| 场景描述每次临时写 | 风格不统一 | 使用场景Token固定描述 |
