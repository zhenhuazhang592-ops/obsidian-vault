# 角色描述公式

> 用于图像/视频生成时的角色描述部分。

---

## 公式模板

```
[年龄段][性别][体型][脸型][发型发色][眼部特征][显著特征],
[服装上装（颜色+款式+材质+状态）],
[服装下装（颜色+款式）],
[配饰],
[姿势/动作],
[表情]
```

---

## 逐项说明

### 1. 年龄段

| 描述 | 适用 |
|------|------|
| 35-40岁中年 | 老布等 |
| 25岁左右年轻 | 店员等 |
| 18-22岁青年 | 学生角色 |
| 50岁以上 | 长辈角色 |

### 2. 性别

- 男 / 女 / 其他

### 3. 体型

| 体型 | 关键词 |
|------|--------|
| 微胖 | slightly overweight, round face, stocky |
| 瘦削 | slim, thin, slender |
| 标准 | average build, normal |
| 健壮 | muscular, athletic |
| 矮小 | short, petite |

### 4. 脸型

| 脸型 | 关键词 |
|------|--------|
| 圆脸 | round face |
| 方脸 | square jaw |
| 椭圆 | oval face |
| 长脸 | long face |
| 心形 | heart-shaped face |

### 5. 发型发色

- 短发/长发/中发
- 直发/卷发/波浪
- 深色/浅色/灰白
- 发际线描述（如：发际线上移、M字额）

### 6. 眼部特征

- 眼窝深（deep-set eyes）
- 眼睛大（large eyes）
- 眯眯眼（narrow eyes）
- 戴眼镜（wearing glasses, black-frame glasses）
- 眼神疲惫（tired eyes）

### 7. 显著特征

- 胎记、疤痕
- 胡须（stubble, beard）
- 饰品（项链、耳环、手表）
- 职业特征（厨师帽、围裙等）

### 8. 服装

```
[颜色] + [款式] + [材质/状态] + [新旧程度]
例：深灰色洗旧棉质卫衣，袖口略起球
    白色整洁棉质制服衬衫
    黑色修身牛仔裤
```

### 9. 姿势/动作

- 站立、行走、坐下
- 手持[物品]
- 双手插兜
- 摸下巴（思考时）
- 推眼镜（疑惑时）

### 10. 表情

| 表情 | 描述 |
|------|------|
| 平静 | calm, neutral, slight frown |
| 喜悦 | slight smile, eyes crinkled |
| 悲伤 | downcast eyes, frown |
| 困惑 | furrowed brow, confused look |
| 坚定 | determined gaze, jaw set |
| 犹豫 | hesitant, eyes wandering |

## 完整示例

### 示例：老布

```
35-40岁中年男性，微胖圆脸，
发际线略上移，深色短发，
眼窝略深，目光温和但略带疲惫，
深灰色洗旧棉质卫衣，袖口略起球，
深色休闲裤，普通运动鞋，无配饰，
站立，手持罐头，指尖轻触瓶身，
微蹙眉，嘴角略微下压，若有所思
```

### 示例：年轻店员

```
25岁左右年轻男性，瘦削脸型，下巴略尖，
黑色短发整齐，黑框眼镜，
眼明亮，白色整洁棉质制服衬衫，
深色工作裤，皮鞋，工牌，
站立挺直，双手交叠于身前，
自然微笑，眼神温和
```

## 常见错误

1. **信息冗余**：不需要写"非常帅气的"等主观描述
2. **风格冲突**：二次元角色不要同时写"真人感"
3. **遗漏关键特征**：眼镜、体型等会影响识别
4. **服装描述模糊**："穿衣服"不如"浅蓝色棉质T恤，旧"
5. **表情和情绪不匹配**：开心的人不会"嘴角下压"

## 场景补充规则

当角色处于特定场景时，在基础描述后追加：

```
[基础角色描述],
in [场景]: [场景补充],
[光线]: [光线补充],
[镜头]: [景别补充]
```

### 示例（添加场景）

```
[老布基础描述],
in a supermarket fresh food aisle, evening, cold white fluorescent light,
warm yellow light from the doorway behind,
medium shot, slightly right of frame, negative space on the left
```

## 迭代记录

> 以下是实际使用中发现的优化规律

### 规律1：体型描述影响整体风格

- 写"微胖"比"slightly overweight"在中文AI工具中效果更好
- 体型和脸型要同时描述，否则AI可能只调整一项

### 规律2：服装状态影响真实感

- "洗旧"（worn, faded）比"旧"更精确
- "袖口起球"比"有磨损"更具体，更容易生成

### 规律3：动作+道具是画面锚点

- 单独写"手持罐头"不如"指尖轻触罐头瓶身"有画面感
- 手的动作描述能大幅提升画面质量
