# 光影描述公式

> 用于图像/视频生成时的光线设计描述。

---

## 光线六要素

```
[光源类型] + [方向] + [色温] + [强度] + [质感] + [特效]
```

---

## 逐项说明

### 1. 光源类型

| 类型 | 描述 | 关键词 |
|------|------|--------|
| 自然光-阳光 | 直射阳光 | sunlight, direct sunlight |
| 自然光-散射 | 阴天/阴凉处 | diffused light, overcast |
| 人工光-荧光 | 超市/办公室 | fluorescent light |
| 人工光-白炽 | 灯泡/台灯 | incandescent, warm bulb |
| 人工光-霓虹 | 夜景/广告牌 | neon light, sign glow |
| 人工光-蜡烛 | 暖光氛围 | candlelight |
| 窗户光 | 透过窗户 | window light, through glass |
| 逆光 | 从背后打光 | backlight, contre-jour, rim light |
| 轮廓光 | 边缘发光 | edge lighting, rim light |
| 混合光 | 多种光源 | mixed lighting |

### 2. 方向

```
正面光  ←———[主体]———→  逆光
正面侧光 ←———[主体]———→  侧逆光
        ↑                    ↑
     侧光              侧背光
        ↑
     顶光
```

| 方向 | 效果 |
|------|------|
| 正面光 | 明亮、平淡、安全感 |
| 侧光 | 立体感强、有戏剧性 |
| 逆光 | 轮廓感、氛围感、诗意 |
| 顶光 | 压迫感、不自然（白天）|
| 底光 | 恐怖感、戏剧张力 |

### 3. 色温

| 色温 | 关键词 | 情绪 |
|------|--------|------|
| 冷调（5000K以下）| cool, blue, cold | 孤独、沉郁 |
| 暖调（3000K以下）| warm, orange, golden | 温暖、希望 |
| 中性（5000K）| neutral, balanced | 日常、客观 |
| 对比（冷暖并存）| warm vs cool, contrasting | 冲突、对峙 |

### 4. 强度

| 强度 | 描述 |
|------|------|
| 强烈 | harsh, bright, high contrast |
| 柔和 | soft, gentle, low contrast |
| 微弱 | dim, faint, low key |
| 戏剧性 | dramatic, high key / low key |

### 5. 质感

| 质感 | 描述 |
|------|------|
| 硬光 | hard light, sharp shadows, defined edges |
| 软光 | soft light, diffused, gentle shadows |
| 散射 | scattered, bounced light, no shadows |
| 混合 | partially diffused, mixed |

### 6. 特效

| 特效 | 描述 |
|------|------|
| 光晕 | lens flare, light halo, glow |
| 光斑 | light spots, sunbeam |
| 投影 | shadow, silhouette |
| 反射 | reflection, light spill |
| 光柱 | god rays, light beam |
| 焦散 | caustics, light refraction |

## 新海诚光影特征库

### 逆光系列

```
逆光轮廓光，背光照明，剪影边缘透光
夕阳逆光，人物周身金边
穿透窗户的逆光，尘埃粒子在光线中漂浮
黄昏时分，冷暖交界处的轮廓光
```

```
镜头光晕，large lens flare, warm
柔和光晕扩散，diffused halo

夕阳透过云层的光晕
```

```
阳光穿透窗户的尘埃感
雨后地面积水的反光
玻璃瓶身的透射光
霓虹灯在潮湿地面的倒影
```

```
雨后乌云缝隙透出的光
```

## 完整示例

### 示例：超市冷暖对峙

```
冷白荧光从头顶均匀投射（顶光、冷调、硬光）
暖黄色门帘光从右侧斜射入（侧光、暖调、柔和）
两束光在罐头架前形成冷暖分界线
金属罐头盖产生高光反射
整体强度适中，无强烈阴影
```

### 示例：逆光诗意

```
夕阳透过超市玻璃门斜射入（侧逆光、暖调、柔和）
人物呈剪影状态，轮廓边缘有金黄色透光（轮廓光）
空气中尘埃粒子在光线中可见（光柱特效）
背景略微过曝，天空呈蓝橙渐变（高光溢出）
```

### 示例：便利店雨夜

```
便利店内部人工照明（正面光、冷调、均匀）
冰柜发出蓝色微弱光（点光源、冷调）
门外霓虹灯光透过玻璃投射（反射、冷暖混合）
雨滴在玻璃窗留下水痕（高光折射）
整体氛围偏暗（low key）
```

## 情绪光影对照表

| 情绪 | 光影模式 |
|------|---------|
| 希望/温暖 | 暖调逆光、光晕、穿透光 |
| 孤独/沉郁 | 冷调顶光、单光源、低照度 |
| 紧张/冲突 | 硬光、强烈对比、侧光 |
| 平静/释然 | 散射光、均匀照明、柔和 |
| 浪漫/诗意 | 逆光轮廓、暖黄光晕、虚焦光斑 |
| 怀旧/回忆 | 泛黄色调、柔焦、褪色感 |
| 现实/当下 | 中性白、正常曝光、清晰 |

## 常见错误

1. **光源方向不明**：写"有光"不如写"侧逆光从左侧打来"
2. **冷暖冲突失控**：可以有对比，但要有主次（8:2或7:3）
3. **忽略光质**：硬光和软光效果完全不同
4. **特效堆砌**：一个新海诚画面最多2种光效

## 迭代记录

### 规律1：光源必须"有来处"

- 所有光线都要有明确的光源位置（窗户、灯泡、窗户等）
- 无来处的光线显得不真实

### 规律2：冷暖对比是新海诚的标志

- 草莓与罐头项目的核心光影：冷白荧光 + 暖黄门帘光
- 这个对比公式可以复用

### 规律3：光晕宁少勿多

- 1个主要光晕 > 多个散乱光晕
- 光晕位置要符合光源方向
