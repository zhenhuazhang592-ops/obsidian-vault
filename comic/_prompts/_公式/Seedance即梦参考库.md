## 一、核心结构公式

> 从所有案例中提炼的即梦提示词标准结构

### 漫剧/短剧标准结构

```markdown
【风格】[风格定义]
【时长】[总时长]
【人物】[角色描述]
【全局要求】[一致性要求/格式要求]

"[00:00-00:05] [景别]。[场景描述]。[动作描述]。[情绪细节]。口型与字幕：[台词]"
"[00:05-00:10] ..."
```

### 结构要素说明

| 要素 | 位置 | 说明 |
|------|------|------|
| 风格定义 | 【风格】 | 第一行，必须有 |
| 时长 | 【时长】 | 15秒/10秒等 |
| 角色描述 | 【人物】 | 简短精准，2-3句话 |
| 全局一致性要求 | 【全局要求】 | 格式/一致性/字幕要求 |
| 镜头脚本 | "" 包裹 | 每段一个镜头 |

### 镜头脚本格式

```markdown
"[镜号] [景别]。[场景]。[动作+细节]。[情绪表现]。[技术参数]。口型与字幕：[台词]"
```

## 二、漫剧/短剧案例精选

### 2.1 豪门恩怨 · 真假千金

> 人物一致性 + 口型字幕 + 节奏控制的典范

**提示词：**
```markdown
【风格】豪门恩怨、真假千金、极致反转、撕绿茶、高定礼服、美艳御姐

【角色】
真千金（烈焰红唇，黑天鹅高定礼裙，气场全开）
假千金（小白花扮相，泪眼装可怜）

【全局要求】
9:16 竖屏，电影质感，奢华宴会厅水晶灯与香槟塔，光影高级。
真千金与假千金人物一致性稳定，脸不变，礼服不变。
口型与字幕逐字完全一致，字幕即台词本身。
每句台词控制在短句，清晰可读。

"[00:00-00:05] 奢华宴会厅中景，假千金故意撞翻桌边古董花瓶，清脆碎裂，她立刻坐地抱住碎片边缘假哭，抬手指向真千金，周围宾客围成半圈，纷纷侧目。口型与字幕：姐姐，你为什么这样"

"[00:05-00:10] 真千金近景，冷艳俯视，红唇微扬带嘲讽，抬手甩出一份文件砸到假千金面前。镜头切文件特写，画面只需要清晰看到大字 DNA 与红色印章 无血缘，不要密集小字。假千金抬眼，泪停住，脸色发白。口型与字幕：演够了吗"

"[00:10-00:15] 全场反应一瞬，宾客捂嘴惊呼，镜头立刻切回真千金。真千金走到主位旁，从假千金头上干脆取下皇冠，稳稳戴回自己头上，转身落座主位，抬眼扫全场。两名保安出现把假千金拖走，只给她被拖走的背影与无力挣扎。真千金定住女王姿态。口型与字幕：这是我家，滚"
```

**学习要点**：
- ✅ 全局要求中写明一致性要求（脸不变，礼服不变）
- ✅ 口型与字幕作为独立标注字段
- ✅ 镜头间有清晰的节奏感（5秒一段）
- ✅ 台词短句，清晰可读

### 2.2 中国网剧 · 雨夜情感戏

> 短剧节奏 + 情感爆发 + 视觉细节的范例

**提示词：**
```markdown
【风格】热门中国网剧风格（短剧风格），极致快切节奏，高颜值滤镜，情感爆发，浪漫且扎心的雨夜。
【时长】15 秒
【人物】深情的霸道总裁男主（黑色大衣，湿漉漉的头发，红了眼眶）VS 倔强心碎的女主（白色连衣裙，满脸泪水）。

[00:00-00:05] 镜头 1：快速剪辑组合。
雨街。女主决然转身离去。男主冲上前，一把拉住她的手腕，猛地拽向自己，两人撞在一起。
镜头组合：雨滴特写 + 两人对视 + 男主眼眶泛红 + 女主泪水滑落。
男主嘶吼："你凭什么替我做决定！"
女主推开他，哭着喊："因为我爱你啊！"
男主愣住，雨水顺着脸颊滑落。他猛地吻上去。
定格在两人雨中拥吻的剪影上，闪电划过。
```

**学习要点**：
- ✅ 人物在【人物】字段中一次定义清楚
- ✅ 镜头内包含"镜头组合"说明（雨滴特写 + 对视 + 情绪）
- ✅ 情绪通过环境外化（雨水=眼泪，闪电=冲击）
- ✅ 快切节奏

### 2.3 春晚风格 · 甄嬛与扈绯

> 历史+现代反差 + 道具细节的范例

**提示词：**
```markdown
10 秒春晚风格舞台表演："甄嬛与扈绯脱口秀"

0–2 秒：
双人中景。舞台整体是"客厅小品"设定，但周围是宏大的红金配色 LED 屏幕。
甄嬛（左）和扈绯（右）并排坐在现代脱口秀沙发上。
关键历史准确性要求：两人都穿着华丽、界限分明的清代宫廷长袍，带有立领和精细刺绣。

2–4 秒：
镜头切换到过肩视角 (OTS)，聚焦在扈绯。
扈绯夸张地翻了个白眼。她用长护甲捏着咸菜，一边指指点点，一边用傲慢的语气说话（对口型）：
"今年的 KPI 又是打这帮小妖精，那老头儿皇上懂什么审美？"

4–6 秒：
迅速切换到甄嬛的过肩视角 (OTS)。
对比细节：甄嬛的一只耳朵戴着现代白色蓝牙耳机（与古代首饰形成强烈对比），手里拿着一台轻薄的平板电脑在滑动。

8–10 秒：
两人之间咖啡桌的特写。
一个现代塑料珍珠奶茶杯，上面印着"一丈红"，放在一个传统的瓷瓶旁边。
```

**学习要点**：
- ✅ 历史准确性和现代元素对比（蓝牙耳机 vs 清宫服饰）
- ✅ 道具作为叙事符号（珍珠奶茶杯印"一丈红"）
- ✅ OTS过肩镜头明确标注
- ✅ 口型作为独立标注

### 2.4 王家卫 · 雨夜电话亭

> 复古胶片 + 抽帧 + 情绪克制

**提示词：**
```markdown
[电影风格]: 90年代香港艺术电影风格，复古胶片感，高ISO颗粒，暧昧的黄绿色调，抽帧效果，忧郁氛围。

[核心对白（用于情感控制）]: "如果记忆是一个罐头，我希望它永远不会过期。"

[视频时长]: 10 秒

[00:00-00:04] 镜头 1: 透过玻璃窥视。
场景: 一个被雨覆盖的红色公共电话亭。
人物: 一个穿着卡其色风衣的男人紧紧握着听筒，没有说话，只是在听。
情感表现: 透过玻璃的折射，看到他/她的眼神空洞却饱含深情。雨水流过玻璃，扭曲了他的脸，像油画一样。
字幕/叙事感: 画面仿佛凝固，只有雨声。

[00:04-00:07] 镜头 2: 极端特写与微表情。
场景: 聚焦在人物的嘴唇和半张脸。
动作: 他/她在听筒里轻声耳语。嘴唇轻微颤抖。
灯光: 街道霓虹灯的虚化光点在他脸上流过，忽明忽暗。
对白情感映射: 展现出"想触碰却收回手"的极致克制与孤独。

[00:07-00:10] 镜头 3: 招牌慢速快门拖影。
视觉效果: 使用抽帧效果，人物的背影变得模糊并带有拖影，仿佛灵魂留在原地，只有身体走开。
环境: 背景是流动的城市车灯，形成拉长的光轨。

[技术参数]: 模拟手持摄影机，浅景深，偏色，情感强烈。
```

**学习要点**：
- ✅ 核心对白作为情感锚点单独标注
- ✅ "情感表现"字段描述内心而非外在
- ✅ 抽帧/慢速快门等技术参数
- ✅ 雨水=眼泪的隐喻外化
- ⚠️ "如果记忆是一个罐头"——与草莓与罐头主题高度相关

## 三、动漫/动画风格案例

### 3.1 哪吒与敖丙 · 冰火交锋

> 高频动作 + 过渡设计的动漫战斗参考

```markdown
第一幕：静止与爆发
视觉：特写。哪吒的混天绫在风中轻轻摇曳，火星四溅。镜头突然快速缩小。
动作：哪吒突然蹬地，导致地面碎裂。
视觉焦点：测试 Seedance 2.0 对碎片轨迹的模拟，以及从静止到超高速运动的过渡。

第二幕：属性转换（测试匹配剪辑）
视觉：哪吒挥舞火尖枪横扫，形成一个圆形的火焰环。
过渡设计：火焰环在旋转时无缝转化为敖丙的旋转冰刃。
动作：镜头跟随武器的旋转轴线，实现从红调到蓝调的瞬间平滑过渡。

第三幕：激战交互
视觉：侧面中景。火尖枪和冰剑在半空中碰撞。
动作：火花和冰屑同时爆炸。

第四幕：终极过渡
视觉：哪吒一拳击碎冰墙。
过渡设计：破碎的冰晶在空中转化为飞舞的红叶或火羽。镜头穿过冰块碎片，瞬间切入下一场。
```

**学习要点**：
- ✅ 分幕式结构，每幕有明确目标
- ✅ 过渡设计作为独立字段（冰→火羽）
- ✅ 色彩转换作为镜头语言（红→蓝）

## 六、核心规律总结

### 6.1 即梦提示词黄金法则

| 法则 | 说明 |
|------|------|
| 风格第一行 | 【风格】必须在最前面 |
| 角色一次定义清楚 | 在【人物】中完整描述，不要在镜头中重复 |
| 全局一致性要求必须写 | "脸不变，服装不变"是关键词 |
| 镜头脚本用引号包裹 | 每个镜头独立一行 |
| 时间戳必须精确 | [00:00-00:05] 格式 |
| 情绪通过环境外化 | 不写"他很悲伤"，写"雨水顺着脸颊滑落" |
| 口型字幕独立标注 | 口型与字幕：后面跟台词 |
| 镜头数量适中 | 10-15秒建议3-4个镜头 |

### 6.2 漫剧特有模式

```
情绪克制 = 慢镜头 + 留白 + 少台词
情感爆发 = 快切 + 特写 + 环境配合
王家卫风格 = 抽帧 + 复古色调 + 隐喻道具
新海诚风格 = 逆光 + 光晕 + 冷暖对峙 + 空气感
```

### 6.3 参考视频的用法

```
将画风动作打斗表现严格对齐 @视频1 的风格
→ 给参考视频/图片，让即梦对齐画风
→ 草莓与罐头项目：给分镜图作为参考
→ 给角色参考图作为一致性锚点
```
