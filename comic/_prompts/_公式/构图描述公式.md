# 构图描述公式

> 用于图像/视频生成时的画面构图描述。

---

## 构图公式模板

```
[景别] + [人物位置] + [留白方向] + [引导线] + [前景/背景] + [特殊构图]
```

---

## 逐项说明

### 1. 景别

| 景别 | 英文 | 描述 |
|------|------|------|
| 极远景 | EWS | 全景，强调环境，人物极小 |
| 远景 | WS | 全人物和环境 |
| 全景 | FS | 人物全身 |
| 中景 | MS | 膝盖以上 |
| 近景 | CU | 胸部以上 |
| 特写 | ECU | 脸部 |
| 微距 | MCU | 眼睛/手等局部 |

### 2. 人物位置

| 位置 | 三分法 | 效果 |
|------|--------|------|
| 左侧三分之一 | left third | 阅读起点 |
| 右侧三分之一 | right third | 视线引导向右 |
| 中心 | center, centered | 强调、压迫、孤立 |
| 底部 | bottom third | 渺小感 |
| 顶部 | top third | 俯瞰感 |

```
三分法：
┌─────────┬─────────┐
│  左上    │  右上    │
├─────────┼─────────┤
│  左下    │  右下    │
│    ★人物位置    │
└─────────┴─────────┘
```

### 3. 留白方向

| 留白方向 | 含义 | 适用场景 |
|---------|------|---------|
| 右侧留白 | 人物朝右，留出视线空间 | 人物向右行走/看向右侧 |
| 左侧留白 | 人物朝左，留出视线空间 | 人物向左行走/看向左侧 |
| 上方留白 | 仰望感、压迫感 | 天花板、低空间 |
| 下方留白 | 稳定、接地 | 大地、地面感 |
| 四周留白 | 孤立感、聚焦感 | 特写、情绪镜头 |

### 4. 引导线

| 引导线类型 | 描述 | 效果 |
|-----------|------|------|
| 消失点 | 平行线在远方汇聚 | 纵深感、空间感 |
| S形曲线 | S-curve | 柔和、自然流动 |
| 对角线 | diagonal lines | 动感、张力 |
| 螺旋线 | spiral | 聚焦、旋转感 |
| 水平线 | horizontal lines | 平稳、平静 |
| 垂直线 | vertical lines | 力量、庄严 |

### 5. 前景/背景

| 类型 | 描述 | 效果 |
|------|------|------|
| 前景虚化 | foreground bokeh, foreground blur | 空间感、层次感 |
| 前景清晰 | foreground in focus | 代入感、身临其境 |
| 背景虚化 | background bokeh, shallow DOF | 聚焦主体、梦幻感 |
| 框架前景 | frame in frame, window frame | 聚焦、强调 |
| 多层次景深 | multi-layer depth | 电影感 |

### 6. 特殊构图类型

| 构图 | 描述 | 适用 |
|------|------|------|
| 对称构图 | symmetrical, centered | 仪式感、平衡 |
| 框架构图 | frame within frame | 聚焦、偷窥感 |
| 黄金分割 | golden ratio | 自然美感 |
| 三角形构图 | triangular composition | 稳定、力量 |
| 对角线构图 | diagonal | 动感、张力 |
| 螺旋构图 | spiral | 动态感 |

## 景别序列规范

### 新海诚常用景别序列

```
开场：EWS/WS（建立环境）
         ↓
中景 MS（进入人物/对话）
         ↓
近景 CU（情绪特写/反应）
         ↓
中景 MS（回到对话/动作）
         ↓
WS/WS（情绪释放/转场）
```

### 对话镜头序列

```
正反打（Shot/Reverse Shot）：
Shot A: 角色A（MS，人物偏左）→ 反打线 → Shot B: 角色B（MS，人物偏右）
         ↓
过肩镜头（OTS）：
角色B肩后 → 看角色A（景别更近，可带部分手部）
         ↓
反应镜头：
角色C的反应（CU，表情）
```

## 完整示例

### 示例：货架前的沉思

```
景别：中景 MS
人物位置：偏右三分法（right third）
留白方向：左侧货架留白（右侧留白，人物朝右看）
引导线：罐头货架形成垂直引导线向纵深
前景/背景：前景虚化罐头瓶，背景货架略微虚化
特殊构图：框架构图，左侧门框形成框架
```

### 示例：逆光对话

```
景别：近景 CU（大头）
人物位置：中心
留白方向：上方留白，逆光轮廓光，头顶光线
引导线：无（主体居中）
前景/背景：背景完全虚化（浅景深），逆光形成光晕
特殊构图：剪影，主体暗部细节保留
```

### 示例：行走跟随

```
景别：中景 MS
人物位置：画面右侧三分之一
留白方向：左侧留白，视线/行走方向
引导线：地面延伸线（脚步）
前景/背景：前景虚化半透明玻璃/雨滴
特殊构图：轻微倾斜（dutch angle），增加动感
```

## 常见错误

1. **景别混乱**：对话场景突然切到极远景又跳回近景，节奏断裂
2. **视线规则违背**：180度轴线错误导致角色视线方向相反
3. **留白反方向**：人物朝左但右侧留白（除非刻意制造压迫感）
4. **前景滥用**：前景太多导致主体不突出

## 迭代记录

### 规律1：新海诚偏爱"偏右+左侧留白"

- 草莓与罐头项目中大量使用"人物偏右，货架留白左侧"
- 这个构图制造了"生活中有空白"的诗意感

### 规律2：前景虚化是层次感的关键

- 至少50%的镜头应该包含前景虚化元素
- 玻璃罐、雨滴、门框等是最常用的前景

### 规律3：特写要有呼吸空间

- 特写镜头不要撑满画面，四周至少留10%呼吸空间
