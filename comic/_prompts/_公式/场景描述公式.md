# 场景描述公式

> 用于图像/视频生成时的场景环境描述部分。

---

## 公式模板

```
[地点] + [时间段] + [天气] + [空间特征] + [陈设道具] + [氛围关键词]
```

---

## 逐项说明

### 1. 地点

| 地点类型 | 具体描述 |
|---------|---------|
| 室内 | 超市生鲜区 / 便利店 / 咖啡馆 / 卧室 / 办公室 |
| 室外 | 街道 / 公园 / 天台 / 十字路口 |
| 特殊 | 水下 / 梦境空间（标注为"超现实"） |

### 2. 时间段

| 时间段 | 光线特征 | 氛围 |
|--------|---------|------|
| 清晨 | 柔和暖光，晨雾 | 清新、希望 |
| 上午 | 明亮的自然光 | 活力、日常 |
| 正午 | 强烈顶光，硬阴影 | 燥热、紧张 |
| 下午 | 斜阳，金色光线 | 慵懒、回忆 |
| 傍晚/黄昏 | 暖橙冷蓝交界 | 诗意、过渡 |
| 夜晚 | 人工光源为主 | 孤独、神秘 |
| 深夜 | 深蓝调，弱光 | 沉郁、孤独 |

### 3. 天气

| 天气 | 关键词 |
|------|--------|
| 晴 | sunny, clear sky |
| 阴 | overcast, cloudy, gray |
| 雨 | rainy, rain drops, reflections |
| 雾 | foggy, misty, hazy |
| 雪 | snowy, falling snow |
| 晨雾 | morning mist |
| 夕雾 | evening haze |

### 4. 空间特征

```
[纵深]: 狭窄走廊 / 开阔空间 / 纵深货架
[层高]: 天花板低 / 天花板高 / 无天花板
[密闭度]: 密闭 / 半开放 / 开放
[人群]: 空无一人 / 三两人 / 人声鼎沸
```

### 5. 陈设道具

- **超市**：罐头货架 / 生鲜冷柜 / 收银台 / 购物篮
- **便利店**：冰柜 / 关东煮 / 杂志架 / 收银台
- **咖啡馆**：吧台 / 靠窗座位 / 吊灯 / 木质桌椅

### 6. 氛围关键词

> 在 [地点/时间/天气/空间] 之后，用一到两个关键词定调

| 氛围 | 关键词 |
|------|--------|
| 日常温馨 | cozy, warm, everyday |
| 孤独疏离 | lonely, isolated, deserted |
| 紧张压迫 | tense, claustrophobic, oppressive |
| 诗意唯美 | poetic, cinematic, dreamy |
| 复古怀旧 | vintage, nostalgic, retro |
| 现代都市 | urban, modern, city life |

## 完整示例

### 示例：超市傍晚

```
超市生鲜区，傍晚时分，
黄昏余晖从入口门帘透入，与冷白荧光对峙，
罐头货架纵深排列，金属架反射光线，
玻璃罐头瓶整齐排列，旁边竹筐盛放鲜草莓，
冷暖光影交错，日常而略带诗意
```

### 示例：便利店雨夜

```
便利店内部，深夜，外面下着小雨，
霓虹灯光透过玻璃门投射进来，
货架整齐排列，冰柜发出微弱蓝光，
雨滴在玻璃窗上留下水痕，
孤独的城市深夜，一个人也没有
```

### 示例：街道黄昏

```
城市街道，黄昏时分，
夕阳斜照，在建筑表面留下金色光斑，
行人匆匆，天空呈蓝橙渐变，
电线杆和电线在天空背景下形成引导线，
略带超现实感的日常诗意
```

## 常见错误

1. **地点描述太泛**：写"超市"不如"超市生鲜区罐头货架前"具体
2. **时间+天气冲突**：如"晴天的夜晚"——检查逻辑
3. **忽略光线来源**：光从哪来直接影响画面质量
4. **氛围词堆砌**：一个场景不超过2个氛围词，否则风格混乱
5. **遗漏空间感**：货架纵深、窗户位置等影响构图

## 迭代记录

### 规律1：光线来源决定一切

- "冷白荧光"+"暖黄门帘光"= 对峙感，比单写"超市灯光"好
- 明确写出光线的**颜色**和**方向**

### 规律2：场景越小越聚焦

- 不要写整个"超市"，写"超市罐头货架前30cm范围"
- 范围越小，AI越能聚焦细节

### 规律3：道具是场景的灵魂

- "罐头货架"比"超市货架"更有故事感
- 道具和环境结合，暗示情节
