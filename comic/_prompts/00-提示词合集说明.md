## 使用逻辑

### 每次生成前的流程

```
1. 明确需求：哪个镜头？需要什么效果？
2. 查找公式：打开 _公式/ 找到对应的公式文件
3. 查找积累：在 _积累/ 中找相似场景的成功案例
4. 组合输出：公式 + 积累案例 + 本项目锚点 → 生成提示词
5. 记录到迭代：写入 _迭代/[项目名]-提示词迭代.md
```

### 每次生成后的流程

```
1. 评估结果：成功 / 一般 / 失败
2. 归因分析：成功是因为什么？失败是因为什么？
3. 提取规律：从个案中提炼可复用的模式
4. 更新积累：如果效果好，移入 _积累/ 相应库
5. 更新公式：如果发现新模式，更新 _公式/ 相应文件
```

## 公式库使用说明

每个公式文件包含：
- **公式本体**：变量占位符格式
- **示例**：填入实际内容后的完整示例
- **常见错误**：容易出问题的地方
- **适用场景**：何时使用这个公式

---

## 持续优化原则

1. **每次生成都要记录** —— 即使失败了也要记
2. **失败比成功更有价值** —— 失败案例能防止重复踩坑
3. **及时归因** —— 时间久了会忘记当时的判断依据
4. **定期复盘** —— 每月整理一次，提取共性规律
5. **项目间共享** —— 好用的提示词可以在项目间复用

### 即梦漫剧脚本结构

> 参考：Seedance即梦参考库.md

即梦（Seedance）的漫剧提示词有固定格式：
```
【风格】新海诚风格，日系动漫，文艺唯美
【时长】15秒
【人物】角色A：[描述]。角色B：[描述]
【全局要求】一致性要求、格式要求

"[00:00-00:05] 景别。场景。动作。情绪。口型与字幕：[台词]"
"[00:05-00:10] ..."
```

**关键规则**：
1. 风格【风格】必须第一行
2. 角色一次定义清楚，后续不重复
3. 【全局要求】写明一致性（"脸不变，服装不变"）
4. 情绪通过环境外化，不直接写情绪词
5. 给参考视频/图片时用：`将画风对齐 @视频1`

### 情绪光影关键词

| 情绪 | 光影描述 |
|------|---------|
| 希望 | 逆光轮廓光、暖黄透射、阳光穿过窗户 |
| 孤独 | 顶灯单光源、冷调、阴影浓重 |
| 温暖 | 烛光/台灯光、橙黄暖调、柔光 |
| 紧张 | 硬光、强烈明暗对比、阴影锐利 |
| 平静 | 散射光、无硬阴影、均匀照明 |

### 构图关键词

| 类型 | 关键词 |
|------|--------|
| 留白 | negative space, 右侧留白, 左侧留白 |
| 中心 | centered, 对称构图 |
| 三分 | rule of thirds |
| 框架 | frame within frame, 窗框/门框 |
| 引导线 | leading lines, 延伸感 |
| 虚实 | bokeh, shallow depth of field |
