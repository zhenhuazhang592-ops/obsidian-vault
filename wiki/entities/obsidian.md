# Summary

Obsidian is a local knowledge base application that serves as the "IDE" in the LLM Wiki workflow. It provides a markdown-based note-taking environment with features like bidirectional linking, graph visualization, and file management. In the LLM Wiki pattern, the human collaborator browses the wiki in real-time using Obsidian while the LLM agent makes edits based on conversation.

## Key Features

- Markdown-based local storage
- Graph view for visualizing connections
- Bidirectional linking between notes
- Plugin ecosystem for extensibility
