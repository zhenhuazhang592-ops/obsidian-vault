# 牛油果测验

## Question 1
根据视频内容，牛油果植物的哪一部分含有最高浓度的天然抗真菌毒素“波斯进”（persin）？

- [ ] 成熟的果肉
- [x] 叶子、果核和外皮
- [ ] 仅限于根部
- [ ] 牛油果油

**Hint:** 考虑植物用来抵御外部真菌侵害的、通常不被直接食用的“防御层”部分。

## Question 2
一个典型的大型牛油果含有大约多少热量？

- [ ] $150$ 卡路里
- [ ] $200$ 卡路里
- [x] $320$ 卡路里
- [ ] $500$ 卡路里

**Hint:** 这种超级食物以高脂肪含量著称，因此其热量通常比普通水果高出数倍。

## Question 3
为什么对天然橡胶乳胶过敏的人在吃牛油果时需要格外小心？

- [ ] 牛油果含有合成橡胶成分
- [x] 因为两者具有相似结构的蛋白质（交叉反应）
- [ ] 牛油果生长在橡胶树林附近
- [ ] 牛油果皮的质地与乳胶相似

**Hint:** 这涉及到一种免疫系统的“身份误认”现象，即身体混淆了两种不同来源但结构相似的物质。

## Question 4
在切开牛油果之前，最关键的食品安全步骤是什么？

- [ ] 将其在室温下放置三天
- [x] 用冷水冲洗并轻轻刷洗外皮
- [ ] 去除所有黑点
- [ ] 浸泡在盐水中

**Hint:** 即使你不吃皮，刀子穿过果皮的过程也会成为细菌进入果肉的“传送带”。

## Question 5
牛油果中的哪种营养素可能干扰华法林（Warfarin）等血液稀释剂的药效？

- [ ] 钾 ($K^+$)
- [ ] 单不饱和脂肪
- [x] 维生素 $K$
- [ ] 膳食纤维

**Hint:** 这种维生素在人体凝血级联反应中起着核心作用，而抗凝药物正是为了限制它的活动。

## Question 6
服用 ACE 抑制剂或保钾利尿剂的患者食用过多牛油果可能导致什么严重后果？

- [ ] 严重的脱水
- [x] 高钾血症（血钾水平过高）
- [ ] 低血糖休克
- [ ] 维生素 $A$ 中毒

**Hint:** 牛油果是这种矿物质的“发电厂”，含量甚至超过香蕉，这与某些血压药的副作用会产生累积效应。

## Question 7
牛油果对患有肠易激综合征（IBS）的人可能产生负面影响，是因为它含有哪种成分？

- [ ] 草酸盐
- [x] 山梨糖醇（一种 FODMAP）
- [ ] 咖啡因
- [ ] 乳糖

**Hint:** 这种物质属于一类被称为“可发酵碳水化合物”的成分，通常存在于某些糖醇中。

## Question 8
根据戴维斯加州大学的一项研究，市售牛油果油存在的主要问题是什么？

- [ ] 由于需求量大，价格过低
- [x] 大部分产品已氧化或掺入了廉价种子油
- [ ] 它含有的 omega-6 比例过高
- [ ] 它不能用于高温烹饪

**Hint:** 这涉及到食品行业的监管缺失，导致消费者购买的产品可能并不是标签上所写的纯油。

## Question 9
为了获得最佳的营养价值，购买牛油果油时应寻找哪种特征？

- [ ] 完全透明且无色
- [x] 带有绿色色调的深色玻璃瓶装
- [ ] 塑料瓶装以降低成本
- [ ] 标签上注明“美国产品”但无产地细节

**Hint:** 想想如何保护不稳定的油脂免受光线氧化，以及什么颜色代表天然植物营养素的存在。

## Question 10
商店如何人工催熟牛油果，这会产生什么副作用？

- [ ] 通过紫外线照射；增加维生素 $D$
- [x] 通过乙烯气体；可能抑制植物营养素和风味的发育
- [ ] 浸泡在热水浴中；导致纤维分解
- [ ] 使用干冰；导致冷害

**Hint:** 这种气体是植物天然分泌的成熟激素，但工业化大规模应用往往会“揠苗助长”。

## Question 11
快餐店里的“假”牛油果酱（Guacamole）通常使用什么作为主要替代填料？

- [ ] 绿色甜椒
- [x] 青豌豆、淀粉和氢化油
- [ ] 碎菠菜
- [ ] 西葫芦泥

**Hint:** 寻找一种同样是绿色、价格低廉且具有糊状质地的蔬菜替代品。

## Question 12
牛油果如何增强沙拉中其他蔬菜的营养吸收？

- [ ] 它的酸性能分解蔬菜纤维
- [x] 它的脂肪能使类胡萝卜素的吸收率提高 $3$ 到 $5$ 倍
- [ ] 它提供的水分有助于溶解维生素 $C$
- [ ] 它能中和蔬菜中的抗营养因子

**Hint:** 某些维生素（$A$、$D$、$E$、$K$）和抗氧化剂需要通过“脂肪载体”才能进入人体系统。

## Question 13
对于正在管理 $2$ 型糖尿病的人，食用牛油果可能面临哪种由于胰岛素敏感性改变引起的风险？

- [ ] 血糖持续飙升
- [ ] 导致胰岛素失效
- [x] 意外的低血糖（Hypoglycemia）
- [ ] 诱发对甜食的渴望

**Hint:** 虽然提高敏感性通常是好事，但如果与药物叠加，可能会导致血糖水平跌至正常范围以下。

## Question 14
关于牛油果的储存，以下哪项描述符合安全建议？

- [ ] 切开的牛油果可以在室温下放置半天
- [x] 切开后应立即冷藏，并尽量在 $1$ 到 $2$ 天内食用
- [ ] 只要果肉没变黑，就可以一直放在桌上
- [ ] 冷冻牛油果会产生毒素

**Hint:** 食品安全准则强调控制温度以限制病原体（如李斯特菌）的繁殖速度。

## Question 15
随着牛油果的成熟，其内部哪种成分的含量会增加，从而可能引起某些人的过敏反应？

- [ ] 饱和脂肪
- [x] 组胺（Histamine）
- [ ] 钾元素
- [ ] 叶酸

**Hint:** 这种物质通常与发酵、陈年或成熟过程相关，会导致头痛或荨麻疹等反应。
