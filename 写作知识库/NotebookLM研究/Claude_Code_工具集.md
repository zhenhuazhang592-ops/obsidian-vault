# Claude Code 工具集与设置指南

> [!info] 来源
> 基于 YouTube 视频内容整理的 Claude Code 相关工具使用指南。

---

## 十大效率提升工具

### 1. Supabase CLI
- 管理数据库和身份验证
- 通过自然语言创建/编辑数据库
- 比 MCP 更轻量

### 2. Skill Creator (Anthropic)
- 最强大的工具之一
- 可创建、修改、改进技能
- 支持性能测量和 A/B 测试

### 3. GSD 框架
- 规范驱动开发框架
- 项目分解管理
- 上下文窗口管理防止质量下降

### 4. NotebookLM-PI
- 研究分析生成
- 可生成视频、信息图、演示文稿

### 5. Obsidian
- 个人助手场景
- 组织和关联 Markdown 文档

### 6. Vercel CLI
- 管理部署
- 自动检查部署状态

### 7. Playwright CLI
- 浏览器自动化
- 自动填充、测试 UI、表单提交

### 8. GitHub CLI
- 自然语言完成 GitHub 操作
- 推送代码、部署等

### 9. Firecrawl
- AI 代理专用网页抓取
- 生成 AI 友好格式数据

### 10. Excalidraw Diagram Skill
- 自然语言生成图表
- 节省手动绘图时间

## Google Workspace CLI

### 功能
- 控制 Gmail、Google Drive、日历等

### 安全设置

> [!warning] 重要安全措施

1. **启用 Model Armor API**
   - 防范提示词注入攻击
   - 每月 200 万免费代币

2. **沙盒策略**
   - 创建替代邮箱账号
   - 仅通过共享文件夹连接

### 安装流程

1. 安装 Node.js
2. Google Cloud 创建项目
3. 配置 OAuth 同意屏幕
4. 生成桌面应用凭据 JSON
5. 启用相关 API 服务

### 推荐技能
- Gmail
- Docs
- Model Armor
- 行政助理
