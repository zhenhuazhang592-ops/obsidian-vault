# 榴莲稀有品种对比

> [!info] 榴莲概述
> 榴莲主要分布在东南亚热带地区，起源于婆罗洲和苏门答腊。

---

## 主要稀有品种

### 马来西亚名种

| 品种 | 特点 |
|------|------|
| 猫山王 (D197) | 果肉亮黄色，味道更浓郁 |
| 苏丹王 (D24) | 金黄色果肉，质地细腻，苦甜 |
| D88 | 肉厚饱满，苦中带甜 |
| 红虾 (D175) | 椭圆形，肉厚，极甜 |
| 竹脚 (Tekka) | 带有独特的黄色核心 |
| IOI (D168) | 常见品种 |

### 泰国名种

| 品种 | 特点 |
|------|------|
| 金枕头 (Monthong) | 泰国主商业品种，奶油质感 |
| 长柄 (Kan Yao) | 甜度高，气味淡 |
| Chantaburi No.1 | 无味品种 |
| Long Laplae | 无味品种 |

### 非 zibethinus 物种

| 品种 | 特点 |
|------|------|
| 红壳榴莲 (D. dulcis) | 深焦糖味+松节油气味 |
| 红肉榴莲 (D. graveolens) | 烤杏仁香气 |
| 库台榴莲 (D. kutejensis) | 特殊风味 |

## 价格对比

| 等级 | 价格 |
|------|------|
| 一般（泰国金枕头） | ~150元人民币 |
| 高档（猫山王） | ~500元人民币 |
| 稀有原生种 | 高于杂交品种 |

## 产地分布

| 产地 | 特点 |
|------|------|
| 马来西亚彭亨州 | 猫山王发源地 |
| 马来西亚柔佛州 | 主要产地 |
| 泰国尖竹汶府 | 全球领先出口地，占产量50% |
| 菲律宾达沃地区 | 占全国产量60% |

## 鉴别方法

### 底部特征

> [!tip] 鉴别要点

| 品种 | 底部特征 |
|------|----------|
| 猫山王 (D197) | 五角星/五毛钱硬币大小黑色圆点 |
| 苏丹王 (D24) | 五分到一角硬币大小凹陷点 |
| D88 | 点非常小 |

### 果柄与外壳

| 品种 | 特征 |
|------|------|
| D24 | 果柄长且弯曲翘起，刺粗分布不均 |
| D88 | 刺较短，果实形状不同 |
| 竹脚 | 果肉中心轴带黄色核心 |
