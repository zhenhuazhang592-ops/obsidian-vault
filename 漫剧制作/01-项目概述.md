# 漫剧制作项目方案

## 项目目标

打造一站式AI漫剧制作系统，将小说/脚本自动转化为动态漫画短剧。

## 核心流程 (7步)

```
小说/脚本 → 角色设定 → 剧本生成 → 分镜设计 → 图片生成 → 视频合成 → 后期制作
```

## 对标参考

- **Toonflow-app**: AI短剧工厂架构 (小说→视频)
- **baoyu-comic**: 知识漫画制作规范 (分镜→图片→PDF)

## Step 0: 前期准备

### 0.1 确定内容来源

| 来源类型 | 说明 | 适用场景 |
|---------|------|---------|
| 小说文本 | 已有小说作品 | 小说影视化 |
| 原创脚本 | 自己编写的剧本 | 原创漫剧 |
| 文章改写 | 将文章转化为漫剧 | 知识科普 |

### 0.2 确定作品参数

| 参数 | 选项 | 说明 |
|-----|------|------|
| 画风 | 日漫/美漫/国风/写实/水墨 | 视觉风格 |
| 时长 | 1-3分钟/3-5分钟/5-10分钟 | 短剧时长 |
| 集数 | 单集/3-5集/多集连载 | 作品规模 |
| 画幅 | 9:16 (竖屏) / 16:9 (横屏) | 输出比例 |
