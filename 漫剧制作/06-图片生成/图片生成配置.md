# 图片生成配置

## 常用AI绘图工具

### 1. Midjourney

```bash
# 基础命令
/imagine prompt: [提示词] --ar [比例] --v [版本] --s [风格化]

# 常用参数
--ar 9:16      # 竖屏
--ar 16:9      # 横屏
--ar 3:4       # 漫画常用比例
--v 6          # 版本
--s 250        # 风格化程度
--iw 0.5       # 参考图权重
```

### 2. Stable Diffusion

```bash
# 基础参数
prompt: [正向提示词]
negative_prompt: [负向提示词]
width: 1024
height: 1536
steps: 30
cfg_scale: 7
seed: -1
```

### 3. DALL-E

```bash
# 基础调用
prompt: [提示词]
size: 1024x1024 / 1792x1024 / 1024x1792
quality: standard / hd
style: vivid / natural
```

## 参数配置表

### 画幅比例

| 用途 | 比例 | 尺寸 | 备注 |
|-----|------|-----|------|
| 竖屏短视频 | 9:16 | 720x1280 | 抖音/快手 |
| 横屏视频 | 16:9 | 1920x1080 | YouTube |
| 漫画 | 3:4 | 768x1024 | 公众号/小红书 |
| 宽幅 | 4:3 | 1024x768 | 横板漫画 |
| 方图 | 1:1 | 1024x1024 | 社交媒体 |

### 画质参数

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| 分辨率 | 1024x1536 | 兼顾质量和速度 |
| Steps | 25-35 | 迭代次数 |
| CFG Scale | 6-8 | 提示词引导 |
| Seed | -1/固定 | 随机/复现 |

## 批量生成配置

### 生成清单

```yaml
batch_generation:
  scene: 第X集
  shots:
    - shot_id: 1.01.01
      prompt_file: prompts/001.md
      output_file: images/001.png
      reference: characters/character.png

    - shot_id: 1.01.02
      prompt_file: prompts/002.md
      output_file: images/002.png
      reference: characters/character.png
```

### 生成顺序

1. 先生成角色参考图 (确保一致性)
2. 生成关键帧/重要镜头
3. 依次生成其他镜头
4. 批量检查和重修

## 质量控制

### 生成前检查

- [ ] 提示词完整无误
- [ ] 参考图已准备
- [ ] 角色描述已嵌入
- [ ] 画风参数正确

### 生成后检查

- [ ] 角色一致性
- [ ] 画面构图
- [ ] 色彩氛围
- [ ] 细节质量

### 重修标准

| 优先级 | 问题类型 | 处理方式 |
|-------|---------|---------|
| P0 | 角色变形 | 重新生成 |
| P1 | 构图问题 | 局部重修 |
| P2 | 细节瑕疵 | 手动修复 |
| P3 | 氛围不足 | 微调优化 |
