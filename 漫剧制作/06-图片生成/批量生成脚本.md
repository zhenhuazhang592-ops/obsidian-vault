# 批量生成脚本

## 图片批量生成流程

```
步骤1: 准备提示词文件
↓
步骤2: 整理生成清单
↓
步骤3: 配置生成参数
↓
步骤4: 执行批量生成
↓
步骤5: 质量检查
↓
步骤6: 重修不合格图片
↓
步骤7: 整理最终图片
```

## 提示词文件准备

### 文件命名规范

```
格式: [序号]-[镜头号]-[描述].md
示例: 001-101-城市全景.md
      002-102-角色对话.md
```

### 提示词文件内容

```markdown
# 镜头 1.01.01: 城市全景

## 基本信息
- 景别: 远景
- 角度: 俯视
- 运动: 固定

## 画面内容
黄昏时分，从高楼俯瞰城市全景。
远处可见CBD建筑群，街道上车流如织。
天空呈现橙黄色渐变，有晚霞。

## 角色
无

## 构图
远景, 俯视角度, 横向构图
电影宽银幕比例

## AI提示词
黄昏城市全景, 俯瞰视角, CBD建筑群,
车流光轨, 晚霞, 橙黄色天空,
城市天际线, 远景, 俯视,
电影感, 宽银幕构图, 史诗感,
写实漫画风格, 8k, 高画质, 细节丰富

## 负向提示词
low quality, worst quality, cartoon, anime style
```

### API 调用示例

```python
import requests
import time

def generate_image(prompt, output_path, reference=None):
    """生成单张图片"""
    url = "https://api.example.com/v1/generation"

    payload = {
        "prompt": prompt,
        "width": 1024,
        "height": 1536,
        "num_inference_steps": 30,
        "guidance_scale": 7.5,
        "reference_image": reference
    }

    response = requests.post(url, json=payload)
    # 处理响应，保存图片
    save_image(response, output_path)

def batch_generate(shot_list):
    """批量生成"""
    results = []

    for shot in shot_list:
        print(f"生成中: {shot['shot_id']}")

        # 读取提示词
        with open(shot['prompt_file'], 'r') as f:
            prompt = extract_prompt(f.read())

        # 生成图片
        result = generate_image(
            prompt=prompt,
            output_path=shot['output_file'],
            reference=shot.get('reference')
        )

        results.append({
            'shot_id': shot['shot_id'],
            'status': 'success' if result else 'failed',
            'output': shot['output_file']
        })

        # 避免API限流
        time.sleep(3)

    return results
```

## 生成结果检查

### 检查清单

```yaml
checklist:
  - shot_id: 1.01.01
    passed: true
    issues: []
    notes: "完美"

  - shot_id: 1.01.02
    passed: false
    issues:
      - "角色脸部变形"
      - "构图偏右"
    fix_action: "重新生成"
```

### 问题分类

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 角色变形 | 提示词不准确 | 优化提示词，加详细描述 |
| 风格不一致 | 参考图不够强 | 提高参考图权重 |
| 构图问题 | 提示词描述不完整 | 指定构图方式 |
| 细节不足 | 参数不够 | 增加steps，提高分辨率 |
