# 画面提示词模板

## 基础提示词结构

```yaml
# AI绘图提示词

## 画面内容
[场景描述 + 角色 + 动作 + 物品]

## 构图
[景别 + 角度 + 摄像机位置]

## 氛围
[光线 + 色调 + 情绪]

## 风格
[画风 + 质感 + 参考]

## 质量词
[高画质 + 细节丰富 + 专业摄影感]
```
