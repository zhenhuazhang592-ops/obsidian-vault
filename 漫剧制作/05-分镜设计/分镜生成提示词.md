# 分镜生成提示词

## Step 1: 场景拆分

### 场景拆分提示词

```
你是分镜规划师。请根据以下剧本内容进行场景拆分。

## 任务说明

1. 识别剧本中的所有场景
2. 为每个场景确定: 场景名、地点、时间、天气、氛围
3. 列出每个场景的出场角色
4. 估算每个场景的镜头数量

## 输出格式

```yaml
scenes:
  - scene_id: 1
    name: 场景名称
    location: 具体地点
    time: 日/夜
    weather: 天气
    atmosphere: 氛围描述
    characters: [角色列表]
    duration: 估计时长
    shot_count: 建议镜头数

  - scene_id: 2
    ...
```

## 剧本内容

[粘贴剧本内容]
```

---

## Step 2: 生成分镜

### 分镜生成提示词

```
你是分镜设计师。请根据以下场景和剧本内容生成分镜。

## 任务说明

1. 为每个场景设计多个镜头
2. 每个镜头要包含: 景别、角度、运动、时长、画面描述、角色动作、对话、AI绘图提示词
3. 确保镜头语言连贯
4. 镜头数量要合理控制

## 画风要求
- 画风: [日漫/美漫/国风/写实]
- 色调: [暖色/冷色/中性]
- 风格参考: [参考作品]

## 角色库
[角色设定摘要]

## 场景信息

```yaml
scenes:
  - scene_id: 1
    name: 场景名
    location: 地点
    time: 日/夜
    atmosphere: 氛围
```

## 剧本内容

[粘贴对应剧本内容]
```

---

## Step 3: 分镜优化

### 分镜优化提示词

```
请优化以下分镜方案。

## 优化目标

1. 提升画面表现力
2. 优化镜头节奏
3. 增强视觉冲击力
4. 确保叙事流畅

## 当前分镜

[粘贴当前分镜内容]

## 优化要求

- 景别要有变化 (远→全→中→近→特)
- 角度要多样化
- 关键镜头要突出
- 情绪节奏要合理
```

---

## 分镜审核检查

### 逻辑检查

- [ ] 场景转换是否合理
- [ ] 角色进出画面是否自然
- [ ] 视线方向是否一致
- [ ] 动作是否连贯

### 视觉检查

- [ ] 景别是否有变化
- [ ] 角度是否多样化
- [ ] 构图是否平衡
- [ ] 运动是否有节奏

### 技术检查

- [ ] 时长是否合适
- [ ] 转场是否自然
- [ ] 提示词是否完整
- [ ] 对话位置是否正确

  priority: 高/中/低
```
