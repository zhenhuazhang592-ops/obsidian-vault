# 分镜模板

## 分镜表模板

```yaml
---
episode: 第X集
title: 集标题
total_scenes: 场景数量
total_shots: 总镜头数
duration: 预计时长
---

# 分镜总览

| 镜头号 | 场景 | 景别 | 角度 | 运动 | 时长 | 内容描述 |
|-------|------|-----|------|-----|------|---------|
| 1 | 1 | 远景 | 固定 | 无 | 5s | 城市全景 |
| 2 | 1 | 全景 | 俯视 | 摇 | 3s | 街道环境 |
| ... | ... | ... | ... | ... | ... | ... |
```

## 单镜分镜卡

```yaml
# 分镜卡片

| 字段 | 内容 |
|-----|------|
| 景别 | 远景/全景/中景/近景/特写 |
| 角度 | 正面/侧面/背面/俯视/仰视 |
| 运动 | 固定/推/拉/摇/移/跟/升/降 |
| 时长 | X秒 |
| 转场 | 切换/淡入淡出/叠化 |

## 画面描述

### 画面内容
[画面中出现的所有元素]

### 角色动作
[角色的动作描述]

### 摄像机运动
[摄像机如何移动]

## 文案内容

### 对话
**角色A**: "对话内容"
**角色B**: "对话内容"

### 旁白
"旁白内容"

### 音效
[音效描述]

### 音乐
[背景音乐描述]

## AI绘图提示词

[为本镜头生成的详细绘图提示词]

## 参考
- 参考图: [如果有]
- 角色状态: [表情/动作]
```

## 分镜布局模板

### 标准格

```
┌─────────────┐
│             │
│   画面内容   │
│             │
└─────────────┘
  [对话/旁白]
```

### 双格横排

```
┌─────────────┬─────────────┐
│             │             │
│   画面1     │   画面2    │
│             │             │
└─────────────┴─────────────┘
    [对话1]      [对话2]
```

### 多格漫画布局

```
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
├─────┼─────┼─────┤
│  7  │  8  │  9  │
└─────┴─────┴─────┘
```

### 电影感横版

```
┌───────────────────────────────────────┐
│                                       │
│              宽幅画面                  │
│                                       │
└───────────────────────────────────────┘
              [宽幅对话]
```

## 分镜编号规范

```
格式: [集数].[场景号].[镜头号]
示例: 1.01.01 (第1集第1场景第1镜头)

镜头号: 01-99
场景号: 01-99
集号: 01-99 (多集作品)
```

---

## 分镜审核清单

- [ ] 镜头数量适中 (单集15-30个)
- [ ] 景别变化丰富
- [ ] 角度有多样性
- [ ] 运动有节奏感
- [ ] 时长分配合理
- [ ] 转场自然流畅
- [ ] 角色视线连贯
- [ ] 动作描述清晰
- [ ] 对话位置正确
- [ ] 提示词完整准确
