# 工作流自动化

## 完整制作流程

```
Step 0: 准备 → Step 1: 角色 → Step 2: 剧本 → Step 3: 分镜
    → Step 4: 图片 → Step 5: 视频 → Step 6: 后期 → Step 7: 输出
```

---

## Step 0: 开始前准备

### 0.1 创建项目文件夹

```
漫剧项目/
├── 00_素材/
├── 01_角色/
├── 02_剧本/
├── 03_分镜/
├── 04_图片/
├── 05_视频/
└── 06_输出/
```

### 0.2 准备内容

- [ ] 小说/脚本文本
- [ ] 作品信息 (标题、类型、风格)
- [ ] 目标平台

---

## Step 1: 角色设定

### 操作流程

1. **输入**: 小说/脚本文本
2. **使用工具**: `03-角色设定/角色生成提示词.md`
3. **生成**: 角色列表 + 角色设定
4. **生成参考图**: 使用文生图工具生成角色参考图
5. **输出**: `01_角色/characters.yaml` + `01_角色/ref.png`

### 产出文件

```
01_角色/
├── characters.yaml    # 角色设定
├── 角色A_ref.png     # 角色参考图
└── 角色B_ref.png
```

---

## Step 2: 剧本生成

### 操作流程

1. **输入**: 小说文本 + 角色设定
2. **使用工具**: `04-剧本生成/剧本生成提示词.md`
3. **生成**: 故事线 → 分集大纲 → 详细剧本
4. **输出**: `02_剧本/storyline.yaml` + `02_剧本/episodes/` + `02_剧本/script.md`

### 产出文件

```
02_剧本/
├── storyline.yaml     # 故事线
├── outline.yaml      # 分集大纲
├── script_ep1.md     # 第1集剧本
└── script_ep2.md     # 第2集剧本
```

---

## Step 3: 分镜设计

### 操作流程

1. **输入**: 剧本内容
2. **使用工具**: `05-分镜设计/分镜生成提示词.md` + `05-分镜设计/画面提示词模板.md`
3. **生成**: 场景拆分 → 分镜表 → 画面提示词
4. **输出**: `03_分镜/storyboard.yaml` + `03_分镜/prompts/`

### 产出文件

```
03_分镜/
├── storyboard.yaml       # 分镜总表
├── ep1_shots.yaml       # 第1集分镜
└── prompts/
    ├── 001_城市全景.md
    ├── 002_角色对话.md
    └── ...
```

---

## Step 4: 图片生成

### 操作流程

1. **输入**: 分镜提示词 + 角色参考图
2. **使用工具**: `06-图片生成/图片生成配置.md` + `06-图片生成/批量生成脚本.md`
3. **生成**: 使用Midjourney/SD等工具生成图片
4. **输出**: `04_图片/` 目录

### 产出文件

```
04_图片/
├── 001_城市全景.png
├── 002_角色对话.png
└── ...
```

---

## Step 5: 视频合成

### 操作流程

1. **输入**: 漫画图片 + 配音 + BGM
2. **使用工具**: `07-视频合成/动态漫制作指南.md`
3. **制作**: 添加镜头运动 → 添加配音 → 添加转场
4. **输出**: `05_视频/` 目录

### 产出文件

```
05_视频/
├── ep1_draft.mp4      # 第1集草稿
├── ep1_final.mp4      # 第1集成片
└── ...
```

---

## Step 6: 后期制作

### 操作流程

1. **输入**: 视频粗片
2. **使用工具**: `08-后期制作/配乐音效配置.md`
3. **制作**: 调色 → 添加音效 → 添加字幕
4. **输出**: 成片

---

## Step 7: 输出发布

### 操作流程

1. **使用工具**: `09-输出规范/输出格式标准.md`
2. **检查**: 格式 + 画质 + 音量
3. **导出**: 各平台适配版本
4. **发布**: 上传各平台

---

## 检查清单

### 每集完成后检查

| 步骤 | 检查项 | 状态 |
|-----|-------|------|
| 剧本 | 逻辑通顺 | ☐ |
| 分镜 | 画面完整 | ☐ |
| 图片 | 角色一致 | ☐ |
| 视频 | 流畅度 | ☐ |
| 后期 | 音画同步 | ☐ |
| 输出 | 格式正确 | ☐ |
