# 后期制作清单

## 后期制作流程

```
配音配乐 → 音效设计 → 特效合成 → 调色 → 字幕 → 输出
```

---

## Step 1: 配音配乐

### 配音清单

| 类型 | 内容 | 来源 | 时长 |
|-----|------|-----|------|
| 对白 | 角色对话 | TTS/录音 | 按剧本 |
| 旁白 | 叙述 | TTS/录音 | 按剧本 |
| 内心独白 | 角色想法 | TTS/录音 | 按剧本 |

### 配乐清单

| 场景 | 音乐风格 | 来源 | 时长 |
|-----|---------|------|------|
| 开场 | 史诗/悬疑 | 版权音乐 | 30s |
| 对话 | 舒缓/紧张 | 版权音乐 | 按场景 |
| 高潮 | 激烈/动作 | 版权音乐 | 按场景 |
| 结尾 | 温馨/悬念 | 版权音乐 | 30s |

---

## Step 2: 音效设计

### 常用音效

| 场景 | 音效类型 | 备注 |
|-----|---------|------|
| 室内 | 脚步声, 门声, 环境音 | 背景氛围 |
| 室外 | 车声, 人声, 自然音 | 环境氛围 |
| 动作 | 打击声, 风声, 特效音 | 增强冲击 |
| 心理 | 心跳, 呼吸, 内心 | 渲染情绪 |

### 音效位置

```yaml
audio:
  effects:
    - name: 开门声
      timestamp: 00:15:30
      volume: 0.7

    - name: 脚步声
      timestamp: 00:15:32
      volume: 0.5

    - name: 背景音乐
      from: 00:00:00
      to: 00:02:00
      volume: 0.3
```

---

## Step 3: 特效合成

### 特效清单

| 类型 | 内容 | 工具 |
|-----|------|-----|
| 转场 | 淡入淡出/滑动/缩放 | AE/剪映 |
| UI | 对话泡/特效文字 | AE/PS |
| 粒子 | 火花/烟雾/樱花 | AE/粒子插件 |
| 光效 | 光晕/光斑/反射 | AE/PS |

---

## Step 4: 调色

### 调色方向

| 风格 | 色调 | 适用场景 |
|-----|------|---------|
| 清新 | 蓝绿色调, 高明度 | 校园/日常 |
| 怀旧 | 暖黄色调, 低饱和 | 回忆/过去 |
| 悬疑 | 冷蓝色调, 低明度 | 惊悚/推理 |
| 热血 | 红橙色调, 高饱和 | 战斗/激情 |

### 调色参数

```yaml
color_grading:
  style: "清新"

  adjustments:
    brightness: +5
    contrast: +10
    saturation: -5

  color_wheels:
    shadows: "#1a2a3a"  # 阴影偏蓝
    midtones: "#4a5a6a" # 中间调
    highlights: "#ffe0b0" # 高光偏暖
```

## Step 5: 字幕

### 字幕清单

| 类型 | 内容 | 格式 |
|-----|------|-----|
| 对话 | 角色对话 | 对话泡/底部 |
| 旁白 | 叙述文字 | 底部居中 |
| 特效 | 说明文字 | 位置根据画面 |
| 片头 | 标题 | 大字标题 |
| 片尾 | 演职员表 | 滚动字幕 |

---

## Step 6: 输出

### 输出检查

- [ ] 画面流畅
- [ ] 声音清晰
- [ ] 音量平衡
- [ ] 字幕同步
- [ ] 无杂音/噪音

|-----|------|-------|-----|
| 抖音 | MP4 | 1080x1920 | 8-12Mbps |
| 快手 | MP4 | 1080x1920 | 8-12Mbps |
| 小红书 | MP4 | 1080x1920 | 8-12Mbps |
| YouTube | MP4 | 1920x1080 | 10-15Mbps |
