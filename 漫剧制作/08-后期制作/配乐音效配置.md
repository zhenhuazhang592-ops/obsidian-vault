## 音量配置

### 混音比例

| 轨道 | 音量 | 说明 |
|-----|------|------|
| 对白 | 0dB (最大) | 最清晰 |
| 旁白 | -3dB | 略低于对白 |
| BGM | -12dB 到 -18dB | 背景 |
| 音效 | -6dB 到 -12dB | 辅助 |
| 环境音 | -18dB 到 -24dB | 氛围 |

### 音量曲线

```yaml
mixing:
  dialogue:
    level: 0dB
    compression: true

  music:
    level: -12dB
    duck_when_speaking: true

  sfx:
    level: -6dB
    fade_in: 0.1s
    fade_out: 0.2s
```
