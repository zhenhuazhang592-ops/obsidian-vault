# 动态漫制作指南

## 动态漫是什么

动态漫是将静态漫画图片通过以下方式"动起来"：
- 镜头运动 (缩放/平移/旋转)
- 逐帧动画 (口型/眨眼/飘动)
- 配音配乐
- 特效叠加

---

## Step 1: 图片整理

### 整理要求

1. **命名规范**
   ```
   E01_S01_001.png  # 第1集 第1场景 第1个镜头
   ```

2. **尺寸统一**
   - 统一为 1080x1920 (竖屏)
   - 或 1920x1080 (横屏)

3. **质量检查**
   - [ ] 分辨率达标
   - [ ] 无明显瑕疵
   - [ ] 角色一致性

---

## Step 2: 添加动态效果

### 方法一: 剪映制作

1. **导入图片**
   - 打开剪映
   - 导入所有漫画图片
   - 勾选"图片时长"设置每张显示时长

2. **添加动画**
   - 选中图片
   - 点击"动画" → 选择动画效果
   - 常用: "放大"、"缩小"、"淡入淡出"

3. **添加关键帧** (高级)
   - 点击"关键帧"
   - 在不同时间点设置缩放/位置

### 方法二: AE/PR制作

1. **导入图片序列**
   - 文件 → 导入 → 文件/文件夹

2. **添加摄像机运动**
   - 效果 → 缩放/位置/旋转
   - 关键帧动画

3. **添加细节动画**
   - 角色眨眼: 替换眨眼帧
   - 头发飘动: 路径动画
   - 物体移动: 位移动画

---

## Step 3: 配音制作

### AI配音工具

| 工具 | 特点 | 适用场景 |
|-----|------|---------|
| 11Labs | 自然, 多语言 | 对话 |
| 微软TTS | 稳定 | 旁白 |
| 剪映配音 | 简单 | 快速制作 |
| 讯飞 | 中文自然 | 中文配音 |

### 配音流程

1. **提取对白**
   从剧本中提取所有对话

2. **生成分角色音**
   使用TTS工具生成

3. **调整时长**
   对齐口型时间

4. **添加背景音乐**
   选择适合风格的BGM

---

## Step 4: 字幕制作

### 字幕格式

| 格式 | 说明 |
|-----|------|
| SRT | 通用字幕格式 |
| ASS | 支持特效字幕 |
| 剪映内置 | 可视化编辑 |

### 对话泡效果

1. **制作对话泡**
   - 使用PS/Canva制作对话泡PNG
   - 或使用剪映内置素材

2. **添加动画**
   - 对话泡出现动画
   - 对话泡消失动画

---

## Step 5: 特效添加

### 常用特效

| 特效 | 场景 | 实现方式 |
|-----|------|---------|
| 速度线 | 动作 | AE/剪映 |
| 冲击波 | 战斗 | 叠加特效 |
| 闪光 | 强调 | 闪白/闪黑 |
| 火花 | 碰撞 | 粒子效果 |
| 樱花飘落 | 浪漫 | 粒子动画 |

### 特效叠加

```
1. 在需要添加特效的画面上新建图层
2. 导入特效素材 (PNG/视频)
3. 调整位置和大小
4. 设置混合模式 (通常用"叠加"或"滤色")
5. 设置不透明度
```

---

## Step 6: 导出设置

### 推荐参数

| 参数 | 值 |
|-----|-----|
| 格式 | MP4 |
| 分辨率 | 1080x1920 |
| 帧率 | 30fps |
| 码率 | 高 (8-12Mbps) |
| H.264 | 是 |

### 平台适配

- 抖音/快手: 竖屏9:16, 带封面
- 小红书: 竖屏9:16
- YouTube: 横屏16:9
