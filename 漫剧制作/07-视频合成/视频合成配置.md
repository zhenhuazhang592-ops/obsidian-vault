# 视频合成配置

## 动态漫制作概述

动态漫 = 图片序列 + 镜头运动 + 配音配乐 + 特效

---

## 视频参数配置

### 输出格式

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| 格式 | MP4 | 兼容性最好 |
| 编解码 | H.264 | 通用 |
| 分辨率 | 1080x1920 | 竖屏9:16 |
| 帧率 | 24fps | 电影标准 |
| 码率 | 8-12Mbps | 高画质 |

### 画幅设置

| 平台 | 分辨率 | 比例 |
|-----|-------|------|
| 抖音/快手 | 1080x1920 | 9:16 |
| 小红书 | 1080x1920 | 9:16 |
| YouTube | 1920x1080 | 16:9 |
| 微信 | 1080x1920 | 9:16 |

## 镜头运动配置

### 自动运动效果

| 效果 | 用途 | 参数 |
|-----|------|------|
| 缩放 | 突出细节 | 缩放比例: 1.0-1.3 |
| 平移 | 展示场景 | 移动方向: L/R/U/D |
| 旋转 | 强调 | 角度: -10~10度 |
| 淡入淡出 | 转场 | 时长: 0.5s |

### 逐帧动画

```yaml
animation:
  type: keyframe  # 关键帧动画

  keyframes:
    - time: 0%
      scale: 1.0
      position: center

    - time: 50%
      scale: 1.2
      position: center

    - time: 100%
      scale: 1.0
      position: center
```

## 动态漫制作流程

```
Step 1: 图片整理
  ↓
Step 2: 添加镜头运动
  ↓
Step 3: 添加转场效果
  ↓
Step 4: 配音/配乐
  ↓
Step 5: 添加字幕
  ↓
Step 6: 添加特效
  ↓
Step 7: 导出成片
```

## 动态效果配置

### 图片动态化

```yaml
image_to_video:
  input: static_image.png
  output: animated_video.mp4

  effects:
    - type: zoom
      start: 1.0
      end: 1.2
      duration: 3s

    - type: pan
      direction: left_to_right
      duration: 2s
```

### 特效叠加

```yaml
effects:
  - name: 速度线
    trigger: 动作场景
    opacity: 0.3

  - name: 闪白
    trigger: 冲击画面
    duration: 0.1s

  - name: 震动
    trigger: 碰撞场景
    intensity: medium
```

## 配音配置

### 配音类型

| 类型 | 来源 | 格式 |
|-----|------|-----|
| AI配音 | TTS工具 | MP3/WAV |
| 人声配音 | 录音 | MP3/WAV |
| 旁白 | 录音/TTS | MP3/WAV |

### 音轨配置

```yaml
audio_tracks:
  - name: 对白
    source: dialogue.mp3
    volume: 0.8

  - name: 背景音乐
    source: bgm.mp3
    volume: 0.3

  - name: 音效
    source: sfx/
    volume: 0.5
```

## 字幕配置

### 字幕格式

```yaml
subtitle:
  font: "思源黑体"
  size: 32
  color: "#FFFFFF"
  stroke: "#000000"
  stroke_width: 2
  position: bottom_center

  # 对话泡字幕
  bubble:
    enabled: true
    style: round_rect
    background: "#FFFFFF"
    tail: left/right
```
