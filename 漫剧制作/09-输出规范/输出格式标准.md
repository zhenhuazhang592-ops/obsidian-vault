# 输出格式标准

## 文件命名规范

### 项目命名

```
[作品名]_[集数]_[版本].mp4
示例: 仙逆动态漫_第01集_v1.mp4
```

### 图片命名

```
[集数]_[场景]_[镜头号]_[版本].png
示例: E01_S01_001_v1.png
```

### 素材命名

```
[类型]_[名称]_[版本].[格式]
示例: BGM_温馨日常_v1.mp3
     SFX_脚步声_v1.mp3
```

## 输出格式要求

### 视频输出

| 平台 | 格式 | 分辨率 | 帧率 | 码率 | 时长 |
|-----|------|-------|------|-----|-----|
| 抖音 | MP4 | 1080x1920 | 30fps | 8Mbps | ≤3分钟 |
| 快手 | MP4 | 1080x1920 | 30fps | 8Mbps | ≤3分钟 |
| 小红书 | MP4 | 1080x1920 | 30fps | 8Mbps | ≤60秒 |
| YouTube | MP4 | 1920x1080 | 30fps | 10Mbps | 无限制 |
| 微信 | MP4 | 1080x1920 | 30fps | 8Mbps | ≤60秒 |

### 图片输出

| 用途 | 格式 | 分辨率 | 模式 |
|-----|------|-------|------|
| 漫画 | PNG | 1024x1536 | RGB |
| 封面 | JPG/PNG | 1080x1920 | RGB |
| 素材 | PNG | 源分辨率 | RGB |

### 音频输出

| 用途 | 格式 | 采样率 | 比特率 |
|-----|------|-------|--------|
| 配音 | MP3 | 44.1kHz | 128kbps |
| BGM | MP3 | 44.1kHz | 192kbps |
| 音效 | WAV/MP3 | 44.1kHz | 256kbps |

## 元数据要求

### 视频元数据

```yaml
metadata:
  title: "作品标题"
  description: "作品简介"
  author: "作者"
  copyright: "版权信息"
  tags: ["标签1", "标签2"]

  # 视频信息
  duration: 120  # 秒
  resolution: "1080x1920"
  fps: 30
  codec: "h264"

  # 音频信息
  audio_codec: "aac"
  audio_channels: 2
  audio_sample_rate: 44100
```

---

## 封面要求

### 封面规格

| 平台 | 尺寸 | 比例 | 格式 |
|-----|------|-----|-----|
| 抖音 | 1080x1920 | 9:16 | JPG |
| 快手 | 1080x1920 | 9:16 | JPG |
| 小红书 | 1080x1464 | 3:4 | JPG |
| YouTube | 1280x720 | 16:9 | JPG |

### 封面内容

- 作品标题 (大字)
- 关键画面 (1-2个)
- 作者/制作方标识
- 适当留白

## 版本管理

### 版本命名

```
v1.0  # 初始版本
v1.1  # 小幅修改
v2.0  # 重大修改
v2.1  # 修复版本
```

### 版本记录

```yaml
versions:
  - version: v1.0
    date: 2024-01-01
    description: "初版发布"
    author: "制作者"

  - version: v1.1
    date: 2024-01-05
    description: "修复配音问题"
    author: "制作者"
```
