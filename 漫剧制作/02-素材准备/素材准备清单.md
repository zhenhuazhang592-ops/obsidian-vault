# 素材准备清单

## Step 1: 内容素材

### 1.1 小说/脚本格式要求

```markdown
# 作品标题

## 第1章 章节名
章节内容...

## 第2章 章节名
章节内容...
```

### 1.2 素材检查清单

- [ ] 小说/脚本完整文本
- [ ] 作品简介 (100-300字)
- [ ] 作品类型标签
- [ ] 目标受众定位

### 1.3 素材预处理

1. **文本清洗**
   - 去除乱码和特殊字符
   - 统一标点符号
   - 分段落整理

2. **章节划分**
   - 清晰标记章节边界
   - 标注重要情节点

## Step 2: 辅助素材

### 2.1 参考图片

| 素材 | 用途 | 数量 |

| 角色参考图 | 角色外貌参照 | 每角色1-3张 |

| 类型 | 用途 | 格式 |
|-----|------|-----|
