# 剧本生成提示词

## 模式一: 小说转剧本

### 第一步: 生成故事线

```
你是故事线编剧。请根据以下小说内容生成故事线。

## 任务说明

1. 梳理小说主线剧情
2. 提取关键情节点
3. 确定核心矛盾冲突
4. 划分故事结构 (起承转合)

## 输出格式

```yaml
storyline:
  title: 作品标题
  genre: 题材类型

  main_conflict: |
    核心矛盾: [A想要X vs B阻碍X]

  story_arc:
    - stage: "起"
      description: "故事开篇，交代背景"
      key_events: [关键事件1, 关键事件2]

    - stage: "承"
      description: "情节发展，矛盾初现"
      key_events: [关键事件1, 关键事件2]

    - stage: "转"
      description: "高潮冲突，形势逆转"
      key_events: [关键事件1, 关键事件2]

    - stage: "合"
      description: "结局收尾，悬念延续"
      key_events: [关键事件1, 关键事件2]

  characters: |
    主要角色及关系简述

  setting: |
    时代背景和世界观
```

## 小说内容

[粘贴小说全文或关键章节]
```

---

### 第二步: 生成分集大纲

```
你是大纲编剧。请根据以下故事线生成分集大纲。

## 任务说明

1. 将故事线拆分为多集
2. 每集包含: 标题、概要、核心矛盾、场景列表
3. 情节点要符合"起承转合"结构
4. 合理分配每集时长

## 输出格式

```yaml
outline:
  total_episodes: 总集数

  episodes:
    - episode: 1
      title: "第1集标题"
      chapter_range: [涉及章节]
      summary: "本集概要(50-100字)"
      core_conflict: "本集核心矛盾"
      opening_hook: "开场镜头描述"
      key_events:
        - 起: [情节点]
        - 承: [情节点]
        - 转: [情节点]
        - 合: [情节点]
      scenes:
        - name: 场景1
          location: 地点
          time: 日/夜
          characters: [角色列表]
        - name: 场景2
          location: 地点
          time: 日/夜
          characters: [角色列表]
      ending_hook: "本集结尾悬念"
      classic_quotes:
        - "经典台词1"
```

## 故事线

[粘贴已生成的故事线]
```

---

### 第三步: 生成详细剧本

```
你是剧本编剧。请根据以下分集大纲生成详细的剧本内容。

## 任务说明

1. 将大纲扩展为详细的剧本格式
2. 每个场景包含多个镜头
3. 镜头要有画面描述、角色动作、对话
4. 控制单集镜头数量 (15-30个镜头)

## 剧本格式

```yaml
episode: 第X集
title: 集标题
summary: 本集概要

## 场景1: [场景名]
### 镜头1.1
[远景/全景/中景/近景/特写] [角度] [运动]
画面: [画面描述]
动作: [角色动作]
对话: |
  角色A: "对话内容"
  角色B: "对话内容"

### 镜头1.2
[远景/全景/中景/近景/特写] [角度] [运动]
画面: [画面描述]
动作: [角色动作]
对话: |
  ...

## 场景2: [场景名]
...
```

## 分集大纲

[粘贴要转化的分集大纲]
```

## 模式二: 原创剧本

### 原创剧本提示词

```
你是原创剧本编剧。请根据以下要求创作漫剧剧本。

## 创作要求

- 题材: [选择或指定]
- 风格: [画风要求]
- 时长: [单集时长]
- 集数: [集数]
- 受众: [目标受众]

## 核心设定

### 主角设定
- 姓名:
- 性格:
- 目标:
- 困境:

### 世界观设定
[时代背景/世界观描述]

### 核心冲突
[A vs B的核心矛盾]

## 输出要求

请按以下结构输出:
1. 故事线 (整体概述)
2. 分集大纲 (每集概要)
3. 详细剧本 (第一集完整剧本)

## 格式要求

参考剧本模板格式输出。
```

## 剧本优化提示词

### 优化对话

```
请优化以下剧本中的对话部分。

## 要求

1. 对话要符合角色性格
2. 避免冗余对白
3. 增加戏剧张力
4. 适当留白

## 原剧本

[粘贴需要优化的剧本]
```

### 节奏调整

```
请分析以下剧本的节奏，并提出调整建议。

## 分析维度

1. 情节点分布
2. 情绪曲线
3. 节奏快慢
4. 高潮安排

## 剧本内容

[粘贴剧本]
```

## 剧本审核反馈模板

```yaml
review:
  episode: 第X集
  status: 待修改/通过/需大改

  scores:
    logic: 1-10  # 逻辑性
    character: 1-10  # 角色表现
    dialogue: 1-10  # 对话质量
    pacing: 1-10  # 节奏把控
    visual: 1-10  # 画面感

  issues:
    - issue: "问题描述"
      location: "位置"
      suggestion: "修改建议"

  strengths:
    - "优点1"
    - "优点2"

  final_comments: |
    最终评语和建议
```
