# 角色设定模板

## 角色卡模板

```yaml
---
name: 角色名称
role: 主角/配角/反派/客串
age: 年龄
gender: 性别
occupation: 职业/身份

# 外貌描写
appearance:
  face: "面部特征描述"
  body: "身材体型描述"
  hair: "发型发色描述"
  clothing: "服装穿着描述"
  distinguishing: "辨识特征"

# 性格特征
personality:
  traits: ["特征1", "特征2", "特征3"]
  strengths: "优点"
  weaknesses: "缺点"

# 背景故事
background:
  origin: "出身背景"
  story: "关键经历"

# 角色关系
relationships:
  - {name: "角色A", relation: "关系", description: "关系描述"}

# 经典台词
quotes:
  - "台词1"
  - "台词2"

# 情绪表达
emotions:
  happy: "开心时的表情"
  angry: "愤怒时的表情"
  sad: "悲伤时的表情"
  surprised: "惊讶时的表情"
```

---

## 角色配置文件示例

```yaml
# 角色配置文件 (characters.yaml)
characters:
  - name: 李明
    role: 主角
    age: 28
    gender: 男
    occupation: 程序员

    appearance:
      face: "剑眉星目，鼻梁高挺，嘴角常带微笑"
      body: "身材修长，身高180cm左右"
      hair: "黑色短发，略显凌乱"
      clothing: "简约的休闲装，格子衬衫"
      distinguishing: "左手戴一块旧手表"

    personality:
      traits: ["内向", "专注", "善良"]
      strengths: "技术能力强，代码写得很好"
      weaknesses: "不善于表达感情"

    background:
      origin: "小镇做题家出身"
      story: "通过努力学习来到大城市成为程序员"

    relationships:
      - name: 王芳
        relation: 暗恋对象
        description: "公司的设计师"

    quotes:
      - "代码改变世界"
      - "bug是永远修不完的"
```

## 角色关系图谱

```
角色关系图谱:

[主角] ←→ [重要配角]
   ↓
[反派] ←→ [主角]

[配角A] ←→ [配角B]
```

---

## 统一性要求

1. **命名统一**: 全程使用统一的中文名/英文名
2. **外貌一致**: 每个角色保持固定的外貌特征
3. **服装统一**: 同一场景下的服装要一致
4. **性格稳定**: 行为逻辑要符合角色性格
