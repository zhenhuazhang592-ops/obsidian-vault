# 角色生成提示词

## Step 1: 分析文本提取角色

### 提示词模板

```
你是一个角色分析专家。请从以下小说/剧本文本中分析并提取所有重要角色。

## 任务要求

1. 提取所有出现的重要角色
2. 为每个角色生成详细的外貌描写
3. 明确角色之间的关系
4. 确定每个角色在故事中的定位（主角/配角/反派等）

## 输出格式

请以YAML格式输出角色信息：

```yaml
characters:
  - name: 角色名
    role: 主角/配角/反派/客串
    importance: 高/中/低
    first_appearance: 首次出场章节
    description: 一句话角色简介
    appearance: 详细外貌描写
    personality: 性格特征
    relationships:
      - {name: 相关角色名, relation: 关系类型, description: 关系描述}
```

## 分析文本

[在此粘贴小说/剧本内容]
```

---

## Step 2: 生成角色参考图

### 通用角色参考图提示词

```
请生成一张角色参考图，用于AI漫画生成。

## 角色信息

- 角色名: [角色名]
- 性别: [性别]
- 年龄: [年龄]
- 职业: [职业]

## 外貌描写

[从角色设定中提取的外貌描写]

## 画风要求

- 画风: [日漫/美漫/国风/写实等]
- 风格: [参考baoyu-comic的画风设定]
- 色调: [暖色/冷色/中性]

## 输出要求

1. 角色正面站立图
2. 展示完整面部特征
3. 展示典型服装造型
4. 清晰展示辨识特征
5. 背景简洁，突出角色
```

---

## Step 3: 角色一致性检查

### 检查清单

- [ ] 所有角色名在全文中一致
- [ ] 角色外貌描述无矛盾
- [ ] 角色性格行为逻辑一致
- [ ] 角色关系描述准确
- [ ] 角色服装在同类场景一致
- [ ] 重要配角有足够辨识度

---

## 角色生成工作流

```
1. 输入小说/剧本文本
2. ↓
3. AI分析提取角色 (Step 1)
4. ↓
5. 人工审核角色列表
6. ↓
7. 生成详细角色设定 (模板)
8. ↓
9. 生成角色参考图 (Step 2)
10. ↓
11. 人工审核参考图
12. ↓
13. 角色库定稿
```

---

## 特殊角色处理

### 反派角色

```yaml
name: [反派名]
role: 反派
special:
  - 突出其邪恶特征
  - 避免美化或同情人设
  - 典型造型要有辨识度
```

### 儿童角色

```yaml
name: [儿童名]
role: 配角
special:
  - 保持可爱、纯真感
  - 服装简洁
  - 避免成熟化处理
```

### 历史人物

```yaml
name: [历史人物名]
role: 主角/配角
special:
  - 参考历史形象
  - 尊重历史事实
  - 可适度艺术化
```
