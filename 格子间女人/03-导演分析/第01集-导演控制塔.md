## 运镜意图指令（Directing Intents）

### P01 · 空荡荡的MPL办公室

```
情绪状态：L1（平静建置）
节拍位置：B01开场画面
运镜类型：WS建立镜头（无人）

运镜意图：
- 建立镜头缓慢推进（dolly in slow, 6s），从空旷大开间→聚焦角落台灯
- 冷蓝月光（窗外5500K+）+ 台灯暖黄（3200K）双色温对比
- 荧光灯逐排熄灭的声音（off-frame SFX）

禁止：
❌ 不要用ECU（情绪未到位）
❌ 不要有角色入画（B01建置必须先建立空间）
```

### P02 · 潭斌侧脸屏幕反光

```
情绪状态：L2（克制）
节拍位置：B03建置
运镜类型：侧脸特写

运镜意图：
- 侧45°中景，屏幕蓝光打在侧脸（短边主光）
- 键盘敲击声作为节奏锚点
- 缓慢推进（dolly 0.3m/4s），从MCU→CU

禁止：
❌ 不要正面镜头（需要保留距离感）
```

### P03 · 邮件弹窗，瞳孔放大

```
情绪状态：L3（隐忍爆发前）
节拍位置：B04催化剂
运镜类型：ECU（特写）

运镜意图：
- 极致特写：邮件标题文字 + 潭斌瞳孔（同一画面）
- 屏幕蓝光→瞳孔→闪白（cut to 邮件内容）
- 心跳声SFX渐强（情绪升级音效）

禁止：
❌ 不要切远景（这里需要最强情绪聚焦）
❌ 不要用慢动作（情绪需要爆发感）
```

### P04 · 潭斌走向窗前

```
情绪状态：L2→L3（内心波动）
节拍位置：B03建置
运镜类型：行走中景 + 窗前特写

运镜意图：
- 侧跟拍（tracking shot），潭斌背影走向窗
- CBD夜景灯火璀璨（长焦压缩，star-map效果）
- 冷蓝月光打在侧脸 = 孤独感视觉化

禁止：
❌ 不要正面镜头（保持背影的距离美学）
```

### P05 · 分屏通话（潭斌+Tony）

```
情绪状态：L3（隐忍）
节拍位置：B03建置
运镜类型：分屏（2画面同步）

运镜意图：
- 左画面（潭斌）：冷蓝办公室，手机蓝光映脸，潭斌表情克制
- 右画面（Tony）：公寓客厅TV暖光→TV关→只剩屏幕冷光
- 分屏比例：1:1（对等关系）
- 声音：左→右依次入画

禁止：
❌ 不要单人镜头（分屏必须同时存在才能建立对比）
❌ 不要快速切换（分屏需要稳定展示对比）
```

### P06-P07 · Tony震惊

```
情绪状态：L3（震惊）
节拍位置：B04催化剂
运镜类型：P06 MCU → P07特写

运镜意图：
- P06：Tony从TV暖光到僵住，MCU展示全身
- P07：公寓书房黑暗中，屏幕亮光特写，"Shit！"踹门
- 光影：屏幕冷光→书房黑暗

禁止：
❌ 不要用暖光（P06的暖光对比P07的冷，形成Tony心理崩塌视觉）
```

### P08-P10 · 季度会议+曾婵贞宣布

```
情绪状态：L3→L4（权力压迫）
节拍位置：B04催化剂+B06失平衡
运镜类型：WS→MCU正反打

运镜意图：
- P08 WS：建立会议室权力格局（曾婵贞正中，乔利维得意，潭斌角落）
- P09 MCU正反打：曾婵贞宣布（主光投影仪白光5500K）
- P10 ECU：潭斌瞳孔放大 + 曾婵贞点指 + 乔利维嘴角微扬（三分屏）
- 投影白光（5500K）+ 荧光天花板灯 = 正式感+压迫感

禁止：
❌ 不要用长镜头（这里是快切，正反打建立张力）
❌ 不要有笑容（曾婵贞和乔利维都是冷峻或得意的表情）
```

### P11 · 方芳送茶（茶水间）

```
情绪状态：L2→L3（短暂喘息）
节拍位置：B06失平衡
运镜类型：MCU暖调

运镜意图：
- 自然窗户光（暖）+ 热水壶暖黄（3200K）
- 与P08-P10会议室形成强烈色温差
- 方芳粉扑扑圆脸vs潭斌疲惫侧脸
- 递茶动作 = 人性微光的视觉符号

禁止：
❌ 不要用冷光（茶水间必须是暖色，给观众喘息空间）
❌ 不要快速剪辑（这里是情绪缓冲，需要节奏放缓）
```

### P12 · 饭局照片（手机）

```
情绪状态：L3（发现阴谋）
节拍位置：B06失平衡
运镜类型：手机屏幕ECU

运镜意图：
- 屏幕特写：饭局偷拍照，曾婵贞+乔利维
- 指尖触屏声 = 潭斌内心翻涌
- 从茶水间暖光→手机屏幕冷光，情绪从L2→L3收紧

禁止：
❌ 不要人物表情（这里是间接信息，悬念需要观众自己解读）
```

### P13 · 深夜修改标书

```
情绪状态：L3（隐忍坚定）
节拍位置：B08游戏
运镜类型：中景台灯孤岛

运镜意图：
- 深夜全暗，只有台灯暖黄孤岛
- 潭斌皱眉翻阅，专注
- 与P01呼应：同一办公室，从L1→L3
- 窗外CBD夜景，star-map效果（远景）

禁止：
❌ 不要用日光（深夜是情绪锚点，必须是暗+台灯）
```

### P14 · 名单上悬停

```
情绪状态：L4（爆发前）
节拍位置：B08游戏
运镜类型：ECU（文件特写）+ 指尖特写

运镜意图：
- 指尖悬停在「投标单位名单」上
- 名单显示MPL竞争对手，但——没有MPL
- 心跳声SFX渐强
- 短促cut：名单→潭斌侧脸→名单（情绪确认）

禁止：
❌ 不要用WS（情绪爆发点需要特写聚焦）
```

### P15 · 匿名短信+CBD指尖悬停（结尾钩子）

```
情绪状态：L4→L5（悬念高潮）
节拍位置：B15终场钩子
运镜类型：分屏+特写

运镜意图：
- 分屏左侧：手机屏幕特写，匿名短信弹窗（归属地FSK）
- 分屏右侧：潭斌指尖悬停CBD落地窗前，月光打在手指
- 手机短信文字（画外音）："明天的标前会，带上你的底牌。"
- 月光蓝白 = 希望与危险并存的视觉隐喻
- 镜头从指尖缓慢拉远（dolly out），停在CBD全景

禁止：
❌ 不要有任何文字水印（短信内容必须由角色读出）
❌ 不要切走（钩子需要停在悬念点）
```

## 180度轴线约束（双人对话场景）

### 轴线1：P05分屏通话

```
轴线：潭斌↔Tony（虚拟连线）
摄像机：分屏两侧各自拍摄（不在轴线上）
规则：两人各自面向镜头方向（分屏通话标准处理）
```

### 轴线2：P08-P10会议室正反打

```
轴线：曾婵贞↔潭斌（会议桌两侧）
摄像机：始终在轴线同一侧
- 曾婵贞→潭斌：曾婵贞在画面右侧，面向左；潭斌在画面左侧，面向右
- 乔利维插入：站在曾婵贞身后，不破坏轴线
规则：禁止180°跳轴（跳轴=破坏权力关系视觉）
```

### 轴线3：P11茶水间

```
轴线：方芳↔潭斌（茶水间台面两侧）
摄像机：轴线侧面
两人面向相反方向（正反打）
```
