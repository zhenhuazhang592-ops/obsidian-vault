## 剪映导出规格

### 草稿规格

| 参数 | 值 |
|------|------|
| 画幅 | 16:9（1920×1080） |
| 帧率 | 24fps |
| 时长 | 120秒（2分0秒） |
| 分辨率 | 1080P |

### 轨道结构

```
轨道1（视频层）：15个视频片段（P01-P15，8秒/个）
轨道2（音频-TTS）：7段配音（P02/P05左/P05右/P06/P08/P09/P11/P15）
轨道3（音频-BGM）：BGM时间轴（由Audio Layer描述生成）
轨道4（SFX）：音效层（心跳/环境音/触屏声等）
```

## Seedance API调用格式

```
模型：seedance-2.0
模式：image-to-video
输入：
  - prompt: [每镜videoPrompt]
  - image: [每镜imagePrompt生成的垫图]
  - duration: 8s
  - aspect_ratio: 16:9

示例（P02）：
{
  "prompt": "Medium close-up side profile shot, 【【潭斌】】in white shirt...",
  "image_url": "https://[生成的垫图URL]",
  "duration": 8,
  "aspect_ratio": "16:9"
}
```
