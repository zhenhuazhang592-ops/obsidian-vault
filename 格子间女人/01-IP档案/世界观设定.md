## 一、时间背景

### 时代定位
- **所属时代**：21世纪初叶，中国加入WTO后的经济腾飞期
- **年代暗示**：
  - 邮件为主要通讯方式
  - 智能手机尚未普及
  - 尚未进入移动互联网时代
  - 推测为2003-2008年间

### 季节时间线
- **开篇**：北京初夏（五六月之交）
- **第二章**：盛夏六月（高温39°C，雨水频繁）
- **时间跨度**：从初夏到盛夏的短暂过渡

### 时代特征
```
经济环境：跨国公司在华扩张期
职场生态：外企金领光环期
社会氛围：奋斗改变命运的主流叙事
消费文化：汽车开始普及（余永麟的君越）
```

**意象符号**：
- 立交桥上车灯如练

**情感映射**：
- 归属感与疏离感并存

### 行业生态

#### 核心行业：IT/通讯设备销售
- **公司类型**：跨国IT企业（MPL vs FSK）
- **客户类型**：大型企业客户（普达集团）
- **销售模式**：省公司分散→总部集中采购

#### 行业特征
```
1. 圈子文化：低头不见抬头见
2. 业绩为王：数字说话
3. 竞业限制：跳槽同行是常态
4. 客户为尊：70%销售依赖单一客户
```

### 商业逻辑

#### 集中采购危机
```
触发事件：普达集团集中采购
影响范围：合同决定权从省公司收归总部
后果：MPL十年在二十几省打下的江山
      80%将失去用武之地
本质：社会主义初级阶段的"爱国"特色
      阻止国有资产外流
```

#### 竞品格局
```
MPL vs FSK
- 旗鼓相当的竞争对手
- 余永麟跳槽：国军被招安
- 行业格局：跳来跳去就这几家
```

## 五、核心规则

### 职场明规则

#### 离职礼仪
```
正常离职：总裁亲自执笔
          极尽感激肉麻之词
          以示挽留和不舍

异常离职：简单、仓促、冷漠
          一句话邮件
          → 程睿敏案例
```

#### 晋升逻辑
```
硬条件：业绩数字
软条件：资历、关系、政治敏感度
变量：  位置出缺（余永麟离开→机会出现）
```

### 职场潜规则

#### 圈子文化
- "低头不见抬头见"
- "整个行业就这么大一个圈子"
- "跳来跳去就是这几家"

#### 政治生存
- 程睿敏九年做到二号人物仍被清洗
- 说明：没有真正的安全区
- 暗示：MPL内部有派系斗争
