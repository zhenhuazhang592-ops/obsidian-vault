# waoowaoo 部署指南

## Docker Compose 服务清单

| 服务 | 镜像 | 端口映射 | 说明 |
|------|------|----------|------|
| `mysql` | `mysql:8.0` | 13306→3306 | MySQL 数据库，ROOT 密码 `waoowaoo123` |
| `redis` | `redis:7-alpine` | 16379→6379 | Redis 队列后端，开启 AOF 持久化 |
| `minio` | `minio/minio:RELEASE.2025-02-28` | 19000→9000, 19001→9001 | S3 兼容对象存储（API + Console） |
| `app` | `ghcr.io/saturndec/waoowaoo:latest` | 13000→3000, 13010→3010 | 主应用（Next.js + Worker） |

## 环境变量配置

```bash
# 复制示例配置
cp .env.example .env
```

### 核心变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `DATABASE_URL` | MySQL 连接串 | `mysql://root:waoowaoo123@localhost:13306/waoowaoo` |
| `STORAGE_TYPE` | 存储类型 | `minio` / `local` / `cos` |
| `MINIO_ENDPOINT` | MinIO API | `http://localhost:19000` |
| `NEXTAUTH_URL` | 认证回调 | `http://localhost:3000` |
| `REDIS_HOST` | Redis 主机 | `127.0.0.1` |
| `REDIS_PORT` | Redis 端口 | `16379` |
| `BILLING_MODE` | 计费模式 | `OFF`（默认关闭）|
| `LOG_LEVEL` | 日志级别 | `ERROR` / `INFO` |
| `TASK_HEARTBEAT_TIMEOUT_MS` | 任务心跳超时 | `90000`（毫秒）|
| `WATCHDOG_INTERVAL_MS` | 看门狗间隔 | `30000`（毫秒）|

## 部署方式

### 方式一：预构建镜像（推荐，最简单）

```bash
# 直接下载 docker-compose.yml 启动
curl -O https://raw.githubusercontent.com/saturndec/waoowaoo/main/docker-compose.yml
docker compose up -d

# 访问
http://localhost:13000
```

> 启动后清空浏览器缓存并重新登录。

### 方式二：克隆 + 构建

```bash
git clone https://github.com/saturndec/waoowaoo.git
cd waoowaoo
docker compose up -d

# 更新
git pull
docker compose down && docker compose up -d --build
```

### 方式三：本地开发

```bash
# 1. 复制配置
cp .env.example .env
# 编辑 .env 填入 API Keys

# 2. 安装依赖
npm install

# 3. 启动基础设施（仅 MySQL/Redis/MinIO）
docker compose up mysql redis minio -d

# 4. 初始化数据库
npx prisma db push

# 5. 启动开发服务器
npm run dev
# Next.js:   http://localhost:3000
# Bull Board: http://localhost:3010/admin/queues
```

## HTTPS 配置（可选）

HTTP 模式下浏览器限制并发连接影响体验，可通过 Caddy 启用 HTTPS：

```bash
# 安装 Caddy
brew install caddy   # macOS
# 或参考 https://caddyserver.com/docs/install

# 启动
caddy run --config Caddyfile

# 访问
https://localhost:1443
```

## 本地开发 npm scripts

```bash
npm run dev              # 并发启动 Next.js + Worker + Watchdog + Bull Board
npm run dev:next         # Next.js dev (Turbopack)
npm run dev:worker        # Worker 进程
npm run dev:watchdog      # 看门狗进程
npm run dev:board         # Bull Board 面板
npm run build             # Prisma generate + Next build
npm run start             # 生产启动（4 进程并发）
npm run typecheck         # TypeScript 检查
npm run lint:all          # ESLint 检查
npm run test:*            # 各类测试脚本
npm run check:*           # 40+ 代码守卫检查
npm run migrate:*         # 数据库迁移
```
