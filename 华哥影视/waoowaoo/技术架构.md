# waoowaoo 技术架构

## 技术栈全景

| 层级 | 技术选型 |
|------|----------|
| 前端框架 | Next.js 15 (App Router) + React 19 |
| UI 样式 | Tailwind CSS v4 |
| 国际化 | next-intl |
| 后端语言 | TypeScript（strict 模式）|
| ORM | Prisma |
| 数据库 | MySQL 8.0 |
| 任务队列 | BullMQ + Redis 7 |
| 对象存储 | MinIO（S3 兼容）/ 本地 / 腾讯 COS |
| AI SDK | OpenAI / Google AI / DashScope / FAL / Anthropic |
| 视频合成 | Remotion 4 |
| 代码质量 | ESLint + Husky + Vitest + 40+ check 脚本 |
| 部署 | Docker Compose |

---

## 项目架构：Feature-Sliced Design

采用 DDD Feature-Sliced 风格组织代码：

```
src/
├── app/                  # App Router 路由层
├── features/
│   ├── admin/           # 管理后台
│   ├── asset-hub/       # 资产中心
│   ├── assets/          # 资产管理
│   ├── auth/            # 认证授权
│   ├── cos/             # 腾讯云 COS 集成
│   ├── files/           # 文件处理
│   ├── novel-promotion/ # 小说推文/漫剧核心 ✦
│   ├── projects/        # 项目管理
│   ├── runs/            # 工作流执行
│   ├── sse/             # Server-Sent Events
│   ├── storage/         # 存储抽象层
│   ├── system/          # 系统配置
│   ├── task-target-states/
│   ├── tasks/           # 任务队列管理
│   ├── user/            # 用户模块
│   ├── user-preference/ # 用户偏好设置
│   └── video-editor/    # 视频编辑器
├── contexts/            # React Context（全局状态）
├── hooks/               # 自定义 Hooks
├── i18n/                # 国际化翻译文件
├── lib/                 # 工具函数库
├── components/          # 公共 UI 组件
└── pages/               # Pages Router（遗留）
```

## 数据库核心模型

### 用户与认证

```
User
  └── UserPreference      # API Keys、AI 模型选择、并发限制
  └── Account             # OAuth 第三方登录
  └── Session
  └── UserBalance         # 账户余额
      └── BalanceFreeze   # 冻结金额
      └── BalanceTransaction  # 收支流水
```

### 创作流程

```
Project
  └── NovelPromotionProject
      ├── NovelPromotionEpisode        # 剧集
      │   └── NovelPromotionClip       # 片段
      └── NovelPromotionStoryboard     # 分镜
          └── NovelPromotionPanel      # 画格（镜头）

GlobalAssetFolder         # 全局资产库
  ├── GlobalCharacter     # 全局角色
  ├── GlobalLocation      # 全局场景
  └── GlobalVoice         # 全局音色
```

### 任务与工作流

```
Task                    # 通用任务队列
  └── GraphRun           # 图形化工作流实例
      └── GraphStep      # 工作流步骤
          └── GraphStepAttempt  # 步骤执行记录

MediaObject             # 统一媒体资产表（图片/视频/音频）
```

## 进程模型（生产环境）

```
npm start 启动 4 个并发进程：
  ① Next.js Server    (端口 3000)
  ② Worker 进程       (tsx watch，处理 BullMQ 队列任务)
  ③ Watchdog 进程     (心跳监控，检测 worker 崩溃重启)
  ④ Bull Board        (端口 3010, /admin/queues 任务监控面板)
```

## 多 AI 模型抽象层

支持在用户设置中动态切换 AI 服务商：

- **DashScope**（阿里通义）
- **OpenAI**（GPT / DALL-E / Sora）
- **Google AI**（Gemini / Imagen）
- **FAL**（Flux 模型）
- **Anthropic**（Claude）
- **火山引擎**（字节豆包）

> 提示词模板统一管理，通过 `scripts/check-prompt-*` 脚本进行质量守卫。

## 代码质量体系

- **ESLint** + `eslint.config.mjs`
- **Husky** pre-commit hooks
- **Vitest** 单元/集成/系统测试
- **40+ check 脚本**：`scripts/check-*`
  - `check-api-handler.ts` — API 规范检查
  - `check-log-semantic.ts` — 日志语义检查
  - `check-no-console.ts` — 禁止 console.log
  - `check-outbound-image-success-rate.ts` — 外部图片成功率
  - `check-pricing-catalog.mjs` — 价格目录检查
  - `check-model-config-contract.mjs` — 模型配置契约检查
  - ... 等等
