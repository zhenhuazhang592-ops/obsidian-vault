# 工作流

## 完整制作链路

```
小说/剧本输入
    ↓
┌──────────────────────────────────────────────────────────┐
│ S1. 剧本创建 (Drama / Episode)                             │
│     POST /api/v1/dramas                                   │
│     - 剧名 / 类型 / 风格 / 集数                            │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S2. 角色提取 (AI LLM)                                     │
│     POST /api/v1/scripts/generate-characters              │
│     - 从剧本解析角色：name/role/appearance/personality     │
│     - 支持批量生成                                     │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S3. 角色图生成 (AI Image)                                 │
│     POST /api/v1/images/generate-character                │
│     - 基于 appearance 描述生成角色立绘图                    │
│     - 支持首帧/尾帧/动作序列多帧模式                       │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S4. 场景提取 (AI LLM)                                     │
│     - 从剧本提取 location + time 组合                      │
│     - 生成纯背景 Prompt（无人物）                          │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S5. 场景图生成 (AI Image)                                  │
│     POST /api/v1/scenes/batch-generate                    │
│     - 纯背景场景图生成                                     │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S6. 分镜生成 (AI LLM)                                     │
│     POST /api/v1/storyboards/generate                    │
│     - 独立动作单元拆分                                    │
│     - 输出：shot_number / shot_type / angle / movement    │
│     - dialogue / emotion / emotion_intensity (3/2/1/0/-1) │
│     - 自动关联角色和场景                                   │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S7. 分镜图生成 (AI Image)                                 │
│     - 首帧 Prompt（动作前静态）                            │
│     - 关键帧 Prompt（动作高潮）                            │
│     - 尾帧 Prompt（动作完成后）                            │
│     - 动作序列 Prompt（3x3 九宫格）                        │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S8. 视频生成 (AI Video)                                   │
│     POST /api/v1/videos/generate                         │
│     - 单图模式 / 首尾帧模式 / 多图模式 / 动作序列模式       │
│     - 支持火山引擎 ARK / OpenAI Sora / MiniMax            │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S9. 时间轴编排 (Timeline Editor)                          │
│     - 多轨道：视频轨 / 音频轨 / 文本轨                     │
│     - TimelineClip：start_time / end_time / trim / speed  │
│     - ClipTransition：fade / crossfade / slide / wipe    │
│     - ClipEffect：filter / color / blur / brightness     │
└──────────────────────────────────────────────────────────┘
    ↓
┌──────────────────────────────────────────────────────────┐
│ S10. 视频合成 (FFmpeg)                                    │
│      POST /api/v1/videos/merge                           │
│      - 按时间轴顺序拼接多个视频片段                        │
│      - 添加转场 / 音效 / BGM                               │
└──────────────────────────────────────────────────────────┘
    ↓
最终视频输出
```

## 分镜数据模型

每个分镜包含的字段：

```go
type Storyboard struct {
    StoryboardNumber int     // 镜头编号
    Title           *string // 镜头标题
    Location        *string // 地点
    Time            *string // 时间
    ShotType        *string // 景别：大远景/远景/中景/近景/特写
    Angle           *string // 角度：平视/仰视/俯视/侧面/背面
    Movement        *string // 运镜：固定/推镜/拉镜/摇镜/跟镜/移镜
    Action          *string // 动作描述
    Result          *string // 画面结果
    Atmosphere      *string // 环境氛围
    Emotion         *string // 情绪
    ImagePrompt     *string // 图生 Prompt
    VideoPrompt     *string // 视频生成 Prompt
    BgmPrompt       *string // 配乐提示词
    SoundEffect     *string // 音效描述
    Dialogue        *string // 对话/旁白
    Duration        int     // 时长（秒），默认 5 秒
    ComposedImage   *string // 合成图 URL
    VideoURL        *string // 视频 URL
    Status          string  // pending/generated/failed
}
```

## 帧类型与视频模式

| 帧类型 | Prompt 策略 | 适用场景 |
|--------|------------|---------|
| 首帧 (First Frame) | 动作前静态状态，不含运动 | 固定镜头、静坐对话 |
| 关键帧 (Key Frame) | 动作高潮瞬间，强调动态张力 | 动作戏、高潮场景 |
| 尾帧 (Last Frame) | 动作完成后状态 | 运镜收尾 |
| 动作序列 (Action Sequence) | 3x3 九宫格完整动作链 | 武术、运动、舞蹈 |

视频生成支持的 referenceMode：

| 模式 | 视频模型 | 说明 |
|------|---------|------|
| `single` | 全部 | 单张参考图，模型自主推断运动 |
| `first_last` | 全部 | 首帧+尾帧双约束 |
| `multiple` | 全部 | 多张参考图序列 |
| `action_sequence` | 全部 | 九宫格动作序列（最高一致性） |
