# 技术架构

## 技术栈总览

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **后端语言** | Go 1.23+ | 高并发，轻量级 |
| **Web 框架** | Gin 1.9+ | HTTP 路由 + 中间件 |
| **ORM** | GORM | SQLite（modernc.org/sqlite）|
| **数据库** | SQLite | WAL 模式，支持 CGO_ENABLED=0 跨平台 |
| **日志** | Zap | 结构化日志 |
| **视频处理** | FFmpeg | 必需依赖 |
| **前端框架** | Vue 3.4+ | Composition API |
| **前端语言** | TypeScript 5+ | 严格类型 |
| **构建工具** | Vite 5 | 前端开发 + 构建 |
| **UI 组件** | Element Plus | 后台管理组件 |
| **CSS** | TailwindCSS | 原子化 CSS |
| **状态管理** | Pinia | Vue 状态管理 |
| **AI 服务** | OpenAI / Gemini / 火山引擎 | 统一抽象接口 |

## 关键设计决策

### SQLite WAL 模式

```go
// infrastructure/database/database.go
db, err := gorm.Open(sqlite.Open(path), &gorm.Config{})
sqlDB, _ := db.DB()
sqlDB.Exec("PRAGMA journal_mode=WAL")
sqlDB.Exec("PRAGMA busy_timeout=5000")
```

解决高并发下 "database is locked" 问题。

### 前后端分离部署

- 后端 Gin 服务端口 `5678`，提供 API + 静态文件
- 前端 Vite 开发模式代理 `/api/*` 到后端
- 生产模式 `npm run build` 输出到 `web/dist/`，嵌入后端二进制

### AI 客户端统一抽象

```go
// pkg/ai/client.go
type AIClient interface {
    GenerateText(prompt string, systemPrompt string, options ...func(*ChatCompletionRequest)) (string, error)
    GenerateImage(prompt string, size string, n int) ([]string, error)
    TestConnection() error
}
```

文本 / 图片 / 视频三大类 AI 能力各有一套 `*Client` 接口，可插拔替换。
