# 部署指南

## 快速开始

### 环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| Go | 1.23+ | 后端运行时 |
| Node.js | 18+ | 前端构建 |
| npm | 9+ | 包管理 |
| **FFmpeg** | 4.0+ | **必需**，视频处理核心依赖 |

### 安装 FFmpeg

```bash
# macOS
brew install ffmpeg

# Ubuntu/Debian
sudo apt update && sudo apt install ffmpeg

# 验证
ffmpeg -version
```

## 配置文件

```bash
cp configs/config.example.yaml configs/config.yaml
vim configs/config.yaml
```

关键配置项：

```yaml
app:
  name: "Huobao Drama API"
  version: "1.0.0"
  debug: true  # 开发 true，生产 false

server:
  port: 5678
  host: "0.0.0.0"
  cors_origins:
    - "http://localhost:3012"  # 前端地址
  read_timeout: 600
  write_timeout: 600

database:
  type: "sqlite"
  path: "./data/drama_generator.db"

storage:
  type: "local"
  local_path: "./data/storage"
  base_url: "http://localhost:5678/static"

ai:
  default_text_provider: "openai"
  default_image_provider: "openai"
  default_video_provider: "doubao"
```

## 启动方式

### 方式一：开发模式（推荐）

```bash
# 终端 1：后端
go run main.go

# 终端 2：前端
cd web
npm install
npm run dev

# 前端: http://localhost:3012
# 后端: http://localhost:5678/api/v1
```

### 方式二：单服务模式

```bash
cd web && npm run build && cd ..
go run main.go
# 前后端都在 http://localhost:5678
```

## Docker 部署

### 国内镜像加速

```bash
cp .env.example .env
# 编辑 .env，启用以下镜像源：

DOCKER_REGISTRY=docker.1ms.run/
NPM_REGISTRY=https://registry.npmmirror.com/
GO_PROXY=https://goproxy.cn,direct
ALPINE_MIRROR=mirrors.aliyun.com

# 构建（必须用 docker compose build）
docker compose build

# 启动
docker compose up -d
docker compose logs -f
```

### 宿主机 Ollama 访问

容器内访问宿主机服务（Ollama 等）：

```bash
# 1. 宿主机启动 Ollama（监听所有接口）
export OLLAMA_HOST=0.0.0.0:11434 && ollama serve

# 2. 容器内访问
# Base URL: http://host.docker.internal:11434/v1
# Provider: openai
# Model: qwen2.5:latest
```

## 生产环境部署

### 编译

```bash
cd web && npm run build && cd ..
go build -o huobao-drama .
```

### systemd 服务

```ini
[Unit]
Description=Huobao Drama Service
After=network.target

[Service]
Type=simple
User=YOUR_USER
WorkingDirectory=/opt/huobao-drama
ExecStart=/opt/huobao-drama/huobao-drama
Restart=on-failure
RestartSec=10
```

### Nginx 反向代理

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:5678;
    }

    location /static/ {
        alias /opt/huobao-drama/data/storage/;
    }
}
```

## 数据库

SQLite 表在首次启动时通过 GORM AutoMigrate 自动创建，无需手动迁移。

数据目录：`./data/`

```
data/
├── drama_generator.db    # SQLite 数据库
└── storage/              # 资产文件
    ├── characters/       # 角色图
    ├── scenes/           # 场景图
    ├── storyboards/      # 分镜图
    └── videos/           # 生成视频
```
