# 魔因漫创 — 技术架构

---

## 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron 30 |
| 前端框架 | React 18 + TypeScript |
| 构建工具 | electron-vite (Vite 5) |
| 状态管理 | Zustand 5 |
| UI 组件 | Radix UI + Tailwind CSS 4 |
| AI 核心 | `@opencut/ai-core`（提示词编译、角色圣经、任务轮询） |
| 图片处理 | sharp（Node.js 图片处理） |
| 打包工具 | electron-builder |

---

## 项目结构

```
moyin-creator/
├── electron/              # Electron 主进程 + Preload
│   ├── main.ts           # 主进程（存储管理、文件系统、协议处理）
│   └── preload.ts        # 安全桥接层
├── src/
│   ├── components/       # React UI 组件
│   │   ├── panels/        # 主面板（剧本、角色、场景、分镜、导演）
│   │   ├── ui/           # 基础 UI 组件库
│   │   ├── Dashboard.tsx
│   │   ├── Layout.tsx
│   │   ├── PreviewPanel.tsx
│   │   ├── ProjectHeader.tsx
│   │   ├── RightPanel.tsx
│   │   ├── TabBar.tsx
│   │   └── BatchProgressOverlay.tsx
│   ├── stores/           # Zustand 全局状态
│   ├── lib/              # 工具库（AI 调度、图片管理、路由）
│   ├── packages/
│   │   └── ai-core/      # AI 核心引擎（@opencut/ai-core）
│   ├── hooks/            # React 自定义 hooks
│   ├── workers/          # Web Workers
│   ├── types/            # TypeScript 类型定义
│   └── assets/           # 静态资源
├── build/                # 构建资源（图标等）
├── scripts/              # 工具脚本
└── docs/                 # 文档（工作流指南、剧本格式示例）
```

---

## 核心模块

### 主进程 (electron/main.ts)
- 窗口管理（1400×900，最小 1200×700）
- 文件系统操作
- 存储管理（electron-store）
- 协议处理（自定义协议注册）
- 外部链接用系统浏览器打开

### AI 核心 (packages/ai-core)
- 提示词编译系统
- 角色圣经管理
- 多供应商任务轮询
- API Key 负载均衡

### 状态管理 (stores/)
- Zustand 5 全局状态
- 各板块状态独立管理

### UI 组件
- Radix UI 基础组件（Dialog、Dropdown、Select、Tabs 等）
- Tailwind CSS 4 样式
- CVA (Class Variance Authority) 组件变体

---

## 供应商系统

v0.1.3 精简后仅保留两个核心供应商：
- **memefast**（魔因 API）
- **RunningHub**

支持多 API Key 轮询负载均衡，自动重试失败任务。
