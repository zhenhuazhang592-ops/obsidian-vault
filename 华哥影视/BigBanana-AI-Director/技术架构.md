# 技术架构

## 技术栈

| 层级 | 技术选型 |
|------|----------|
| **前端** | React 19 + Tailwind CSS（Sony Industrial Design Style）|
| **数据存储** | IndexedDB（本地浏览器数据库，数据隐私安全，无后端依赖）|
| **AI 模型（AntSK）** | 见下方模型矩阵 |

## AI 模型矩阵（AntSK API）

### 文本/逻辑模型

| 模型 | 用途 |
|------|------|
| `gpt-5.2` | 高智能剧本分析 |
| `gpt-5.1` | 剧本生成 |
| `Claude 3.5 Sonnet` | 备选逻辑模型 |

### 视觉模型

| 模型 | 用途 |
|------|------|
| `gemini-3-pro-image-preview` | 高速绘图、场景生成 |
| `nano-banana-pro` | 角色/道具绘制 |

### 视频模型

| 模型 | 用途 |
|------|------|
| `veo_3_1-fast` | 首尾帧视频插值（推荐）|
| `sora-2` | 图生视频 |

## AntSK API 平台

> https://api.antsk.cn/

- **OpenAI 兼容协议**：零代码迁移成本
- **定价**：所有模型价格均低于官方渠道 80%
- **SLA**：99.9% 企业级保障

## 容器架构

```
web (React 前端)  :3005
  └── media-proxy  :8787   （媒体资源代理）
  └── new-api-proxy :8788  （API 代理）
  └── cutos-api    :8789   （DashScope 视频/绘图集成）
```

详见：[[docker-compose.yaml]]

## 数据流

```
用户操作 → React 前端 → IndexedDB 本地存储
                              ↓
                    AntSK API / DashScope API
                              ↓
                       生成结果 → 渲染 → 导出
```
