## 项目概览

BigBanana AI Director（AI 漫剧工场）是一个 **AI 一站式短剧/漫剧平台**，采用 **"Script-to-Asset-to-Keyframe"** 工业化工作流，通过 AntSK API 集成先进 AI 模型，实现从剧本到成片的全自动化生产，同时精准控制角色一致性、场景连续性与镜头运动。

**许可证**：CC BY-NC-SA 4.0（禁止商业用途）

---

## 核心概念：关键帧驱动 (Keyframe-Driven)

BigBanana 引入动画制作中的**关键帧 (Keyframe)** 概念，突破传统 Text-to-Video 的控制难题：

1. **先画后动**：先生成精准的起始帧 (Start) 和结束帧 (End)
2. **插值生成**：利用 Veo 模型在两帧之间生成平滑视频过渡
3. **资产约束**：所有画面生成均受到"角色定妆照"和"场景概念图"的强约束，杜绝人物变形

## 五阶段工作流

```
小说/大纲输入
    │
    ▼
Phase 01 叙事规划
    │  剧本生成 / AI续写 / 镜头拆分
    ▼
Phase 02 一致性资产
    │  角色定妆照 · 场景概念图 · 道具参考图
    ▼
Phase 03 镜头制作
    │  关键帧控制 · 九宫格分镜 · 首尾帧插值
    ▼
Phase 04 成片交付
    │  时间线预览 · CutOS粗剪 · 导出母版
    ▼
Phase 05 提示词管理
       版本回滚 · 跨阶段排查
```

## 功能模块

### 项目工作台 (Project Workspace)

| 模块 | 说明 |
|------|------|
| 项目中心 (Project Hub) | 最近项目、账号、模型配置、全局资产库、数据导入导出 |
| 项目概览 (Project Overview) | 按"项目 → 季 → 集"组织，支持整篇小说导入自动拆多集 |
| 世界观构建 | 地图、区域、地点、音乐风格等世界观锚点 |

### Phase 01: 叙事规划

- 结构化剧本生成（大纲/小说片段 → AI 自动拆解角色/场景/道具/镜头）
- 配置驱动生成（语言、时长、视觉风格、模型组合）
- AI 续写与手动精修（正文、视觉描述、镜头动作、台词、提示词）
- 全自动计划预审（逐镜头决定"九宫格分镜"或"首尾帧"链路）

### Phase 02: 一致性资产 (Consistency Assets)

- **角色一致性定妆**：标准参考图 + 衣橱系统多套造型
- **场景/道具资产化**：独立提示词、参考图、形体参考
- **资产库复用**：跨项目选择角色、场景、道具
- **批量补齐**：一键补齐缺失图片

### Phase 03: 镜头制作 (Shot Workbench)

- 网格化镜头工作台（全景管理所有镜头）
- 关键帧精控（Start/End Frame 生成、上传、继承、编辑）
- 九宫格分镜预览（先生成9个候选视角，再选整图或裁切）
- 上下文感知生成（自动读取场景图、角色服装、道具参考）
- 双视频链路（单图 Image-to-Video 或首尾帧插值）

### Phase 04: 成片交付 (Delivery Center)

- 时间线预览与渲染追踪
- CutOS 风格 AI 粗剪（调序、裁剪、滤镜）
- 多种交付方式（母版视频、片段压缩包、源素材）
- 剧集级数据导入导出

### Phase 05: 提示词管理

- 集中检索与编辑（模板、角色、场景、道具、关键帧、视频提示词）
- 版本回滚
- 跨阶段问题排查

## 技术架构

详见：[[技术架构]]

| 层级 | 技术选型 |
|------|----------|
| 前端 | React 19 + Tailwind CSS（Sony Industrial Design Style）|
| 数据存储 | IndexedDB（本地浏览器数据库，无后端依赖）|
| AI 模型层 | AntSK API（OpenAI 兼容协议）|

### AI 模型矩阵

**文本模型**：`gpt-5.2`（高智能剧本分析）、`gpt-5.1`（剧本生成）、`Claude 3.5 Sonnet`（备选）
**视觉模型**：`gemini-3-pro-image-preview`（高速绘图）、`nano-banana-pro`（角色/道具）
**视频模型**：`veo_3_1-fast`（首尾帧插值，推荐）、`sora-2`（图生视频）

### 容器架构

```
web :3005
  └── media-proxy  :8787   （媒体资源代理）
  └── new-api-proxy :8788  （API 代理）
  └── cutos-api    :8789   （DashScope 视频/绘图集成）
```
