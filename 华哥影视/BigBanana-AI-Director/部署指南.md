# 部署指南

> ⚠️ 源码已停止公开同步，本部署方式基于公开版本 v3.1.0。

## 快速部署（推荐）

### 首次部署

```bash
# 1. 克隆项目（仅文档参考，镜像部署）
git clone https://github.com/shuyu-labs/BigBanana-AI-Director.git
cd BigBanana-AI-Director

# 2. 启动服务（自动拉取官方镜像）
docker-compose up -d

# 3. 访问应用
# 浏览器打开 http://localhost:3005

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

### 更新到最新版本

```bash
docker-compose pull
docker-compose up -d --force-recreate
```

## 环境变量

启动前需配置 API Key（填入 `docker-compose.yaml`）：

| 变量 | 说明 |
|------|------|
| `DASHSCOPE_API_KEY` | DashScope API 密钥（用于视频/绘图生成）|

## Docker Compose 配置说明

详见：[[docker-compose.yaml]]

```yaml
services:
  web:           # 前端 (React) → 端口 3005
  media-proxy:   # 媒体资源代理 → 端口 8787
  new-api-proxy: # API 代理 → 端口 8788
  cutos-api:     # CutOS 剪辑/DashScope 集成 → 端口 8789
```

## 账号配置

首次进入时，在新手引导、账号中心或模型配置中填入 AntSK API Key：

- **注册地址**: https://api.antsk.cn/
- **购买额度**: https://api.antsk.cn（按需计费，无最低消费）
