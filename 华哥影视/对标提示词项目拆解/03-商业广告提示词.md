# 商业广告与品牌提示词

## 核心特点

商业广告提示词强调：
- 产品展示
- 品牌调性
- 分镜节奏
- 商业质感

---

## 2.1 MUJI 品牌宣传片

**来源**: 歸藏(guizang.ai) (@op7418)

**提示词**:
```
Help me generate a promotional video about the MUJI brand.
```

**特点**:
- 简洁的提示词
- 直接告诉品牌名称
- AI 自动匹配品牌调性

## 2.2 香水 MG 动画风格

**来源**: Vicky (@BFAVicky)

**提示词结构**:
```
Based on the script from Image 1, generate advertising content for the perfume product in Image 2.
[具体要求]
```

**完整示例**:
```
Based on the script from Image 1, generate advertising content for the perfume product in Image 2. The voiceover should reference a natural female voice speaking in English. Pay attention to the proportions of the perfume bottle, integrating it into the background with natural lighting. Avoid heavy texture overlay and cutout effects. The pace can be more brisk.
```

**关键技巧**:
- 使用 `@图1` `@图2` 引用参考图片
- 明确 `voiceover` 要求
- 指定 `avoid` 避免的效果

## 运动饮料广告模板

```markdown
为图中产品生成一个精美高级的[产品类型]广告，
注意分镜编排，明快的节奏和快剪，高级的商业广告。
```

**要点**:
- `精美高级` 定义质量标准
- `分镜编排` 强调镜头设计
- `快剪` 描述节奏

---

## 品牌宣传片模板

```markdown
帮我生成一个讲述[品牌名]这个品牌的宣传片，
中间植入这个[产品/元素]
```

**特点**:
- 品牌名可自动识别调性
- 5秒也能呈现完整状态

## 穿搭变装模板

```markdown
让一个女生依次换上@图1 @图2 @图3 @图4 @图5 @图6 六套服装进行卡点变装展示。
每套服装需要包含半身走位和整体穿搭全身的展示。
运镜要求使用不同景别流畅切换，加上符合调性的广告音乐
```

**关键技巧**:
- 使用 `@图N` 引用多张图片
- 明确 `半身走位` + `全身展示`
- 指定 `不同景别流畅切换`

## 直播带货模板

```markdown
生成一段 [时长] 秒带货口播视频，产品为图中[产品类型]。
要求[动作要求]，给出近景展示，[镜头切换要求]。
口播要包含[卖点描述]，最后给出[行动号召]。
自动生成字幕，节奏紧凑，带轻微环境音。
```

**示例**:
```
生成一段 15 秒带货口播视频，产品为图中面霜。
要求人物亲手涂手上，给出近景展示，侧脸转动展示细节，镜头从半身到特写切换 3 次。
口播要包含卖点，最后给出强行动号召。
自动生成字幕，节奏紧凑，带轻微环境音。
```

## 动态海报模板

```markdown
一个[时长]秒竖屏 [比例] 的卡点音乐短片，
背景音乐使用@音频1，视频全程保持固定机位景别不变，
视频中的元素陆续按@图片1中的九宫格分镜依次显现，
从左上角第一个镜头作为开始从左到右、从上到下依次推进。
```

**流程**:
1. 用 Nano Banana Pro 生成九宫格分镜图
2. 让 Seedance 2.0 根据九宫格生成动态效果

## 广告复刻模板

```markdown
模仿【@视频1】的分镜设计，
把视频中所有产品都替换成【@图片1】的[产品名]，
制作的视频完全是围绕【@图片1】的[产品名]进行多角度的展示，
同时更换配音旁白和音乐为介绍[产品名]的内容，
画面主要颜色使用[颜色1]和[颜色2]
```

**技巧**:
- 引用参考视频的分镜设计
- 指定替换的产品图片
- 明确配色方案
- 可用 Nano Banana Pro 补充特定镜头

## 商业广告提示词要点

### 1. 产品展示

| 要求 | 描述 |
|-----|------|
| 近景展示 | 产品细节特写 |
| 多角度 | 360度展示 |
| 使用演示 | 实际使用场景 |

### 2. 节奏控制

| 关键词 | 效果 |
|-------|------|
| 快剪 | 快速切换镜头 |
| 明快 | 节奏感强 |
| 卡点 | 配合音乐节奏 |

### 3. 视觉风格

| 关键词 | 说明 |
|-------|------|
| 高级 | 高质感 |
| 商业广告 | 专业级 |
| 精美 | 细节丰富 |
