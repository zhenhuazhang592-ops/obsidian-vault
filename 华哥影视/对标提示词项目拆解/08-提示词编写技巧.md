# Seedance 2.0 提示词编写技巧

## 核心结构

### 标准提示词模板

```markdown
【Style】[风格类型], [视觉特征], [情绪]
【Duration】[时长]s
【Scene】[场景描述]

[时间段] Shot [序号]: [镜头类型].
[场景描述]
[动作描述]
[细节]

【Dialogue lip-sync guidance】[角色]: "[台词]"
```

### 分镜提示词模板

```
Style: [风格], [光线], [氛围]
Duration: [时长]s

[00-05s] Shot 1: [镜头类型].
[场景描述]
Dialogue Cue: [台词]

[05-10s] Shot 2: [镜头类型].
[场景描述]
Dialogue Cue: [台词]

[10-15s] Shot 3: [镜头类型].
[场景描述]
Dialogue Cue: [台词]
```

## 关键技巧

### 1. 时间轴控制

| 格式 | 示例 |
|-----|------|
| 标准 | `[00:00-00:05]` |
| 简写 | `[00-05s]` |
| 单点 | `[00:00]` |

### 2. 镜头类型

| 类型 | 缩写 |
|-----|------|
| Extreme Close-up | ECU |
| Close-up | CU |
| Medium Shot | MS |
| Wide Shot | WS |
| Extreme Wide Shot | EWS |
| Over The Shoulder | OTS |
| Point of View | POV |

### 3. 参考素材

| 格式 | 用途 |
|-----|------|
| `@图1` | 参考图片 |
| `@视频1` | 参考视频 |
| `with input image` | 输入图片 |
| `based on Image 1` | 基于图片 |

### 4. 角色一致性

```
Figure 1 character battling Figure 2 character
```

- 使用 `character` 指代角色
- 使用 `with input image` 引用输入

### 5. 口型同步

```markdown
【Dialogue lip-sync guidance】[角色]: "[台词]"
Dialogue Cue: "[台词]"
```

## 提示词优化技巧

### 1. 详细程度

- 场景描述要具体
- 动作描述要明确
- 添加关键细节

### 2. 参考素材

- 给参考图片/视频
- 描述想要的风格
- 说明要避免的效果

### 3. 格式规范

- 使用时间轴标记
- 使用镜头类型标签
- 使用角色标签

### 4. 痛点解决

| 问题 | 解决方案 |
|-----|------|
| 顺序不准 | 补充详细顺序信息 |
| 某镜头不好 | 用 Nano Banana Pro 补充 |
| 效果不理想 | 给更多参考画面 |
