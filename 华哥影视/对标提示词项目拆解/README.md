## 核心要点总结

### 提示词结构

```
【Style】风格定义
【Duration】时长
【Scene】场景

[时间轴] 镜头类型
场景描述
动作描述
【Dialogue】对话
```

### 八大提示词类型

| 类型 | 特点 |
|-----|------|
| 电影级 | 分镜脚本、时间轴控制、导演风格 |
| 商业广告 | 产品展示、品牌调性、节奏控制 |
| 动漫动画 | 角色一致性、动作流畅性、风格参考 |
| 短剧网剧 | 快节奏、强反转、口型同步 |
| UGC风格 | 病毒式、幽默、视觉奇观 |
| 视觉特效 | 超现实、实验性 |
| 社交媒体 | 移动端优先、传播性 |
| 商用场景 | 追热点、带货、品牌 |

### 关键技巧

1. **时间轴控制**: 使用 `[00:00-00:05]` 格式
2. **镜头类型**: ECU/CU/WS/OTS 等专业术语
3. **参考素材**: 使用 `@图1` `@视频1` 引用
4. **口型同步**: 使用 `Dialogue lip-sync guidance`
5. **细节补充**: 效果不好时用 Nano Banana Pro 补充
