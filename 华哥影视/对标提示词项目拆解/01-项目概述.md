# Awesome Seedance 项目概述

## 项目简介

**Awesome Seedance** 是一个精心整理的 **Seedance 2.0 AI 视频生成提示词**精选集合，汇集了来自 X (Twitter)、微信以及顶级提示词工程师的最佳实践。

## 核心内容

| 内容 | 说明 |
|-----|------|
| **提示词库** | 电影级、广告、动画、短剧等多种风格 |
| **视频示例** | 18个实际生成效果视频 |
| **商用案例** | 9种商业应用场景 |
| **技术资源** | API 文档、使用指南 |

## 什么是 Seedance 2.0

Seedance 2.0 是字节跳动推出的 **AI 视频生成工具**，支持：
- 文生视频
- 图生视频
- 视频续写
- 多风格转换

## 提示词分类

项目将提示词分为 **8 大类**：

1. **电影级风格** - Hollywood/Wong Kar-wai/Denis Villeneuve 等导演风格
2. **广告与品牌** - 产品展示、品牌故事
3. **社交媒体与病毒内容** - 爆款 meme
4. **UGC 风格** - 用户生成内容风格
5. **动漫与动画** - 角色一致性、动作测试
6. **短剧与网剧** - 国产短剧风格
7. **视觉特效** - 超现实主义、实验风格
8. **资源** - API 与使用指南
