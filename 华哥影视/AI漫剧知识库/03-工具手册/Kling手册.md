## 功能模块

### 1. 文生视频

**适用**：生成场景动态视频

**Prompt写法**：

```markdown
# 基础结构
[主体描述], [场景], [动作],
[运镜参数],
[比例], 高质量电影感

# 运镜参数格式（Kling特色）
camera: [运镜类型] [强度] [时长]
camera: forward 0.5 3s    # 前进推进
camera: backward 0.5 3s   # 后退拉远
camera: pan_left 0.5 3s   # 左摇
camera: pan_right 0.5 3s  # 右摇
```

### 2. 图生视频

**适用**：将角色图/场景图转化为动态视频

**关键参数**：

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 首帧图片 | 参考图 | 必须上传 |
| 运镜模式 | 自动/手动 | 手动更精准 |
| 时长 | 5秒/10秒 | 5秒优先 |
| 比例 | 9:16/16:9 | 9:16 |

### 3. 运镜控制（Kling特色）

**优势**：运镜参数最精准，支持多轴联动

```
camera: forward 0.8 5s     # Z轴前进
camera: up 0.5 3s         # Y轴上升
camera: pan_left 0.6 4s    # X轴左摇
```

## 常见问题

> [!warning] 运镜参数没生效
> **原因**：运镜格式写法不对
> **解决**：使用 `camera: forward 0.5 3s` 格式，而非 `camera movement: dolly in`

> [!warning] 人物变形
> **原因**：动作幅度太大
> **解决**：减少动作描述，或降低运镜强度值（0.5以下）
