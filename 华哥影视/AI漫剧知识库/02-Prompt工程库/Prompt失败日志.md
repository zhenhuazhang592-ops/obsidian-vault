## 高频失败类型参考

| 失败类型 | 常见原因 | 解决方向 |
|---------|---------|---------|
| 角色不一致 | Prompt未引用DNA外貌词 | 强制引用char_XX ID + DNA外貌描述 |
| 场景不对 | 缺少氛围标签 | 补充光线/色调/时间标签 |
| 运镜没有执行 | 运镜参数写法不对 | 参考运镜对应表 |
| 画面过曝/欠曝 | 光线描述不精确 | 使用Roger Deakins光影规范 |
| 构图不准确 | 景别描述模糊 | 使用标准化景别代号 |
| 风格不一致 | 风格后缀缺失 | 必须添加风格预设后缀 |
| 文字/水印残留 | 缺少禁止项声明 | 添加(worst quality)等禁止项 |
