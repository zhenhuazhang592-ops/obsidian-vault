# 技术架构

## 技术栈

| 层级 | 技术选型 |
|------|----------|
| **后端** | Python FastAPI + SQLAlchemy |
| **数据库** | MySQL 8.0.45+ + Alembic 迁移 |
| **前端** | 原生 HTML/CSS/JS（多页面架构）|
| **包管理** | uv（推荐）或 pip/conda |
| **视频处理** | FFmpeg |
| **存储** | 七牛云（七牛 CDN）|
| **许可证** | 修改版 Apache 2.0 |

## 环境要求

- Python 3.9+（建议 3.10.12）
- MySQL 8.0.45+
- uv 包管理器
- FFmpeg（视频处理）

## AI 模型集成

| 服务商 | 用途 | 配置 key |
|--------|------|----------|
| **RunningHub** | 视频生成工作流 | `runninghub.api_key` |
| **Duomi** | 图生视频 | `duomi.token` |
| **Vidu** | 视频生成 | `vidu.token` |
| **火山引擎** | Seedream 5.0 文生图 | `volcengine.api_key` |
| **百度千帆** | LLM 剧本分析 | `llm.baidu.*` |
| **阿里通义千问** | LLM | `llm.qwen.*` |
| **Google Gemini** | LLM / 绘图 | `llm.google.*` / `google.api_key` |
| **Jiekou API** | 统一 API 代理 | `jiekou.api_key` |

## 文件存储（七牛云）

```yaml
file_storage:
  qiniu:
    access_key: "七牛 Access Key"
    secret_key: "七牛 Secret Key"
    bucket_name: "存储空间名称"
    cdn_domain: "cdn.perseids.cn"        # CDN 加速域名
```

标准存储配额：10GB 存储 + 10GB CDN 流量/月

## 数据库

使用 Alembic 管理迁移：
```bash
alembic upgrade head        # 升级到最新
alembic downgrade -1        # 回滚一个版本
alembic revision -m "描述"   # 创建新迁移
```
