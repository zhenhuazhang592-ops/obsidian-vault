# 部署指南

## Windows 部署（推荐）

### 一键启动

**双击 `点我启动.exe` 即可运行**

功能：
- ✅ 系统托盘图标显示启动状态
- ✅ 服务就绪后自动打开浏览器
- ✅ 右键菜单：打开浏览器、查看日志、退出
- ✅ 退出时自动停止所有服务

首次启动会自动创建 `config.yml`，一般无需修改。

### 手动启动

```powershell
# 显示日志方式（适合调试）
双击 start.bat
```

`start.bat` 会自动：
1. 检查 Python 和 uv 环境
2. 启动本地 MySQL 服务（首次自动初始化）
3. 执行数据库迁移
4. 启动 Web 服务和定时任务
5. 监控服务状态，异常时自动重启

### 停止服务

- 右键系统托盘图标 → 退出
- 或双击 `stop.bat`

## macOS 部署

### 方式一：命令行

```bash
# 首次安装
chmod +x 首次安装-Mac.command
./首次安装-Mac.command

# 启动
chmod +x start.command
./start.command

# 停止
chmod +x stop.command
./stop.command
```

### 方式二：手动

```bash
# 1. 安装依赖
uv sync
# 或
pip install -r requirements.txt

# 2. 复制配置
cp config.example.yml config_prod.yml

# 3. 修改数据库配置
# 编辑 config_prod.yml 中的 database.* 配置

# 4. 导入基线数据库
mysql -u root -p your_database < model/sql/baseline.sql

# 5. 启动
python3 scripts/running/run_prod.py
```

## Linux 部署

```bash
# 1. 安装依赖
uv sync

# 2. 复制配置
cp config.example.yml config_prod.yml

# 3. 修改 config_prod.yml 数据库配置

# 4. 导入数据库基线
mysql -u root -p your_database < model/sql/baseline.sql

# 5. 启动
python3 scripts/running/run_prod.py
```

## 配置说明

### 核心配置项（config.yml）

```yaml
server:
  host: "http://localhost:9003"
  port: 9003
  is_local: true          # 本地环境：生成时上传图床

database:
  host: "localhost"
  port: 3306
  user: "root"
  password: "数据库密码"
  database: "zjt"
  charset: "utf8mb4"
```

### 视频 API

```yaml
runninghub:
  api_key: "your_key"
  max_concurrent_slots: 3

duomi:
  token: "your_token"

vidu:
  token: "your_token"
```

### LLM 模型

```yaml
llm:
  baidu:
    api_key: "your_key"
    model: "ernie-4.5-turbo-vl-latest"
  qwen:
    api_key: "your_key"
    model: "qwen-plus"
  google:
    api_key: "your_key"
```

## 开发环境

```bash
# 开发环境（详细日志）
python3 scripts/running/run_dev.py

# 生产环境（日志精简）
python3 scripts/running/run_prod.py
```

| 启动方式 | 配置文件 | 日志级别 |
|----------|----------|----------|
| `run_prod.py` | `config_prod.yml` | WARNING |
| `run_dev.py` | `config_dev.yml` | DEBUG |

## 常见问题

- **数据库迁移失败** → 检查 `PYTHONUTF8=1` 环境变量
- **MySQL 启动失败** → 检查端口 3306 是否被占用
- **视频生成失败** → 检查 RunningHub/Duomi/Vidu API 配置
- **TTS 合成失败** → 检查 `tts.api_url` 配置
