# 时间轴柱子系统（核心架构）

## 概述

时间轴柱子系统是视频工作流时间轴的核心架构，用于实现基于分镜的时间区域管理。每个柱子对应一个分镜（shot），作为视频轴和音频轴的占位符和分区。

## 核心概念

### 柱子（Pillar）

柱子是时间轴的基本分区单位，每个柱子对应剧本中的一个分镜。

**柱子标识格式**: `{scriptId}_{shotNumber}`

例如：
- `123_1` → 剧本节点ID为123的第1个分镜
- `123_2` → 剧本节点ID为123的第2个分镜

### 柱子数据结构

```javascript
{
  id: "123_1",           // 柱子标识: {scriptId}_{shotNumber}
  scriptId: 123,          // 剧本节点ID
  shotNumber: 1,          // 分镜编号
  defaultDuration: 15,    // 默认时长（秒），等于分镜组最长时长
  videoClipIds: [1, 2],  // 该柱子内的视频片段ID列表
  audioClipIds: [3, 4]   // 该柱子内的音频片段ID列表
}
```

## 设计核心：预创建机制

**关键机制**：柱子在剧本解析时预先创建，而不是在片段加入时才创建。

剧本解析成功后，系统会：
1. 遍历所有 `shot_groups` 和 `shots`
2. 为每个分镜预先创建对应的柱子
3. 柱子按 `shot_number` 顺序排列
4. 即使某些镜头的视频还未生成，柱子也已经存在
5. 自动显示时间轴，展示所有空柱子

**好处**：
- **保证顺序**：即使先加入镜头2的视频，镜头1的空白区域也会正确显示
- **可视化结构**：用户可以看到完整的时间轴结构，了解有多少个镜头
- **避免混乱**：片段只能加入到预先存在的柱子中，不会出现位置错乱

## 时长计算

### 有媒体时

```
实际时长 = max(视频轨道总时长, 音频轨道总时长)
```

### 无媒体时（既没有视频也没有音频）

```
实际时长 = 默认时长
```

### 动态调整

当柱子内添加或删除片段时：
1. 重新计算柱子实际时长
2. 后续所有柱子起始位置自动后移
3. 确保时间轴没有空隙

## 移动约束

**核心规则**：视频和音频片段只能在对应的柱子内移动，不允许跨柱子移动。

```
[柱子1: 15秒] | [柱子2: 20秒] | [柱子3: 15秒]
  0-15秒     |   15-35秒     |   35-50秒
```

## 导出兼容：占位符机制

导出到剪映时，即使某些镜头没有视频，也能正确导出：
- 为没有视频的柱子创建占位符片段（不可见、静音）
- 占位符时长 = 柱子默认时长，确保时间轴连续

## UI 轨道高度

| 轨道 | 高度 | 说明 |
|------|------|------|
| 视频轨道 | 112px | 展示缩略图 |
| 音频轨道 | 48px | 波形+文本紧凑横向布局 |
| 时间轴整体 | 220px | 适应音频轨道高度调整 |

## 刻度尺设计

- **左侧占位**：60px（与轨道标签宽度一致）
- **主刻度**：显示时间标签（0:00、0:05、0:10），刻度线高度12px
- **次刻度**：无标签，刻度线高度6px
- **主刻度间隔**：总时长>60秒时为10秒，否则为5秒
- **z-index: 10**：刻度线显示在视频片段上方

## 点击跳转

| 点击对象 | 跳转目标 |
|----------|----------|
| 视频片段 | 对应的视频节点（画布平移+蓝色光晕）|
| 空柱子 | 对应的分镜节点 |
