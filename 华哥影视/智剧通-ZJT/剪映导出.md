# 剪映草稿导出功能

## 功能概述

视频工作流支持将时间轴导出为剪映（JianyingPro）草稿文件，方便用户在剪映中进一步编辑。

## 导出流程

```
用户点击"导出到剪影" → 输入草稿路径 → 发送到后端
                                              ↓
                              下载媒体文件 → 生成草稿 JSON
                                              ↓
                              ZIP打包 → 返回下载链接
                                              ↓
                              用户下载 → 解压 → 复制到剪映草稿目录 → 打开剪映
```

## API 接口

### POST /api/export_timeline_draft

**请求参数**：
```json
{
  "draft_path": "C:\\Users\\...\\JianyingPro\\User Data\\Projects\\com.lveditor.draft",
  "video_clips": [
    {
      "url": "视频URL",
      "name": "视频名称",
      "duration": 10.5,
      "startTime": 0,
      "endTime": 10.5,
      "pillarId": "scriptId_shotNumber"
    }
  ],
  "audio_clips": [...],
  "pillars": [...],
  "workflow_name": "工作流名称"
}
```

**响应**：
```json
{
  "success": true,
  "download_url": "下载链接",
  "zip_filename": "压缩包文件名"
}
```

## 柱子系统处理逻辑

### 有柱子数据时

1. **按柱子顺序处理**：根据 `scriptId` 和 `shotNumber` 排序
2. **处理每个柱子**：
   - 收集该柱子内的所有视频片段（通过 `pillarId` 匹配）
   - **如果柱子没有视频**：创建占位符片段（不可见、静音、时长=默认时长）
   - 收集该柱子内的所有音频片段
3. **时间轴累加**：每个柱子结束后，时间轴向前推进该柱子的实际时长

### 经典模式（无柱子数据）

1. 视频轨道：按 `video_clips` 数组顺序连续排列
2. 音频轨道：按 `audio_clips` 数组顺序连续排列

## 技术细节

| 项目 | 说明 |
|------|------|
| 时间单位 | 前端秒（浮点数）→ 后端微秒（整数）|
| 视频命名 | `video_{序号}_{随机ID}.{扩展名}` |
| 音频命名 | `audio_{序号}_{随机ID}.{扩展名}` |
| 草稿路径 | `{用户提供的draft_path}/草稿文件夹/Resources/local/文件名` |

## 注意事项

1. **路径格式**：Windows 路径使用反斜杠（`\`）
2. **临时文件**：系统自动清理下载的临时文件，ZIP 包保留在服务器
3. **文件大小**：大量媒体会导致下载时间较长
