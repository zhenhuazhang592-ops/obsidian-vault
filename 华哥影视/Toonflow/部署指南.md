# Toonflow 部署指南

## 三种部署方式

### 方式一：桌面客户端（Windows，推荐普通用户）

1. 下载 [Release 安装包](https://github.com/HBAI-Ltd/Toonflow-app/releases)
2. 或从 [夸克网盘](https://pan.quark.cn/s/94ef07509df0) 下载
3. 安装后启动即可

> 首次登录：账号 `admin`，密码 `admin123`

---

### 方式二：Docker 部署（推荐服务器）

#### 在线构建（从 GitHub/Gitee 自动拉取）

```bash
docker-compose -f docker/docker-compose.yml up -d --build
```

**构建参数：**

```bash
# Gitee 源（国内速度快）
GIT=gitee docker-compose -f docker/docker-compose.yml up -d --build

# 指定版本标签
TAG=v1.0.6 docker-compose -f docker/docker-compose.yml up -d --build

# 指定分支 + Gitee
GIT=gitee BRANCH=dev docker-compose -f docker/docker-compose.yml up -d --build
```

#### 本地构建（已有源码）

```bash
git clone https://github.com/HBAI-Ltd/Toonflow-app.git
cd Toonflow-app
docker-compose -f docker/docker-compose.local.yml up -d --build
```

**端口映射：**

| 端口 | 用途 | 在线部署 | 本地构建 |
|------|------|----------|----------|
| `80` | Nginx 前端 | 随机端口 | `8080:80` |
| `60000` | 后端 API | `60000:60000` | `60000:60000` |

**常用命令：**

```bash
# 查看容器状态
docker-compose -f docker/docker-compose.yml ps

# 查看实时日志
docker-compose -f docker/docker-compose.yml logs -f

# 停止服务
docker-compose -f docker/docker-compose.yml down

# 重新构建（更新版本）
docker-compose -f docker/docker-compose.yml up -d --build

# 进入容器调试
docker exec -it toonflow sh
```

### 方式三：PM2 云服务器部署

#### 环境要求

- 系统：Ubuntu 20.04+ / CentOS 7+
- Node.js：23.11.1+（推荐 24.x）
- 内存：2GB+

#### 部署步骤

```bash
# 1. 安装 Node.js
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 24

# 2. 安装 Yarn 和 PM2
npm install -g yarn pm2

# 3. 克隆项目
cd /opt
git clone https://github.com/HBAI-Ltd/Toonflow-app.git
cd Toonflow-app

# 国内用 Gitee（更快）
git clone https://gitee.com/HBAI-Ltd/Toonflow-app.git

# 4. 安装依赖 + 构建
yarn install
yarn build

# 5. 创建 pm2.json
```

**pm2.json 配置：**

```json
{
  "name": "toonflow-app",
  "script": "build/app.js",
  "instances": "max",
  "exec_mode": "cluster",
  "env": {
    "NODE_ENV": "prod",
    "PORT": 60000,
    "OSSURL": "http://127.0.0.1:60000/"
  }
}
```

**环境变量说明：**

| 变量 | 说明 |
|------|------|
| `NODE_ENV` | `prod` = 生产环境 |
| `PORT` | 服务监听端口（默认 60000）|
| `OSSURL` | 文件存储访问地址 |

```bash
# 6. 启动
pm2 start pm2.json
pm2 startup
pm2 save

# 常用命令
pm2 list              # 查看进程
pm2 logs toonflow-app # 查看日志
pm2 restart all       # 重启
pm2 monit             # 监控面板
```

## 前端单独部署（可选）

前端源码独立仓库：[Toonflow-web](https://github.com/HBAI-Ltd/Toonflow-web)

构建前端后，将 `dist` 目录内容复制到本项目的 `scripts/web` 目录即可集成。

---

## 开发模式

```bash
# 克隆
git clone https://github.com/HBAI-Ltd/Toonflow-app.git
cd Toonflow-app

# 安装
yarn install

# 仅启动后端（端口 60000）
yarn dev

# 启动 Electron 桌面客户端（推荐）
yarn dev:gui

# 构建
yarn build

# 打包
yarn dist:win   # Windows
yarn dist:mac   # macOS
yarn dist:linux # Linux

# 代码检查
yarn lint
```

> Node.js 要求：23.11.1+
