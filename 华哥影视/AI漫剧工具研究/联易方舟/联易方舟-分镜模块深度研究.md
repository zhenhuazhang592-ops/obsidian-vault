## 三、故事脚本（Step 2）

### 3.1 核心流程
```
导入TXT/DOCX → 自动解析章节 → 用户选择章节 → CDP解析（提取资产+生成镜头）→ 同步资产库
```

### 3.2 解析参数
- **字数范围**：支持20,000字输入
- **模板**：4个可选模板（包括CDP 15S版）
- **追加模式**：追加到当前剧本 / 只识别新增文本
- **增量基准**：支持"设为基准"重置

### 3.3 CDP解析输出（UI显示）
- 镜头数：8
- 角色数：8
- 场景数：8
- 物品数：30

### 3.4 解析Prompt模板（从API获取）

**Agent**: `comic-drama-script-generator` (AI 漫剧·一键改编CDP脚本)

**模板**: CDP 15S版（完整Prompt见剧本研究文档）

**关键约束**:
- 每个shot对应15秒镜头单元
- 镜头目标：开场抓人→冲突升级→结尾钩子
- 角色/场景/道具复用
- 支持增量追加

**ID**: `cmjcs33ri009q1q46hxmksxku`
**模板**: AI 漫剧-九宫格分镜表（单图）官方模板

**硬约束**:
1. 单张图内为3x3网格（九格），每格有清晰边框/分隔线

## 十一、关键发现

### 11.1 CDP是核心引擎
整个V3漫剧工作台以CDP JSON为核心枢纽：
- Step2解析小说 → 生成CDP JSON
- Step3资产 → 同步CDP中的角色/场景/物品
- Step4分镜 → 编辑CDP中的shot
- Step5视频 → 用CDP中的videoPrompt生成
- Step6预览 → 预览CDP最终效果

### 11.2 Sora2是最优性价比
- sora-2-all: 10/15s仅¥0.14（灵石3000）
- 比veo3.1(¥0.35)和grok(¥0.28-0.35)都便宜

### 11.3 九宫格是差异化亮点
单张3x3分镜图解决了多镜头连续性问题，保证机位变化流畅度

### 11.4 剪映一键导出
自动检测本地剪映草稿目录，实现了从AI生成到剪辑软件的无缝衔接
